01 · WHERE I AM

此刻，正停在这一站。

旅途没有固定终点。现在最让我好奇的，是机器人能否稳稳地拿起那些没见过的东西。

ONGOING · 正在探索

Pick Anything
未知物体抓取

一只被踩扁的烟灰盒、歪倒的饮料瓶、皱巴巴的零食袋……它们没有统一形状，也不一定有 CAD 模型。
想知道：只靠当前看到的 RGB-D、目标 Mask 和夹爪约束，能不能找到靠谱的抓法？

当前边界：静态场景 · 单次抓取 · 两指平行夹爪 · 暂不依赖重建与多视角

RGB-DInstance Mask6DoF Grasp PoseGeometryGraspGen碰撞检查
目前走到哪里了？

已尝试利用深度图、Mask 和生成式抓取模型产生候选姿态。下一步不是单纯生成更多 Pose，而是检验：夹爪能否进入、会不会碰撞、真实物体能否被提起。

路边的小提醒

模型能给出姿态，不等于机器人就能抓成功。好看的可视化值得高兴，真正的成功率还得靠实验说话。

01
GEOMETRY / 先让手动起来

第一站 · 从看见，到触碰

深度图已经有了，怎么变成一个能抓的 Pose？

正在打底+

沿途遇到的问题

识别了物体，并不等于知道夹爪该放哪。先从可解释的几何方法开始：点云、法线、PCA、平面与抓取约束。

这一站想带走什么

在形状相对规则、可观测几何可靠时，能稳定产生抓取候选；更重要的是知道它为什么成功、为什么失败。

研究关键词：RGB-D · Point Cloud · PCA / OBB · Surface Normal · Collision Check

02
GENERALIZATION / 世界不止一种形状

第二站 · 陌生的东西，也想试试

碰到变形的瓶子和纸盒，总不能为每一种形状重写规则。

正在实验+

沿途遇到的问题

固定的几何规则难覆盖未知实例与变形。尝试用数据驱动模型从局部几何中生成多个候选抓取，留给几何检查与规划器筛选。

这一站想带走什么

换个新形状，也能给出合理候选；但要验证碰撞、深度噪声、薄片或贴地物体等失败情况，而非只看模型输出。

研究关键词：Contact-GraspNet · GSNet / Graspness · GraspGen · Unseen Instances

03
SEMANTICS / 先听懂想做什么

第三站 · 同一件东西，抓法也会变

是把杯子拿走，还是递给别人？任务不同，合适的接触点也不同。

已有探索+

沿途遇到的问题

几何上“抓得起来”，未必符合任务。希望 VLM 提供目标语义、可供区域或动作先验，几何模块仍负责可执行性。

这一站想带走什么

理解任务意图如何影响抓取选择，同时区分“形状泛化”和“语义泛化”：它们相关，却不是一回事。

研究关键词：VLM · Grounding · Mask · Affordance · Task-conditioned Grasp

04
POLICY / 不只有一个终点

第四站 · 学着走完一整段动作

知道抓取位姿，不等于已经知道每一步怎么动。

远处的路标+

沿途遇到的问题

单次 Grasp Pose 只是一个动作目标。真正操作时，观察和状态会变，还需要连续控制、状态反馈和动作序列。

这一站想带走什么

从“预测一个目标姿态”走向“根据当前观测生成下一步行动”；评测维度也从 Pose 质量转向任务完成情况。

研究关键词：Behavior Cloning · Diffusion Policy · Visuomotor Policy · VLA

05
AGENT / 还有下一次尝试

第五站 · 失败了，也可以再想想

如果没抓住、任务变了，机器人能自己发现并调整吗？

远处的路标+

沿途遇到的问题

一个动作执行完，并不代表任务完成。还需要任务拆解、结果验证、技能调用、失败恢复和必要时的重新规划。

这一站想带走什么

让系统不仅“会做动作”，还知道“做成了没有”；把一次次尝试真正变成可用的经验。

研究关键词：Task-level Agent · Skill Library · Feedback · Replanning · Memory
