研究边界 / TECHNICAL ATLAS

先把六条路线放在一张图上

传统二维视觉不是一条「阈值 → 边缘 → Hough → RANSAC」的升级链。它更像一组不同的数学工具：有的从像素统计找区域，有的从灰度变化找边界，有的在参数空间搜索形状，也有的专门把已有观测变成精确尺寸。研究这些方法，重要的不只是记住名字，而是弄清输入条件和求解机制。

02优化式分割把区域与边界一起求解
03边缘与轮廓从梯度到连续几何边界
04局部图像特征角点、矩、稳定局部结构
05几何形状检测直线、线段、圆、椭圆
06拟合与精密测量鲁棒参数估计与亚像素

这份附录限定在单视角二维图像。它不以学习式检测、SAM、跨图像对应或点云位姿求解为主题：相关内容分别留给 A02–A04 与 Q01/Q02。另一方面，一些传统图像算法本身包含数据驱动的设计过程，例如 FAST 的高效判别树；这里的「传统」指方法家族与部署方式，并不宣称所有方法在历史上完全没有学习成分。

阅读这张技术地图时

不要用年份给技术排序。Hough 擅长发现候选，最小二乘擅长从可信点估计参数；它们既能竞争，也能搭配。

01
REGION & MORPHOLOGY

区域提取：从灰度统计到形态结构

区域路线非常直接：如果目标与背景在灰度或颜色上可分，就能把像素组合成前景。这套方法既不神秘，也远不止一个 threshold。沿着它的发展，可以看到自动阈值选择、形态学结构处理、连通域和分水岭区域划分几个不同的问题。

阈值的难点不在公式，而在可分性

二值化可以写成 B(x,y)=1[I(x,y)>T]。当曝光和颜色条件稳定，它可能已经足够。真正要研究的是阈值如何从图像中得到，以及当目标与背景分布重叠时，分割是否还可能成立。

1979核心里程碑

Otsu · 自动阈值 原始资料 ↗

利用灰度直方图的类间方差准则确定全局二值化阈值。它解决了反复手工选择阈值的一部分问题。

边界 它不是前景识别器。双峰不明显、光照不均或灰度重叠时，全局阈值可能没有足够判别力。

局部自适应阈值、HSV/Lab 颜色阈值以及位置约束，都是针对不同成像条件的合理选择，并非简单的“更先进版本”。如果区域已经找出来，却存在孔洞和细碎结构，问题就从像素判别转向了空间形状处理。

1982理论体系

Serra · Mathematical Morphology

用结构元素对区域执行腐蚀、膨胀、开闭运算等集合操作，为二值图像的几何结构处理建立系统化理论。

边界 结构元素的尺度就是先验：能去掉噪点，也可能删掉真实细节；闭运算能填补空隙，也可能误连相邻实例。

形态学往往是最容易被低估的工具：它不仅“去噪”，还把先验写进了操作。例如细长结构元素会偏好特定方向，圆形结构元素更倾向于保留对应尺度的团块。随后可以通过 Connected Components 分析独立区域的面积、位置与外接框。

当两个实例连在一起

连接域只能告诉我们哪些前景像素相连，并不能自动区分两个互相接触的物体。这也是 Watershed 这一类区域划分方法值得研究的原因。

1991重要发展

Vincent–Soille · Watershed

基于数字图像的地形与分水岭思想，将区域划分成不同的集水盆地；可与距离变换、Marker 结合分开黏连区域。

边界 局部极值过多会带来过分割；标记和预处理条件常比算法名称更影响结果。
这一支什么时候好用？

场景中存在可以明确描述的颜色/灰度差异，而且区域结构相对稳定时非常直接。困难通常来自前景与背景不可分、阴影和反射，而不只是“阈值不够智能”。

02
ENERGY-BASED SEGMENTATION

优化式分割：从局部规则走向整体约束

传统分割并没有止步于阈值。另一条重要研究线，是把“区域应该长什么样”写成一个能量函数，再优化整个分割结果。它与 Otsu、Canny 不构成简单替代：同样要得到区域，但依赖的是不同的约束组织方式。

例如，边界应该尽量贴合图像变化，又不能因为每一个噪声点而剧烈弯折。这样就不必把所有决策交给单个像素的阈值，而可以把边界连续性、区域颜色分布、外部提示等信息共同考虑。

1988核心里程碑

Snakes · Active Contours 原始资料 ↗

将轮廓看成可以移动的曲线，通过图像能量与内部平滑能量共同引导它贴合感兴趣结构。

边界 经典模型依赖初始化和能量形式，容易受局部极小值、弱边缘和过度平滑影响。
轮廓优化的思路E(C) = Einternal(C) + Eimage(C) + Econstraint(C)不同实现使用不同的参数化和能量项，此处只展示共通思想。

Snakes 有意思的地方不在于“又能找到边界”，而是第一次接触时会很直观地看到：边界本身也可以是优化变量。后续研究进一步思考，没有强烈梯度的地方能否借助区域统计恢复边界。

2001另一种模型

Chan–Vese · 区域型主动轮廓 原始资料 ↗

通过区域内外的统计差异与边界长度约束共同划分图像，不要求目标边界必须有强烈的梯度峰。

边界 经典分段常值假设对纹理复杂、光照变化明显的区域可能不充分；参数与初始化仍然重要。
2001核心里程碑

Boykov–Jolly · Interactive Graph Cuts

把前景背景标签、像素统计和邻域边界代价整合进图割能量模型，让外部提示参与区域求解。

边界 要求能量项满足相应图优化条件；颜色不可分、提示不准确时仍会退化。
2004重要发展

GrabCut · 交互式前景提取 原始资料 ↗

在图割思想上结合颜色混合模型和迭代估计，使“给出一个大致矩形框 → 提取前景”成为实用工作流。

边界 框内目标与背景外观高度相似、细长结构复杂或初始前景不完整时，仍可能分错。

这里值得与 A04 保留一个交叉入口：今天使用 BBOX 提示 SAM 获取 Mask，很容易让人以为“提示式分割”只属于学习模型。事实上，GrabCut 早已证明外部提示 + 分割优化是一种有长期生命力的任务组织方式。两者机制不同，也不应被写成直接的算法继承关系。

技术认识

分割困难不等于需要更复杂的分割器。先检查前景与背景是否具备可区分的视觉信息；缺少信息时，无论图割还是区域能量，都需要额外先验。

03
EDGES & CONTOURS

边缘与轮廓：发现边界之后，还要组织它

“找到边缘”往往只是第一步。梯度响应是一组局部证据，Contour 是有拓扑和顺序的边界，Polygon 又是对轮廓的几何近似。把这三件事混在一起，很容易误以为 Canny、findContours、approxPolyDP 是同类算法。

从局部梯度到可靠边缘

1986核心里程碑

Canny · A Computational Approach to Edge Detection 原始资料 ↗

系统讨论边缘检测能力、定位精度与单一响应的目标，形成平滑、梯度、非极大值抑制和滞后阈值等经典处理思路。

边界 强平滑可能损失细节；弱阈值会引入无关边缘；图像梯度边界不等同于物体实例边界。

光照阴影、材质纹理和物体真实轮廓都能产生梯度。这也是为什么“边缘很多”和“定位很准确”之间并没有必然联系。边缘的来源需要再依靠区域、拓扑或几何约束辨认。

1985基础工具

Suzuki–Abe · Border Following

研究二值图的边界追踪与层级关系，使外轮廓、内孔洞等成为可组织和可测量的结构。

边界 输入需具有可解释的二值区域结构；粘连和错误分割会直接改变轮廓拓扑。
1973跨领域经典

Douglas–Peucker · 曲线简化

用一系列线段近似密集的数字曲线，在误差阈值约束下保留主要几何转折；今天常用于轮廓多边形近似。

边界 阈值太大可能抹掉真实转角，太小则保留噪声；近似顶点不自动等于物体语义关键点。

这几个年份也提醒我：算法历史并不是按实际工作流排序的。Douglas–Peucker 早于 Canny，但我们可以在今天的同一条视觉流程里同时使用它们；Suzuki–Abe 提供的轮廓追踪与 Canny 的边缘检测也并非竞争替代。

边缘链为什么后来又值得研究？

如果希望将散落的边缘像素连接成更干净的曲线，就会遇到 Edge Drawing 这类工作。它重点关注连续边缘链的提取和计算效率，也为后面的 EDLines 等线段方法提供了可用结构。这里先认识“边缘像素 → 有序边缘链”的变化，线段检测的历史放在第五章展开。

三个输出，三个概念

Edge 可以是局部梯度响应；Contour 强调边界追踪和拓扑；Polygon 强调用少量几何顶点近似曲线。它们可以连续使用，但不能互相替代。

04
LOCAL FEATURES

局部几何特征：哪些位置值得保留？

除了完整边界，图像还包含许多局部结构。一个角点在多个方向上都具有变化，比一段均匀直线上的普通点更容易被定位。不过，局部“显著”不等于属于目标，更不等于它天然具有物体坐标系中的几何身份。

1962形状描述基础

Hu Moments · 形状不变量 原始资料 ↗

通过二维矩构造在一定几何变换下保持不变的形状描述，适合对整体区域的形状特征进行统计表达。

边界 对区域质量、遮挡和离散噪声敏感；不同类别也可能具有相近描述。

区域矩适合描述整体区域，例如质心和主方向；但如果要找的是局部角点，就要研究邻域灰度如何在不同方向变化。

1988核心里程碑

Harris · Corner Detection

利用局部二阶矩矩阵，寻找沿两个方向移动都会引起明显灰度变化的位置。

边界 可能把文字、纹理等背景角点一起找出；也没有自动提供目标特定关键点身份。
Harris 响应（简化表示）R = det(M) − k · trace(M)2M 来自邻域图像梯度的二阶统计；响应与阈值共同决定候选角点。
1994重要发展

Shi–Tomasi · Good Features to Track

使用二阶矩矩阵的最小特征值等准则选择适合后续跟踪的局部点。

边界 用于跟踪的稳定性与用于物体关键点识别的适用性并不相同。
2006工程里程碑

FAST · 高效角点检测

通过候选点周围一圈像素的强度比较实现快速角点判断，并在原始研究中使用学习得到的高效判别结构。

边界 专注实时性并不代表对尺度、视角变化具有任意鲁棒性；本身也不负责跨图像描述和匹配。

这一章最好明确停止在“单图像特征检测和整体区域描述”。SIFT、ORB、SuperPoint、SuperGlue 等将局部信息用于跨图像对应的系统研究，应该留在 A02 · 参考图像与局部对应 ↗。

值得区分

Harris 给出图像角点；Hu Moments 描述区域整体形状；物体 Keypoints 还要求点的身份定义。它们都与二维几何有关，但不能画上等号。

05
SHAPE DETECTION

几何形状检测：在像素里寻找直线与曲线

有时图像已经提取出许多边缘点，但还不知道它们属于什么几何结构。这里出现了非常漂亮的分叉：可以把证据带进参数空间投票，也可以直接从连续边缘链构建线段，或者从局部弧段组合更大的曲线。它们寻找的可能都是直线或圆，求解机制却不同。

几何参数空间这条线

1962 / 1972核心里程碑

Hough / Duda–Hart · 参数空间投票

让图像中的观测点为可能的几何模型参数投票；采用法线式直线参数可避免斜率形式对垂直直线的不便。

边界 参数空间量化、候选范围和无关边缘都会影响计算开销与结果精度。
1981重要扩展

Generalized Hough · 任意形状的参数搜索

从简单几何曲线的参数空间思想，推广到使用已知边界形状在图像中寻找候选位置。

边界 一旦依赖具体实例的形状参考，就与 A02 的参考模板匹配产生交叉；几何自由度增加时搜索成本也随之变化。

Hough 的价值并不是检测结果必然最准，而是它可以从分散、不连续的证据中寻找整体几何一致性。若目标已经有一批准确的轮廓点，用参数空间全局搜索反而可能多此一举。

线段不是无限延长的直线

直线参数回答方向与位置，但许多工程任务还需要有限线段的起止点，以及是否跨越断裂边缘。这里 LSD、EDLines、ELSED 形成了值得对照的另一组重要发展，研究重点涉及统计验证、边缘链与快速线段恢复。

2010 / 2012核心节点

LSD · Line Segment Detector 原始资料 ↗

由局部梯度方向一致的像素组成候选线段区域，并使用 a-contrario 统计验证控制误检，直接输出有限长度的线段。

边界 真实线段可能断裂或被拆分；梯度和边缘区域的局部质量仍然影响端点。
2011重要发展

EDLines · Edge Drawing + Lines 原始资料 ↗

先形成较干净的连续边缘链，再快速提取并验证线段，注重实时性与误检控制。

边界 对边缘链的组织质量敏感；断裂、纹理和复杂交叉位置可能增加歧义。
2022重要发展

ELSED · 高效线段检测

继续优化线段增长、局部断裂处理和实时推理，在传统几何检测路线中改进效率与线段质量。

边界 不是在所有环境里都绝对优于其他线段检测器；需要按端点误差、重复性和场景结构评估。

圆与椭圆：相似的输出，不同的机制

圆可以用 Hough Circle 搜索，也可以从已有圆周点直接拟合。如果边缘只剩短弧段，则可能需要弧段组合、法线方向或几何约束来生成候选。椭圆更涉及五参数结构，短弧、遮挡和轮廓混入会让估计更不稳定。

在这里最需要分清的是：形状检测负责发现候选，而形状拟合负责利用已关联的观测求参数。它们可以串联，却不总是需要一起使用。

这一章的真正分叉

参数空间投票、梯度区域线段检测、边缘链生长和弧段组合，并非同一条必经的升级路径。研究不同范式，才能解释它们在遮挡、纹理、速度和精度上的表现差异。

06
ROBUST FITTING & METROLOGY

几何拟合：从“找到了”到“测量得准”

工业视觉里最关心的常常不是画出一条看起来正确的边，而是圆心是否稳定、线的角度能否重复、尺寸有没有系统误差。有了几何候选以后，仍需认真研究参数估计与观测质量。

最小二乘：有可信观测，就应该直接利用

Least Squares 的基本思想是最小化残差平方和。直线、圆和椭圆的模型形式不同，残差可以是代数残差，也可以更接近真实几何距离。对可信的点集，最小二乘往往直接而高效。

参数估计的一般表达θ* = arg minθ Σ ri(θ)2真正影响结果的是残差定义、点集质量与约束条件。

如果把属于背景的点也一同送进拟合，普通平方残差会对较大偏差给予更高权重。这不是最小二乘理论出错，而是输入数据不再符合我们期望的观测模型。

1981核心里程碑

RANSAC · 鲁棒模型估计 原始资料 ↗

从含离群点的观测中随机采样建立模型，用一致性支持数量寻找合理候选；之后常用全部内点进一步精化参数。

边界 需要模型、最小样本集、内点阈值和足够的有效观测；低内点率、多模型混杂时迭代次数和歧义都会增加。
常见成功概率与采样次数关系N = log(1−p) / log(1−ws)p：希望至少抽到一次全内点样本的概率；w：内点比例；s：最小样本数。基于独立随机采样等条件。
1999经典拟合方案

Fitzgibbon 等 · Direct Least Squares Ellipse Fitting 原始资料 ↗

针对椭圆施加特定二次曲线约束，把代数椭圆拟合组织成可高效求解的广义特征值问题。

边界 代数距离不等于真实点到曲线的欧氏距离；短弧、点分布偏斜及离群点仍会影响拟合。

Subpixel 不是“精度自动提高”

边缘位置处于连续的成像空间，整数像素只是采样。亚像素测量通过局部灰度、梯度形状或模型拟合估计更细的边缘位置，从而改善参数估计的分辨力。

但亚像素定位结果的小数位并不等于真实测量准确度。光学畸变、焦距与尺度标定、噪声、运动模糊，以及边缘模型本身的偏差，都可能形成系统误差。

检测精度是否找到了正确的几何结构
重复性同一条件多次测量是否稳定
准确度换算到真实物理尺寸是否接近真值

RANSAC 和 Least Squares 也可以组合使用：先在混杂点中找可靠支持集，再对内点进行精化。这不是新旧方法的替代，而是两个不同职责自然配合。

不能忽略的测量条件

如果边缘来自高度反光、模糊或不正确的相机标定，拟合器再复杂也不能凭空补出可信的尺寸信息。

07
ACADEMIC × INDUSTRY

工业视觉：经典算法怎样成为稳定的测量流程？

学术论文更常围绕一个机制的理论性质、统计判别或速度展开；工业现场则经常要求长期可重复、可维护、可解释。一个成熟的工业测量流程，通常会把先验搜索范围、边缘提取、鲁棒筛选与参数拟合结合起来，而不是只调用一个“找圆算法”。

HALCON · 2D Metrology

先定义线、圆等测量对象和几何搜索区域，在指定范围内寻找可用边缘，再拟合模型参数。它把已知测量位置转化成显式搜索约束，不一定需要完整地分割出整个物体。

值得学：测量模型、ROI / Measure Region、边缘筛选、亚像素、精化与重复性。官方 2D Metrology 文档 ↗
HALCON · XLD

以带有亚像素坐标的轮廓表示连接边界提取与几何拟合，适合需要精细轮廓和参数估计的任务。

值得学：像素轮廓与亚像素轮廓的差异、拟合残差与几何精化。
Cognex · PatMax

工业界具有代表性的几何图案匹配技术，可在一定位置、旋转与尺度变化下寻找已知图案。这里作为工业几何定位的入口，具体参考建模与匹配机制留在 A02。

值得学：图案特征、位置/旋转不变性以及受限条件下的稳定性。官方资料 ↗
OpenCV · 通用实现

threshold、morphologyEx、findContours、Canny、HoughLinesP、fitEllipse、cornerHarris 等提供易于实验的基础组件。

值得学：这些 API 分别属于哪种数学问题，而不是把函数清单当作技术谱系。
研究对象学术界更关心工业界更关心
分割与边界优化准则、泛化条件、统计性质固定工况下的阈值稳定性和可配置性
直线、圆与椭圆检测率、误检、参数估计机制重复精度、尺寸测量与物理标定
部署系统计算复杂度、数据集与理论分析异常检测、参数维护、生产环境变化
一种非常实用的工程观察

工业流程经常不是“用更强的算法取代弱算法”，而是充分利用稳定工位、光源、几何尺度与测量区域，把原本开放的搜索问题变成受控的测量问题。

METHOD RELATIONS

同一个目标，为什么会有多种合理方法？

把所有算法放回同一张图里，最容易理解的一组例子是圆的检测与测量：最终都可能给出圆心和半径，但每一种方法要求的前提并不一样。选型时如果只看“能不能检测圆”，就会忽略这层差异。

方法路线输入前提它擅长做的事需要留意
阈值 → Contour区域可分且轮廓可恢复低成本提取目标边界阈值会改变轮廓几何
Hough Circle存在足够的圆形边缘证据从大量候选边缘中搜索圆搜索范围与参数量化

09
CLOSING NOTES

最后留下的技术认识

读完这条路线，最大的变化并不是掌握更多算子名称，而是开始能从求解机制看待经典视觉。它们不是等待被同一个新模型淘汰的旧工具，而是在不同条件下长期共存的方法集合。

区域方法利用像素统计与空间形态；优化式分割利用整体区域和边界代价；边缘分析提取并组织局部结构；局部特征寻找值得保留的位置；Hough 等检测方法搜索几何形状；最小二乘与 RANSAC从可信或含离群点的数据中估计参数；工业测量又将这些能力组织成可维护的流程。

其中一些方法今天依然非常适合固定工位、已知几何和精密测量；另一些则在边界模糊、外观变化或强干扰下存在明确限制。限制本身恰好告诉我们，使用前该检查哪些条件。

而对于外观种类变化很大、语义目标不固定的场景，单纯依赖有限的人工规则就可能很难扩展。于是 Q03 会自然走向 A03 的学习式目标检测、A04 的分割和 A05 的 Grounding。即使如此，传统几何仍然可以用于局部边缘精化、参数拟合与结果验证。

这篇附录到这里可以先收束。后续如果真要实现某项技术，再补充它的工程测试、参数敏感性和失败案例；现在至少已经能够回答：面对一组二维观测，我有哪些不同的数学方法，以及各自需要什么样的信息。
