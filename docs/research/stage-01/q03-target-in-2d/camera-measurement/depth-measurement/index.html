00 · 开场｜方向知道了，距离谁来告诉我？

上一篇知道了：像素能恢复一条空间射线，却不知道瓶子在射线上的哪里。

那就想办法测距离。有人换个位置再看一眼，有人主动投射图案，也有人测量光传播造成的时间或相位变化。

这次不只记住方法名字，而是追着一个像素，看它怎样一步步算出深度。

01 · 先认认路｜这些方法究竟在哪一步不同？

先把各种方法的输入、关键计算和输出放在一起。这里的分类按深度的测量证据划分，不是严格的发明时间线。

路线 原始观测 真正要计算的东西 最后怎么得深度
被动双目 两幅不同视角的自然图像 左右图中的像素对应 → 视差 三角测量，理想校正双目
主动双目 两幅红外图像 + 投到物体上的纹理 仍然找左右像素对应 → 视差 仍然三角测量
编码结构光 相机拍摄已知投影图案 解码「相机像素 ↔ 投影器像素」 已标定的相机—投影器三角测量
dToF 光脉冲发射与回波到达事件 传播延迟 理想往返测距
iToF / AMCW 若干相位下的相关采样 调制光的相位差 ，并处理相位歧义

这里最容易混淆的是中间三种：「主动」只说明相机主动向场景提供了光，不自动说明它使用哪种求深度算法。 主动双目通常仍做立体匹配；编码结构光则必须知道投射图案的编码含义。

一句先记住的结论：双目在找“另一台相机里同一个点”；编码结构光在找“投影器里的哪个位置照亮了它”；ToF 在找“光传播造成了多少延迟”。

读这张表时，可以再加一个更实用的判断：每条路线到底把困难放在了哪里？ 双目把困难放在「匹配」，编码结构光放在「解码」，ToF 则放在「正确读取返回光信号」。算出数值只是最后一步，前面的证据不成立，公式也救不了。

做法最明显的优点最核心的局限
被动双目不用主动照明；可利用自然纹理弱纹理、遮挡、远距离小视差
主动双目可给弱纹理表面增加匹配线索红外投射对比度、透明反光、功耗与干扰
Gray Code 结构光编码明确，能直接求投影器位置多帧采集、运动敏感、编码分辨率有限
相移结构光亚像素级的投影位置估计能力周期歧义、低调制度、运动与高光
dToF直接从回波时间推距离，可利用多回波极高的计时/探测要求、背景光与光子统计
iToF / AMCW面阵并行测相位，适合密集深度图相位折返、多路径混合、弱信号与饱和

SAD / SSD / NCC · 局部亮度匹配的取舍

为什么值得用
  • SAD 只需整数相减与求和，计算廉价，适合做实时基线。
  • SSD 对较大的灰度差更敏感，求导与优化方便；NCC 能弱化部分线性亮度、对比度变化。
什么情况下容易失效
  • 没有纹理时，不同候选窗口几乎同分，最低代价不等于找到真实对应。
  • SAD/SSD 对曝光与反射变化敏感；大窗口跨越深度边界时会混合前后景。
  • NCC 需要有足够灰度方差；在常值窗口中归一化不稳定，也不擅长遮挡。
工程取舍：便宜、直观，但只解决「窗口怎么比较」，不能解决「有没有足够证据」。
常见补救：用 Census 增强亮度鲁棒性、空间聚合抑制孤立误匹配，再做左右一致性检查。

Census · 用亮度的相对顺序代替绝对灰度

为什么值得用
  • 对保序的亮度变化更加稳健，适合左右红外相机曝光不完全相同的情况。
  • 比较结果可打包成位串，再用 XOR 与 popcount 计算汉明距离，便于高效实现。
什么情况下容易失效
  • 白墙依然缺少有辨识度的顺序结构；大量像素相同时，描述子会重复。
  • 量化噪声可能翻转邻近灰度值的大小关系；局部反光、阴影、遮挡会破坏顺序。
工程取舍：Census 并非「去掉光照问题」，只是把匹配证据由灰度数值换成更稳定的局部排序。

BM 与 SGM · 相似性之外还需要空间约束

为什么值得用
  • BM：窗口聚合简单且运行快，便于低成本部署和实时验证。
  • SGM：多方向累积代价，可让局部噪声很大的区域利用邻域一致性，通常比孤立逐像素匹配更平滑。
什么情况下容易失效
  • BM：窗口越大越容易跨物体边界，前后景会被一起平均；窗口越小则越噪。
  • SGM：P₁、P₂ 等惩罚并不自动代表真实物理连续性，薄杆、小台阶及深度突变可能被抹平。
  • SGM 需要保存和累积多个方向的视差代价，计算与内存明显高于简单窗口匹配。
工程取舍：BM 选得快，SGM 尝试选得更一致；两者都不能给真正被遮挡的像素凭空找到对应。

亚像素与左右一致性 · 一个提高精度，一个拒绝错误

为什么值得用
  • 亚像素插值可把离散整像素视差估计细化，对远距离小视差尤其有价值。
  • 左右一致性检查能发现许多单侧遮挡和不自洽的匹配，比无条件输出深度更安全。
什么情况下容易失效
  • 若代价曲线有多个谷底或最低点不明显，抛物线拟合只是给错误匹配一个更精细的数字。
  • 左右一致性会使深度图出现更多空洞；两边共同犯同一个错误时也未必能检出。
工程取舍：这两种措施目的不同：亚像素提高数值精度，一致性检查控制有效深度的可信度。

学习式匹配 · GC-Net / PSMNet 与 RAFT-Stereo 的取舍

为什么值得用
  • GC-Net / PSMNet：在空间和视差维度上学习上下文，弱纹理或局部歧义时能够利用更大范围信息。
  • RAFT-Stereo：用相关信息引导迭代更新，可以逐步纠正视差，不必只做一次固定窗口选择。
什么情况下容易失效
  • 代价体与 3D 卷积可能非常耗显存，计算量随分辨率与候选视差范围增长。
  • 对训练数据的相机域、纹理、曝光、材质分布敏感；换到红外散斑域未必无需微调。
  • 在缺少可靠匹配证据时，网络可能输出合理但未被真实观测确认的视差；迭代方法也有时延开销。
工程取舍：学习式并不是「不需要对应关系」，而是学习如何表达、聚合和更新对应关系。部署时同时量测置信度、泛化、延时和资源。

03 · 主动双目｜自己投上纹理，算法需要换一套吗？

03.1 · 先回答最关键的问题：基本匹配算法可以一样

被动双目拍的是物体表面的自然纹理。主动双目则增加一个投射器，在物体上打出红外散斑等纹理，然后仍由左、右两台相机观察同一表面。

拿一面原本几乎纯白的墙为例：关掉投射器，左右相机看到的局部窗口可能都是 [120,120,120,...]，各个候选视差相差无几；打开投射器后，窗口变成了不规则亮暗斑点，正确对应位置出现更独特的纹理模式，于是 SAD、Census、SGM 等都有更可靠的代价差异。

所以主动双目同样可以执行：

左右 IR 图 → Rectify → 计算 SAD/Census/学习式匹配代价 → SGM/其他聚合 → 视差 → 。

不必改变核心几何公式，也不必先识别每颗投射光点的编号。 某个厂商的实际固件究竟采用了哪种匹配器，需要以公开资料或源码为准；不能仅凭它是主动双目就断言「内部一定用了 SGM」。

03.2 · 那投影器的位置和投影图案完全没用吗？

不是。它们会影响哪些表面能形成清楚的纹理、照亮多大范围、不同相机观察到的亮暗结构是否足够稳定；但在典型主动双目的对应计算中，投影器不是第三个用于三角测量的观测视角，它主要是改善图像内容。

典型主动双目可以不要求事先准确知道每一颗散斑在投影器中的坐标，也不必对每颗散斑做唯一身份解码。只需要同一个表面局部的图案，能在左右相机里被稳定识别。

而且「关投影器测不到、开投影器能测到」的根本变化不是距离公式发生变化，而是原来扁平的代价曲线出现了更明显的最低点。

03.3 · 如果算法类似，那主动双目真正多了哪些代价？

  • 投影可见性： 过远、强环境红外、低反射率表面，散斑对比度可能不足。
  • 材质效应： 透明或镜面目标可能把投影折射、反射到别处，导致错误对应。
  • 遮挡差异： 左右 IR 相机与投射器的观察/照明方向不同，有些区域被照亮却未必同时被两台相机看见。
  • 多设备干扰： 其他投射器可能改变纹理，效果取决于图案与系统，不能一概认为一定有利或一定有害。
  • 计算与功耗： 投影器要供电、散热、控制曝光，匹配部分的计算负担仍在。

对于熟悉的 RealSense D435i，理解成「红外双目 + 辅助红外纹理 + 立体匹配」最合适。RealSense 官方文档也明确把主动双目和需要特定编码图案解码的结构光区分开来。

小结： 被动双目靠环境提供可匹配的纹理；主动双目先给环境增加纹理。两者的核心问题仍是「左右图对应像素是谁」。

主动双目真正的优势：把白墙这种低纹理表面变得更容易匹配；算法仍可沿用校正、SAD/Census、SGM 等被动双目流程。
真正的限制：如果红外散斑照不到、反射方向错误，或左右图仍无法稳定找到同一纹理，主动照明也无济于事。它改善输入证据，不替你解决所有对应问题。

为什么值得用
  • 相位在周期内连续变化，能做到比单纯整数列编码更细的投影位置估计。
  • Gray Code 提供粗编号、相移提供细位置，二者组合具有较好的精度与抗周期歧义能力。

04.6 · 为什么结构光常常不喜欢运动？

多帧 Gray Code 和多步相移默认相机同一个像素在这些曝光中观察的是同一处物理表面。如果物体移动，编码位与相位来自不同位置，就可能把不存在的编码拼在一起。

因此会出现更少帧的编码方案、单帧彩色编码、空间邻域编码，以及速度与精度的折中。但单帧方法往往更依赖局部纹理结构、颜色可分性或更复杂的解码，未必适合任意表面。

还有一个重要区别：结构光使用的相位，是投射图案在空间中的位置相位；后面 ToF 使用的相位，是调制光随时间传播产生的延迟相位。名字一样，测的不是同一个物理量。

为什么值得用
  • 短脉冲的直接时间信息直观；时间直方图在有足够光子时有机会区分不同回波峰。
  • 适用于多种中远距测距应用；统计多个脉冲可改善随机触发的稳定性。
什么情况下容易失效
  • 纳秒甚至皮秒量级的时间差要求专用探测器和计时电路，像素、读出、功耗与成本存在取舍。
  • 背景光与暗计数会制造随机光子事件；弱反射目标的峰值可能淹没在噪声中。
  • 多目标反射、SPAD 死时间、Pile-up 等会让直方图偏置；简单选最高 bin 不保证对应真实表面。
工程取舍：dToF 的长处在回波时间信息，短处在高质量时间计数与光子统计的硬件代价。

但真实模型里只有 1 m 与 2 m 两条回波。1.5 米是信号混合造出来的，并不保证有任何表面在这里。 更复杂的 MPI、不同幅度和相位折返只会让问题更难。

05.6 · 回波太弱或太强，为什么都会错？

四相位计算实际上在量一个向量的角度：横向 A = C0−C2，纵向 B = C3−C1。这个向量的长度与调制信号强弱相关。

Amplitude ∝ √(A² + B²)；Phase = atan2(B, A)

低反射率、距离远、投射阴影： A 和 B 都接近 0，传感器噪声轻微变化就会让角度大幅改变。它造成随机深度波动，严重时应拒绝输出。高反光与近距离：接收信号可能饱和，相关响应被削平；这不是信号「更强更准」，而是相位计算模型被破坏。

弱信号与饱和 · 两头都可能失效

为什么值得用
  • iToF 使用主动照明，在某些缺乏纹理的表面也可以得到密集距离，不需要左右窗口匹配。
  • 信号幅度和饱和状态提供了重要的质量线索，设备有机会主动无效化可疑像素。
什么情况下容易失效
  • 弱信号时相位向量太短，角度对噪声极敏感；透明/吸光表面、远距离、强环境光都可能造成低信噪比。
  • 过强的高光或近距离回波会让接收电路饱和，四相位关系不再线性，深度可能偏置或直接被标为 0。
工程取舍：优先看原始 IR 幅度、曝光和深度有效率；不能把所有 0 当成“物体离相机 0 米”。

05.7 · 边缘混合不是随机飞点：一个像素可能看到了两个深度

瓶身边缘的一块成像区域可能同时覆盖 1 m 处的瓶子和 2 m 处的背景墙。返回信号含有两个相位，单相位模型就可能算出它们之间的假位置。与上一节的多次反射路径相比，这里的两条回波来自一个像素混合多个表面，不一定发生二次反射。

优点：ToF 可以在大面积低纹理表面逐像素测量。局限：物体轮廓、细杆、墙角最容易发生混合，深度边界可能偏移、空洞增多。空间平滑滤波有可能把前景和背景进一步混在一起，应优先进行边缘有效性检查。

05.8 · 物体动了，为什么相关测量可能拼错？

四相位采样以及多频测量在某些实现中跨多个积分或子帧获得。若曝光期间物体快速移动，各相位读数可能来自不同表面位置；它们不再满足同一个 a、b、φ 模型。表现为运动模糊、深度拖尾、边缘空洞或偏移。

优势：iToF 可面阵并行采集、适合实时深度流。代价：较长积分有利于积累光子，却增加运动伪影；较短曝光利于动态场景，却可能牺牲信噪比。多台 ToF 同时工作时，还可能引入主动光干扰，通常要研究同步或错时策略。

05.9 · 深度一直偏一点，为什么多帧平均也没用？

并不是所有错误都来自信号波动。调制电路的相位偏置、温度变化、像素间时延、光路几何和距离非线性，都可能产生系统偏差。把一块静止平面连续拍 100 帧，随机波动会因平均而减小，但稳定的 10 mm 偏差不会自动消失。

补救：厂家多距离/多温度校准、设备温度补偿、已知平面距离验证、系统偏差与随机误差分别评测。无效测量不能靠简单时间平均恢复成真实测量。

05.12 · 从传感器内部 r，到用户看到的 Z

ToF 的基本传播模型常先讨论光路距离 ；但深度图接口可能输出经过几何转换、校正的 Z-depth。

例如 Orbbec Femto Bolt 官方说明采用 AMCW iToF，其 Depth Frame 的每个有效像素是毫米为单位的 Z 坐标。所以即使内部依赖光程推导，也不能把 ROS 深度数组里的整数直接当成沿射线的欧氏距离。

ToF 的总体优缺点 · 先看测量证据，再看算法

为什么值得用
  • 摆脱双目纹理对应搜索，可在部分均匀表面上形成密集深度。
  • 可以直接基于时间/相位证据构建深度，而不是仅靠图像外观推断。
  • 设备可输出幅度/IR 与深度有效性线索，方便做工程质量判断。
什么情况下容易失效
  • 单频相位歧义、MPI、多表面混合可能给出平滑却错误的距离。
  • 反射率、环境光、饱和、运动和硬件温度都会影响实际精度。
  • 额外主动光源、算力与功耗；多机干扰和工作范围限制需要评估。
工程取舍：不要只比较深度图有效点比例；要分别评测不同材质下的系统误差、随机误差、边缘质量和失效比例。

07 · 动手验证｜三个最值得亲手跑一遍的小实验

07.1 · 用一个像素真正跑通双目：SAD → 视差 → Z

下面是单个像素的教学示例，不是能直接部署的完整双目驱动。已假设左右图校正完毕，并且都是二维灰度数组。

import numpy as np

def sad_disparity_at(left, right, x, y, ds=range(1, 65), r=2):
    patch_l = left[y-r:y+r+1, x-r:x+r+1].astype(np.float32)
    costs = {}
    for d in ds:
        xr = x - d
        if xr-r < 0:
            continue
        patch_r = right[y-r:y+r+1, xr-r:xr+r+1].astype(np.float32)
        if patch_r.shape == patch_l.shape:
            costs[d] = np.abs(patch_l - patch_r).sum()
    if not costs:
        return None, None
    d_best = min(costs, key=costs.get)
    return d_best, costs

# 假设已算出 d=30 px, f=600 px, B=0.05 m
Z = 600.0 * 0.05 / 30.0
print('depth:', Z, 'm')  # 1.0 m

动手时应绘制每个候选 的代价曲线：纹理丰富时通常更容易形成清晰极小值；白墙则可能出现很平的曲线，重复条纹可能出现多个谷底。这个观察比只看最后的 Depth Map 更能说明匹配算法的局限。

07.2 · 手算结构光解码：Gray 111 → 投影器第 5 列

def gray_to_binary(gray):
    binary = gray
    while gray > 0:
        gray >>= 1
        binary ^= gray
    return binary

print(gray_to_binary(0b111))  # 5

真实结构光还需要根据相机采集的亮暗图案逐位判断 Gray 值，确保编码来自有效照明区域，然后才能把解出的投影器像素交给三角测量。

07.3 · 手算 iToF：四个相关采样 → 相位

import math
C0, C1, C2, C3 = 120.0, 65.36, 80.0, 134.64
phi = math.atan2(C3 - C1, C0 - C2)
fm = 30e6
c = 299792458.0
r = c * phi / (4 * math.pi * fm)
print('phase_deg:', math.degrees(phi))  # 约 60 度
print('ideal ray distance:', r, 'm')

这个示例计算的是理想光路距离，不是 Femto Bolt ROS 消息的实际 Z 值；真实设备内部还存在校准、多频率/相位处理和坐标几何转换。

08.1 · 主动双目和被动双目，究竟是不是同一套匹配算法？

可以相同，但不保证某两台商品相机内部代码相同。 如果给 OpenCV 的 StereoSGBM 输入左右相机图像，无论光照来自环境还是投影散斑，求视差的数学问题都仍然成立。主动投射改变的是匹配信息的质量，不是把 Z = fB / d 换掉；厂商自己的深度芯片则可能使用不同的专有匹配代价、优化和后处理策略。

08.2 · 梅卡的“编码”与 ToF 的“相位”，不要混为一谈

Mech-Eye 结构光的典型计算链要找的是相机像素对应投影器的哪个编码位置，对应成功后再用三角测量；ToF 的相位测量找的是光传播造成的时间延迟，再换算测距。名字里都有“条纹”“相位”，未知量却完全不同。

关于“现在 ToF 在用什么”：在 iToF 侧，工程系统重点处理多相位采样、相位歧义、幅度/置信度和多路径；多频解歧义是一类常用技术方向，但不能据此断定每一款商用 ToF 都采用完全相同的多频方案。在 dToF 侧，则常见 SPAD 探测、时间统计与回波提取。前面 05 节的计算过程恰好对应这两条路线。

08.3 · 放回抓取场景：到底哪个方法更占优势？

如果是纹理丰富、无需主动照明的场景，被动双目结构简单；如果是静态、弱纹理的物体，主动双目借助散斑往往更有机会获得视差；如果需要可控场景下精细的表面扫描，编码结构光可通过投影器定位与相位细化提高对应精度；如果希望直接获得密集深度、避免双目纹理匹配，iToF 是一条成熟路线，但尤其要关注边缘、反射与多路径。

这里是根据测量机制推导的适用条件，不是对厂商产品的普遍性能排序。最终还要看型号、镜头、模式、固件、工作距离、物体材质与实际测试。

09 · 回头看｜这次不只是记住了名字

这次追着一个像素看下来，几条技术路线已经能够明确区分。

被动双目的问题是：左右相机拍到的自然纹理怎样建立可靠对应？SAD、Census、SGM、Cost Volume、RAFT-Stereo 都在不同环节尝试解决它。

主动双目没有把双目计算逻辑整个推翻，而是先改善匹配所需的输入纹理。它可以沿用同一类匹配算法，随后同样计算视差与深度。

编码结构光真的换了对应关系的建立方式：先从投影图案解码投影器位置，再把投影器当成几何约束来源。Gray Code 负责粗编码，相移则可以提供细分辨率，但两者都需要处理歧义与错误解码。

ToF 绕开左右图像匹配，转而估计光传播的延迟；dToF 从回波时间事件中找距离，iToF 从相关采样中恢复相位，再处理周期歧义与多路径。
