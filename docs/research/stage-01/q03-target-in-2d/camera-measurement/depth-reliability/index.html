07 / Measurement Reliability

深度图变平滑了，
就能放心用了吗？

把深度图滤得平平整整，新的问题反而更明显了：强光下为什么突然测不到？玻璃瓶为什么经常缺失？距离越远，误差为何越来越明显？如果 RGB 和 Depth 不在同一时刻采集，运动中的物体又会发生什么？

这些问题未必能靠滤波解决。有些来自设备怎样获取信号，有些来自材质与环境的测量极限，还有些来自采集时序和数据处理的选择。

这一站不再追求让点云更好看，而是认识深度测量的可信边界：什么时候值得相信，什么时候可以调整条件，什么时候应该承认这里没有可靠测量。

02 · First-principles Exploration / 01

相机给了一个深度值，就代表它测到了吗？

最容易判断的问题，是深度图里根本没有数据：像素值为零，或者被标记为无效。但真实的危险并不总是这么明显。有时相机输出一个连续、平滑、看似合理的表面，它的位置却是错的。

这说明我们首先应该区分三种不同的失败，而不是把它们都叫做“深度噪声”。

A · NO MEASUREMENT

没有可靠观测

匹配找不到、返回光太弱、红外饱和、超出有效范围，深度被置为无效。

正确处理：保留无效状态，不要因为缺一个数字就凭空补出表面。

B · WRONG MEASUREMENT

有数值，却测错了

错误立体匹配、反射、多路径或跨边缘混合，使深度落在错误位置。

正确处理：不能只检测零值，还需结合信号证据、几何与场景条件。

C · INCONSISTENT TIME

每个数都可能对，却不是同一时刻

RGB、Depth 或机器人状态各自有效，但对应的是不同采集时刻。

正确处理：明确曝光时间与时间戳，建立同步或运动补偿。

D · PROCESSING ARTIFACT

处理后看起来合理

空间/时间滤波、插值可能把噪声抹平，也可能跨越真实的几何边界。

正确处理：保存原始深度和有效掩码，必要时区分真实测量与推断补值。

这里还有一个细节：有效深度和置信度并不是一回事。有效掩码只表示数据通过某些设备或软件的有效性检查；置信度可能来自立体匹配代价、红外幅度、相位一致性或厂商内部阈值。不同设备未必公开逐像素置信度，更不能把某个 0–255 数字当成通用的“深度正确概率”。

第一条认识

先承认“不知道”，再讨论怎样测得更好。没有数据、错误数据、时间错位和算法补全，是四件需要分开处理的事。

02 · First-principles Exploration / 02

Advanced Controls 到底是在控制什么？

如果深度不可靠，最直接的想法是去调曝光、增益、激光功率或深度预设。但为什么相同的操作，在不同相机上效果完全不同？

因为这些控制项并不是统一的“深度增强开关”，它们实际作用于测量链的不同位置。

01 / RealSense D435i：让双目更容易找到正确对应

D435i 的深度主要来自主动双目：左右红外相机寻找对应点，通过视差计算距离。红外投射器负责提供纹理线索，本身并不是直接测量飞行时间。

因此，对它最重要的并不是“照得越亮越好”，而是让两台红外相机得到足够清晰、不过曝、能够可靠匹配的图案。

控制项影响到哪里它不能保证什么
IR Exposure / Gain左右红外成像的信号亮度、噪声与运动模糊延长曝光不能恢复已饱和或无法匹配的区域
Emitter / Laser Power主动投射纹理的强弱，可能帮助弱纹理区域匹配不能让透明玻璃自动变成不透明，也未必在强环境红外下有效
Visual Preset匹配可靠性与深度覆盖率之间的选择High Density 不等于高精度；High Accuracy 也不代表深度更完整
Advanced Mode对立体匹配、深度生成等内部参数作更细调节不是后处理滤镜；参数需要针对应用验证，不宜盲目逐项修改

RealSense 官方的 Visual Presets 正好暴露了这种取舍：High Density 倾向保留更多深度，High Accuracy 倾向通过更严格的接受条件减少可疑深度，因此有效覆盖率可能降低。厂商还提供可保存为 JSON 的 Advanced Mode 配置。查看官方说明 ↗

一个经常搞混的控制对象

调整彩色相机的 RGB Exposure，主要改变的是颜色画面；D435i 双目匹配依赖红外成像，不能把 RGB 的曝光参数直接当作深度测量曝光。检查配置时，先弄清参数作用的是哪一个传感器。

02 / Orbbec Femto Bolt：不是匹配图案，而是测量返回光的相位

Femto Bolt 使用 AMCW iToF：向场景发射调制近红外光，再通过返回信号的相位信息恢复距离。除了深度图，设备还可以提供反映接收光信号强度的 Active IR 图像。

因此，这里的控制思路首先变成了：收到了多少可用的调制光？返回信号是否足够清晰？多次反射有没有让相位发生混合？

Femto Bolt 提供不同的视场与像素合并（Binning）模式。降低空间分辨率可能换来更大的有效测距范围，并不是所有模式都能同时拥有最高分辨率、最大视野与最长距离。

厂商还在深度引擎中进行相位相关计算，并对过弱、饱和、多路径等不可用观测做失效判定。一个被置零的像素，有时不是算法忘了填它，而是系统主动拒绝输出不可信的测量。

为什么距离、强光和玻璃，会让同一台相机突然失效？

有些失败来自参数没有选好；另一些并不是调参能解决的。要区分两者，我们仍然需要回到测距原理。

01 / 为什么双目距离越远越难测准？

双目深度满足一个熟悉的关系：

Z = f · b / d
Z：深度；f：像素单位焦距；b：双目基线；d：视差

远处物体的视差越来越小。假设匹配中存在微小的视差误差 σd，把它传递到深度，会得到近似关系：

σZ ≈ Z² · σd / (f · b)
在固定焦距、基线及相近视差精度下，双目深度不确定性近似随距离平方增大

这意味着：即使视差匹配的亚像素精度没有变差，物体从 1 m 移到 2 m，深度误差尺度也可能接近原来的四倍。这是几何放大效应，不是单靠平滑就可以消除的误差。

对于 iToF，距离增长时也会因为返回信号减弱、反射率、光学结构和相位测量条件而损失精度，但它不遵循双目的同一套视差误差公式。不能把 Z² 视差关系直接套给所有 ToF 相机。

02 / 强光为什么可能让主动深度更差？

主动双目与 iToF 都可能依赖近红外信号。强烈环境光，尤其是强红外背景，可能削弱主动投射纹理的对比度，或者压缩 ToF 接收信号可用的动态范围。

这并不等于“一到室外就一定不能测”。是否可用还取决于光谱、距离、传感器曝光、滤光结构、物体反射率以及设备本身的设计。

面对强光，需要先看原始 IR 图是否过曝或对比度不足，再决定尝试曝光、增益或模式调整，而不是直接对深度做更强的滤波。

03 / 为什么玻璃、金属和黑色物体各有麻烦？

物体 / 环境可能破坏的测量假设值得优先考虑的动作
透明玻璃 / 透明塑料光会透射、折射或从背景返回；观测可能落在背景、表面或多条光路的混合结果上不能默认深度属于物体；必要时依据 RGB 轮廓、其他视角或其他测量手段
镜面金属 / 高反光表面镜面反射方向偏离接收器，或形成复杂反射路径；可能产生缺失与虚假深度尝试改变观察角度与照明几何；无法解决时标记不可测区域
深色吸光表面返回的红外光不足，匹配纹理或调制信号变弱检查 IR 信号；在硬件允许范围内优化采集条件与距离
墙角 / 凹腔 / 多重反射ToF 中多条回波叠加产生多路径干扰（MPI）改变视角、减少反射路径；参考设备内置的无效化策略
深度突变边界像素足迹同时包含前景与背景；双目也可能出现遮挡与错误匹配对边缘保留谨慎处理，不把插值结果当作真实接触表面
多台主动相机同时工作其他主动光源可能干扰纹理或调制测距针对设备采用时分、触发同步、相机布置或模式调整

尤其值得注意的是 Femto Bolt 的厂商说明：深度引擎会把IR 信号过低、饱和、有效照明范围之外、疑似多路径等像素判为无效。它的做法不只是“把所有数值滤平”，还包括主动地拒绝给出某些深度。查看工作原理与无效化说明 ↗

这一站的关键

失效时不要先问“用哪个滤镜”，而应该问“哪一种物理测量条件被破坏了”。有些条件可以调整，有些只能通过换视角、换传感器或承认不可测来解决。

02 · First-principles Exploration / 04

几何配准已经正确，运动物体为什么仍然会错位？

前面的 Color–Depth Alignment 解决了空间坐标关系。但是它还有一个隐藏假设：两次观测对应的空间场景没有变化。

假设彩色相机在 tC 拍到瓶子，而深度相机在 tD 测到瓶子。即使内外参完美，只要瓶子或相机在运动，两份观测就不再描述同一个瞬间。

Δx ≈ v · |tC − tD|
简化的一维匀速运动近似：位移由相对速度与采集时间差决定

例如物体相对相机以 0.5 m/s 运动，两路采集如果相差 20 ms，就可能引入约 10 mm 的空间位移。对于厘米级的抓取目标，这已不再是可以忽略的偏移。

要分开认识三种“同步”

数据配对：是否把对应帧放到了一起？

软件能按时间戳寻找相近帧，但“相近”不等于“同时曝光”。

硬件同步：不同传感器是否在约定时刻采样？

触发、传感器时钟、曝光起止时间和实际设备支持情况，共同决定同步能力。

机器人状态同步：位姿属于哪一刻？

机械臂运动时，RGB-D 应与对应采集时刻的机器人位姿关联；否则手眼外参本身正确也不够。

还需要留意曝光是一段时间，而不只是一个理想时间点。滚动快门的不同图像行甚至可能对应不同采集时刻。SDK 提供的硬件时间戳、系统时间戳或 frameset 关系，也不能在未确认时钟域和曝光定义前混为一谈。

Femto Bolt 官方提供同步 RGB/Depth 流与可配置的帧间延迟，并支持多设备外部同步。RealSense 的多相机文档则明确强调硬件时钟与系统时钟域的差异，说明“时间戳看起来对齐”未必能证明真正同时采样。Orbbec 同步能力 ↗　RealSense 时钟说明 ↗

这一站的关键

几何对齐回答“从哪里看”，时间同步回答“在什么时候看”。运动场景只有同时考虑空间和时间，才可能得到一致的三维观测。

02 · First-principles Exploration / 05

怎样决定一份深度“可以用”？

现在知道了各种失效原因，但工程上仍然要作出一个决定：这台设备、这组参数、这类场景，是否能满足我的任务？

不能只展示一张深度彩图。至少需要把看不看得到、测得准不准、稳不稳定、能不能及时拿到分开。

01 / 四种不能混用的测量指标

指标一个直接的定义它回答什么
Valid / Fill Rate目标 ROI 中有效深度像素数 / ROI 总像素数物体有多少区域真正被测到？
Systematic Error / Bias固定真值下，多帧平均深度与真值的偏差测量是否整体偏深或偏浅？
Temporal Random Error静止目标同一位置，多帧深度的标准差重复测量是否稳定？
Spatial Plane Residual平面点云到最佳拟合平面的残差 RMS局部平面是否凹凸抖动？
Timing / Availability采集时间差、端到端延迟、有效帧率与掉帧动态系统能否及时、持续得到观测？

注意，空间平面残差小，只说明拟合出来的表面平滑；它不能证明整个平面离真实位置很近。 一个偏移了 2 cm 的平面，也可能有极小的 RMS 残差。

bias = mean(Zmeas) − ZGT
σt = std(Zmeas,1, …, Zmeas,N)
仅为某个固定目标/位置的简化定义；真实验收还需明确坐标系、真值来源和有效像素筛选规则

02 / 把验收设计成“可解释的对照实验”

不用一下子做复杂的大型实验。先固定设备、距离、目标位置与后处理状态；每次只改变一个条件，就能判断哪个环节真正影响了测量。

建立一个参考场景

使用已知距离的漫反射平面或已知尺寸的几何物体。分别保存原始深度、IR、RGB、相机模式、时间戳与参数配置。

做距离扫描

选近距离、典型工作距离和远距离，比较有效率、系统偏差与时间标准差，观察可工作区间怎样变化。

做材质与环境对照

保持距离不变，依次测试普通白纸、黑色哑光、反光面、透明容器以及不同环境光。区分“没值”和“错误有效值”。

做参数 A/B 对照

D435i 比较 IR 曝光、投射器和预设；Femto Bolt 比较 NFOV/WFOV、Binning 等支持的模式。参数修改前后采用相同的目标与采样规则。

最后测试运动与多相机工况

加入目标运动、机器人运动或多台设备，检查时序误差与互相干扰。静态验收合格，并不自动意味着动态场景合格。

03 / 不是所有像素，都要追求同一种可信度

如果任务只是判断桌面前方是否存在大障碍物，少量缺失点可能可以容忍；但如果要在玻璃瓶边缘确定夹爪接触位置，相同的缺失比例可能完全无法接受。

因此，验收应该从应用反推约束：容许多大的位置误差？必须保留多少可见表面？需要多快更新？哪些接触区域绝对不能靠插值补出来？

结论典型证据下一步
可以使用关键 ROI 有足够有效点，偏差、抖动和时延满足任务要求固定配置并记录适用范围
调整采集条件IR 信号不足、曝光不合适、当前模式范围不足、时间不同步改曝光 / 工作距离 / 深度模式 / 触发条件后重新验证
不应强行使用透明与镜面导致错误回波，显著多路径，关键区域长期不可观测改变视角、融合其他观测或明确输出“不可信”

最后一点尤其重要：对于真实机器人，把“不可信”作为一种允许的输出，并不是系统能力不足。相反，它避免了下游算法把虚假的 XYZ 当作确定事实。

这一站的关键

测量验收不是给相机打一个抽象总分，而是为具体场景、具体距离、具体物体和具体动作定义一个可信的工作范围。超出范围时，系统需要知道应该改条件，还是停止相信它。

03 · Looking Back

回头看｜深度可靠，不等于深度好看

从最初的一张深度图，到一台真实 RGB-D 相机能否参与机器人操作，我们已经经历了三个层次：

FIRST
能输出

相机知道如何根据光学信号获得深度，再把像素提升到三维空间。

THEN
能处理

标定、配准和后处理，让不同观测建立几何关系，并改善数据的可用形态。

FINALLY
知道什么时候不该相信

测量机理、设备控制、物理极限、时间一致性与任务验收，共同划出一条可信边界。

这一站最终留下的工程判断可以很简单：

测得可靠，就使用；条件可改善，就调整；没有可靠观测，就坦然承认“不知道”。

让相机输出 XYZ 只是开始，知道这些 XYZ 在什么条件下成立，才是测量工程真正完成的标志。
