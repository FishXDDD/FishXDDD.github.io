04 / DEPTH POST-PROCESSING · 研究手记

深度已经测出来了，
为什么还要再修一遍？

上一段终于弄清楚了深度相机怎样测量距离。按理说，每个像素有了深度，就可以恢复三维点云了。

但实际测量并不总是顺利。平整的桌面有些起伏，物体边缘偶尔出现飞点，静止的瓶子在连续帧中轻微抖动。遇到反光、透明或弱纹理表面，有些位置甚至完全没有深度。

最直接的想法，是把这些数据滤一遍。不过，仔细看看 RealSense、Orbbec、Luxonis、Zivid 等厂商的做法，会发现事情远不止平滑和去噪。

如果一个深度本来就是错的，为什么要修正它，而不是直接拒绝？如果测量根本没有得到有效信息，又凭什么能够把它补回来？

这两个问题，让深度质量的探索逐渐从数值修正，走向测量可信度、物理错误识别、多观测融合，以及学习式增强。

01 / RESEARCH MAP

技术路线｜我们究竟还能利用什么信息？

深度图的问题，可以先分成五类：错误值、空间噪声、时间波动、无效区域，以及数据冗余。

不过，按照现象分类还不足以理解现代厂商为什么选择不同算法。更值得问的是：一张已经算出来的深度图，还能够借助什么信息改善自身？

01
利用邻域与时间的统计关系

空间滤波、时序滤波、视差域处理｜RealSense

02
利用测量过程的可信度

匹配代价、左右一致性、可信度引导修正｜Luxonis

03
利用错误产生机制的特征

假深度形态、反射干扰、传感器物理证据｜Orbbec / Zivid

04
利用互补观测获取新的证据

HDR Merge、多曝光、不同采集条件｜Orbbec

05
利用学习到的视觉与几何先验

RGB-D 增强、神经网络深度估计｜LingBot-Depth / ZED

一个需要提前说明的边界

这些并不是严格的年代顺序，也不是五种互相替代的方案。第一、二、三类包含深度后处理或紧贴深度计算的质量检查；HDR 采集、Neural Stereo 等方法已经部分进入深度生成阶段。这里研究它们，是为了看清“已有深度不够好”时，业界走出了哪些不同的技术路线。

02 / CLASSICAL FILTERING

从平滑开始｜为什么 RealSense 不直接使用普通均值滤波？

假设相机看向一张平整的桌面。理想情况下，反投影得到的点应该落在一个平面上。但实际测量中，相邻像素的深度可能轻微波动。

如果波动主要来自随机噪声，用邻域求平均确实有帮助。问题是，瓶子与桌面在深度图中同样彼此相邻。如果对所有邻居一视同仁，瓶子的边缘也会被平均到背景里。

于是，问题从“怎样平滑深度”变成：怎样只在可能属于同一个表面的像素之间平滑？

02.1 · 从普通平滑到边缘保持

Median Filter 通过邻域中位数降低孤立异常值的影响；Bilateral Filter 同时考虑空间距离与数值差异，让深度差别很大的像素不轻易互相影响。

但实时深度相机还需要计算足够快。RealSense D400 系列的 Spatial Filter 采用基于 Domain Transform 的边缘保持滤波，而不只是对每个像素直接计算二维双边加权。

它将水平和垂直方向的处理分解为多次一维遍历：如果相邻像素之间的深度变化很小，就允许平滑信息传播；如果出现较大的深度突变，就减弱跨越边界的影响。

概念示意：深度突变通常提示不同表面，但真实斜面、薄物体等情况会让边缘判断更复杂。

因此，RealSense 的几个常见参数并非简单“画质增强等级”：Smooth Alpha 决定原始与滤波结果之间的混合权重，Smooth Delta 影响边缘判定，Filter Magnitude 决定处理迭代程度。

它选择的是一个明确的工程方向：在较低延迟内完成平滑，同时尽量阻止跨物体边界的信息混合。

02.2 · 为什么还要回到视差域？

在双目相机里，深度与视差的关系是：

Z = fB / d
Z 为光轴方向深度，f 为焦距，B 为双目基线，d 为视差

对误差做局部近似，有：

|ΔZ| ≈ Z2 |Δd| / (fB)
相同视差误差对应的深度误差，随距离增大而显著扩大

这意味着对不同距离的深度一律套用相同的平滑尺度，未必符合双目测量的误差结构。RealSense D400 的推荐 SDK 处理链包含 Depth → Disparity → Spatial / Temporal → Depth。

真正的思路不是换个数值单位，而是回到更贴近双目测量误差的空间处理数据。 但这种物理动机属于双目相机，不能直接照搬到 ToF 的测距模型。

02.3 · 一帧不稳定，历史帧能不能帮忙？

Spatial 利用空间邻域；Temporal 利用时间邻域。最简单的办法是指数滑动平均：

Ẑt = α Zt + (1 − α) Ẑt−1
当场景近似静止、历史测量有效时，能够降低帧间随机波动

RealSense Temporal Filter 还提供 Persistency 规则：当前像素无效时，可以参考近期帧的有效性历史，决定是否沿用过去的测量。

但如果瓶子移动、相机自身移动，过去同一像素的位置可能已经看向另一个物体。时间滤波越坚持历史，就越容易产生拖影或残留表面。

再进一步，可以先根据运动把历史观测对齐到当前帧，然后融合。但这要求更复杂的运动估计与几何关联，已经不是简单逐像素时间滤波。

这一阶段的结论： 经典滤波没有过时。它在延迟、资源占用、可解释性和确定性方面仍很有价值。但它主要利用已有深度的统计关系，无法保证识别所有系统性错误。

03 / MEASUREMENT CONFIDENCE

不再修正所有深度｜能不能先判断哪些测量可信？

空间滤波暗含一个前提：参与平滑的数值，大体围绕真实值波动。但双目匹配错了位置，可能得到一片很稳定、却完全错误的深度。

如果错误本身不是随机噪声，再怎么平均都未必能修回来。于是问题变了：既然深度来自一套计算过程，能不能从这套过程里找出“它是否可信”的证据？

03.1 · Luxonis：从匹配代价到 Confidence

双目匹配不是凭空产生一个视差。对于左图像素，算法需要在右图相应极线上寻找候选位置，并评估匹配代价。

如果某个候选明显好于其他位置，匹配可能较可信。如果许多候选看起来都差不多——例如一大片低纹理白墙——就很难知道哪个位置才对。

Luxonis DepthAI 的 StereoDepth 提供置信度阈值，根据立体匹配产生的质量信息拒绝部分不可靠视差。

过去问的是“这个深度该修成多少”。现在先问：这个深度有没有足够证据值得留下？

03.2 · 左右一致性：为什么不反过来再算一次？

从左图找到右图对应点之后，再从右图反向寻找左图。如果两次匹配准确且该位置可见，它们应该大致互相一致。

|dL(x,y) − dR(x−dL,y)| < τ
以相同视差方向约定描述的左右一致性检验；超过阈值 τ 的匹配可判为不可信
示意而非具体硬件实现。遮挡区域天生可能无法双向匹配，因此检查也会减少可用深度。

它比普通平滑多利用了一条几何关系：可靠对应应该尽可能具备双向一致性。 但错误有时可能碰巧一致；真实遮挡边缘也常常无法通过检查。

03.3 · 既然知道可信度，能不能只修不可靠的区域？

Luxonis 的较新处理架构提供自适应中值滤波等能力，利用匹配质量等线索，针对可疑深度做更有选择的修正。

其区域引导的空洞处理方向，也不再满足于从左、右、上方复制某个邻居，而是尝试先在图像中找到具有相似性质的区域，再结合可信深度估计缺失值。

这个方向的核心变化是：已经可信的值不必反复修改；缺乏依据的值才需要进一步检查、修正或拒绝。

这一阶段的结论： 置信度能够让“修正”变成有条件的决策。不过低置信度往往集中在小物体、边界和弱纹理处，阈值过严也可能删除真正重要的几何。

04 / FAILURE-MECHANISM AWARE

错误并不只有一种｜能否直接针对错误产生的原因？

置信度是更聪明的第一步，但不同深度相机产生错误的原因并不一样。双目可能错误匹配；结构光可能受到多次反射干扰；ToF 可能受到多径、相位噪声或信号强度影响。

这些问题最后都可能呈现为飞点或虚假表面，可它们的形成过程完全不同。于是另一种想法出现了：利用测量失败所留下的特定形态或物理信号，而不是将全部错误当作随机噪声。

04.1 · Orbbec：普通 Noise Removal 为什么不够？

Orbbec Gemini 330 系列的 NoiseRemovalFilter 使用深度区域聚类：通过相邻深度差异建立连通区域，再结合规模等规则删除可疑小区域。

这能够处理局部孤立错误，却存在天然矛盾：细小真实结构与一小块错误深度，在连通区域统计上可能十分相似。

于是还需要 FalsePositiveFilter。公开文档将其区分为几类失效现象：

FAILURE MODE 01

Edge Bleed｜为什么物体边缘会向外延伸？

一些错误会形成横向延伸、数值不合理地重复的区域。Orbbec 使用特定的深度形态规则，例如长串相同深度值，识别疑似边缘扩散。

代价：真实平坦结构有时也可能表现出相似形态，因而需要限制适用范围。

FAILURE MODE 02

Texture Sparsity｜没有纹理，为什么更容易测错？

双目对应关系缺乏唯一线索时，会产生低可信甚至错误的深度。专门的弱纹理错误规则利用特定区域和深度特征进行识别。

代价：弱纹理并不必然等于错误，过度拒绝会损失整片真实表面。

FAILURE MODE 03

Pattern Ambiguity｜重复纹理为什么更加危险？

周期性纹理可能让多个候选位置都具有相似匹配代价，错误视差甚至可能组成一片连续表面。识别这种错误需要利用更具体的噪声形态与场景条件。

代价：专门规则通常有适用场景，不能保证覆盖所有错误模式。

这里的探索已经从“所有噪声都用一个阈值处理”，发展到了“不同的测量失败机制应该寻找不同证据”。

04.2 · Zivid：既然知道自己投射了什么，为什么不用这些信息？

工业结构光相机 Zivid 面对的某些错误，来源于反射路径而非一般随机噪声。光线在反光物体之间发生多次反射，返回时不再满足算法预期的路径，就可能生成悬浮在物体之间的虚假表面（Ghost Planes）。

普通点云离群点剔除能清除部分问题，但它并不知道这些点为什么产生。Zivid 的 Reflection Filter 则能够利用投射光与相机接收到的信号关系，寻找疑似受反射影响的测量。

概念性光路示意，用于解释直接反射与多次反射的区别；具体 Zivid 算法内部不等同于图中几何规则。

其 Reflection Filter 还提供不同的取舍模式。更积极地清除反射相关异常，可能同时伤及细薄、尖锐的真实结构；在一些场景里需要选择更偏向局部保留的处理策略。

这和 Orbbec 的想法有共通之处：不是简单判断“偏离邻居的深度是错的”，而是使用更贴近传感器物理原理的证据。

技术不可随意移植

双目错误匹配与 ToF 多径反射都可能生成飞点，但两者的原始证据不同。双目可以检查视差匹配关系；ToF 则可能需要分析相位、调制信号或回波特征。名称相同的“后处理”，未必属于同一算法。

这一阶段的结论： 更先进的深度处理，有时并非一个更复杂的通用滤波器，而是针对特定失效机制引入更准确的判断依据。

05 / MISSING DEPTH

没有深度怎么办｜填洞，还是承认不知道？

前面的方法让深度更平滑，也删除了不可信的测量。但这样得到的深度图，很可能仍然存在空洞。

简单 Hole Filling 可以把附近有效像素复制到无效位置。RealSense 和 Orbbec 都提供了类似策略。对一片连续平面上的小空洞，这往往很实用。

但如果空洞恰好出现在瓶子与背景的交界处，旁边那个看似“最近”的有效深度，可能属于完全不同的表面。

情况 A：连续表面中的小空洞

邻域测量有机会为缺失值提供约束。谨慎插值可能改善点云连续性。

情况 B：遮挡或无法测量的区域

邻域并不一定属于同一个表面。直接补值可能把背景画到前景上。

这解释了为什么厂商会探索区域引导填洞、置信度约束、修复严格程度等方法：不仅要看有没有相邻的有效深度，还要判断那些深度是否真能解释当前缺失区域。

对于视觉呈现，一张填满的深度图常常更讨喜。但对于真实三维测量，保留“未知”，有时比填入一个看起来合理的值更正确。

因此，应当区分原始有效测量、经过数值滤波的测量、根据邻域补出的估计。如果将三者视为完全同等可信，下游几何计算就可能在错误的表面上做出十分确定的判断。

这一阶段的结论： 深度完整率不是唯一质量指标。填洞真正要解决的是“能否合理推断”，而不只是“能否消除空像素”。

06 / COMPLEMENTARY OBSERVATIONS

如果原始信息不够｜为什么不改变观测条件？

前面的办法，大多仍在处理已有观测。但如果一块表面在当前曝光下根本得不到可靠信号，再复杂的空间滤波也不能保证凭空恢复它。

于是有一个简单却重要的转折：与其在缺失值上反复猜测，为什么不换一种观测条件，再测一次？

06.1 · Orbbec：HDR 不只是把画面调亮

Orbbec Gemini 330 系列支持深度 HDR 相关功能，通过在不同曝光或增益设置之间采集并融合深度，使不同亮度/反射条件下的有效观测互相补充。

一档曝光可能更适合低信号区域，另一档更适合避免强反射区域出现信号过强。HDR Merge 引入的是新的观测证据，而不只是对旧数据平滑。

仅为多曝光互补性的概念示意，非厂商 HDR 算法的内部流程图。

但它有明显代价：不同曝光可能发生在不同时间。相机或物体一旦运动，直接融合就可能发生错位，实时性也会受到限制。而且 HDR 只改善与采集条件互补性有关的问题，不能消除所有遮挡与物理测量限制。

06.2 · 从多曝光到多观测

相同的思想可以延伸到不同照明、不同视角、不同时间的互补观测。但越往后，越需要解决时序和几何对齐问题。

这里不继续展开多视角重建；重要的是看清：一旦信息在采集时已经缺失，增加互补证据与凭邻域猜测，是两条本质不同的路。

这一阶段的结论： 对受采集条件限制的区域，改变观测方式有时比更复杂的后处理更有价值；但它会将问题带到采集策略与多观测融合。

07 / LEARNED ENHANCEMENT

能不能让模型恢复深度｜学习式增强已经走到哪里了？

到这里，大部分方法还在依赖明确的统计、几何或物理规则。可透明、反光、弱纹理或细小结构等困难区域，往往缺少足够的局部几何证据。

如果为每一种失败条件手工编写规则，维护起来又会很复杂。于是新的思路出现了：能不能利用 RGB 图像和大量数据中学习到的结构规律，去推断缺失或错误的深度？

07.1 · Orbbec LingBot-Depth：不只靠几何邻域补洞

Orbbec SDK v2 提供了 LingBot Enhanced Depth Filter 的公开集成方案。根据厂商资料，它联合 RGB 与已有深度信息，针对噪声、空洞以及物体边缘等问题进行深度增强。

这和简单的 Hole Filling 不一样。原始深度中某片区域缺失，但 RGB 仍然可能提供轮廓、纹理、外观与局部结构线索；模型尝试把它们与已有三维观测联系起来。

于是，算法使用的不再只有“附近深度是多少”，还包含“画面看起来可能具有什么几何结构”。

已知与未知的边界

可以确认：RGB-D 联合的学习式增强已进入厂商工具链

公开资料说明其增强目标与部署要求，但没有完整披露模型内部网络层、训练损失和推理细节。因此不能仅凭功能名称推断具体网络架构，也不能将所有宣传效果当作跨场景精度保证。

07.2 · Stereolabs：让网络直接参与深度解算

Stereolabs ZED SDK 提供 NEURAL LIGHT、NEURAL、NEURAL PLUS 等神经网络深度模式，旨在不同质量与计算预算之间取舍。

这比“先求出一张深度图，再用模型修复”走得更远：学习模型已经进入双目深度生成本身，在复杂纹理、细节恢复等方面尝试突破传统匹配方法的限制。

因此，它更准确地属于学习式深度估计，不应被强行归成普通后处理。但它说明：当学习模型可以同时参与深度生成和增强时，传统边界正在变化。

07.3 · 恢复出来的几何，什么时候可以相信？

假设透明瓶身的深度原本完全缺失。模型利用 RGB 轮廓与部分深度恢复了一片连续表面。

从视觉效果看，这片表面可能非常自然。但它也可能只是训练数据中常见的瓶身形状，并非当前物体的真实测量。

对于三维抓取，表面位置偏差可能直接影响接触位置。因此不能简单用“补全了多少像素”证明几何精度。

恢复得完整 ≠ 测量得准确。 学习式方法提供更丰富的先验，也引入了泛化误差和推断结果可能看似真实的问题。

这一阶段的结论： 学习式增强让深度恢复突破简单局部规则，但必须区分原始有效测量、数值修正与模型估计。

08 / LOOKING BACK

回头看｜深度后处理究竟发展出了哪些思想？

重新看这些方法，会发现它们并不在解决同一类问题。

RealSense 的 Domain Transform 与视差域处理，代表对测量误差和实时计算的认真权衡。

Luxonis 的置信度与左右一致性检查，提醒我们与其修正全部深度，不如先判断哪些值值得相信。

Orbbec 的 FalsePositiveFilter 尝试识别特定错误形态；Zivid 的 Reflection Filter 则利用主动投射系统独有的物理信息。

Orbbec HDR Merge 通过互补观测弥补单次采集的局限；LingBot-Depth 与 ZED Neural Depth 则展示了学习模型参与深度增强与生成的实际路线。

依据什么信息？可以做出什么处理？主要付出什么代价？
空间 / 时间邻域平滑、历史融合细节损失、延迟、拖影
匹配质量与一致性拒绝不可信深度有效区域减少、边缘误删
特定错误机制针对性异常检测适用场景受限
互补采集条件增加有效观测采集、时序与融合成本
学习得到的先验增强、修复、重新推断算力、泛化和可信度问题

另外，Decimation、Threshold、常规降采样仍然很重要，只是它们主要解决计算效率、数据范围和表达成本，不该和深度真实性提升混为一谈。

有没有一种方法，可以直接取代其他所有方法？

似乎没有。

规则、静态、测量本身可靠的表面，经典滤波往往足够；错误匹配更多时，可信度判断比强行平滑更有依据；反光或信号异常场景，专门的物理机制检测可能更有价值；采集信息不足时，互补曝光可以增加证据；学习式方法可以尝试突破传统局部规则，却需要面对新的不确定性。

所以，“厂商还在用经典滤波”不等于技术落后。更现实的判断标准始终是真实几何精度、鲁棒性、延迟、硬件资源与可解释性之间的平衡。

最后，回到真正需要的三维观测

深度图不是最终作品。对于机器人而言，我们最终需要的是能够支撑几何计算、物体定位和真实操作的三维信息。

一张非常平滑的瓶身，如果轮廓已被拉歪，并不比原始深度更准确。一片补得很完整的透明表面，如果没有测量证据，也不应该被直接视为真实接触面。

深度后处理真正值得追求的，不是让所有像素都有一个 XYZ，而是尽可能区分：哪些几何是测量得到的，哪些被修正过，哪些只是有依据的估计。

到这里，深度后处理就不再只是“把图像修得更干净”，而是包含三种不同的行为：减少已有误差、拒绝不可信测量、利用额外信息推断未知几何。

可即使每个深度都足够可靠，假如相机内参、畸变或 RGB-D 对齐关系存在偏差，恢复出来的三维点仍然可能落在错误位置。
