04 / 05  ·  DEPTH POST-PROCESSING

深度测出来了，
为什么还要再处理？

EVIDENCE · ALGORITHMS · GEOMETRY

上一部分已经弄清楚，双目通过视差、结构光通过投影对应、ToF 通过光传播信号计算距离。于是，相机终于能输出一张 Depth Map。

但它并不一定是连续、稳定、可以直接用来计算物体表面的几何：平整桌面上有细小起伏，瓶子边缘偶尔飞出几个点；相机和物体都不动，深度却轻微跳动；一些位置干脆没有有效值。

后处理不负责重新发明测距原理。 它研究的是：已经拿到的观测中，哪些值得保留，哪些可以利用空间或时间证据改善，哪些根本没有足够信息补回来。

这篇按四种操作组织：剔除错误值、减小空间噪声、融合时间观测、估计缺失区域。每个部分先讲可迁移的数学机制，再简短看看 RealSense 和 Orbbec 把这些思想做成了什么。厂商例子是具体实现，不是第五种独立算法。

从四种处理行为开始
00处理地图

算法究竟在修改什么？

深度图可以表示为一个函数 ，其中 是像素位置。再使用一个有效性掩码 ：有效测量为 1，无效测量为 0。数值为 0 常被一些深度格式用作无效值，但并不是所有设备与数据格式都采用同一表示。

从算法的行为看，后处理主要有四种：

要做的事 输入的主要证据 输出发生什么变化 最需要警惕的代价
异常剔除 局部统计、连通性、三维邻域、测量质量信息 把可疑值设为无效 细杆、边缘和真实小物体被删掉
空间去噪 同一帧邻域的深度、颜色或视差 调整现有有效值 轮廓变圆、两个表面被混合
时间融合 历史帧与当前帧 降低帧间变化或沿用历史值 动态物体拖影与残留
空洞补全 邻近有效值、RGB、表面先验 对原本无效位置给出估计 制造原本不存在的三维表面

一个重要的区别是：“深度看起来更平滑”不等于“深度更准确”。 例如，把本来正确的瓶子边缘与背后的墙平均，得到的数值可能很平稳，却对应一个真实世界中根本不存在的位置。

下面的章节顺序是为了理解算法之间的边界，并不意味着所有设备都应严格按照这个顺序执行。具体滤波链取决于测距类型、使用目的和 SDK 实现。

01异常剔除

先判断哪些值值得留下

Outlier Rejection · Statistics, Connectivity & Measurement Evidence

最直观的异常是：周围一大片表面都在 0.8 m 附近，某个像素却突然报出 2.5 m。这种情况可以先不急着“修成 0.8 m”，而是判断它是否应当进入后续几何计算。

01.1 局部中位数与 MAD：不让极端值主导判断

对于像素 周围的有效深度集合 ，先求局部中位数：

当深度满足 时，可以将它标为统计意义上的可疑值。 是正态噪声下的常见尺度校正； 防止局部变化几乎为零时阈值退化。

例如邻域为 799、801、800、798、2500 mm，中位数是 800 mm，比均值更不容易被 2500 mm 拖偏。

但偏离邻域并不等于测量错误。瓶口、细杆或前景与背景的真实深度断层，同样可能与邻居差别很大。因此局部统计更适合标记或拒绝孤立异常，而不是在所有位置无条件替换。

01.2 连通区域：错误值可能是一整小块

有些飞点不是一个像素，而是一小片深度相近、与主体不相连的区域。可以构造邻接图：两个相邻有效像素 满足

时，认为它们在深度上可连通。再求各个连通区域 的大小 ，删除满足 的小区域。

这类方法适合清理稀疏散点和部分小型假深度簇；不过一根真实线缆或一个远处小瓶盖也可能形成小区域。区域大小是筛选线索，不是“真实性证明”。

01.3 换到 XYZ：利用三维邻居关系

二维像素相邻，不意味着对应三维点也接近。将有效深度反投影到 XYZ 后，可以直接使用空间邻域。

三维离群点检测更贴近后续点云任务，但需要内参，计算量通常也更高。边缘上的真实稀疏点仍可能被误删。

01.4 若能拿到内部质量信息，判断会更有依据

前面的方法主要看计算完成后的深度分布。如果能访问测距过程内部的信息，还可以根据匹配质量、左右一致性或返回信号质量拒绝一部分异常。

例如双目中，如果左图到右图、再从右图回左图的匹配无法回到原始位置，说明这次对应可疑。它与局部中位数不同：前者检查生成深度所依赖的测量关系，后者只检查最终数值是否像邻居。

不过，不是每台设备都会向应用层提供逐像素置信度。不能把其他型号提供的置信度接口，默认当成当前相机已经有的数据。

02空间去噪

让表面更稳定，但别抹掉边缘

Spatial Denoising · Neighborhoods, Edges & Disparity

如果一张深度图没有特别离谱的坏点，却在平面上出现细小的随机起伏，就很适合利用空间邻域。问题在于：平面上的邻居应当协作，瓶子边缘与后方背景却不该被直接平均。

这样，距离近但深度相差很大的像素会被赋予较小权重。瓶子与墙之间的深度跳变通常就不容易被普通均值直接混合。

然而它仍然可能遇到问题：如果中心像素本身已经是错误值，使用它作为相似度参照可能让错误值继续留在原地；一个真实斜面也可能被错误地切成几块互不平滑的区域。

02.3 Guided Filter：可不可以借助 RGB 的边缘？

如果同时有对齐后的 RGB 图，颜色边缘可以作为另一类信息。Guided Filter 的一个经典假设是：在局部窗口 中，滤波输出 与引导图像 近似满足

通过拟合 （带有正则项）并对重叠窗口求平均，得到一张受到图像结构约束的平滑结果。对深度而言，需处理无效值并保证 RGB—Depth 已经对齐。

它的价值是利用图像边缘减少跨区域传播；代价是 RGB 的纹理未必对应深度断层——印在同一平面上的图案，会在颜色图上形成边缘，却不应该产生几何台阶。

02.4 Domain Transform：不用每次都计算大范围二维权重

双边滤波直观，但对每个像素计算二维邻域权重可能较昂贵。Domain Transform 的思想是将图像上的边缘差异编码为一种新的累计距离，在经过明显边缘的方向上拉大“距离”，然后用高效的一维滤波完成边缘保持平滑。

概念上，对于沿一行的信号 ，可以构造随边缘变化的坐标：

当 在某处变化明显时，变换后相邻位置被拉得更远，滤波信息就不容易跨越它。这是理解机制的简化表达，不是某厂商 SDK 内部的逐行实现源码。

水平和垂直方向上的多次一维处理，使这一类算法适合需要低延迟的深度流。

重复观测怎样让深度不再跳动？

看向静止桌面时，同一个像素的深度可能是 800、804、798、802 mm。空间邻域可以提供帮助；但如果相机连续拍到同一个表面，历史帧也是一种可利用的证据。

03.2 Temporal Median 与 Persistency：是平滑，还是沿用旧值？

Temporal Median 对近期有效观测求中位数，不像平均那样被单次尖峰强烈影响，但需要一个历史窗口，对快速变化也有延迟。

Persistency（历史有效值保持） 解决的是不同问题：当前像素缺失时，如果前几帧曾出现有效观测，按特定规则复用旧值。

这种规则能减少深度图中的闪烁空洞，但复用历史值不等于重新测量到了物体。当前景移走、背景露出时，旧前景可能短暂停留在错误的位置。

03.3 最关键的假设：同一像素是否还对应同一个表面？

简单逐像素时间滤波隐含着一个非常强的假设：前后帧的 对应同一个物体表面位置。

如果相机移动了，或者瓶子从左向右运动，这个假设就会失效。旧值与新值混合可能制造拖影、双层表面甚至错误障碍物。

RealSense D400： Temporal Filter 提供 Smooth Alpha、Smooth Delta，以及不同 Persistency 模式，例如要求最近若干帧中达到一定有效次数才允许复用旧值。其官方文档明确指出，历史数据会造成 blur/smearing，尤其适合静态场景。很有意思的是：厂商把“数值平滑”和“缺失时要不要相信过去”做成了两个不同的控制维度。参见 RealSense 滤波说明。

值得追问： 对停着的瓶子，滤波后标准差变小是好事；对正在搬运的瓶子，更重要的可能是观察到的边缘有没有延迟。不能用静态场景的平稳程度，代替动态场景的质量评价。

04深度补全

没有观测，究竟能推断到哪一步？

Depth Completion · Interpolation, Guidance & Priors

有时某个像素没有有效深度，并不是它的数值波动过大，而是根本没有得到可用测量。后处理可以试着估计，但必须承认估计值和真实观测是不同的。

04.1 最近邻与插值：先假定局部表面连续

最简单的方式是从附近有效像素复制一个深度，或者按距离做加权平均：

这相当于假设空洞附近属于同一连续表面。对于平整桌面上的少量随机空洞，可能足够实用。

但如果空洞刚好落在瓶子轮廓和背景之间，邻近有效深度可能分别是 0.8 m 与 2.0 m。把它们平均成 1.4 m，得到的不是更完整的真实场景，而是一层不存在的中间表面。

因此，空洞的形状和位置比“填完了多少像素”更重要：小而封闭、且在连续表面内部的空洞，与物体遮挡边界处的大片缺失，不能采用同一种无条件插值策略。

04.2 Joint Bilateral：借助 RGB 限制填充来源

若 RGB 与深度已经正确配准，可以构造同时依赖空间距离与颜色差异的权重：

但颜色并不是深度的充分证据。一个物体表面有彩色贴纸，不代表表面高度变化；玻璃、镜面和阴影也可能让颜色引导失效。

学习式方法在大面积缺失时能够利用更强的先验，甚至推断局部遮挡后的形状。但这种“合理”可能只是训练分布下的猜测。对于机器人夹取接触位置，不能把网络补出的深度与真实有效测量不加区分地混用。

RealSense D400： 官方 Hole Filling Filter 会从上、下、左、右等相邻位置中按模式选取深度，包含“左侧值”“周围最远值”“周围最近值”等选择。Spatial Filter 自身还可开启有限范围的横向空洞修补。看似简单的“补洞”，实际上隐含了选前景还是背景的不同偏好；它并没有凭空重建被挡住的表面。参见 RealSense 官方后处理文档。

Orbbec Gemini 330 系列： 官方 HoleFillingFilter 提供 TOP / NEAREST / FAREST 等模式，但文档特别提醒：填满所有空洞可能引入虚假数据，因此一般不推荐无条件开启；在确实要求较完整深度的特殊应用中，建议使用特定模式。这个提醒很有价值：SDK 提供了能力，不代表厂商认为任何任务都应该启用它。 参见 Orbbec 详细滤波参考。

值得区分： 对图像展示、背景虚化而言，填洞有时比保留黑洞重要；对精确三维抓取，错误的补全可能比“这里没有数据”更危险。对补全结果最好保留一个独立的估计来源标记。

05方法选择

怎样判断后处理究竟有没有变好？

不能只比较滤波前后哪张深度图更平滑。更有用的是按照处理目标，检查几何性质是否真正改善。

当前最明显的问题 首先考虑 一定要同时检查
零星远离主体的深度点 局部统计、连通区域、3D 离群点 真实小目标和细杆是否被误删
平面表面轻微抖动 Gaussian / Bilateral / Domain Transform 平面拟合残差与真实边缘是否改变
远距离双目深度波动 视差域滤波、亚像素与匹配质量排查 远距离的绝对误差、视差失配是否仍在
静态物体帧间跳动 EMA、Temporal Median 标准差降低时是否产生延迟
当前帧偶发无效值 历史有效值策略 动态场景有无旧值残留
连续平面上的少量空洞 局部插值、RGB / 几何引导 跨越深度边缘是否制造假表面
大面积、材质导致的无效深度 回到曝光、投射、测距模式或更换观测方式 后处理不应虚构从未获得的可靠测量

还有哪些相关方法，不必强行放在四类滤波中？

Decimation / Downsampling 主要减少分辨率与后续计算量，可能顺带消除一些高频噪声，但也可能吞掉薄结构；改变图像分辨率后，内参必须相应调整。

Threshold 主要按有效工作距离或业务范围拒绝无关值；它没有证明保留区域内的深度正确。

HDR、多曝光与不同采集模式 通过改变实际观测获取更互补的数据；它们可能改善最终深度，但不应与“对同一张深度图做滤波”混为一谈。例如 Orbbec Gemini 330 系列提供相关 HDR Merge 处理模块，具体启用条件依赖该系列支持的采集方式。

学习式深度生成 与“对已有深度进行增强/补全”同样需要分开：重新从 RGB / 双目生成深度属于测量算法范围；只对已有 Depth Map 估计无效区域则属于这里讨论的后处理。

一次更有效的比较实验

选择静止平面、前后深度断层、小薄物体和少量真实空洞四种场景，固定采集条件，再分别开启不同算法。除了展示原始图与处理结果，还记录：有效像素比例、静态深度标准差、平面拟合残差、边界定位变化，以及小物体被保留的比例。

对时间滤波，再增加一段简单运动测试，观察拖影和响应延迟。不同方法不必追求一个总分；因为它们优化的目标本来就不完全相同。

END回头看

处理深度，不只是“把图修漂亮”

这篇的四类方法，实际上代表四种不同的判断：

  • 异常剔除： 我有证据认为某些测量不应该留下。
  • 空间去噪： 我认为邻近观测大体描述同一个表面，可以互相帮助。
  • 时间融合： 我认为历史观测与当前观测有足够的对应关系。
  • 空洞补全： 我没有当前的有效测量，但愿意根据额外假设给出一个估计。

它们的共同点，是都在利用比单个深度值更多的信息；区别则在于所相信的证据和愿意承担的几何代价不同。

RealSense 的视差域与 Domain Transform、Orbbec 对不同假深度形态的专项处理，都很值得借鉴。真正的收获并不是学会某个开关，而是明白这些工程选择对应哪一类数学假设。

对于机器人后续需要的三维定位，结果既要足够稳定，也要保留真实边界与细小结构。一个没有深度的点可以标成未知；一个被补出、却没有事实依据的表面，则可能悄悄进入后续的几何计算。

所以，这一部分的终点不是找到一个“最强滤波器”，而是能够判断：它利用了什么、改善了什么，以及在什么时候宁可保留无效值，也不要生成看起来正确的假几何。
