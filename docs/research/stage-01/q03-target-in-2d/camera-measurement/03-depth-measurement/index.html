00 / THE QUESTION

开场｜方向知道了，距离谁来告诉我？

上一段探索已经知道：一个像素通过相机内参，能够恢复一条从相机出发的空间射线。但瓶子究竟落在射线上的哪个位置，我们仍然不知道。

那就需要测量距离。最朴素的想法是换个位置再看一眼；如果表面太光滑，就自己投上一点纹理；如果知道投射图案来自哪里，也许能直接恢复空间对应；还有一条路，干脆让光往返一次，用传播时间告诉我们距离。

已知像素方向不等于已知三维位置：还缺少一项能约束距离的观测。

这次的主线：每种方法究竟观测到什么，怎样把它变成深度；遇到运动、光照和材质变化时，哪些证据会失效？最后再去看真实厂商如何在这些约束中做选择。

02 / PASSIVE STEREO

被动双目｜两个视角怎样一步步算出 Z？

换一个位置再看同一个点，两个方向似乎就能交出它的位置。但问题马上出现：右图里哪个像素才是左图中的同一个物理点？

02.1 · 为什么视差能够代表距离？

假设左右相机已标定、极线校正后焦距相同，左右中心相距 B，水平焦距为 f。同一点在左右图中的横坐标为 uL、uR，消除主点差后得到视差 d = uL − uR。

Z = fB / d

理想双目：两条来自同一空间点的射线提供三角测量约束。

举例：f = 600 px、B = 0.05 m，视差 30 px 时 Z = 1 m；视差 15 px 时 Z = 2 m。远处点的视差变小，所以微小的视差误差在远处会被放大。

02.2 · 为什么先极线校正，而不是直接到另一幅图找？

未校正的两个视角，对应点落在一条极线上，却不一定处在相同行。利用两台相机的内参与相对外参做 Rectification，构造校正后的虚拟成像平面，才可以沿同一行搜索 (u − d, v)。

校正不是计算深度，而是把二维搜索收敛成一维搜索。接下来仍然必须判断哪个候选匹配可信。

02.3 · SAD、SSD、NCC：最朴素的匹配怎样发生？

取左图某像素周围的小窗口 W，对每个候选视差 d，在右图取相应窗口。SAD 累计对应灰度的绝对差；SSD 累计平方差；NCC 则比较归一化相关性。

CSAD(u,v,d) = Σ(i,j)∈W | IL(u+i,v+j) − IR(u+i−d,v+j) |

例如左窗口为 [80,120,100]，某候选右窗口为 [81,119,103]，SAD = 1+1+3 = 5。代价越小，说明窗口更相似。但在整面白墙上，各个候选窗口都可能非常相似；找到了“最低代价”，不等于找到了真实对应。

为什么值得用

SAD 廉价，SSD 易与优化结合，NCC 对部分线性亮度变化更稳健；都是很清楚的匹配基线。

真正会失败在哪里

弱纹理、重复纹理、遮挡；窗口跨越物体边界；左右图亮度关系改变。

02.4 · Census：不比绝对灰度，改比相对顺序

左右曝光不一致时，灰度相减会变得不稳。Census 把每个邻居与中心像素比较：较暗记 1，反之记 0，从而得到一个位串。两个位串通过 XOR 与 bit count 计算汉明距离。

例如一个窗口的 Census 位串是 10011010，另一个是 10011000，只有一位不同，汉明距离是 1。它对保留局部灰度排序的光照变化更稳健，却依然无法从没有纹理的表面凭空造出特征。

02.5 · BM 与 SGM：为什么只看一个像素还不够？

Block Matching 通过窗口聚合，让单个像素借助邻域证据；窗口过大却会混入前后景。SGM 则提出另一种约束：连续表面上，相邻像素的视差通常相近，但深度边界允许突变。它沿多个方向累计匹配代价。

Lr(p,d) = C(p,d) + min{ Lr(p−r,d), Lr(p−r,d±1)+P1, minkLr(p−r,k)+P2 } − minkLr(p−r,k)

记住直觉即可：不改变视差不处罚，小幅跳变付较小代价 P₁，大幅跳变付更大代价 P₂。SGM 往往比孤立匹配稳定，但细杆、薄物体和突然出现的深度台阶，恰恰可能被“平滑一致”的假设误伤。

02.6 · 还差两步：亚像素与左右一致性

离散候选 d 通常首先得到整数像素视差。可在代价最低点附近做抛物线拟合，细化为亚像素视差。另一方面，左图匹配到右图，再从右图反向匹配回来；若无法回到原处，说明可能存在遮挡或误匹配，应当拒绝这份深度。

标定与校正→匹配代价→聚合/优化→视差→可信度检查→Z

02.7 · 学习式立体匹配，究竟学走了哪部分？

GC-Net、PSMNet 使用特征提取与 Cost Volume，让网络学习“哪些候选看上去对应”及“如何使用周围上下文”；RAFT-Stereo 从相关特征和初始视差出发，通过迭代更新反复修正匹配结果。

技术核心变化工程代价
GC-Net / PSMNet学习特征与视差代价体聚合视差范围、分辨率与 3D 卷积带来显存和计算开销
RAFT-Stereo通过相关特征与更新单元迭代修正视差迭代次数影响速度；跨数据域需要关注泛化
传统 Census + SGM显式的特征、匹配代价与空间惩罚可控、易部署，但人为设定的先验有局限

学习式匹配仍然在求对应关系。它可能对弱纹理作出有用推测，却不代表每个输出都有真实图像证据支持；尤其面对与训练集不同的红外图、投影纹理、透明材质时，需要警惕看似平滑的错误。

02.8 · 为什么远处的距离误差增长这么快？

Z = fB / d　 ⇒　 |δZ| ≈ (Z² / fB) · |δd|

在同样的视差误差下，深度误差近似随 Z² 增长。加大基线 B、增大焦距 f 或提高匹配精度，都可能改善远距离测量，但大基线也增加遮挡差异并改变近距共同视野。这就是一台近距离腕部相机和一台中远距双目相机，未必采用相同基线的原因。

02.8A · 为什么被动双目对“动态”并不天然吃亏？

双目匹配虽然需要两幅图，但它们可以在同一个瞬间同时曝光。因此动态目标对双目的首要问题，常常不是“跨帧时序”，而是快门不一致、曝光运动模糊、纹理不足或遮挡变化。

举个对照：一个印有标签的瓶子在传送带上匀速移动。如果左右全局快门同步，两个传感器看的是同一时刻的瓶子，可以直接寻找左右对应；相反，一个需要 12 张不同条纹的结构光系统，即使单帧照片都清楚，合成整个编码序列时瓶子可能已经移走。

同一个运动目标最重要的时间要求典型失败的来源
同步全局快门双目左右曝光重叠且足够短自然纹理不足、单次曝光模糊、左右遮挡
多帧结构光整组投射编码期间物体几乎不变，或实现补偿不同编码帧不是同一个物理点
iToF多相位/频率采集保持一致，或采用抗运动方案相位读数错配、积分模糊、边缘混合

这也意味着：需要实时感知动态目标，首先确认曝光与完整测量窗口，而不是先按技术名称淘汰双目。

02.9 · 什么时候更适合被动双目？

自然纹理

纸箱、印刷标签、街景

有足够可匹配细节时，完全可以不投射红外图案。

目标运动

同步曝光的动态场景

两幅图可以同一时刻采集；曝光、快门和运动模糊仍然关键。

室外环境

不依赖投射器

阳光不必与主动纹理竞争，但弱纹理和反光照样可能失效。

得到的选择：场景已经提供足够自然纹理、希望实时观察运动、主动照明不方便时，被动双目很值得优先考虑。它最根本的边界不是“能不能在室外”，而是能不能稳定找到同一个表面点。
03 / ACTIVE STEREO

主动双目｜自己投上纹理，算法需要换一套吗？

被动双目在白墙上找不到稳定对应，可如果问题仅仅是没有纹理呢？既然相机需要纹理，我们能不能主动给白墙加上一层？

03.1 · 打上散斑之后，计算链其实没有变

投射器把近红外散斑打到物体表面，两台红外相机同时观察这些散斑。过去白墙上许多窗口看起来都一样；现在不规则亮暗分布让正确位置更容易拥有独特的匹配代价。

典型主动双目：投射器帮助制造“可比较的局部纹理”，左右 IR 相机仍然负责对应关系。

投射散斑→左右 IR 曝光→Rectify→Census / SGM 等立体匹配→d→Z

这只是通用技术结构。实际商用相机在芯片内采用何种具体匹配代价和后处理，未公开的部分不能随意断言“它一定用了某一个开源版本的 SGM”。

03.2 · 投射器的位置真的完全不重要吗？

投射图案的角度、功率、密度会影响散斑能否覆盖目标，以及是否能被两台相机稳定看到。但在典型主动双目中，投射器通常不承担第二台已标定相机那样的几何解码角色。不需要先为每颗散斑恢复一个唯一的投影器编号，才能计算 d。

这与下节编码结构光的分岔很清楚：一个是“改善左右对应关系的证据”，另一个是“从已知投影编码中直接恢复对应关系”。

03.3 · 主动纹理额外付出了哪些代价？

新增的条件为什么会影响深度真正的边界
散斑对比度投射纹理需要从环境光中区分出来远距、强太阳光与低反射表面会降低辅助效果
投射可见性投射器与左右相机的光路不同存在投射阴影、左右可见区域不一致
材质反射透明/镜面可能改变光线传播方向错误纹理并不等于目标表面的真实位置
多机与功耗多组主动投射可能互相干扰需要考虑错时、同步、功率和曝光

03.3A · 为什么散斑解决的是“匹配证据”，而不是所有测量难题？

假设一面白墙在两张红外图中灰度完全相同，SAD、Census 都很难区分“左图这一点”究竟对应“右图哪一点”。投射随机散斑后，局部窗口出现独特纹理，对应问题从无解倾向变成可求解。但真正的深度误差仍受 Z²/(fB) 支配。

因此投影器开/关可能大幅改变有效深度点数量，却未必同比改善远处单点几何误差；同时白墙以外的透明、镜面、黑色目标也不一定能正确“接收并反射”这种纹理。

主动双目 vs 结构光：两者都能用红外投射帮助低纹理目标，但前者通常用散斑帮助两个相机互相匹配；后者把投影器图案本身当作几何身份。决定选哪种，不该只看“都有激光点”，而要看对应关系如何恢复、时序与精度代价是什么。

03.4 · 为什么常用于室内机器人，到了室外却可能退回被动双目？

室内物体经常没有足够自然纹理，主动散斑能明显增强匹配证据。但强阳光中大量近红外背景会淹没投射图案，使“人工增加纹理”这一优势减弱。

关键在于：辅助图案看不清，不一定意味着立体匹配公式无法使用。如果现场物体自身有足够的自然纹理，双目图仍可能建立可靠对应。反过来，即使在室内，光滑玻璃瓶也可能因为反射、折射而测不准。

室内机器人

优先考虑的原因

近距、低纹理、不透明物体较多；可以利用投射器增加纹理，输出实时深度。

强日照室外

需要重新评估的原因

主动纹理可能失去对比度。是否仍能使用，取决于自然纹理、曝光、滤光与工作距离。

得到的选择：主动双目不是比被动双目“多了一个直接测距器”，而是多了一种改善输入证据的能力。它尤其适合室内机器人，但不能把“有投射器”理解为弱纹理、透明和室外问题已经自动解决。
04 / STRUCTURED LIGHT · THE MATH FROM ZERO

编码结构光｜我投出去的那一道光，究竟怎样变成 XYZ？

主动双目靠“左眼找右眼”；结构光却提出一个不同的问题：相机拍到的这条亮纹，究竟是投影器发出的哪一条？ 如果知道了它的出发方向，相机的一条视线就可以与投影器的光路求交。下面不跳步骤，从一个像素开始把坐标真正算出来。

对应与几何Gray Code相移与解包裹误差到毫米工业级如何提升

04.1 · 先不投条纹：只知道一条相机射线，为什么求不出深度？

假设相机像素坐标是 (uc,vc)。去畸变、除以内参后，知道该像素对应一个三维方向 dc。空间点只能写成 P = C + λdc，其中 λ 未知。哪怕拍得特别清楚，也无法单靠一条视线把距离确定下来。

P(λ) = C + λ Kc−1[uc,vc,1]T　　（方向需要进一步归一化与坐标约定）

增加第二个已知位置的视角，就能三角求交。结构光的关键是：把投影器视作一台“反向工作的相机”。相机是从物体接收光；投影器从自己的像素位置向空间发射已知图案。事先标定好投影器位置和方向，某个投影像素 up 就对应已知的一束光或一个光平面。

相机的一条观察射线，与已解码投影列对应的光平面求交，通常就能得到唯一空间点；并非一定要知道投影器的二维行列坐标。

第一处常见混淆：RealSense 一类主动双目虽然也会投散斑，但主要在两台接收相机之间匹配对应；编码结构光则是恢复相机像素 ↔ 已知投影图案位置的关系。外观都是红外点阵，求解证据可能完全不同。

04.2 · 用最简单的二维几何，先求一次深度

先使用教学专用的理想模型：相机与投影器都朝正前方，光轴平行、焦距相同、图像坐标已经消去主点、没有畸变，投影器在相机右边 B。设空间点位置是 (X,Z)。

相机看到的像素位置

按照针孔成像，点的横向位置与深度决定相机像素的水平坐标。

uc = f X / Z

投影器发出它的像素位置

在投影器坐标系中，相同的空间点横坐标变成 X − B。

up = f (X − B) / Z

两式相减，未知的 X 消失

只剩相机坐标和投影器坐标之间的“视差” d。

d = uc − up = f B / Z

解出 Z，再回去解 X

Z = f B / d　　 X = (uc / f) Z

这与校正双目最常见的数学式相同，但如何得到右侧对应位置完全不同：双目靠匹配另一台相机，结构光靠解码已知图案。

贯穿本章的数值例子｜从 374 px 走到 1.2 m

取 f = 1000 px，B = 60 mm，相机看到 uc = 374 px。如果投影图案能够告诉我们：它来自投影器的 up = 324 px，则：

d = 374 − 324 = 50 px
Z = (1000 px × 60 mm) / 50 px = 1200 mm
X = 374 × 1200 / 1000 = 448.8 mm

所有像素坐标在本例均按已去主点、已极线校正的理想坐标表示。真实设备用相机内外参、投影器几何和标定后的射线/光平面求交，不要求两者必须平行或焦距相同。

现在只剩一个真正的难题：相机拍到一个亮点，怎么知道它来自投影器第 324 列，而不是第 325 列、第 724 列？ Gray Code 和相移法，正是为这个问题而出现的。

04.3 · Gray Code：给投影器列编号，不再猜它是哪一列

先假设投影器只有 8 列。需要区分 8 种身份，就要 3 个二进制位。最容易想到的办法是连续投射 3 张黑白条纹图：在第 1 张中记录第一位，在第 2 张中记录第二位，在第 3 张中记录第三位。相机同一个像素看到的亮/暗序列，就组成这列的身份。

Gray Code 的相邻投影列只改变一个编码位。示意第 5 列的三个灰度读数为 1、1、1；对该列解码得到 Gray 111。

为什么使用 Gray Code 而不是普通二进制？因为相邻列在亮暗边界上如果多个 bit 同时跳变，稍微错位就会组成相距很远的错误列。Gray Code 保证相邻编号只变化一位，降低这类边界误解码的严重性。

一个实际解码｜Gray 111 为什么等于第 5 列？

Gray 码不能直接把 111 当成二进制 7。它需做逐位异或还原：

g = 111　 →　 b2 = 1，b1 = 1⊕1 = 0，b0 = 0⊕1 = 1
b = 101(2) = 5

于是投影器的第 5 列有了确定身份。在 1024 列的投影器上，理论至少需要 ceil(log₂ 1024) = 10 个编码位；实际还可能投反相图、白/黑参考图来增强判读可靠性，采集数量因此增加。

Gray Code 的优点是绝对身份：哪一列通常不会和另一列混淆。但只用二值编码，识别精度受到投影像素、图案边界、成像模糊等限制。对于希望得到亚像素级投影位置的测量，接下来要改变思路：不只判黑/白，而是测量亮度变化的连续相位。

04.4 · 相移法：不再给每列一个硬编号，让亮度告诉我落在周期的哪里

在投影器上放出正弦条纹。某一像素处的亮度，不再只有 0 或 1，而是在一个周期内连续变化。为了排除未知表面反射率、背景亮度对单次读数的影响，我们让同一条纹依次移动三个相位：0、120°、240°。

I0 = a + b cos(φ)
I1 = a + b cos(φ+2π/3)
I2 = a + b cos(φ+4π/3)

这里 a 是背景亮度，b 是条纹调制度，φ 才是我们关心的位置。看起来有三个未知量，但三张图恰好给出三个方程。

先用相减消去背景亮度 a

三个相位均匀分布，利用余弦和差恒等式，可以得到正交的两组量。

C = 2I0−I1−I2 = 3b cosφ
S = √3 (I2−I1) = 3b sinφ

再把未知的条纹幅度 b 约掉

把 S,C 看成平面向量，其方向就是相位角。

φ = atan2(S,C)

相位角就代表周期内的位置

在一条宽度 T 的投影条纹周期内，φ/(2π) 是周期内的细分比例。

ulocal = (T/2π) φ　 （设相位零点和方向已约定）
代入真实数字｜亮度 100、70、130，为什么是 90°？

同一个相机像素在三张相移图里的测量值为 I₀=100，I₁=70，I₂=130：

C=2×100−70−130=0
S=√3×(130−70)≈103.92
φ=atan2(103.92,0)=90°=π/2

这意味着它位于该条纹周期的 1/4 位置。没有预先知道这个表面的反射亮度是多少，也能恢复它在周期内的相位。

符号和偏移正负取决于图案生成及图像索引约定；上面三式与计算保持同一约定。要用正弦模型，仍需非饱和、非极暗、足够调制度和同一点跨帧一致。

04.5 · 相位已经比二值编码细，为什么仍然算不出绝对位置？

如果投影器上摆着 64 条完全相同的正弦条纹，每个周期中间都可能测得 φ=π。只知道周期内的细位置，仍然不知道来自第几个周期。这个问题叫相位包裹。

Φ = φ + 2πk，　up = u0 + T·Φ/(2π)

其中 k 是条纹周期编号。解决途径至少有三类：Gray Code + 相移 用二值条纹给周期编号；多频/多波长相移 用多个周期长度共同推断绝对周期；空间相位展开 利用邻域连续性，但可能被台阶、遮挡、物体分离等条件破坏。

把全部链条接起来｜我们终于得到了第 324 列

现在回到 04.2 的数字例子。设投影器每条正弦条纹周期宽 T=16 px，Gray Code 或多频方法告诉我们当前在第 k=20 个周期；相移测得 φ=π/2。

up =16×(20+ (π/2)/(2π))
up =16×20.25 = 324 px

相机像素 uc=374，于是 d=50 px，刚才的 Z=1200 mm 就不再是一笔假设，而是从“编码 + 相移 + 三角几何”完整走出的结果。

投射已知图案→相机逐像素读亮度→解周期 k→解相位 φ→恢复 uₚ→标定几何求交→XYZ

04.6 · 真正的设备并不平行，甚至可能只投“竖条纹”：还算得出来吗？

可以。上面平行模型只为了把数学关系看清。真实设备会标定相机内参 Kc、投影器模型 Kp、二者相对旋转与平移 R,t。相机像素给出一条三维视线；解码的投影器一列，对应空间的一张光平面。一条射线与光平面相交，就得到空间点。

相机射线：P(λ)=C+λdc
投影光平面：nT(P−Q)=0
λ = nT(Q−C) / (nTdc)

其中 Q 是光平面上的已知点，n 是其法向量。若分母接近零，射线与光平面几乎平行，三角交会会非常不稳定。这就是几何角度为何直接影响测量精度。 如果设备同时得到投影器的完整 (uₚ,vₚ)，也可以采用两条射线的最小距离三角化。

04.7 · 为什么多帧结构光最先输给了运动，而不一定输给噪声？

Gray Code 的 bit 0、bit 1、bit 2，或者相移的 I₀、I₁、I₂，数学上默认是同一个表面点的不同照明观测。运动时，相机同一像素可能先看到瓶身、后来看到背景；甚至表面没换，只是移动了几个像素，也会让亮暗串错位，组合出不存在的投影坐标。

Δu ≈ f · v⊥·Tcapture / Z　 （近似横向像素位移）

例如 f=900 px、Z=1m、物体侧向速度 v=0.5m/s，整组编码用 20ms：像素移动约 9px。如果采集缩短为 5ms，仍约 2.25px。这解释了为什么动态测量需要单帧空间编码、高速图案/快门、运动补偿或并行成像，而不能只依赖静态情况下更细的相移算法。

结构光分支如何拿到投影位置典型优势真正支付的代价
单帧空间编码 / 伪随机图案在一帧图案的局部邻域中识别身份采集时间短，具备动态潜力编码唯一性、邻域完整、纹理对比度；细节可能受限
Gray Code多帧二值身份绝对对应清晰跨帧一致性，通常需要多次曝光
N 步相移周期内相位亚像素位置精细的对应定位相位折返、调制度、非线性和运动
Gray + 相移 / 多频既得周期身份，也得周期细位置大范围与细分辨率兼顾帧数、同步、曝光及完整率
高速/并行结构光改变时序、编码和采集硬件让高速工件保持时域一致硬件复杂度、吞吐、信噪比、眼安全
不要把“投射激光”与“高速”划等号，也不要把“30 fps 输出”当成“30 fps 内投射了 30 张 Gray Code”。深度帧率、每份深度使用的原始曝光数量、总采集窗口，是不同指标。

04.8 · 到了工业精度，究竟是哪一个误差被放大了？

从 Z=fB/d 出发，对视差做微小扰动，得到非常重要的一阶误差传播关系：

|δZ| ≈ (Z² / (fB)) |δd|

这里 δd 是相机与投影器对应位置的估计误差，包含图案解码、相位估计、成像像素定位等误差。结构光提高精度，很多努力首先是在把 δd 减小；但也必须控制 f、B 的标定、畸变和工作温度。

统一设定｜f=1000 px，B=60 mm，Z=1.2 m

上例 d=50 px，此时 Z²/(fB)=24 mm/px。深度误差随对应位置误差变化：

等效对应误差 δd估计 Z 误差 |δZ|意味着什么
1.0 px约 24 mm粗匹配，深度非常容易跳变
0.20 px约 4.8 mm做了亚像素定位，仍有毫米级误差
0.05 px约 1.2 mm更稳定的相位/图案定位
0.02 px约 0.48 mm但还没计入几何系统误差

这些是理想化误差传播，不是任何产品实测值，也不意味着提升图案细分能力就必然达到相应绝对精度。

04.9 · 相移为什么能够把对应误差压到亚像素？

相位本身是一种连续估计。条纹周期宽 T，小的相位误差 δφ 对应投影位置误差：

δup ≈ (T / 2π)δφ

把它接在三角测量误差后面：

|δZ| ≈ [Z²T/(2πfB)] · |δφ|
同一组设备｜改进相位估计能省下多少毫米？

仍设 Z=1200 mm, f=1000 px, B=60 mm，条纹周期 T=16 px。

相位误差等效投影位置误差理想 Z 误差
0.20 rad0.509 px12.22 mm
0.05 rad0.127 px3.06 mm
0.01 rad0.0255 px0.61 mm

这才是“使用更精细的条纹、采更多帧、提高投影对比度”如何通向毫米精度的真实路径。只是它改善了相位随机误差，无法自动修好错误标定造成的整幅点云弯曲。

04.11 · 为什么增大基线、缩窄视场也能变准，却不能无止境增大？

误差式里 fB 在分母：相同距离、相同像素对应误差下，增大有效基线 B 或焦距 f 都能提高三角测量对深度变化的敏感度。

改动理想优势反过来发生什么
基线 60 → 120 mm相同 δd 时，深度误差约减半遮挡区增大，近处两视图共同区域变小，体积增加
焦距 1000 → 2000 px（像素单位）同条件误差约减半同样像元数下视场通常变窄；更依赖稳定对焦和标定
测距 1.2 → 2.4 m没有直接优势对应误差不变时，深度误差约变为 4 倍

因此“工业相机精度更高”，有时并不是深度网络或滤波算法突然高级了，而是专门为一个工作距离设计了光学几何、较窄视场、较长或优化的基线，以及充分的光学标定。要注意，同视场约束下无法单独任意改变这些参数。

04.13 · 四个常被写在“精度”一栏、实际完全不同的指标

PRECISION

单点重复性

同一静态点反复测量的 Z 有多分散。平均多帧可能改善随机波动，不保证消除偏差。

TRUENESS

绝对准确与尺寸真值

相机一直测出 1002mm，但真值为 1000mm，即使结果丝毫不抖，也存在 2mm 偏差。

SPATIAL DETAIL

空间细节能力

两条相距很近的棱边能不能分开；取决于光学成像、投影、采样和算法，不等于单点重复性。

COMPLETENESS

有效深度与物体边界

玻璃、黑色或反光区域有多少有效点，真实台阶有没有被抹平；“看起来平滑”不是指标。

工业规格常把重复性、尺寸真值、全局平面弯曲等分开定义。某个设备在 1m 表现出 0.05mm Z 向重复性，并不意味着它在整个视野里的绝对尺寸误差也是 0.05mm，更不意味着可以测出 0.05mm 宽的细线。

04.14 · 还有一个常被忽略的事实：精度提升不是免费的

静态小工件：可以把更多时间换成更多条纹、更好的相位统计、更合适的曝光，以及更稳定的标定；这时工业结构光非常有竞争力。

传送带运动工件：再多的相移帧反而可能采错物体位置。更快、单帧或并行的结构光可能比慢速高精度模式更有意义。

玻璃瓶与镜面：多曝光只解决亮暗范围的一部分问题，折射、镜面多次反射造成的错误对应仍可能需要改变光学几何、表面处理或承认不可测。

这一章最终想清楚了：结构光不是“投条纹，所以精度高”。它从身份 k → 细位置 φ → 投影坐标 uₚ → 几何求交 XYZ，每一步都有自己的误差。工业系统正是在减少这些误差、控制标定偏差、适应特殊材质的同时，接受更长采集时间、更窄工作范围或更高硬件成本。

延伸核对：Mech-Eye V3 基线/重复性/采集时间 · 梅卡条纹 Fast/Accurate/Reflective · Zivid 精度术语

05 / TIME OF FLIGHT

ToF｜不找左右对应，怎样从光里算出距离？

前面几种方案终究依赖角度与几何求交。如果我们发出一道光，再让它返回，能不能直接通过往返过程估计距离？这就是 Time of Flight 的出发点。

05.1 · dToF：直接记录传播时间，究竟有多难？

r = cΔt / 2 （理想往返光程，c 为光速）

光走到 1 m 处的目标再返回，往返时间仅约 6.67 ns；1 mm 距离变化对应的时间差只有约 6.67 ps。普通软件时钟无法承担这种测量。实际系统会使用高速光电探测器、SPAD（单光子雪崩二极管）、时间数字转换器等硬件。

一条典型的直接测时路线是：反复发出短脉冲，记录收到光子事件的时间，把事件累积成时间直方图，再从背景噪声中找出可信回波。某些系统可在时间维度上分辨不止一个回波，但效果取决于光子数、时间分辨率和回波分离能力。

发射短脉冲→回波时间事件→时间直方图→寻找可信回波→r

弱反射目标可能几乎没有有效光子，强背景光会带来噪声事件；探测器死时间和 pile-up 也可能偏置统计结果。这条路线的核心困难，是从有限且有噪声的光子事件中估计可信时间。

05.2 · iToF：计时太难，能不能测周期信号的相位？

不直接测单次脉冲时间，而让发出的近红外光强随时间周期变化；返回信号相对于发射信号会产生相位滞后。假设调制频率为 fm、延迟为 Δt：

φ = 2πfmΔt，　r = cφ / (4πfm) （单频、单主回波、未折返）

现在问题从“如何测皮秒的绝对时刻”变成“如何估计周期信号的相位角”。这需要多个相关采样，而不是直接从一张普通亮度图读出相位。

05.3 · 四相位采样：4 个读数怎样得到 1.99 m？

以常见的相关采样教学模型为例，分别使用 0°、90°、180°、270° 的参考相位，得到 C₀、C₁、C₂、C₃。让相隔 180° 的两组相减，消去共同背景项：

A = C₀ − C₂， B = C₃ − C₁， φ = atan2(B, A)
采样相位0° / C₀90° / C₁180° / C₂270° / C₃
相关读数12142826

因此 A = −16、B = 12，恢复的相位约为 143.13°。当 fm = 30 MHz，代入单频理想往返关系：

r = c × 2.498 / (4π × 30 × 10⁶) ≈ 1.99 m

注意这只是让人理解相位恢复的数值模型。实际 iToF 芯片的采样、正负号约定、调制度校正与多频处理可能不同；内部得到的光程距离也未必就是 SDK 中的 Z。

05.4 · 为什么相位算对了，距离还可能错 5 米？

相位每隔 2π 就会重复。单频 iToF 在理想情况下的无歧义距离范围：

Runamb = c / (2fm)

30 MHz 对应约 5 m 的周期；理想模型中 2 m 与 7 m 可产生相同包裹相位。利用多个调制频率可以共同消除部分周期歧义，但也增加采集、标定和跨频率一致性的难度。

调制频率单频无歧义距离假设 1° 相位误差所致距离误差
10 MHz约 15 m约 41.7 mm
30 MHz约 5 m约 13.9 mm
60 MHz约 2.5 m约 6.9 mm

这里假设相同的相位误差，只展示公式比例；真实芯片的相位噪声与硬件带宽会随频率而改变，不能把表格当成产品精度。

05.5 · 多路径：为什么能测出一个根本不存在的 1.5 m？

四相位公式通常假设一个像素的主要回波来自一条光路。但是墙面、瓶身、桌角之间可能发生多次反射；传感器接收的是不同传播时间回波的叠加。

在 30 MHz 时，1 m 与 2 m 分别对应约 72° 与 144°。若两条回波强度相同，合成相位向量恰好指向约 108°，单相位模型会给出 1.5 m——而真实场景里可能根本没有任何表面位于 1.5 m。

S = Aej72° + Aej144°　 ⇒　 arg(S) = 108°　 ⇒　 rapparent = 1.5 m

这就是 Multi-Path Interference（MPI）。它造成的是偏差，不是简单随机噪声；多帧平均可能让错误结果看起来更加平滑。

05.6 · 为什么回波太弱和太强都会出问题？

可以把相关采样恢复出的 (A,B) 看成一个二维相位向量。方向决定相位，长度反映调制信号强弱：

Amplitude ∝ √(A² + B²)，　Phase = atan2(B,A)

物体太暗、距离太远、红外照明不足时，向量几乎为零，微小噪声都会明显改变相位角。反过来，近距离高反光使接收信号饱和，相关曲线被截断，解相位的数学模型同样被破坏。

05.7 · 为什么物体边缘可能出现不属于任何表面的深度？

一个成像像素或光学点扩散区域可能同时覆盖前景瓶身和后方墙面。即使不存在复杂多次反射，接收端也可能混合两个深度的信号。这种 Flying Pixels / Mixed Pixels 往往集中在物体轮廓、细杆、凹角附近。

空间滤波虽然能降低随机起伏，却也可能把前景和背景进一步混成假表面。应该先理解错误产生的机制，再决定是否滤波。

05.8 · 运动目标不是 ToF 的天然胜利

iToF 能面阵并行获得密集深度，因而很适合实时感知。但有些实现的多相位或多频测量跨越多个采样窗口。如果物体在此期间移动，四个读数可能来自不同物理位置，无法再用同一个相位模型解释。

更适合动态的条件

短采集窗口 + 足够信噪比

采样够快、运动模糊有限、回波可靠时，可以稳定输出运动场景深度。

动态风险

多相位/多频不一致

较长积分、多次曝光与高速边缘运动容易产生拖尾、空洞和偏移。

05.9 · 为什么拍 100 帧，稳定偏差也不会自己消失？

调制电路相位偏置、温度变化、像素间延迟、光路几何误差和距离非线性都可能带来系统误差。平均 100 帧可以压低一部分随机波动，却不会自动消除稳定的 10 mm 偏差。

05.12 · 设备内部的光程 r，为什么不等于 ROS Depth Map 的 Z？

ToF 内部根据传播时间或相位估计的距离，通常首先关联发射/接收光路；实际传感器的深度图可能已经经过几何模型、像素标定和坐标转换，最终输出相机光轴方向的 Z-depth。

例如 Orbbec Femto Bolt 的深度数据文档将有效像素定义为相机坐标下、以毫米为单位的 Z 值。不能把所有设备输出的深度整数都理解为沿像素射线的欧氏距离。

05.13 · 既然 ToF 不找纹理，为什么它没有替代双目和结构光？

答案不是“哪种技术更先进”，而是观测代价不一样。ToF 能在一些低纹理表面获得密集深度，不需要左右匹配；但在玻璃、镜面、凹角、高反光、细小边缘等场景中，回波强度和传播路径反而成了新困难。

得到的选择：实时密集感知、低纹理表面、适当工作距离，是优先研究 iToF 的常见理由；需要细小结构、严格尺寸检测时，仍值得优先研究高质量结构光。运动物体可以选择 ToF，但不能仅凭“运动”二字排除同步双目和高速结构光。

05.14 · 为什么有人说 ToF 更适合运动？先把“运动”拆开

说 ToF 适合运动并非完全错误。它的吸引力在于：每个像素可以在不搜索左右对应、也不识别投射图案身份的情况下，直接从回波信号估计距离。 对低纹理人体、宽视场动态空间感知，这很有价值。但所谓“更适合”，必须指向一个明确的比较对象。

拿来比较的对象ToF 真正赢在哪里它并没有赢在哪里

vs 主动双目无需寻找左右散斑对应，某些低纹理面更直接主动双目也可以全局快门实时输出；强反射、多径下 ToF 未必更可靠

05.15 · 一个运动数字例子：帧率 30 fps 不等于每个像素采集了 33 ms

决定运动伪影的是实际积分/曝光时间、不同采样之间的时间跨度、传感器读出方式和同步方式。标称 30 fps 只说明深度输出的时间间隔约 33 ms，不表示每一份深度一定持续曝光 33 ms。

对于 ToF，某些芯片可在像素或电荷域高效收集相关采样，另一些则需要时序子曝光或多个频率。因此要看完整深度采集窗口，而不是把“iToF”自动等同于“单瞬间”。Femto Bolt 公布的不同模式具有不同曝光时间，也是实际选型更值得研究的指标。

05.17 · 室外强光下为什么不是简单的“ToF 胜出”？

强阳光包含大量红外背景光。对于主动双目，它会降低主动散斑的对比度；对于结构光，它会影响图案解码的信噪比；对于 ToF，它会抬高背景电荷/光子噪声，甚至造成饱和。被动双目不用主动红外投射，可以在有自然纹理和足够曝光控制的场景下继续工作。

这四者真正的环境边界：双目需要“可对应的局部外观”，结构光需要“可辨认的投影身份”，ToF 需要“可分离且可信的回波时序/相位”。太阳光、反光、纹理缺失，只是在破坏不同的证据。

06 / THE COMMON OUTPUT

Depth Map｜为什么最后还要统一数据定义？

走过这些不同的测量路径，最终都可能拿到一张“深度图”。可是它们内部估计的物理量完全不同，最后的像素数值必须有明确的几何含义，才能用来反投影。

06.1 · 相机 Z-depth 和 Ray-distance 不是同一个量

量含义能否直接代入针孔反投影？
视差 d左右图对应像素的水平位移不能，需先做三角测量
结构光编码/相位投影器身份或位置不能，需先解码/三角测量
ToF 时间/相位光传播延迟的观测量不能，需按设备模型转换
Z-depth相机坐标系里的 Z 分量可以，需匹配相机内参与畸变模型
Ray-distance沿单位视线方向的欧氏距离不能直接作为 Z，要先按射线方向转换

对于理想去畸变后的针孔模型，假设像素 (u,v) 的归一化成像平面坐标为：

x = (u−cx)/fx，　y = (v−cy)/fy
Z-depth：P = Z · (x, y, 1)
Ray-distance：P = r · (x, y, 1) / √(x²+y²+1)

把一张 Ray-distance 误认为 Z-depth，边缘像素的重建位置就会出现系统偏差；反过来也一样。

06.2 · 图像中的数值 1000 代表 1000 什么？

16UC1 只是存储类型，并不自动规定物理单位。很多 RGB-D 驱动将它约定为毫米，因此 1000 对应 1 m；32FC1 常用米作为浮点深度单位。无效值可以是 0、NaN 或设备定义的标记，需要查看具体驱动。

深度图对齐到另一台 RGB 相机后，像素网格可能从一个分辨率变成另一个分辨率，但这不表示新增了同等数量的独立深度观测。重投影还会带来遮挡、重采样和空洞。

07 / INDUSTRY EXPLORATION

业界怎么做？｜从三家厂商的选择，反过来看测距技术

前面已经知道深度怎样算出来了。现在换一个问题：当一家公司真正需要做一台相机，为什么会采用某种测量原理、某种投射方式和某种采集模式，而不是另一种？

这里不做十几家品牌的参数排行榜，也不假装知道厂家没有公开的芯片算法。我们只追三条有辨识度的实际技术路线：RealSense 的通用实时双目、Orbbec 的多路线产品布局、梅卡曼德的工业结构光。其余公司只在出现新的技术思想时顺路探访。

CASE 01 · REALSENSE

07.1 · RealSense｜为什么通用机器人喜欢主动双目？

看一台熟悉的 RealSense D435i：左右红外相机提供立体观测；红外投射器帮助低纹理场景增加可匹配细节；硬件深度处理器负责从图像得到深度；额外的 IMU 提供惯性测量，但IMU 不负责给双目公式直接提供距离。

左右 IR+可选的 IR 纹理投射→立体对应→视差→Depth Map

先问第一个问题：既然都主动发光，为什么不是结构光或 ToF？

因为投射器在典型 D400 主动双目中主要改善匹配纹理。它不要求将每颗红外散斑唯一解码为投影器像素，也不使用调制光飞行相位作为主要测距证据。这让它继续沿用双目几何的优势：利用同时看到的两幅图像直接求视差。

再问第二个问题：为什么 D435i 对运动场景有价值？

D435i 的深度红外传感器采用全局快门，左右图可以更好地对应同一时刻的运动场景，避免滚动快门带来的部分几何形变。不过 RGB 传感器与深度传感器的快门特性不能混为一谈：D435i 的 RGB 侧为滚动快门。

追加观察：同样拍动态瓶子，为什么 D435i 可能比慢速精密结构光更合适？

全局快门同步捕获两幅 IR 图，要求的是一次曝光内目标清楚、左右看见相同瞬间；多帧 Gray Code / 相移要求整段编码窗口里目标基本一致。当瓶身移动时，这是两种截然不同的时序约束。

RealSense 的选择不是“主动双目测得比工业结构光更细”，而是“对运动目标不必等待完整编码序列”。近距离、低纹理面则可以靠红外纹理提高成功匹配概率；代价是依赖纹理、遮挡与深度误差随距离增大。

最后一个问题：D455 为什么又改变了工作距离的取舍？

双目距离误差近似满足 |δZ| ≈ Z²|δd|/(fB)。为了更好的远距精度，可以适当增加有效基线 B；但这也影响近距离共同视野、遮挡与结构尺寸。D455 面向更长工作距离，同时深度和 RGB 传感器都使用全局快门，是另一组针对机器人应用的平衡。

观察维度D435 / D435i 的选择D455 的延伸
根本原理主动 IR 双目三角测量仍是主动 IR 双目
运动观测深度端全局快门；D435i 增加 IMU深度与 RGB 端均为全局快门

缺点仍存在弱纹理、遮挡、透明/镜面、强光投射受限基线与场景条件的几何代价仍存在

D435i 与 D455 的标称距离、精度会随设置和场景改变，不能把型号的推荐工作区间直接当成实际抓取精度的保证。内部专有匹配算法的细节以公开文档为准。

从 RealSense 学到的：主动双目真正吸引人的，是实时性、相对简单的图像对应链、对自然纹理与主动纹理的兼容。它追求的不是在所有材质上达到最高测量精度，而是在相机体积、视场、工作距离、运动与部署成本之间取得平衡。

07.2 · Orbbec｜为什么一家厂商同时采用多条测距路线？

如果只看一台深度相机，似乎某种原理已经足够。但把 Orbbec 的产品放在一起，情况变得有趣：同一家厂商同时提供被动双目、主动双目、结构光和 ToF 产品。原因不是无法判断哪项技术“最好”，而是任务目标完全不同。

01 · Gemini 305：为什么短基线反而有意义？

Gemini 305 面向机械臂腕部近距离观察，官方给出 18 mm 双目基线与约 4 cm 起的工作能力。短基线在远距离会降低视差敏感度，但在极近距、轻小体积和共同视野方面有独立价值。它的存在提醒我们：更长基线不是无条件更好。

02 · Gemini 2：什么时候需要自己制造纹理？

Gemini 2 官方明确采用 Active Stereo IR。室内机器人常见塑料外壳、低纹理面、包装物等场景，自然图像未必给出足够好的局部对应；主动 IR 提供辅助纹理，就能让已有的立体匹配链更有机会工作。至于具体芯片内部采用哪一类代价函数，不从产品名称猜测。

03 · Astra 2：它是结构光，为何又能实时输出 Depth Map？

Astra 2 官方归类为 Structured Light，提供可实时输出的较高分辨率深度。这里应当认识到：结构光是“通过已知投影图案建立几何对应”的技术总类，不等于某一个具体的多帧 Gray Code 实验流程。

若厂商没有完整披露帧级编码方案，就不能仅凭“结构光”和“30 fps”倒推出它使用哪一种 Gray Code、相移或单帧空间编码。可核对的是公开的原理类别、工作环境、距离、视野和测量指标；未知部分应明确保留。

04 · Femto Bolt：什么时候会从立体匹配直接转向 ToF？

Femto Bolt 采用 ToF 路线，公开规格提供不同视场与帧率模式。它不依赖图像左右纹理对应，更适合讨论室内大范围密集深度、低纹理表面与空间感知；代价则转向相位歧义、多路径、反射率、边缘混合和深度校准。

观察这四台设备会发现，厂家所面对的不是单个“相机精度”指标，而是尺寸、工作距离、场景材质、采集时间和成像质量的不同组合。

从 Orbbec 学到的：四条路线同时存在，就是因为目标类型、工作距离、光照和运动条件之间不存在唯一最优解。尤其要区分 Gemini 2 的“主动红外双目”和 Astra 2 的“结构光”，不能因两者都主动投红外而混为一类。

CASE 03 · MECH-MIND

07.3 · 梅卡曼德｜为什么工业结构光与通用结构光价格会差这么多？

有了前面的结构光分支，再看梅卡曼德就不应该只问“它的像素数是多少”。更值得研究的是：为了应对不同工件、距离与反射特性，工业系统怎样改变投射器类型、条纹采集方式、曝光条件和可量化的测量性能。

01 · 同叫 Mech-Eye，为什么出现 DLP 与 Laser 两条实现？

以文档中 V4 系列为例，PRO S、PRO M、NANO 使用 DLP 投影体系；LSR L、DEEP 则采用激光结构光设计。它们属于结构光家族，但并不意味着投射方式、接收相机配置、视场、工作距离和编码策略全部相同。

DLP 投影结构光PRO S / PRO M、NANO主动投射可控图案，通过相机—投影几何恢复表面定位、装配、近中距精细测量、工业抓取

这里也要避免另一个误会：带激光投射的结构光相机不一定就是一条激光线从左扫到右的单线轮廓仪。Mech-Eye 不同机型可能采用多个相机和不同编码条纹，必须按该机型公开说明理解，不能用“激光扫描”四个字替代其机制。

02 · Fast / Accurate 到底改变了什么？

梅卡曼德官方把 Fringe Coding Mode 定义为会改变投射结构光图案及采集结果的模式。Fast 优先减少采集时间，Accurate 则通常用更长采集换取更高质量的深度数据。这不是简单给同一张深度图换个后处理滤镜，而是涉及测量证据如何被采集。

FAST

采集时间优先

对静止时间短、生产节拍敏感的工件更有吸引力，但原始深度质量可能下降。

ACCURATE

测量质量优先

允许更多或不同的编码观测，提高有效重建质量，但采集时间更长，对运动更敏感。

相关型号还可能支持针对反光材质的采集模式、投射亮度和曝光调整。不过不能断言所有代际、所有型号都拥有相同模式；是否提供 Reflective、Fast 或 Accurate，要查看该机型与软件版本。

对照观察：两家“结构光”官方标称，为什么不能直接按一个数字排名？

Orbbec Astra 2 公布结构光、最高 1600×1200@30fps，并给出 1m 时 ≤0.16% 一项深度性能指标；梅卡 Pro S Enhanced（V3） 在 1m 提供 0.05mm 的 Z 向重复性及 0.1mm 的测量准确度，但典型采集时间约 0.5–0.8s。

这两组规格表面上看相差量级很大，实际上性能定义并不一致，不能直接作百分比和毫米的一对一判决；它们反映的首先是不同的速度/测量目标。想公平比较，必须在同一距离、共同视场和同一标准靶上，分别测量重复性、尺寸真值、空间细节、无效点与完整采集时间。

再反推：为了获得这一级别的重复性，可能做对了哪些事？

先从 04.8 的误差式入手。如果目标 1m、几何敏感度达到了每 1px 对应数毫米至十余毫米深度变化，那么 0.05mm 的 Z 波动意味着等效投影对应噪声可能需要控制到远小于 0.1px，同时满足合适的基线、焦距和相位质量。工业系统可以通过高调制度条纹、亚像素相位定位、精确标定与稳定光学来共同实现，但仅凭公开重复性数字无法倒推出具体内部算法或单项误差预算。

这样就能理解 Fast/Accurate 的真正意义：它不是一键把某个算法“变聪明”，而是在增加有效观测、改善对应置信度与采集代价之间切换。

03 · 为什么工业相机的测量规格不能只看“精度 0.1 mm”？

以公开的 PRO S 工业规格为例，厂家会在规定的工作距离与测试条件下分别提供Z 向重复性和测量准确度等指标。重复性回答“同一个点反复测量会波动多少”；测量准确度则还要回答“测得的结果偏离真实参考多少”。

这一点和上一节 ToF 的系统误差/随机误差形成对应：一个结果完全可以非常稳定，却一直偏离真值。工业相机售价差异不能脱离温度稳定、光学标定、采集策略、工作距离以及这些验证指标来讨论。

04 · 为什么“结构光不能室外”也不是绝对结论？

典型低功率、多帧投影结构光在强环境光下确实容易失去编码对比度。但工业机型可以采用不同投射方式、光学滤波、曝光与专门采集模式提升强背景光下的表现。梅卡曼德在 LSR 等型号的应用说明中就强调对工业环境光的适应性。

因此真正的问题是：工作距离和环境照度下，投影条纹能否被清晰且稳定地观测到？而不是看到“结构光”三个字就一概排除室外或工业强光。

回到最初的价格疑问：低价实时结构光与工业结构光，在大类上可以基于相同的三角测量思想，但不必使用相同的图案与解码流程；即使某些求解方法相似，光学器件、标定、采集方式、材质适应能力和测量规格也能带来巨大差异。应先分辨技术分支，再比较在同一工作条件下的真实测量能力，不要只拿商品价格或深度分辨率做推论。
从梅卡曼德学到的：工业结构光的核心价值不止是“投射编码更精细”，还在于知道什么条件下得到可靠的三维结果，并通过模式、光学系统和标定，控制精度、速度、材料和环境之间的代价。

Zivid

把多次采集变成测量能力

研究工业结构光如何通过不同曝光与 HDR 采集策略，在暗色、高反光和复杂材质之间改善可靠性。重点不是品牌参数，而是曝光组合怎样改变可用测量证据。

Photoneo MotionCam-3D

运动工件也能使用结构光

Parallel Structured Light 等高速成像思想说明，多帧结构光怕运动，不代表整个结构光家族只能测静态工件。

技术延伸 A｜Zivid：为什么同一个物体需要三组曝光？

假设一个工件同时有镜面金属和黑色塑料。短曝光能够避免金属高光烧白，却让黑塑料几乎没有条纹；长曝光能看清暗部，却让高光失去相位信息。这不是条纹解码公式不够聪明，而是输入信息早已丢失。

曝光高光金属中等反射区域暗色塑料用途
很短不过曝，可计算相位偏暗严重欠曝保住高光证据
中等局部饱和有效略暗覆盖普通区域
较长过曝可能过亮有效补足暗部证据

Zivid 文档展示的 HDR 思路是组合多组不同采集参数，让各区域至少有一组可用的结构光观测。它提升的是动态范围与有效表面覆盖，并不是简单把同一个深度点平均三次。静态零件可以付出额外采集时间；如果工件在移动，HDR 也需要面对组间错位。

再进一步，Zivid 对透明物体还提供针对性视觉引擎和预设，并提醒透明物体可能把背景错测成自身表面。这说明高价工业相机解决的是“哪些证据可信”，不只是把随机误差降到最低。

技术延伸 B｜Photoneo：不让“多种编码信息”沿时间排队

如果高精度需要多种投影信息，而运动又不允许连续曝光，能否让这些信息在同一次采集中并行获得？Photoneo 的 Parallel Structured Light 是很有启发的回答：它使用专用 CMOS 传感器及像素/快门编码，让一个采集窗口内形成多个虚拟编码观测，不是常规意义上连续投射 Gray Code 并让工件保持静止。

常见多帧条纹：信息放在时间轴→跨帧运动风险
Parallel Structured Light：编码能力移向传感器采集结构→单次窗口获得多个虚拟观测

这条路线的重要性在于它直接改变“测量证据如何被采集”，而不只是把传统相移公式跑得更快。专用硬件和复杂传感器设计是它的代价。Photoneo 官方还区分 Camera 动态模式与 Scanner 静态模式，意味着运动能力和极致静态精度仍存在权衡。

这两条延伸非常值得记住：Zivid 的想法是多次采集不同证据来覆盖复杂材质；Photoneo 的想法是改变信息采集结构，避免动态场景必须按时间顺序凑齐多幅观测。它们不是再列两个品牌，而是在原有物理框架外，展示两种有意思的工程创新。

所有方法最终都必须回答

输出的究竟是 Z 还是沿射线距离？哪些像素有效，标定条件与误差来源是否清楚？

这次真正得到的结论：不存在适合一切物体和场景的深度测量原理。技术之间不是谁更高级，而是把困难放在了不同的观测证据上。理解证据从哪里来、什么时候会失效，才知道为什么会做出不同的相机设计。

下一段探索再去研究：当相机已经给出了深度，怎样减少噪声、判断无效观测，以及为什么“深度图变平滑了”不代表测量就可靠。之后再进入标定对齐与完整的测量可信边界。

08.1 · 一个具体选择：运动饮料瓶与静态机械零件，为什么不该用同一张榜单？

场景 A · 动态

1m 外传送带上的饮料瓶

瓶子以 0.5m/s 运动。首先检查 5–20ms 内位移是否足以破坏跨帧采集，再检查标签、瓶身透明与高光区域提供哪一种可信证据。同步全局快门双目和短窗口 ToF 值得优先试；慢速 Gray+相移需要额外论证。

场景 B · 静态

固定夹具上的小型金属工件

允许 0.5s 采集、要求稳定轮廓与尺寸。更适合研究相移混合编码、专用工作距离标定、HDR、对反光表面优化的工业结构光；ToF 的高帧率可能完全不是第一指标。

08.2 · 再压缩成一个真正可以反复使用的判断顺序

先问物体提供什么证据

有自然纹理吗？表面是漫反射、透明、镜面、黑色还是混合材质？

再问物体给你多少时间

它是否运动？速度多大？允许多少毫秒的完整测量窗口？是否能同步曝光？

最后问你究竟需要多准确

只是判断有障碍，还是求毫米级抓取位置，或者检验 0.1mm 的零件尺寸？可用点比例、重复性、真值误差不是一回事。

再让四条原理接受检验

双目看对应是否可靠；结构光看编码是否解得出来；ToF 看回波相位/时序是否可信；最后把深度误差传播到真正的三维任务。
