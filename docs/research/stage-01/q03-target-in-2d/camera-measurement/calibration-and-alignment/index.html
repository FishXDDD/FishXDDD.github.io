THE STARTING POINT

我们究竟默认了什么？

反投影公式已经告诉我们，如何利用一个像素的位置和深度恢复三维坐标。但仔细想想，公式其实默认了不少事情：焦距和主点是已知的，镜头满足选定的相机模型，像素和深度能够正确对应。

现实中的 RGB-D 相机未必天然满足这些假设。与其继续往公式里代数值，不如回到观测本身，逐个弄清这些关系从哪里来。

01

Camera Model & Distortion

相机模型与畸变｜真实镜头真的符合针孔模型吗？

先从最熟悉的针孔模型开始。它把光线和像素连接得很漂亮，可真实镜头的表现，似乎总有一点不一样。

从理想模型开始

在针孔模型中，一个空间点 \(P=(X,Y,Z)\) 经过透视投影，落在归一化像平面上：

\[x=\frac{X}{Z},\qquad y=\frac{Y}{Z}\]

再通过相机内参矩阵 \(K\)，转换为图像中的像素坐标。在常见的零 Skew 假设下：

\[K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix},\qquad \begin{cases}u=f_xx+c_x\\v=f_yy+c_y\end{cases}\]

其中，\(f_x,f_y\) 是以像素为单位的焦距，\(c_x,c_y\) 是主点位置。这个模型的核心非常简单：空间点、光心和成像位置之间，可以通过一条直线建立关系。

但真实镜头由多个透镜组成。光线经过镜片时，可能偏离理想针孔模型给出的方向；这种差异在图像边缘往往更明显。

能不能保留针孔模型的结构，再增加一层修正，描述真实镜头的偏差？

第一种修正：径向畸变

观察广角镜头拍摄的直线，有时会发现它向外鼓起，或者向内弯曲。一个很自然的想法是：让偏移量与像素到中心的距离有关。

在归一化像平面上，定义 \(r^2=x^2+y^2\)，使用径向多项式：

\[\begin{aligned}x_d&=x(1+k_1r^2+k_2r^4+k_3r^6)\\y_d&=y(1+k_1r^2+k_2r^4+k_3r^6)\end{aligned}\]

它表达的是：距离中心越远，允许产生越大的径向修正。不同系数能够描述常见的桶形畸变、枕形畸变及更复杂的径向变化。

第二种修正：切向畸变

刚才默认偏移大致围绕光轴呈旋转对称。但真实镜头的光学元件可能存在偏心或倾斜，偏移不一定沿着径向发生。

于是再引入切向畸变系数 \(p_1,p_2\)，与径向畸变合在一起，形成常见的 Brown–Conrady 模型：

\[\begin{aligned} x_d={}&x(1+k_1r^2+k_2r^4+k_3r^6)\\&+2p_1xy+p_2(r^2+2x^2)\\[3pt] y_d={}&y(1+k_1r^2+k_2r^4+k_3r^6)\\&+p_1(r^2+2y^2)+2p_2xy \end{aligned}\]

这样，完整的成像关系就可以理解为三个步骤：三维透视投影 → 畸变修正 → 内参转换为像素坐标。 OpenCV 常规相机标定便广泛采用这一类模型。

如果视角大到普通针孔模型也不合适呢？

对于大视场鱼眼镜头，问题可能不再是给针孔投影增加几个修正项，而是投影关系本身需要改变。

针孔投影中的归一化半径与入射角满足 \(r=\tan\theta\)。当视角接近甚至跨越 180° 时，它难以作为整个视场的合适描述。

另一类思路是直接描述光线入射角 \(\theta\) 与成像半径之间的关系。例如 Kannala–Brandt 类型的角度多项式：

\[\theta_d=\theta(1+k_1\theta^2+k_2\theta^4+k_3\theta^6+k_4\theta^8)\]

之后根据 \(\theta_d\) 与光线方位角确定图像位置。这与在普通针孔投影上叠加畸变系数，是两种不同的建模选择。

模型核心想法典型适用情况
Pinhole理想中心透视投影理论建模、已去畸变的透视图像
Brown–Conrady在针孔投影后叠加径向与切向畸变常规透视镜头
Rational Polynomial使用有理多项式增强径向畸变表达畸变较复杂的透视镜头
Fisheye / Kannala–Brandt以入射角建立成像关系大视场、鱼眼镜头

回到反投影：从真实像素怎么找回空间光线？

这里有一个容易被忽略的方向问题：畸变模型一般先描述的是理想光线如何变成畸变像素；而深度反投影需要的是反方向，即实际像素对应哪条空间光线。

对于 Brown–Conrady，反向关系一般不能简单地把畸变系数取负，而需要通过数值求解等方式恢复无畸变归一化坐标。OpenCV 的 cv2.undistortPoints() 就可以完成对应模型下的这项工作。

A SMALL BUT IMPORTANT DISTINCTION

如果使用的是已经去畸变、校正后的图像，就应使用与这张新图像相匹配的内参，而不是再把原始畸变模型重复施加一遍。

这一站留下的认识

真实像素与空间光线的对应关系，不仅需要 K，还需要与图像状态一致的畸变模型。反投影之前，要先确认手里的是原始图像还是已经校正过的图像。

02

Camera Calibration

相机标定｜知道模型以后，参数从哪里来？

成像模型终于清楚了，可 \(f_x,f_y,c_x,c_y\) 和那些畸变系数，并不会自己出现在公式里。怎样从真实观测中反推出它们？

先从已知的空间点想起

如果知道一个空间点的三维位置，也知道它在图像中的像素位置，那么模型预测的像素，就必须与真实观测相符。

更多的 3D–2D 对应，意味着更多约束。理论上，我们可以利用这些对应反推出未知的相机参数。

可在真实三维空间里精确布置大量标记点并不轻松。有更方便的办法吗？

一张平面棋盘格，为什么能完成标定？

棋盘格提供了已知的几何结构。只要知道方格边长，就能在标定板坐标系中给每个角点定义位置，例如：

\[(0,0,0),\ (20,0,0),\ (40,0,0),\ \ldots\quad\text{(mm)}\]

虽然全部角点都在同一个平面上，反而能利用一条特殊的投影关系：在忽略畸变的针孔模型下，平面点与图像点之间存在 Homography（单应变换）。

\[s\begin{bmatrix}u\\v\\1\end{bmatrix}=H\begin{bmatrix}X\\Y\\1\end{bmatrix}\]

只要能找到棋盘角点的平面坐标与图像坐标对应，就可以估计这次拍摄的 H。

不过，H 不是内参。它同时包含相机内参，以及当前标定板相对于相机的位姿。

如果每次拍摄姿态都不同，但使用的始终是同一台相机，能不能从这些变化中把固定内参分离出来？

张正友标定：用多个姿态，寻找不变的内参

这正是张正友平面标定法的重要思想。对于标定板所在的 \(Z=0\) 平面，有：

\[H=K\begin{bmatrix}r_1&r_2&t\end{bmatrix}\]

这里的 \(r_1,r_2\) 是旋转矩阵的前两列，t 是平移。关键在于：旋转矩阵的两个列向量并非任意取值，它们必须互相垂直且长度相等。

\[r_1^{\mathsf T}r_2=0,\qquad \|r_1\|=\|r_2\|=1\]

于是，每个观测到的 H 都能为内参提供约束。让标定板在不同视角和倾斜角度下被拍摄，就能从多个 Homography 中恢复共享的 K；在常见五内参参数化下，至少需要多个非退化姿态，通常远不止拍几张就结束。

为什么还需要非线性重投影优化？

通过平面几何约束，可以获得内参初值。但这一过程通常先采用理想针孔假设，而真实图像还存在镜头畸变以及角点定位的不完美。

接下来，就可以把内参、畸变参数和每张图像的标定板位姿放进同一个优化问题：

\[\hat p_{ij}=\pi(K,D,R_i,t_i,P_j)\]
\[\min_{K,D,\{R_i,t_i\}}\sum_{i,j}\left\|p_{ij}-\hat p_{ij}\right\|^2\]

其中，\(p_{ij}\) 是实际检测到的角点，\(\hat p_{ij}\) 是根据当前参数重新投影得到的像素。通过 Levenberg–Marquardt 等非线性最小二乘算法，寻找让预测与观测尽量一致的一组参数。

这便构成了一条经典的求解路线：平面几何给出初值，再用完整成像模型进行联合优化。

一定要用棋盘格吗？

并不需要。标定问题真正依赖的是可靠的参考几何和像素对应，棋盘格只是其中一种实现。

参考物怎样建立对应更有价值的场景
Chessboard规则棋盘角点与已知网格坐标常规高质量相机标定
Circle Grid圆心与规则排列关系圆点定位稳定、布置方便的场景
ChArUco编码标记提供身份，棋盘角点提供精确位置标定板部分可见、存在遮挡
AprilTag Grid独立标签 ID 与已知板面布局多视角、大面积参考布置

这些参考物并不代表四套完全不同的内参求解理论。它们首先解决的是怎样找到已知参考点与图像像素之间可靠的对应。

另外，拍摄标定板也不只是收集更多图像。如果所有图像几乎来自同一个方向，就只是在重复近似的约束。让标定板产生适度的平移、倾斜和视角变化，才更有利于区分未知参数。

得到 K 之后，还能一直照搬吗？

参数应当对应实际使用的图像坐标定义。例如，图像从 \(1280\times720\) 等比或非等比缩放到另一尺寸时，焦距和主点的像素数值需要随对应轴缩放；如果图像被裁剪，主点还要减去裁剪偏移。

而对于经过整流、去畸变的图像，还可能存在一组新的有效投影内参。因此，比起只保存一串 \(f_x,f_y,c_x,c_y\)，更重要的是知道：这组参数究竟属于哪种图像。

这一站留下的认识

相机标定不是把棋盘格交给一个 API，而是利用已知几何与图像观测建立约束。张正友标定提供平面求解思路，非线性重投影优化把畸变也纳入了模型。

03

Color–Depth Extrinsics

Color–Depth 外参｜同一个像素，为什么不代表同一个点？

一台相机的几何关系已经建立。可 RGB-D 设备不是简单地给 RGB 图像附上一列深度数值——颜色与深度，可能来自两个不同的观察位置。

两张图像，不一定站在同一个地方观察

以主动双目 RGB-D 设备为例，它可能包含一台 Color 相机、两台红外相机以及一个红外投射器。深度图可能对应某个红外参考相机的坐标系，而 RGB 图像来自独立的彩色相机。

它们的光心、光轴、焦距、分辨率和畸变模型，都可能不同。

因此，Color 图像中的 \((u,v)\) 与原始 Depth 图像中的同名像素，不保证观察的是同一条空间射线。

一个数字例子：为什么不能固定平移图像？

假设两台相机已经极线校正，光轴平行，焦距为 600 px，水平基线为 5 cm。在这种理想双目情况下，同一空间点的水平视差近似满足：

\[d=\frac{fb}{Z}\]

当物体位于 0.5 m 处，视差约为 60 px；当物体位于 1 m 处，视差就变成约 30 px。

换句话说，两台相机的相对位置没有变，但像素偏移仍然取决于物体的深度。

对于只有一个平面、纯旋转等特殊情况，固定 Homography 可能成立。但具有多个深度层次的一般三维场景，不能指望用同一个二维变换把所有物体精确叠好。

既然像素关系随着深度变化，能不能先把两台相机放到同一个三维空间里？

用外参连接两个观察者

定义 Depth 相机坐标系为 D，Color 相机坐标系为 C。若三维点在 D 坐标系下的位置为 \(P_D\)，它在 C 坐标系下的位置由刚体变换给出：

\[P_C=R_{CD}P_D+t_{CD}\]
\[\begin{bmatrix}P_C\\1\end{bmatrix}={}^CT_D\begin{bmatrix}P_D\\1\end{bmatrix}\]

这里的 \({}^CT_D\) 是 Depth → Color 的坐标变换；R 表示相对旋转，t 表示相对平移，整体属于 SE(3) 刚体变换。

由于 Color 与 Depth 相机通常固定安装在同一设备内部，这个相对变换一般可以当作固定值使用。

两台相机之间的外参从哪里来？

本质上仍然依赖共同的几何约束，只是未知量从单台相机内参，变成了两个坐标系之间的相对位姿。

技术思路怎样获得外参适用前提
共同标定板分别求出标定板在两相机下的位姿，再组合坐标变换两套传感器均可观测同一参考
3D–3D 对应建立共同三维点对应，用 Kabsch / SVD 等方法求刚体变换两边能恢复可对应的三维结构
联合标定优化利用多组观测联合优化多传感器的几何参数需要统一处理多相机参数和位姿

对于 RealSense 等集成式 RGB-D 相机，通常可以直接向 SDK 查询出厂标定的外参，不需要每次从头求解。

别忘了确认参考坐标系

设备提供的 Depth 图像，可能已经经过双目整流，甚至已经对齐到 Color。使用外参之前，要先确认当前图像究竟属于哪个参考相机坐标系，避免重复变换。

这一站留下的认识

Color–Depth 外参连接的是两套三维坐标系，而不是直接定义两个像素之间的固定移动量。只有先统一空间坐标，才能讨论一个空间点应该出现在哪个 RGB 像素。

04

RGB-D Geometric Alignment

RGB-D 几何配准｜如何让颜色与深度真正对应？

相机模型、标定参数和 Color–Depth 外参终于都到位了。接下来不是寻找更复杂的二维图像变换，而是让两个观察者回到同一个三维空间。

第一步：从 Depth 像素回到三维空间

给定原始 Depth 图像中的像素 \(p_D=(u_D,v_D)\) 及深度值 \(Z_D\)，先依据 Depth 相机的模型去畸变，恢复归一化光线方向 \((x_D,y_D,1)\)。

如果深度图存储的是相机光轴方向的 Z 深度，则：

\[P_D=Z_D\begin{bmatrix}x_D\\y_D\\1\end{bmatrix}\]

这一步必须留意两个定义：深度图可能以设备原始整数单位存储，需要通过 depth_scale 等参数转换为长度；而有的距离测量表示的是到光心的欧氏距离，不可以直接冒充 Z 深度。

第二步：把点变换到 Color 相机

现在，Depth 坐标系下的三维点已经存在。使用刚才获得的外参：

\[P_C=R_{CD}P_D+t_{CD}=(X_C,Y_C,Z_C)\]

点没有移动，改变的是描述它的坐标系：原先由 Depth 相机描述，现在由 Color 相机描述。

第三步：让 Color 相机重新投影这个点

把点 \(P_C\) 投影回 Color 相机。如果目标是原始 Color 图像，就使用它的畸变模型和原始内参；如果目标是校正后的图像，则使用对应的校正投影模型。

\[x_C=\frac{X_C}{Z_C},\qquad y_C=\frac{Y_C}{Z_C}\]

在无畸变的简化情况下：

\[u_C=f_{x,C}x_C+c_{x,C},\qquad v_C=f_{y,C}y_C+c_{y,C}\]

终于可以知道：原始 Depth 像素 \((u_D,v_D)\) 对应到 Color 图像的哪个位置。

第四步：把单点映射变成整张对齐深度图

对整张 Depth 图像，最直接的实现可以按照以下过程：

1

遍历原始 Depth 图像中的有效像素，读取对应深度值并转换到实际长度单位。

2

根据 Depth 成像模型反投影，得到 Depth 坐标系中的三维点 \(P_D\)。

3

通过 \({}^CT_D\) 将点转换到 Color 坐标系，得到 \(P_C\)。

4

投影到目标 Color 图像网格，并处理取整/采样、有效像素和深度冲突。

这里有个细节容易被忽略：对齐后的深度如果定义为 Color 相机光轴方向的 Z 深度，原则上应写入 \(Z_C\)，而不是在所有情况下直接照搬原始的 \(Z_D\)。

当相机之间存在相对旋转或沿光轴方向的平移时，这两个值可能并不相等。

多个 Depth 点投到同一个 Color 像素，应该留谁？

由于两个图像网格不同，重投影后可能会出现多个深度点落在同一个 Color 像素的情况。

对普通不透明场景，最自然的思路来自计算机图形学：Z-buffer。比较这些点在 Color 坐标系下的有效正深度，保留更靠近 Color 相机的表面。

与此同时，有些 Color 像素可能根本得不到深度：可能是采样间隔、视场差异，也可能是 Color 看得见、Depth 却被遮挡的区域。

这些空洞有时能通过邻域投影、插值或深度补全改善，但物体边缘存在前景与背景的深度突变，不能随意把背景深度填到前景上。

对齐不等于补齐

几何配准负责确定已有观测应当对应哪里；它不能凭空保证每个 RGB 像素都拥有真实有效的深度。

为什么还存在 Color-to-Depth Alignment？

刚才的路线选择 Color 图像作为参考网格，让 Depth 观测对齐到它上面。也可以反过来，保持 Depth 的参考网格，让 Color 信息对应到深度采样位置。

对齐方向参考图像网格常见用途
Depth-to-ColorColorRGB 检测、分割后提取目标对应深度与点云
Color-to-DepthDepth为深度像素关联颜色、生成彩色点云

虽然坐标变换可以求逆，但两种对齐方向的有效像素覆盖、可见性和采样策略并不完全对称。并不能只把矩阵求逆，就假定得到了一张没有空洞的新图像。

那 SDK 里的 Align 究竟封装了什么？

到了这里，RealSense 和 Orbbec 的对齐接口就不再神秘：其核心仍是已知的内外参、三维反投影、坐标变换和目标图像的重采样。

例如 ROS 中的 /camera/aligned_depth_to_color/image_raw，通常表示已经对齐到 Color 图像参考网格的深度数据。

如果随后要根据 RGB 检测框或者 Mask 提取点云，应使用与这张对齐后深度图一致的 Color 相机几何模型；不要再拿原始 Depth 相机内参直接套上去，也不要对已经完成的对齐再次重复外参变换。

同样，Depth 图像的名称不能代替坐标系定义。先确定图像属于哪个采样网格、使用哪个相机模型、深度表示哪个坐标系下的 Z，再进行反投影。

这一站留下的认识

RGB-D 几何配准不是把两张二维图强行叠在一起，而是通过三维空间建立对应，再把观测投回目标图像网格。对齐后的像素关系，来自真正的空间几何。

LOOKING BACK · 回头看

真实 RGB-D 相机的几何关系，终于完整了。

最初，我们只有一套理想针孔模型。发现真实镜头并不完全理想，于是引入畸变模型；发现模型参数未知，于是通过已知几何与图像观测进行标定；发现 Color 和 Depth 站在不同位置观察世界，于是建立它们之间的外参。

最后，利用反投影、坐标变换和重投影，让两套观测在三维空间中真正发生联系。

  • 相机模型：定义像素与空间光线的关系。
  • 相机标定：根据已知几何与观测求出模型参数。
  • Color–Depth 外参：连接不同相机的三维坐标系。
  • RGB-D 几何配准：把颜色与深度关联到一致的空间位置。

反投影公式从来没有要求我们使用某一组固定的焦距和主点。它真正要求的是：输入的像素、深度、相机模型和坐标系，必须描述同一种观测。

公式终于不只是纸上的公式，而是真正接到了手里的相机上。

至此，相机与三维测量的五条专题路线已经闭环：从图像形成和成像几何出发，经由深度测量与后处理，最后让数学模型真正对应手里的设备。
