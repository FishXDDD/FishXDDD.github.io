CAMERA GEOMETRY · 独立技术笔记

从空间点到像素射线

从针孔模型到逆投影、镜头畸变与大视场成像，认真弄清照片里到底保留了哪些空间信息。

00 · 开场

照片明明是平的，空间去哪了？

拿相机对着桌上的瓶子拍张照片，明明瓶子有长度、宽度和深度，照片里却只剩下二维像素。近处看起来更大，远处更小；相机动一动，瓶子又跑到了别的位置。

如果已知三维点 XYZ，似乎能算出像素 UV。反过来，只有一个像素，能不能找回真正的三维点？

这次先不研究深度是怎样测出来的，也不研究标定程序怎么运行。只跟着一个问题：相机怎样建立空间点与图像像素的几何关系？

01 · 技术路线

先摆结论：究竟有哪些几何关系？

这不是一大堆互相竞争的算法，而是对同一个“空间方向 ↔ 像素”问题的逐层建模。

技术体系核心机制何时需要
针孔 / 透视投影中心投影、相似三角形、内参 K普通相机的 3D → 2D
逆投影使用 K⁻¹ 恢复空间射线像素 → 空间方向
畸变模型Brown–Conrady、Rational、Thin Prism真实镜头偏离理想模型
广角 / 全向模型角度投影、Kannala–Brandt、Unified Model大视场相机
工程计算OpenCV 正投影与去畸变参数、像素状态一致性验证
两条主线：3D → 2D，确定空间点投影在哪个像素；2D → Ray，确定某个像素对应哪个空间方向。距离仍需额外约束。
02 · 理想相机

为什么三维点会落在那个像素？

02.1 · 从小孔与相似三角形开始

假设相机中心为 O，光轴取 Z，空间点为 P=(X,Y,Z)。使用位于相机前方的虚拟成像平面，它到 O 的距离为 f。投影点、相机中心和空间点在同一条直线上，因此相似三角形给出：

x=f\frac{X}{Z},\qquad y=f\frac{Y}{Z}

为什么一定要除以 Z？假设横向 X 固定，深度 Z 加倍，则投影偏移减半：近大远小来自中心投影几何，并不是软件主动缩放。对任意正数 λ，(λX,λY,λZ) 的投影完全一样——这预告了逆投影的尺度歧义。

02.2 · 为什么 f 变成了 fx、fy？

几何成像位置不是像素坐标。先令归一化坐标 xn=X/Z, yn=Y/Z，再考虑像素尺度和主点偏移：

u=f_x\frac{X}{Z}+c_x,\qquad v=f_y\frac{Y}{Z}+c_y

其中 fx、fy 以像素为单位，cx、cy 是主点。它通常靠近图像中心，却不保证精确等于宽高的一半。

02.3 · K 的含义究竟是什么？

K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix},\qquad Z\begin{bmatrix}u\\v\\1\end{bmatrix}=K\begin{bmatrix}X\\Y\\Z\end{bmatrix}

这里采用零 skew 的常见形式。透视除法先形成 X/Z 与 Y/Z，K 再把归一化位置变成像素位置；K 自己并不是三维到二维的全部。

02.4 · 世界坐标为什么不能直接投影？

投影公式使用相机坐标。如果点先表示在世界坐标系，需要先使用外参：

P_C=R_{CW}P_W+t_{CW}
Z_C\tilde p=K(R_{CW}P_W+t_{CW})

外参描述坐标系之间的几何关系；如何估计它们，留到标定专题。这里先牢牢记住顺序：世界坐标 → 相机坐标 → 归一化平面 → 像素。

03 · 逆投影

为什么一个像素只对应一条射线？

03.1 · 把公式反过来

从像素出发：

X=\frac{u-c_x}{f_x}Z,\qquad Y=\frac{v-c_y}{f_y}Z

此时两个方程却有 X、Y、Z 三个未知量。不是计算技巧不够好，而是投影已经丢掉了沿光线方向的距离。

\mathbf d=K^{-1}\begin{bmatrix}u\\v\\1\end{bmatrix}=\begin{bmatrix}x_n\\y_n\\1\end{bmatrix},\quad P_C(Z)=Z\mathbf d

03.2 · Z-depth 和 Ray-distance 为什么不一样？

向量 d 的第三分量是 1，通常不是单位方向；因此 P=Zd 中的 Z 是光轴方向深度。如果单位化 d，令 P=r d/‖d‖，此时 r 才是沿射线的欧氏距离：

r=Z\sqrt{1+x_n^2+y_n^2}

例如 d=(0.6,0.8,1) 时，Z=1 m 对应 r≈1.414 m。把这两种深度直接混用，会得到系统性错误的三维坐标。

03.3 · 射线变换到世界坐标时，平移加在哪里？

P_W(\lambda)=t_{WC}+\lambda R_{WC}\mathbf d_C

射线原点要旋转平移，射线方向只旋转、不平移。这个区别在机器人坐标变换中非常重要。

03.4 · 如何把射线变回唯一的点？

必须补上一条约束。已知 Z-depth 时直接反投影；知道空间平面时求射线与平面交点；另一台相机提供第二条射线时可以三角测量；已知模型点与图像点对应时则连接到 PnP。

\mathbf n^TP+d=0,\quad P(\lambda)=\mathbf o+\lambda\mathbf v
\lambda=-\frac{\mathbf n^T\mathbf o+d}{\mathbf n^T\mathbf v}

这是射线和平面求交的例子。要求分母非零，且交点位于射线前方。它也说明：额外几何先验能弥补丢失的信息，但必须确保先验成立。

04 · 真实镜头

为什么针孔公式正确，图像却可能弯曲？

04.1 · 先区分 K 与畸变 D

K 描述理想归一化坐标到像素的映射；畸变模型描述实际镜头相对理想模型的非线性偏移。常见路线是 3D → 理想归一化坐标 → 畸变归一化坐标 → 原始像素。

04.2 · 径向畸变从哪里来？

如果畸变大致围绕光轴对称，那么偏移自然可以依赖到中心的距离。令：

r^2=x^2+y^2,\quad L(r)=1+k_1r^2+k_2r^4+k_3r^6
x_d=xL(r),\qquad y_d=yL(r)

在 r=0 时 L=1；图像越靠边，高阶项往往越显著。径向压缩或扩张对应桶形、枕形畸变趋势。但畸变形状由多项系数共同决定，不能只看某个系数正负。

04.3 · 切向畸变又是什么？

镜头与传感器的装配等因素可能引入非径向偏移。常用参数 p₁、p₂ 表示：

x_d=xL+2p_1xy+p_2(r^2+2x^2)
y_d=yL+p_1(r^2+2y^2)+2p_2xy

Brown–Conrady 是一套有效的参数化几何模型，并不是所有真实镜头的唯一精确光学定律。扩展的 Rational 模型将径向项变成分式，还存在 Thin Prism 等扩展项。参数更多并不必然更准，标定观测不足时容易过拟合。

04.4 · 去畸变是在求一个逆函数

正向畸变是从 (x,y) 到 (xd,yd)。真实相机首先给出畸变像素；想获得理想射线，就需要解逆问题。因为畸变非线性，通常通过数值迭代完成，不是把畸变系数简单取反。

OpenCV 的 undistortPoints 可恢复对应的理想归一化坐标（根据是否设置输出投影矩阵而定）。几何求点并不一定需要先对整张图做去畸变和插值。

工程检查：原始图像使用匹配的原始 K+D；去畸变图像使用其输出 K′ 和相应模型；裁剪、缩放后须更新像素坐标系和内参。1280×720 改为 640×360 的等比例缩放，与改成 640×480 的非等比例变换，不是一回事。
05 · 其他相机模型

鱼眼为什么不能无脑套针孔公式？

05.1 · 针孔大视角问题来自哪里？

令光线与光轴夹角为 θ，则普通针孔投影的理想半径满足：

r=f\tan\theta

当 θ 接近 90°，投影半径趋于无穷。有限的透视成像平面无法装下整个半球方向；鱼眼镜头则希望把更大的方向范围压进有限图像。

05.2 · 换掉角度到半径的映射

理想模型投影半径几何特性
Rectilinearr=f tan θ透视投影；大角度增长迅速
Equidistantr=f θ角度增量对应相同径向增量
Equisolid-angler=2f sin(θ/2)理想等立体角成像
Stereographicr=2f tan(θ/2)理想保角投影
Orthographicr=f sin θ半径对应方向横向分量

05.3 · Kannala–Brandt 为什么出现？

真实鱼眼往往不严格符合某一种理想公式。于是直接让入射角 θ 进入多项式映射：

\theta_d=\theta+k_1\theta^3+k_2\theta^5+k_3\theta^7+k_4\theta^9

与常规 Brown–Conrady 从理想透视坐标半径建立畸变不同，它围绕光线入射角描述成像。这就是为什么 OpenCV fisheye 与普通 calib3d 的畸变参数不能混用。

05.4 · 全向投影的另一个想法

某些中心全向成像系统可使用 Unified Camera Model。一个常见归一化形式是：

x=\frac{X}{Z+\xi\sqrt{X^2+Y^2+Z^2}},\quad y=\frac{Y}{Z+\xi\sqrt{X^2+Y^2+Z^2}}

当 ξ=0 时退化为普通针孔归一化投影形式（仍需满足对应有效定义域）。这不意味着所有全向系统都具有共同的投影中心：非中心系统需要更一般的射线模型。

05.5 · 我该选哪个？

普通 RGB-D 相机通常首先考虑针孔与匹配的畸变模型；宽视场鱼眼考虑 Kannala–Brandt 类角度模型；特殊全向系统按光学结构与标定方案选用 Unified 或其他模型。模型选择不是算法排行榜，而是让数学描述与实际光学系统相符。

06 · 动手验证

让公式在 Python / OpenCV 里真正动起来

一篇独立笔记不必把所有实验代码硬塞进正文，但至少应当明确每个实验验证哪个物理或几何结论。

A · 近大远小

固定真实尺寸 W，让 Z 从 0.5 m 增加到 4 m，验证像素宽度 w=fxW/Z。

B · 焦距与主点

固定 3D 点，分别改变 fx、fy、cx、cy。区分尺度变化与像素偏移。

C · 一个像素，多组 XYZ

计算 K⁻¹[u,v,1]ᵀ，在多种 Z 下生成点并重新投影，验证 UV 相同。

D · 畸变与去畸变

在规则网格上添加 Brown–Conrady 畸变，再尝试逆变换；比较参数正确和错误时的结果。

E · 完整闭环

3D → 投影 → UV；与原始有效 Z 一起反投影 → 3D′，比较 ‖P′−P‖。理想一致模型下应接近 0。

实验时把模型误差、像素量化误差、深度测量误差分开控制；只有这样才能知道误差从哪里来。
07 · 回头看

空间和像素到底是什么关系？

走完这一段，可以把问题归结成三类操作。

操作已知能得到什么
ProjectionXYZ + 正确相机模型像素 UV（有效视野内）
UnprojectionUV + 正确相机模型空间射线
Back-projection with DepthUV + 正确相机模型 + 有效深度确定的相机坐标 XYZ

透视投影除以 Z，是相似三角形的结果；一个像素只确定方向，是投影丢失了距离自由度；真实相机需要匹配实际镜头与图像状态的模型。

下一段才继续追问：深度相机如何补上距离？真实参数如何标定？RGB 与 Depth 如何配准？这些不属于本文的投影几何核心，但会决定最后的 XYZ 究竟可信到什么程度。

相机不是把 XYZ 直接装进照片里；它先记录了空间方向。我们再依靠距离或额外几何约束，沿着方向重新找回三维世界。
