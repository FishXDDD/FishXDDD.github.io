从图像中找到目标

2D Target Localization · 问题定义与技术路线

前面折腾了好一阵相机，终于弄清楚光是怎么变成图像的，深度又是怎么测出来的。只要像素有可靠的深度，连它在三维空间中的 XYZ 都能算出来。

看起来万事俱备了。

结果镜头对准桌上的三个瓶子，才发现漏了一件事：我知道每个像素在哪里，却还不知道哪些像素属于我要找的瓶子。

总不能让机器人自己猜吧。

这一站先把三维坐标放在一边，回到二维图像，看看怎样从一整张画面中找到目标。

单帧二维图像三条技术路线先明确边界，再进入算法
00THE TASK · 问题边界

先明确：我们究竟在找什么？

二维目标定位：给定单帧图像与目标条件，确定符合条件的目标在图像中的位置或区域。

需要明确定义例如
找什么目标条件瓶子、红色物体、指定实例
找到什么程度输出形式点、BBox、Mask、轮廓、关键点
凭什么找可用依据当前图像、已有参考、训练获得的视觉知识

还需要允许多个候选、未找到和无法确定，而不是默认每次都有唯一答案。

一个必须区分的问题

图像里有一条边缘，不代表那里就是物体边界；找到一个完整区域，也不代表它就是目标。边缘、区域、轮廓、骨架等是可提取的视觉结构；目标定位还需要判断它们与目标条件的关系。

明确这个区别，再来看看有哪些路可以走。

01CURRENT IMAGE · 当前图像

图像特征与结构提取

Classical Vision · 从图像本身寻找线索

如果桌面是白色的，瓶子是红色的，最自然的想法就是利用颜色把它找出来。

但颜色不是唯一线索。有些目标可以通过边缘与轮廓区分，有些具有明显的几何形状；面对一根弯曲的线缆，曲线和骨架可能比颜色更值得关注。

当前图像里，有哪些能够被明确计算的视觉特征与结构？它们能否帮助我们区分目标？

像素与纹理、区域、边缘、轮廓、几何曲线、骨架、拓扑及局部特征，描述的是不同层面的视觉信息，并不都直接等于目标边界。

这条路线的研究边界

不依赖目标专属参考或学习得到的目标识别知识，从当前图像提取可计算的视觉结构，再通过显式规则组织、筛选目标。

当不同物体缺乏足以区分的可见特征时，仅靠这些规则可能无法确定目标。

02KNOWN REFERENCE · 已知参考

参考匹配与视觉对应

Reference Matching · 用已知信息寻找对应

如果我要找的盒子之前已经拍过照片，似乎就没必要重新描述它的颜色、纹理和轮廓了。

能不能直接拿着参考图，在当前画面中寻找对应的位置？

参考也不一定是完整照片，还可能是一块局部图像、已知轮廓、形状结构，或者提前记录的背景。

已知参考中的哪些信息，能够与当前图像建立可靠对应？

这条路线的研究边界

利用已有目标或场景的外观、特征、形状等参考信息，通过相似性与对应关系确定目标位置。

它可以借助传统视觉提取特征，但关键区别是引入了已有参考。参考与现场差异过大，或多个位置同样相似时，可能无法得到可靠或唯一的对应。

03LEARNED KNOWLEDGE · 训练知识

学习式视觉定位

Learned Vision · 从样本中学习视觉规律

但如果每天面对的瓶子都不一样呢？颜色、尺寸、形状不断变化，总不能每出现一种新外观，就重新写一套规则或准备一张参考照片。

能不能让模型提前看过许多样本，从中学会哪些视觉规律能够用于识别目标？

传统机器学习通常利用人工设计的视觉特征学习判别规则；深度学习则可以从数据中学习视觉表示和预测关系。两者都能服务于目标定位。

至于输出 BBox、Mask 还是关键点，属于定位任务与结果形式的区别，并不是学习路线的划分依据。

这条路线的研究边界

利用训练数据学习可复用的视觉特征与判别、定位关系，在新图像中寻找符合任务定义的目标。

这一站仅讨论传统机器学习与常规深度视觉方法，不深入开放词汇 Grounding、VLM 和多模态推理。学习到的规律仍可能受到目标与场景变化的限制。

↳LOOKING BACK · 回头看看

原来有三条不同的路

一开始只是想找到桌上的瓶子。走到这里，至少能从三种不同的依据出发。

技术路线核心依据主要边界
图像特征与结构提取当前图像 + 显式规则是否存在足以区分目标的视觉结构
参考匹配与视觉对应当前图像 + 已有参考是否存在可靠、可区分的对应
学习式视觉定位当前图像 + 训练获得的视觉知识学到的规律能否适用于当前目标

它们不是依次升级的三个阶段，也不互相排斥。传统视觉可以用于参考匹配，学习式方法也可以结合显式规则。

不过，无论选择哪一条，提取到视觉结构、发现候选区域、确定指定目标，始终是不同层次的问题。

这一站只研究单帧二维目标定位。目标跟踪、三维位姿、点云配准和抓取规划，留给其他路线。

先弄清楚凭什么找，再研究究竟怎么找。
