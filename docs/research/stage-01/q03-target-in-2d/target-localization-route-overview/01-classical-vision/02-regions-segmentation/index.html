区域与分割

像素已经分好类，为什么还没有找到一个物体？

在上一站，我们已经能比较颜色、描述纹理，甚至为每个像素得到一份前景概率。可真正看向图像时，问题还在：两只红杯子会被算成同一种颜色；杯身上的反光可能让一只杯子断成几块；两件物体碰在一起，又可能只剩下一整块前景。

这次不急着识别“这是什么”。先研究一个更具体的问题：利用像素之间的空间关系，究竟怎样建立、修正和拆分候选区域？

单张 RGB · 传统视觉拓扑 / 相似性 / 几何 / 优化机制 + 计算 + 可验证实验离线可阅读
00 · SCOPE

先划清边界：像素类别，不等于物体实例

上一篇主要处理像素本身和局部邻域的外观证据。现在我们需要处理像素之间的空间组织关系。二者不能直接划等号。

同样两个物体，从颜色响应到区域组织
示意图只说明标签的含义。区域 A / B 可以是两个候选实例，但连通域标签本身并不是语义识别结果。
INPUT / 01
已有的视觉证据

RGB、颜色/纹理特征、二值 Mask、前景概率，或者可靠种子。

PROCESS / 02
区域组织规则

邻接关系、局部相似性、形状地形、标签一致性与区域聚合。

OUTPUT / 03
候选区域与标签

Connected Components、修正 Mask、分割标签图、超像素等。

这篇明确不解决：一个区域是否就是一个真实物体；某个区域是不是我们想抓的瓶子；它在三维空间中哪里；也不研究边缘检测和轮廓拟合。对于“物体身份”，本篇最多提供候选区域，不能暗中赋予语义。

问题接下来分成六条路径。它们并不是必须按顺序运行的固定流水线，而是在不同证据条件下采用的不同方法。

01 · CONNECTED COMPONENTS

外观相同但相隔很远，为什么还能分成两块？

颜色阈值会把所有“像红色”的像素设为 1，哪怕它们分散在整张图上。现在增加一个最基础的规则：要属于同一块区域，两个前景像素之间必须存在一条由前景邻居组成的路径。

1.1 · 先定义“邻居”：4 邻接还是 8 邻接？

N₄(p) = {(x−1,y), (x+1,y), (x,y−1), (x,y+1)}
N₈(p) = N₄(p) ∪ {(x±1,y±1)}
p ~ q ⇔ 存在一条只经过前景像素的邻接路径 p → … → q
可操作的 3×3 例子 · 斜着接触算不算一块？修改邻接规则
前景 Mask
输出标签

采用 BFS / DFS 的方式很直观：找到一个未标记的前景点，持续访问它所有可到达的前景邻居，并赋同一个 ID。处理完后再寻找下一块前景。

1.2 · 大图怎么计算：两遍扫描与并查集

  1. 第一遍：顺序扫描每个前景像素，查看已经访问过的邻居；为它分配标签，并记录不同标签实际上连通的等价关系。
  2. 等价合并：使用 Union-Find（并查集）合并属于同一连通分量的暂存标签。
  3. 第二遍：将每个暂存标签替换为其最终代表标签，再统计面积、BBox 和质心。
Python · 连通域和统计量
import cv2
import numpy as np

# mask: H×W, 0 表示背景；非零表示前景
mask = np.asarray(mask, dtype=np.uint8)
count, labels, stats, centroids = cv2.connectedComponentsWithStats(
    mask, connectivity=8
)
# 标签 0 始终是背景
for label_id in range(1, count):
    x, y, w, h, area = stats[label_id]
    cx, cy = centroids[label_id]
    print(label_id, (x, y, w, h), area, (cx, cy))

计算代价：对于 H×W 图像，典型实现接近线性于像素数。结果：标签图、连通块统计量。它没有检查颜色之外的结构，也不知道前景是不是一个物体。

关键失效：接触的两个杯子可能变成一个连通块；一根被遮挡或反光切断的绳子可能变成多块。连通性不是实例个数。
02 · MATHEMATICAL MORPHOLOGY

已经有 Mask，但碎了、漏了、粘了，怎么修？

如果一张 Mask 只有零星的点、微小的孔或狭窄的间隙，我们是否可以直接利用它的局部形状处理？数学形态学就是在明确的结构元素下，修改前景的空间分布。

EROSION · 腐蚀
局部全部满足才保留

对全 1 方形结构元素：窗口里只要有背景，当前输出就是背景。前景缩小，细连接容易断。

DILATION · 膨胀
局部有前景就扩张

窗口里只要有前景，当前输出就设为前景。小间隙可能被补上，邻近目标也可能粘连。

腐蚀：A ⊖ B = {x | Bₓ ⊆ A}
膨胀：A ⊕ B = {x | (B̌)ₓ ∩ A ≠ ∅}
开运算：A ○ B = (A ⊖ B) ⊕ B
闭运算：A • B = (A ⊕ B) ⊖ B

这里的 B 表示结构元素。使用中心对称的方形或圆形结构元素时，直觉上可以理解为局部最小值/最大值。开运算常用于去除小凸起与孤立前景，闭运算常用于填补狭窄空隙和小孔，但效果取决于结构元素的形状及尺度。

交互实验 · 同一张 Mask，操作一换，结构就变真实二值运算，背景采用零填充
3×3

请特别看最右侧那根细线：它究竟是噪声，还是一根真实电线？形态学本身没有判断依据。使用 3×3 腐蚀时，宽度只有 1 像素的线会消失；开运算的后续膨胀也无法凭空恢复。

Python · 二值形态学
import cv2

# mask 为 0/255 的 uint8 二值图
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
opened = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
closed = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)
局限：所谓“修复”有明确几何代价：小孔可能被当成伪影，小目标可能被删除，两个距离很近的物体可能被合并。因此，应先知道需要保护的最小结构尺度。
03 · REGION GROWING

没有完整的 Mask，只知道一个内部像素，能长出区域吗？

连通域要求我们先有二值前景。现在换一种思路：如果只知道一个可靠的内部像素，可以从这里出发，逐个检查邻居，逐步把相似像素纳入目标区域。这就是区域生长的基本想法。

3.1 · 接纳一个像素，需要同时满足两条规则

① 邻接约束：q ∈ N(R)（q 必须接触当前区域）
② 相似约束：| I(q) − I(seed) | ≤ τ（固定种子参考）
也可以将参考替换为当前区域均值 μ_R：|I(q) − μ_R| ≤ τ
交互实验 · 从种子扩张，阈值越大越好吗？4 邻接 / 固定种子灰度 82
8
灰度观测（格中为灰度值）
可达且满足判据的区域

这个实验用固定种子灰度作比较，因此终止条件是“再也没有符合条件的可达邻居”。换成动态区域均值，每次接受像素都会改变 μR；增长次序与接受策略在某些实现中会影响结果，颜色缓慢变化的背景也可能引发区域泄漏。

Python · 固定种子均值的最小区域生长
from collections import deque
import numpy as np

def region_grow(gray, seed_yx, threshold):
    gray = np.asarray(gray)
    h, w = gray.shape
    sy, sx = seed_yx
    ref = float(gray[sy, sx])
    visited = np.zeros((h, w), dtype=bool)
    region = np.zeros((h, w), dtype=bool)
    queue = deque([(sy, sx)])
    visited[sy, sx] = True

    while queue:
        y, x = queue.popleft()
        if abs(float(gray[y, x]) - ref) > threshold:
            continue
        region[y, x] = True
        for ny, nx in ((y-1, x), (y+1, x), (y, x-1), (y, x+1)):
            if 0 <= ny < h and 0 <= nx < w and not visited[ny, nx]:
                visited[ny, nx] = True
                queue.append((ny, nx))
    return region
何时成立：内部能找到可信种子，目标在选用特征上相对一致，与背景存在足够差异。何时不成立：目标内部颜色突变、反光，或者目标与背景之间出现相似性通道。
04 · MARKER-CONTROLLED WATERSHED

两个物体连在一起，可不可以从内部形状把它们拆开？

再回到两只接触的杯子。连通域只能看到一整块前景，靠膨胀或闭运算还可能把它们粘得更紧。假设物体近似圆形：每个杯子的内部较厚，接触处较窄。可不可以利用“内部厚度”的变化定位分界？

4.1 · 把前景变成一张“离背景有多远”的距离图

D(p) = min { ||p − q||₂ : q ∈ 背景 }
前景中心 D 大，靠近边界 D 小；将 D 取负形成地形：T = −D
两个接触的圆 · 同一个 Mask，不同的表示
概念示意，不是精确数值计算结果。实际分界由二维距离图、标记位置、边界条件和分水岭算法共同决定。

4.2 · 为什么必须额外指定标记？

  1. 在二值 Mask 内计算欧氏距离变换 D。
  2. 寻找足够可靠的内部峰值，或由外部信息直接给出两个前景种子。
  3. 在 -D 的地形上让不同标签竞争扩张，并把相遇位置作为分隔界限。

如果直接从所有微小局部极值开始分水岭，噪声可能制造出大量无意义的分区。Marker-controlled Watershed 的关键往往是标记如何产生，而不只是执行一次分水岭。

Python · 由 Mask 构造距离地形并分水岭
import numpy as np
from scipy import ndimage as ndi
from skimage.feature import peak_local_max
from skimage.segmentation import watershed

# mask: bool, 两个接触物体构成的一片前景
distance = ndi.distance_transform_edt(mask)
coords = peak_local_max(distance, min_distance=12,
                        labels=mask, exclude_border=False)
markers = np.zeros(mask.shape, dtype=np.int32)
for i, (y, x) in enumerate(coords, start=1):
    markers[y, x] = i
labels = watershed(-distance, markers, mask=mask)

# 仅为最小演示：真实任务需审查种子数量和质量
根本边界：“有两个距离峰”不等于“有两个物体”。一个细腰目标也可能有两个峰；两个外形很扁的物体甚至可能没有清晰双峰。算法并不知道实例数量。
05 · GRAPH CUT / GRABCUT

单个像素判断互相矛盾，能否让整片区域一起决定？

局部阈值会把“颜色略像背景”的像素判为背景，即使它被一整圈稳定前景包围。接下来需要一种机制，同时权衡像素自己的证据和相邻标签的空间一致性。

5.1 · 先把分割写成一个总代价

E(L) = Σₚ Dₚ(Lₚ) + λ Σ₍ₚ,ᵩ₎ wₚᵩ · [Lₚ ≠ Lᵩ]
Dₚ：像素 p 归于前景/背景的代价（数据项）
wₚᵩ：相邻像素跨标签的惩罚权重（平滑项）
λ：愿意付出多少代价来获得相邻标签一致性

如果相邻像素颜色接近，通常更希望它们标签一致；如果差异很明显，可以减小跨标签惩罚，使分界更容易落在视觉变化处。此处先把权重设为 1，看一个小到可以手算的例子。

交互实验 · 三个像素一起选标签穷举全部 2³ 种组合，无近似

三个像素的前景代价是 [0, 3, 0]；背景代价是 [2, 0, 2]。相邻的标签若不同，付出一次 λ。

2.00
最小能量对应的标签
几组代表方案的代价

当 λ 较小时，允许中间像素单独做背景，得到前—背—前。当 λ 变大时，即使中间像素单独看更像背景，整体方案也可能选择前—前—前，以避免标签跳变。

5.2 · 从 Graph Cut 到 GrabCut，具体增加了什么？

图割是在指定能量形式下求标签。对于满足条件的二元可图表示子模能量，可构造 s–t 最小割求全局最优。GrabCut 则进一步建立前景和背景的颜色分布模型，典型实现使用两个 GMM：根据现有标签拟合分布，再用更新的数据项重新优化标签，交替迭代。

矩形 / 初始 Mask→前景与背景 GMM→图割更新标签↺

这里可以与上一篇的 GMM 接起来：GMM 只描述颜色出现的概率，空间标签一致性来自图上的邻接代价。两者合起来才是 GrabCut 这类方法的核心思路。

Python · OpenCV GrabCut
import cv2
import numpy as np

# image 为 uint8 BGR，rect=(x, y, w, h) 且位于图像内
seg = np.zeros(image.shape[:2], dtype=np.uint8)
bg_model = np.zeros((1, 65), dtype=np.float64)
fg_model = np.zeros((1, 65), dtype=np.float64)
cv2.grabCut(image, seg, rect, bg_model, fg_model,
            iterCount=5, mode=cv2.GC_INIT_WITH_RECT)

# 0/2: 背景或可能背景，1/3: 前景或可能前景
mask = np.isin(seg, [cv2.GC_FGD, cv2.GC_PR_FGD]).astype(np.uint8)
局限：代价函数优化得很好，不代表物体识别正确。初始化错误、目标与背景颜色高度相似、被复杂遮挡时，算法仍可能选择一个能量较低却语义错误的区域。
06 · SLIC SUPERPIXELS

逐像素研究太零散，能不能先把图像整理成小块？

此前的方法大多直接处理像素的前景/背景归属。如果图像很大、局部纹理复杂，逐像素建立空间关系会显得繁琐。另一条路是先形成外观和空间都相对一致的小区域，用这些区域作为后续处理单元。

6.1 · SLIC 为什么不只是 K-means？

SLIC 会将像素表示为颜色和坐标的联合特征。常用形式是 [L*, a*, b*, x, y]，但既不能只按颜色聚类，也不能只按空间距离聚类。它在局部搜索范围内进行类似 K-means 的迭代，以颜色差异和空间紧凑性共同决定归属。

d_c = || Lab(p) − Lab(c) ||₂
d_s = || (xₚ, yₚ) − (x_c, y_c) ||₂
D = √[ d_c² + (m/S)² · d_s² ]
S ≈ √(N/K)：期望超像素间距；m：空间紧凑性系数
SLIC 的结果更像“遵循局部图像结构的小块”，而不是物体 Mask
超像素边界是示意线而非真实 SLIC 运算输出。图的重点在于：一个真实物体通常由多个超像素组成；超像素不直接提供实例语义。

常见处理过程是：先按期望区域数初始化网格中心；在每个中心附近约 2S × 2S 的邻域中计算联合距离；更新中心并迭代；最后根据需要修正不连通的标签。相比全图 K-means，局部搜索降低计算量，也倾向于保留空间紧凑性。

Python · SLIC 超像素
from skimage.segmentation import slic
from skimage.util import img_as_float

# rgb: H×W×3, RGB 通道顺序
image = img_as_float(rgb)
segments = slic(image, n_segments=250,
                compactness=10, sigma=1,
                start_label=1, channel_axis=-1)
# segments: 整数区域标签图；不是物体实例标签
SLIC 的意义：把图像从大量像素变成较少的、具空间结构的小区域，方便统计或构造区域邻接图。它不能单独回答：哪几个超像素应该合并为一个物体；这仍需要额外的相似性、图模型或其他先验。
07 · SUMMARY & NEXT QUESTION

这六条路线，其实分别在相信什么证据？

到这里，技术名字已经不少。整理时最该留下的不是一张“算法越来越先进”的路线图，而是：每种方法利用了什么证据，又在哪种情况下没有充分依据？

方法依赖的关键证据典型输出最容易失效的条件
连通域 CCL二值前景与 4/8 邻接连通区域标签接触、遮挡断裂、细连接
数学形态学结构元素形状与尺度修正后的 Mask目标细节与噪声尺度重叠
区域生长可靠种子、邻域相似性由种子扩张的区域反光、颜色突变、背景相似
分水岭距离/梯度地形、可靠标记竞争分隔后的区域错误种子、凹形单目标、无清晰峰
Graph Cut / GrabCut前景/背景分布与平滑性二类标签 / 前景 Mask初始化错误、分布重叠严重
SLIC颜色近似 + 空间紧凑性超像素标签图边界弱、参数尺度不合适；不提供实例

这一篇最终得到什么？

我们已经能够利用邻接、相似性、内部形状以及空间一致性，将原始像素证据整理成一个或多个候选区域；也认识到“区域是否连续”“区域边界是否合理”和“它是不是一个真实物体”是三件不同的事。

如果后续需要物体的边缘形态、轮廓、直线、圆等几何结构，需要继续研究边缘与轮廓。至于“到底哪个区域是要抓的目标”，仍然需要更强的先验或语义信息。
