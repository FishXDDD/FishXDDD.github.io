04 / GEOMETRIC STRUCTURES · 从观测到约束

边缘找到了，
怎样知道它是什么形状？

上一节已经能从图像中找出边缘、追踪轮廓。可边缘一旦断开，或混进背景线条，轮廓就不一定完整。如果目标本来具有规则形状，能不能反过来利用几何规律，找回丢失的结构？

本页只关心一件事：怎样用几何模型从图像证据中提出、计算并检验一个二维结构假设。
一个贯穿全文的例子：矩形物体的部分边缘不可见，但直线与交点的关系仍可能帮助我们恢复四边形。示意不是“已证明它是矩形”，而是“找到了一个需要验证的候选”。
关键词　参数模型 / 最小二乘 / Hough / RANSAC / 结构约束 / 几何验证
00 / PROBLEM & SCOPE

先把问题说清楚：边界与几何结构有什么不同？

边缘告诉我们“这里有变化”，轮廓告诉我们“这些边界连起来了”。但我们仍然没有一个可用来计算、比较和预测的规则形状模型。

想象桌面上有一个矩形盒子。左边缘被手遮挡一段，右边缘和背景纹理混在一起。若只追踪可见边缘，它可能是一串断开的像素；若假设它有四条直边，就能进一步估计直线、求交点，并对缺失部分提出预测。

输入 / EVIDENCE

观测证据

边缘点、轮廓点、图像梯度、区域边界，或者已有候选线段。

假设 / MODEL

几何规律

某些点应当共线、共圆；某些边应当相交或构成封闭结构。

输出 / RESULT

参数与证据

直线、圆、椭圆、交点、四边形及其残差、支持点和不确定性。

这一节的研究边界

不把多项式、Bézier、B 样条等自由曲线表示当作本节主线。它们很适合描述或平滑任意轮廓，但仅仅“拟合得像”，还不能说明目标符合哪一种特定几何规律。本节重点是有明确结构约束的几何模型及其检测和验证。也不把二维形状直接等同于物体类别或三维位姿。

注意：几何模型不只可以从边缘点估计，也可以从区域、角点等图像证据估计。下文用边缘作为直观入口，不把它当成唯一输入。

01 / GEOMETRIC MODELS

如果物体有规则形状，先把“规则”写成什么？

先不谈检测算法。只有知道模型含有哪些参数、限制了什么，才能判断图像证据足不足以确定它。

LINE · 2 DOF

直线：方向与位置

一般式 ax + by + c = 0；归一化 a² + b² = 1。无限直线本身有两个自由度。

CIRCLE · 3 DOF

圆：中心与半径

三个参数；三个非共线点能够确定一个圆，但点的位置会影响计算是否稳定。

ELLIPSE · 5 DOF

椭圆：更一般的二次曲线

中心两个、半轴两个、旋转一个参数。完整模型比圆更灵活，也更需要足够的观测。

1.1 直线：为什么尽量不用 y = kx + b？

斜截式很容易理解，却无法自然表示竖直线。检测算法更常使用一般式或法线式：

a x + b y + c = 0，  a² + b² = 1ρ = x cosθ + y sinθ
ρ 是原点到直线的有符号距离；θ 表示单位法向量方向

一条直线可以用法线方向 θ 和距离 ρ 来确定。这个表示也恰好为后面的 Hough 投票提供了参数空间。

1.2 圆：少数参数带来强约束

(x − cₓ)² + (y − cᵧ)² = r²

圆上所有点到圆心的距离都相同。这个规律使我们能够用很少的点提出模型，但最少能求解，不等于足够可靠：如果只观察到一小段近似直线的圆弧，很多不同半径的圆都可能与其近似吻合。

1.3 椭圆：为什么还需要更多自由度？

斜着观察平面上的圆形标记时，图像中通常会得到一个椭圆。它需要中心、长短半轴和旋转角共五个参数。一般二次曲线可写作：

A x² + B xy + C y² + D x + E y + F = 0
实非退化椭圆还必须满足合适的系数与实点条件；仅写出二次方程并不够

这里用直线、圆、椭圆说明规则形状 = 数学约束 + 有限参数。任意形状曲线当然也可以参数化，但本页不系统展开曲线设计与插值理论。

发现了一个新问题

模型已经有了，可真实图像里的点不会整齐落在这些公式上。到底取哪两个点、哪三个点来计算？如果所有点都有误差，我们该怎样利用它们？

02 / PARAMETER ESTIMATION

明明是一条直边，为什么检测到的点却不共线？

假设我们已经有了一组基本属于同一条边的点。先解决最朴素的问题：用多个带误差的观测，计算一条最合理的直线。

2.1 从“两点连线”走向“多点估计”

随意选两个点，可以画出一条直线；但如果那两个点刚好受噪声干扰，方向就会偏。让所有点一起参与估计更稳定。这里有两种常见、但误差假设不同的做法。

这里画的是“误差方向”的区别，图中两条示意直线并非根据这些示意点精确计算的结果。
OLS / 普通最小二乘

最小化纵向误差

min ∑ᵢ (yᵢ − kxᵢ − b)²

适合把 x 当作准确自变量、y 含误差的回归任务；不适合直接表示竖直线。

TLS / 正交距离拟合

最小化几何距离

min ∑ᵢ (axᵢ + byᵢ + c)²
使 a² + b² = 1

对二维边缘点更自然。直线方向不依赖于把哪一轴指定为“自变量”。

2.2 TLS 到底怎样算？为什么 SVD 能出现？

  1. 求中心：对点集 pᵢ = (xᵢ,yᵢ) 求均值 p̄。
  2. 去中心化：构造矩阵 X，每行是 pᵢ − p̄。
  3. 寻找变化最小的方向：对 X 做 SVD。最小奇异值对应的右奇异向量，就是拟合直线的单位法向量 n=(a,b)。
  4. 恢复位置：令 c=−n·p̄，得到 ax+by+c=0。最大奇异值对应的方向是直线方向。
X = U Σ Vᵀ，  n = V 的最小奇异值对应向量
本质是寻找让所有点的正交投影误差平方和最小的方向
展开：最小可运行示例 · 用 NumPy 拟合二维直线
import numpy as np

def fit_line_tls(points):
    points = np.asarray(points, dtype=np.float64)
    if points.ndim != 2 or points.shape[1] != 2 or len(points) < 2:
        raise ValueError("至少需要两个二维点")

    center = points.mean(axis=0)
    centered = points - center
    if np.linalg.norm(centered) < 1e-10:
        raise ValueError("所有点重合，无法确定直线方向")

    _, _, vt = np.linalg.svd(centered, full_matrices=False)
    normal = vt[-1]              # [a, b]，单位法向量
    c = -normal @ center         # ax + by + c = 0
    residuals = np.abs(points @ normal + c)
    return normal[0], normal[1], c, residuals

points = [[10, 11], [20, 19], [30, 31], [40, 39], [50, 51]]
a, b, c, errors = fit_line_tls(points)
print("直线参数:", a, b, c)
print("正交误差:", errors)

这段代码仅拟合已知属于同一结构的点，不会自动从一张复杂图像中识别目标线条。

2.3 圆与椭圆也可以拟合，但误差定义很重要

圆的一种简便做法是先展开为 x²+y²+Dx+Ey+F=0，对 D,E,F 做线性最小二乘，再恢复圆心和半径。这叫代数拟合，计算快，却不一定最小化真实的点到圆距离。

min Σᵢ ( √[(xᵢ−cₓ)²+(yᵢ−cᵧ)²] − r )²
几何圆拟合：最小化每个点到圆周的径向距离，通常需要非线性优化

椭圆拟合同样需要区分代数误差与几何误差，而且必须避免退化成双曲线、抛物线或其他不合适的二次曲线。直接最小二乘椭圆拟合会引入约束来保证拟合的是椭圆。

新的局限

这些方法默认：我们交给它的一组点，已经大体属于同一个模型。可现实中，一张图的边缘点可能同时来自盒子的四条边、桌面接缝和阴影。现在的困难不再是“怎么拟合”，而是“从哪里发现应该拟合的结构”。

03 / MODEL DETECTION

点都混在一起，怎么知道哪一条线真的存在？

我们不能把整张图里的点都交给一个直线拟合器。需要能从大量干扰中提出候选模型的办法。Hough、RANSAC 和线段检测，分别利用不同的线索。

3.1 Hough：如果每个点都对可能的直线投票呢？

两点可以确定一条直线，但在混杂的边缘图里随机挑两点并不可靠。换个想法：对每个边缘点，把所有经过它的可能直线都记一票。同一条直线上的多个点，会在参数空间的同一个位置累积支持。

ρ = x cosθ + y sinθ
固定某个像素 (x,y)，让 θ 改变，它就在 (θ,ρ) 参数空间描出一条曲线
机制示意：图像空间中的多个共线点，在直线参数空间中支持相同的 (θ,ρ)；实际实现把连续空间离散为累加器格子，再寻找峰值。右图曲线用于示意交点关系。
  1. 给定边缘图，设定角度步长 Δθ 和距离步长 Δρ，建立离散累加器。
  2. 每个边缘点按多个 θ 计算 ρ，对对应格子投票；可利用梯度方向限制候选 θ 以减少计算。
  3. 找得票显著的峰值，得到直线候选 (θ,ρ)；再与边缘证据关联，求取有限线段。

优点：不要求边缘点连续，断开的同向线条也可能被检测出来。代价：角度、距离离散化决定精度与计算量，复杂场景可能产生多个峰值；标准直线 Hough 输出的是无限直线，而非物体边界的两个真实端点。

圆形 Hough 可以扩展到圆心与半径投票，但参数空间更大，通常要限制半径范围或利用梯度减少候选。它不是比圆拟合“更精确”的同义词，而是解决“在哪里有圆”的发现问题。

3.2 RANSAC：如果先猜一条线，再问有多少点认可？

另一种思路不建立完整投票空间。每次取足够少的点生成模型，然后检验剩余观测与模型的距离。如果支持者很多，就留下候选；重复若干次，选出有较大一致集的模型，并用内点重拟合。

  1. 提出假设：拟合直线随机取两个不重合点；拟合圆至少取三个非共线点。
  2. 计算残差：对所有数据点计算到候选几何模型的距离。
  3. 选择内点：距离小于阈值 τ 的点算作一致，得到共识集。
  4. 迭代比较：按内点数量和残差质量筛选模型。
  5. 内点重估计：用最终内点重新拟合，避免结果只取决于最初抽到的最小点集。
小实验：RANSAC 的“内点阈值”意味着什么？调节 τ，看哪些点被候选直线接纳
7 px—
这是对一条固定候选线的内点判定演示，并不是完整 RANSAC 迭代。阈值变大，内点通常变多，但也更容易把不属于这条线的点接纳进来。
N ≥ log(1−p) / log(1−wˢ)
p：至少抽到一次全内点最小样本的期望概率；w：内点比例估计；s：最小样本数。此式给出经典独立均匀抽样假设下的迭代估计。

例如要拟合直线，最小样本数 s=2；若估计内点比例 w=0.5，希望成功概率 p=0.99，则大约需要 17 次采样。实际中还要考虑退化样本、局部结构、迭代不足及阈值选择。

RANSAC 有一个不能忽略的前提

它只回答“哪些点支持某一种模型”，不自动证明“这些点属于目标”。如果背景中有一条更长的直线，它可能比目标边缘获得更多内点。多个目标或多条边也不能简单地假设运行一次 RANSAC 就结束。

3.3 为什么还会有 LSD 这类线段检测？

Hough 常从整张边缘图寻找参数峰值，RANSAC 从采样中提出模型；但有时我们更关心图像中从哪里到哪里确实存在一段边，而不想先得到无限延长的直线。

LSD（Line Segment Detector）利用局部图像梯度的方向一致性组织候选矩形支持区域，检测出具有端点、方向、长度的线段，并通过统计准则控制虚警。它不是简单地“把 Hough 的直线截短”。

方法它主要解决什么使用时容易误解的地方
LS / TLS已知大体属于同一结构的点，求模型参数不负责从所有边缘里找出正确点集
Hough从复杂边缘中按参数支持度发现显著直线、圆参数峰值不直接等于有正确端点的目标边
RANSAC在含离群点的数据中鲁棒提出和估计模型阈值和“哪个模型值得找”仍需要定义
LSD从图像局部梯度的组织中直接发现线段局部线段并不自动构成完整物体结构

这一站得到：不再需要事先知道全部内点，就能提出多条线、圆或线段的候选。可候选一多，又回到目标本身：哪些线才应该放在一起？

04 / GEOMETRIC RELATIONS

四条直线出现了，为什么还不能说找到了盒子？

一个模型描述局部形状；目标结构往往由多个元素及其关系构成。这里开始把“线的集合”变成“受约束的四边形候选”。

4.1 先研究关系，而不是立即贴上“矩形”标签

INCIDENCE

共线 / 相交

两条线是否相交？交点落在哪里？若两条线近乎平行，交点会对小误差很敏感。

ORIENTATION

方向 / 夹角

线段方向是否一致？是否有成组的边？平行和垂直的判断必须考虑成像假设。

ORGANIZATION

连接 / 闭合

哪些端点能够连接？线段是否组成简单封闭四边形？候选有无相互矛盾？

两条一般式直线 a₁x+b₁y+c₁=0 与 a₂x+b₂y+c₂=0，可通过 2×2 线性方程组求交。若系数行列式 a₁b₂−a₂b₁ 接近零，说明两线接近平行，交点可能极不稳定。

4.2 一个最小可行的矩形边界恢复实验

  1. 从边缘或梯度中检测出多条候选线段，保留端点、方向和支持证据。
  2. 根据距离、方向及空间邻近关系，形成可能属于同一边界的组合。
  3. 延长候选线并计算相邻交点，生成若干四边形候选；检查顶点顺序和是否自交。
  4. 用原始边缘重新检查每条候选边的实际支持范围，过滤“只靠无限延长的线碰巧形成”的形状。
注意这个几何陷阱：实际矩形在一般透视投影下形成四边形。直接用图像中的“必须垂直、必须平行”过滤，可能把正确目标删掉。

4.3 哪些几何关系可以直接用？哪些需要条件？

关系在一般平面透视变换下使用建议
共线与线交点保持适合直接构造与检验图像中的线结构
平行通常不保持除非有近似正视、弱透视或校正等额外条件
直角 / 长度比通常不保持要结合成像模型、标定或平面矫正推理
圆 / 椭圆一般圆可投影成二次曲线圆形平面标记通常呈椭圆，不能只按像素圆找
这一节不是在做完整的单应性与位姿估计

我们这里只利用图像中可直接观测、或在明确成像条件下成立的几何约束，组合二维结构。若要利用已知矩形的真实尺寸来推断平面单应性、相机相对姿态，那已经进入后续的成像几何与位姿研究。

这一站得到：一个由多条线和交点组成的二维四边形候选。然而，漂亮的四边形并不等于真实目标——背景线条也能“拼”出四边形。

05 / GEOMETRIC VALIDATION

算法画出了完整的形状，凭什么相信它？

模型检测容易让人产生错觉：线越直、圆越圆，结果越正确。但一个完美的几何解释，也可能只是解释了错误的像素。

5.1 不要只盯着一个平均残差

A / FIT

拟合质量

平均距离、最大误差、误差分布。回答“点与模型贴得近不近”。

B / SUPPORT

支持证据

内点数量、比例、梯度方向一致性。回答“有多少观测支持它”。

C / COVERAGE

空间覆盖

点是沿整条边分布，还是只挤在短短的一角？回答“参数是否真的被约束”。

D / CONSISTENCY

结构一致性

边与边、交点、封闭关系是否相互支持？回答“组合后的形状是否自洽”。

5.2 为什么短圆弧是一个很好的反例？

示意：局部观测范围很窄时，多种曲率很接近的圆都可能解释数据。即使残差小，也不意味着圆心和半径被稳定确定；图中各圆只用于体现这一退化现象。

同样，一条直线只有两个很近的支持点时，方向对像素误差会非常敏感。一个四边形如果只依赖几条被大幅延长的线相交，交点可能远离实际可见证据。

5.3 最后还要回答“能否排除其他解释”

遮挡：看不到的区域可以由模型预测，但预测区并没有新观测支持，不能和真实测到的边缘等价。

重复结构：多个相似的盒子、栏杆或桌面接缝可能产生多个几何上同样合理的候选。

模型错配：柔性袋、变形瓶子、不规则破损物，不一定满足直线、圆或标准椭圆的强假设。

几何正确但目标错误：背景中的直线、圆形纹理可能比真正物体边缘更“规则”。

一个需要保留的结论

几何验证不能承诺“这个一定是目标”。它能给出的是：某个模型受到多少图像证据支持、有哪些约束成立、在哪些地方依赖推断，以及是否仍存在同样合理的其他候选。

参数是实验起点，不是通用最优设置。HoughLinesP 的 threshold 是累加器支持阈值；minLineLength / maxLineGap 是像素尺度参数。fitLine 在 DIST_L2 下对应最小二乘直线拟合；LSD 与 Hough 的输出机制不同。以上示例均不包含后续的结构组合与语义确认。

最后把方法放回它们真正的位置

模型定义
直线、圆、椭圆：约束是什么，参数有多少，观测够不够。
参数估计
LS / TLS / 圆与椭圆拟合：给定候选点，怎样求出参数。
模型发现
Hough / RANSAC / LSD：在混杂证据中怎样找候选，适用前提有什么不同。
结构组合
线段、交点、关联、闭合与透视约束：怎样从局部结构组成目标候选。
结果验证
残差、支持、覆盖、歧义：为什么这个候选值得相信，哪里仍不确定。
到这里，最初的问题有了一个边界清晰的答案

规则物体的二维结构，不一定需要逐像素完整可见。只要可用的证据足够、几何假设合理，就可能估计缺失的部分。但几何模型是一种约束和解释，不是万能的识别器。当目标不具备稳定的规则形状时，就需要转向其他视觉证据。

本页的 00–06 是知识研究的逻辑顺序，不是工程中必须逐级执行的固定流水线。实际项目可以直接使用 LSD，也可以由区域轮廓拟合椭圆，或把 Hough 候选交给结构约束验证。
