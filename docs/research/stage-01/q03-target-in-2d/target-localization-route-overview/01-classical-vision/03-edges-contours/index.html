边缘与轮廓

Edges & Contours — From Image Changes to Traceable Boundaries

颜色分不开的地方，能不能从图像的变化里，找到物体的边界？

上一站尝试从像素组织出区域。这一站换一个角度：不急着判断“里面是什么”，先观察“哪里发生了变化”。可是变化不等于边界，检测到的边缘也不等于完整轮廓。我们得弄清楚：从局部响应到一条可计算的二维曲线，中间还差什么？

梯度与尺度Canny / NMSEdge LinkingContour Tracing亚像素定位

概念示意：同一幅图像中的强变化可能来自目标边界，也可能来自目标内部纹理。可追踪轮廓是对边缘证据的进一步组织，而不是梯度检测的直接同义词。

00PROBLEM & SCOPE

先把问题划清：我们要找的究竟是什么？

同一条物体边界，既可以表现为明暗交界，也可以是二值区域的外沿；而相机看到的明暗交界，又不一定来自物体边界。先把这几个概念分开，后面的算法才不会混成一团。

EDGE / 边缘

哪里发生了局部变化？

从图像强度或其他特征的空间变化得到响应。边缘点可能无序、断开、来自纹理或阴影。

CONTOUR / 轮廓

哪些边界点属于同一条曲线？

按邻接关系组织成有序点列。轮廓可以闭合，也可以是开放曲线；有外轮廓与孔洞。

GEOMETRY / 几何模型

这些点符合什么几何约束？

直线、圆、矩形和其他参数化形状属于下一章。轮廓点并不天然等于几何模型。

两种输入，不要写成一条必经流水线

研究边界：本页研究边缘响应、边缘定位、曲线连接、轮廓提取、轮廓表示与定位精度；不研究语义识别、实例分割网络，也不提前展开 Hough、RANSAC、直线 / 圆 / OBB 的几何模型估计。
01IMAGE GRADIENTS

边缘从哪里来：图像变化能不能算出来？

先不要看二维图片。想象一排像素，灰度先保持在 50，跨过某个位置后变为 200。如果只关心单点灰度，我们并不知道哪里是边界；但如果比较相邻像素，就会发现这里的变化特别大。

I′(x) ≈ [I(x + 1) − I(x − 1)] / 2有限差分：用邻域灰度的变化近似一阶导数。真实图像的边缘通常会受到光学模糊与采样影响，而不是理想的瞬时阶跃。

二维图像在水平方向和竖直方向分别计算变化，形成梯度向量。梯度幅值表示变化有多强；梯度方向指向灰度增加最快的方向，通常与该处的边缘切线垂直。

∇I = (Ix, Iy)    G = √(Ix² + Iy²)    θ = atan2(Iy, Ix)Ix、Iy 是两个方向的一阶导数近似。后续 NMS 要用到梯度方向，而不只是强度。

为什么图像里的小噪声也可能变成“强边缘”？

求导强调局部变化，并不区分变化来自物体边界还是噪声。为了降低噪声响应，可以先平滑图像。但平滑越强，细节越容易丢失，相邻的两条窄边缘也可能合并。

可调实验 · 模糊与噪声改变了什么？

同一条理想阶跃边界，改变高斯平滑尺度与噪声幅度

几种常见工具，到底在哪里不同？

方法计算机制真正值得关注的差异
Sobel离散的一阶导数近似，并包含另一个方向上的局部平滑卷积核尺寸、梯度方向、噪声响应
Scharr改进的 3×3 一阶导数算子小核时改善不同方向的梯度近似一致性
Laplacian二阶导数 ∂²I/∂x² + ∂²I/∂y²响应强调梯度变化，对噪声敏感；符号与零交叉值得关注
LoG先高斯平滑，再施加拉普拉斯算子尺度 σ 会决定保留或抑制哪些空间结构
这一节的结论：梯度能告诉我们“哪里变化明显”，不能直接告诉我们“这是不是物体轮廓”。而且梯度响应通常有宽度，仍需解决边缘的定位与筛选。
02EDGE LOCALIZATION · CANNY

梯度算出来了，为什么还不是一条清楚的边？

图像在一个过渡带内可能连续发生变化。梯度图会形成一条较宽的亮带，附近还可能分布着较弱的噪声响应。如果把所有高梯度像素直接当成边缘，得到的就不是理想的细线。

Canny 其实在逐步回答四个问题

平滑压低高频噪声
→
梯度强度与方向
→
NMS沿梯度方向取局部峰值
→
双阈值追踪强弱边缘的连接关系

2.1 · NMS：为什么沿梯度方向比较？

要把宽亮带变成细线，就在当前像素附近沿梯度方向比较响应强度。如果当前点不是该方向的局部极大值，就抑制它；如果是峰值，就保留下来。斜向边缘需要在梯度方向的采样点上做插值或采用方向量化近似。

2.2 · 双阈值：为什么弱边缘有时也需要保留？

只使用一个阈值，阈值高会导致弱边界断裂，阈值低又会引入噪声。Canny 先划分三类候选：强边缘、弱边缘、被排除的响应；再检查弱边缘是否能够通过邻接链连接到强边缘。

G ≥ Thigh → 强边缘；  Tlow ≤ G < Thigh → 弱边缘；  G < Tlow → 抑制弱边缘的保留仍取决于与强边缘的连通关系。具体邻域追踪遵循实现的像素连接规则。
LOW THRESHOLD

低阈值太低

弱噪声和纹理更容易进入候选集，即使随后做滞后连接，也可能被保留为伪边缘。

HIGH THRESHOLD

高阈值太高

真正的边界可能缺少足够的强边缘种子，导致某些轮廓段整体消失。

边界要清楚：Canny 的滞后追踪是在已有候选边缘像素中找连通性，它不会凭空创造一条跨越大缺口的真实边界。发生明显断裂时，我们需要另行研究边缘连接问题。
03EDGE LINKING

边缘断了，靠什么判断它们属于同一条线？

有些边界很弱，Canny 只能检测出前后两段。如果把两段直接接上，也许能恢复完整轮廓；但如果接错了，就会把两个物体或一条阴影误当成同一条边界。

先分清两件事：追踪已存在的边缘，还是补全缺失的边缘？

追踪
沿 8 邻域或局部邻接图，把已有边缘像素组织为线段。面对分叉点，要有明确的选择规则。
连接
当两条边缘之间有缺口，需要根据端点距离、梯度方向、切线一致性和可能的曲率推断是否连接。
风险
连接并不是“修复真值”，而是引入平滑、连续或闭合等先验。被遮挡的真实边界尤其可能存在多种解释。
score(i, j) = wd · d(i, j) + wθ · Δθ(i, j) + wκ · Δκ(i, j)示例性的连接代价：距离、方向与曲率可以共同参与判断。它不是某个 OpenCV 函数的标准公式；各项需归一化，权重与候选筛选规则需通过实验设计。

实际研究时，不必一上来就实现复杂的全局曲线优化。可以先做边缘连通域追踪 → 端点查找 → 距离门限 → 方向约束，再验证哪些缺口能补、哪些缺口不能补。

这一节的结论：把像素组织成连续边缘，需要邻接关系；跨越缺口还需要额外假设。连接规则越强，越可能补全边界，也越可能制造错误边界。
04CONTOUR TRACING

一堆边界像素，怎样变成一条有序曲线？

现在假设我们已经有了二值 Mask：前景为 255，背景为 0。我们不只想知道哪些像素属于前景，还希望沿着外侧边界走一圈，得到按顺序排列的坐标。

这就是轮廓追踪的任务。边界追踪在前景和背景的邻接关系上工作，不需要先通过 Sobel 或 Canny 求梯度。

为什么轮廓还会有“父子关系”？

OpenCV 参数实际返回什么什么时候要注意
RETR_EXTERNAL仅最外层边界孔洞和子轮廓将不会完整返回
RETR_LIST所有检索到的轮廓，但不建立父子层级需要轮廓，但不关心包含关系
RETR_TREE所有轮廓与完整的嵌套关系需要区分外边界、孔洞、内层前景
CHAIN_APPROX_NONE保留边界追踪中所有相邻点后续需要更完整的点采样
CHAIN_APPROX_SIMPLE压缩水平、竖直与对角的连续段节省存储，不等于一般意义的曲线拟合
contours, hierarchy = cv2.findContours(mask, mode, method)典型输入为单通道 8-bit 二值图；输出 contours 是有序点列的集合，hierarchy 中每条轮廓对应 [next, prev, first_child, parent]。不同 OpenCV 主版本的 Python 返回形式可能不同。
一个重要误区：给 findContours 一张 Canny 边缘图，它会沿非零像素区域的边界组织轮廓，但不会知道哪条线才是物体真实外轮廓。细线还可能产生与期望不同的点列、闭合边界或层级关系。不要把它当成“智能连接 Canny 边缘”的函数。
05CONTOUR REPRESENTATION

轮廓有了，怎么让它更容易保存、比较和计算？

沿边界追踪一圈，可能得到几百或几千个像素坐标。并不是每一种任务都需要完整保存它们。接下来有两种完全不同的思路：简化轮廓的表示，或者利用图像证据继续优化轮廓位置。

REPRESENTATION

链码（Chain Code）

把相邻轮廓点之间的方向记成 4 邻域或 8 邻域方向编号。重点不是新建边界，而是编码已有的有序路径。

SIMPLIFICATION

Douglas–Peucker

保留足以逼近原始曲线的关键顶点。允许的近似误差越大，一般保留的点越少，也越可能损失小尺度细节。

5.1 · 为什么可以删掉某些轮廓点？

想象一条近似直线的边界，上面保存了几十个点。如果只保留首尾两点，几乎也能表达原来的形状。但对弯曲明显的部分，只保留首尾点就会产生较大偏差。Douglas–Peucker 正是根据偏差递归决定是否保留中间点。

ε = 允许的最大近似偏差  ·  approxPolyDP(contour, ε, closed)ε 与输入点坐标使用同一长度单位；对 OpenCV 图像轮廓而言，通常就是像素。常见做法可把 ε 设为轮廓周长的某个比例，但不是通用最优值。

5.2 · 如果想让曲线继续贴近真实图像边界呢？

轮廓简化不会自动变得更准确。另一类方法是 Active Contour（Snakes）：给曲线定义能量，既希望它靠近有图像证据的位置，又希望曲线不要随意拉伸或发生不必要的弯折。

E[v] = ∫ [ α|v′(s)|² + β|v″(s)|² + Eimage(v(s)) ] ds一种典型的轮廓能量形式：一阶、二阶项控制曲线内部正则性；图像能量项吸引曲线到候选边界。具体模型还有外力、约束与不同参数化形式。

它的局限也很明确：需要初始轮廓，可能陷入局部极小值；对弱边界、凹陷区域和错误的图像能量容易产生偏差。不是把 Canny 结果丢进去就一定会改善。

这一节的结论：链码关心“怎么存”；轮廓简化关心“用更少点表达”；Active Contour 关心“依据图像约束继续优化”。直线 / 圆 / 矩形等形状模型参数估计仍然留在下一章。
06LOCALIZATION PRECISION

最后一个问题：找到的边界究竟有多准确？

一张图里的边缘看起来很细，不代表测量位置就一定准确。标准的 Canny 边缘图标记在整数像素网格上，真实连续空间中的边界却不必恰好落在像素中心。

亚像素定位来自哪里？

如果在边界法线方向上有一个比较平滑、孤立的梯度峰值，可以利用峰值附近的响应，在相邻整数像素之间估计它的连续位置。例如，用三个采样点拟合局部二次曲线：

δ = ½ · (g−1 − g+1) / (g−1 − 2g0 + g+1)δ 是相对于中心采样位置的偏移量。要求分母非零且局部响应符合峰值近似；二维边缘还需沿梯度方向采样并把偏移投影回图像坐标。这只是亚像素估计的一种方式。
SAMPLING

像素离散化

边界位于整数像素之间，直接取最大响应所在像素会产生量化偏差。

IMAGE FORMATION

成像与噪声

光学模糊、反光、运动模糊及信噪比都会改变局部灰度剖面与峰值。

ALGORITHM

检测与表示

平滑核、阈值、连接、轮廓近似与亚像素模型都可能进一步改变位置。

评估时，究竟应该测什么？

指标回答的问题必要前提
边界位置偏差检测点距离已知真实边界有多远？需要可控的合成真值或更高精度参考
连续性 / 召回真实边界中，有多少段被成功检出？定义匹配距离容差、可见边界范围
误检比例检测到的边缘有多少来自纹理与噪声？真实目标边界与其他图像变化要分开标注
重复性同一静态场景连续采集，轮廓位置跳动多大？尽可能固定光照、曝光与相机姿态
务必分开：亚像素只是输出坐标能细于一个像素，不代表绝对定位误差必然小于一个像素。即使曲线拟合残差很小，也可能因为错误边缘、系统偏差或错误的前景定义，偏离真实目标。
07EXPERIMENTS & TAKEAWAYS

怎样把这一章真正学明白？

不需要为每个算法都找一套数据集。用一张形状已知的合成图，再加一张真实图像，逐次改变一个条件，就能验证很多问题。

EXP 01
为什么要平滑？

对固定边缘加入不同强度噪声，比较 Sobel 梯度响应及不同 σ 下的定位、误检与边缘宽度。

EXP 02
Canny 哪一步真正改变了边缘？

观察梯度幅值、NMS 候选、阈值连接后的结果；分别改变平滑尺度和上下阈值，记录断裂与伪边缘。

EXP 03
边缘图和 Mask 的轮廓有什么不同？

构造含孔洞、内部纹理、断裂线的图像，分别对二值 Mask 和 Canny 输出进行 findContours，比对点列与层级。

EXP 04
轮廓简化与定位的代价是什么？

逐步增大 ε，绘制点数和最大偏差的变化；在亚像素平移的合成边缘上比较整数像素和连续峰值估计。

一份最小可复现的 OpenCV 实验

下面的代码只演示其中两个输入路径：同一张灰度图 → Canny → 轮廓，以及已知前景 Mask → 轮廓。故意在目标内部加入纹理线，看看它们是否会进入边缘结果。需要安装 numpy、opencv-python 和 matplotlib。

展开完整代码：生成测试图、对比 Canny 与 Mask 轮廓 
import cv2
import numpy as np
import matplotlib.pyplot as plt

# 固定随机种子，便于重复实验
rng = np.random.default_rng(42)
h, w = 300, 480

# 1. 构造前景 Mask：一个实体 + 一个孔洞
mask = np.zeros((h, w), dtype=np.uint8)
cv2.rectangle(mask, (95, 65), (370, 235), 255, -1)
cv2.circle(mask, (233, 151), 48, 0, -1)

# 2. 用 Mask 制作灰度图；额外加入内部纹理与少量噪声
img = np.full((h, w), 62, dtype=np.float32)
img[mask > 0] = 180
cv2.line(img, (120, 92), (345, 92), 110, 3)
cv2.line(img, (122, 112), (340, 112), 220, 3)
img += rng.normal(0, 9, (h, w)).astype(np.float32)
img = np.clip(img, 0, 255).astype(np.uint8)

# 3. 图像变化路径：平滑 -> Canny -> 轮廓追踪
smooth = cv2.GaussianBlur(img, (5, 5), 1.2)
edge = cv2.Canny(smooth, 60, 130, L2gradient=True)
edge_contours, _ = cv2.findContours(
    edge, cv2.RETR_LIST, cv2.CHAIN_APPROX_NONE
)

# 4. 已知区域路径：直接从 Mask 追踪轮廓
mask_contours, hierarchy = cv2.findContours(
    mask, cv2.RETR_TREE, cv2.CHAIN_APPROX_NONE
)

# 5. 比较两组结果（注意：轮廓数量不是检测质量指标）
view_edge = cv2.cvtColor(img, cv2.COLOR_GRAY2RGB)
view_mask = view_edge.copy()
cv2.drawContours(view_edge, edge_contours, -1, (240, 130, 65), 1)
cv2.drawContours(view_mask, mask_contours, -1, (40, 155, 110), 2)

fig, axes = plt.subplots(2, 2, figsize=(11, 6.5))
for ax, data, title in zip(
    axes.flat,
    [img, edge, view_edge, view_mask],
    ["Grayscale input", "Canny edges", "Contours on edges", "Contours on mask"],
):
    ax.imshow(data, cmap="gray" if data.ndim == 2 else None)
    ax.set_title(title)
    ax.axis("off")
plt.tight_layout()
plt.savefig("edges_contours_experiment.png", dpi=180)
plt.show()

print("Edge contours:", len(edge_contours))
print("Mask contours:", len(mask_contours))
print("Mask hierarchy:", hierarchy[0].tolist() if hierarchy is not None else None)

轮廓断成几段弱边缘滞后追踪、连接与补全假设“findContours 会自动把断口接上”
已经有了 Mask边界追踪、孔洞、轮廓层级“必须先 Canny 再 findContours”
轮廓点太多链码、曲线压缩、近似偏差“近似后的顶点就是真实角点”
测得位置不稳定误差来源、重复性、亚像素估计“有小数坐标就说明精度高”
这一站得到的答案：原始图像只能提供局部变化证据；梯度与 Canny 负责检测和定位候选边缘，边缘连接利用连续性假设，轮廓追踪把边界组织为有序点列，曲线近似与亚像素方法进一步改变它的表示或坐标。每一步都可能减少噪声，也可能损失或制造几何信息。
