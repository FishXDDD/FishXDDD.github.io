局部特征与对应

Local Features & Correspondence · 从两张图像里认出同一处

前面研究了颜色、区域、边缘、几何和骨架。这些信息可以描述目标当前长什么样。不过，还有一种场景：我手上已经有目标的一张照片，现在想在另一张图像中找到它。

假设是一只带标签的盒子。它可能换了位置、大小或拍摄角度，甚至只露出一部分。能不能不要求先分出完整物体，而是找到两张图像里确实对应的几个局部位置？

这一页从最直接的局部像素比较开始，了解关键点、描述子、匹配和几何验证分别在干什么。保留核心数学表达来帮助记忆，不深入完整推导与代码复现。

输入：参考图 + 当前图输出：局部对应 / 平面定位重点：核心机制与公式
00 · PROBLEM & SCOPE

先把任务定义清楚

局部特征与对应：给定两张图像，寻找来自同一物理位置或结构的局部图像位置，并判断这些对应关系是否可信。

它可以用于参考目标定位、图像配准、视觉里程计等任务；本篇只讨论二维图像中的局部特征与匹配机制。至于三维重建和相机位姿估计，留给对应章节。

整条技术链可以先记成四件事：在哪里找点 → 用什么描述它 → 怎样找对应 → 对应是否符合几何关系。它们是不同子问题，不应当把 Harris、SIFT、ORB 和 RANSAC 当成同一种算法来比较。

01 · DIRECT PATCH MATCHING

直接拿一块像素去搜索，为什么还需要特征？

最容易想到的方法，是从参考图里截取一块小图像，然后在当前图里逐位置比较。哪一处的像素最相似，就认为它可能对应参考区域。这就是模板匹配的基本想法。

关键公式 · SSD（平方差和）像素到底怎样比较？
SSD(u,v) = Σ(x,y)∈W [ T(x,y) − I(x+u,y+v) ]²

T 是参考小块，I 是当前图像，(u,v) 是搜索位置，W 是小窗口内的像素集合。结果越小，说明该位置的像素越接近模板。

例子

同一图案只是水平移动，找到正确偏移量后 SSD 可以很小；一旦旋转，原来相邻的像素对应不上，即使还是同一物体，SSD 也会变大。

所以我们需要两件新能力：先找到有辨识度、容易再次出现的位置，再用一种比原始像素更稳健的方式描述它们。

02 · KEYPOINT DETECTION

图像里哪些位置值得被记住？

考虑一个小窗口。如果里面几乎是纯色，不管挪到哪里都差不多；如果只有一条直边，沿着边的方向移动仍然相似。角点更有价值：在水平和竖直方向上稍微挪动，窗口里的内容通常都会明显变化。

Harris / Shi–Tomasi 把这种直觉写成数学：观察窗口内的水平、垂直灰度变化，分析它在不同方向上究竟有多敏感。

关键公式 · 结构张量 为什么角点需要两个方向都有变化？
M=∑p∈Ww(p)·[Ix2IxIyIxIyIy2]

这里的方括号表示一个 2×2 矩阵。Ix、Iy 是图像在水平、竖直方向的灰度变化，w(p) 是窗口权重。矩阵的两个特征值 λ₁、λ₂ 表示两个主方向上的变化强弱。

两者都小 → 平坦；一大一小 → 更像边缘；两者都大 → 更像角点。
Harris: R = det(M) − k · tr(M)²Shi–Tomasi: s = min(λ₁, λ₂)

Harris 用矩阵行列式与迹得到角点响应；Shi–Tomasi 直接看最弱方向是否也变化明显。这里记住判断依据即可，不需要推导特征值的求解过程。

另一种常见选择是 FAST：不构造结构张量，而是看候选点周围圆环上的一圈像素，是否存在连续一段明显比中心更亮或更暗。它的检测计算更简单、速度通常更快；不过它主要解决的是找点，不是描述点。

03 · SCALE & ORIENTATION

同一个局部变大、旋转以后，怎样再次找到？

只在原图上找角点还不够。比如标签在远处只有几十像素，靠近后变成上百像素：固定大小的窗口看到的已经不是相同范围。旋转之后，局部纹理的方向也变了。

SIFT · 尺度空间 + 主方向

把图像做不同程度的高斯模糊，在位置与尺度上寻找稳定的 DoG 极值，再根据局部梯度分布估计主方向。后续描述子以选定尺度、方向为参考。

ORB · 图像金字塔 + FAST + 方向

先在多层缩放图像中用 FAST 找候选点，再估计局部灰度质心方向，生成可随方向调整的二进制描述子。通常更注重速度和资源开销。

关键公式 · SIFT 的 DoG 怎样在不同尺度中找显著结构？
D(x,y,σ) = L(x,y,kσ) − L(x,y,σ)

L(x,y,σ) 是图像经尺度为 σ 的高斯平滑后的值；kσ 是更大的模糊尺度。相减可以突出随尺度变化的局部结构，SIFT 会在空间和尺度邻域内找极值来确定候选位置及特征尺度。

记住

金字塔不等于尺度不变性。多尺度观察只是基础，还需要在尺度之间选择对应的稳定特征。ORB 的多层 FAST 与 SIFT 的 DoG 极值也不是同一个检测机制。

04 · LOCAL DESCRIPTORS

两张图里都找到角点，凭什么判断是同一处？

关键点检测解决了“在哪里看”，但两张图里可能各有几百个角点。只知道坐标没有办法判断它们是否对应，所以需要给每个关键点生成一份能够比较的局部描述子。

SIFT 描述子：浮点向量

把按尺度、方向对齐的邻域分成 4×4 个子区，每区统计 8 个梯度方向，得到 4×4×8=128 维向量，再作归一化等处理。描述子之间常用 d₂(a,b)=√Σᵢ(aᵢ−bᵢ)²（L2 距离）。

BRIEF / ORB：二进制描述

在局部区域选若干像素对，比较亮度并记录 0 或 1；ORB 会使用带方向的 BRIEF 变体，使比较模式随关键点方向调整。描述子常用 Hamming 距离。

关键公式 · 二进制描述与 Hamming 距离 如何把局部比较变成数字？
bi = 1[ I(pi) < I(qi) ]dH(a,b) = popcount(a XOR b)

第一个式子表示：比较一对像素 pi、qi 的亮度，条件成立记 1，否则记 0。第二个式子统计两串二进制描述子有多少位不同。

例子

101100 与 100110 有两位不同，因此 Hamming 距离为 2。不同的位越少，通常表示局部描述越相似。

描述子只是局部外观的近似表示：重复纹理可能生成很像的描述子，光照或视角剧变也可能让同一处不再相似。

05 · FEATURE MATCHING

找到最相似的描述子，就一定匹配对了吗？

有了描述子，就能对参考图的一个关键点，在当前图中寻找描述距离最小的候选。但最像不等于真的对应，尤其是图像里有相似文字、栅格或重复螺丝孔时。

关键公式 · Lowe Ratio Test 为什么要比较第一名和第二名？
d₁ / d₂ < ρ　( d₁ ≤ d₂, d₂ > 0 )

d₁ 是最近邻距离，d₂ 是次近邻距离，ρ 是接受阈值。两者差距越大，最佳匹配通常越没有歧义。阈值常以 0.7～0.8 作为实验起点，但不是通用真理。

例子

16/40=0.4：最佳候选明显领先；18/20=0.9：第一和第二几乎一样，难以区分。

另一种筛选是 Cross-check（交叉检查）：A 认为 B 最像，同时 B 也认为 A 最像，才留下对应。它和 Ratio Test 判断的是不同性质，不会自动保证几何正确。

还缺一步：如果桌上有好几个相同包装盒，多个局部匹配可能分别落在不同盒子上。怎样判断它们是否真属于同一个目标？

06 · GEOMETRIC VERIFICATION

怎样判断多个匹配是否符合同一个几何变化？

描述子只判断“局部看起来像不像”。但如果参考图中的一组点都来自同一块平面，那么它们在当前图中的位置应该满足同一个平面投影变换。错误对应往往无法同时满足这种约束。

关键公式 · Homography（单应性）平面点在两幅图像中如何对应？
s · [x′, y′, 1]ᵀ = H · [x, y, 1]ᵀ

(x,y) 是参考图像中的点，(x′,y′) 是当前图中的对应点；H 是 3×3 单应性矩阵，s 是齐次坐标的尺度。对于同一平面上的点，可以用一个 H 来描述两张图之间的透视映射。

注意：单应性不仅能用于纯平面，也可描述相机纯旋转情形的两视图关系；但这里讨论的是平面参考目标的定位。

eᵢ = ‖ p′ᵢ − π(H · pᵢ) ‖₂

eᵢ 是一个匹配点的重投影误差；π 表示把齐次坐标除以最后一个分量，还原成二维像素。若 eᵢ < τ，就可以把该匹配视作候选几何内点（τ 为像素误差阈值）。

RANSAC 的核心思路是：从匹配中反复抽取少量点估计候选 H，统计有多少匹配的重投影误差较小，选取几何一致性较强的模型，再用内点重估与检查。对于一般平面单应性，至少需要 4 组非退化点对应来估计候选 H。

局限：足够多的内点不等于一定识别对了物体。重复图案可能形成错误却自洽的对应；点集中在一小块区域可能导致四角投影不稳定；明显非平面的目标通常也不应直接套用一个平面 H。

07 · CHOICE & BOUNDARY

回头看：到底要记住哪些方法？

这一页并不是要求按顺序掌握所有经典算法。你真正要建立的是技术分工：哪一步负责找位置，哪一步记录局部外观，哪一步解决匹配歧义，哪一步验证几何是否说得通。

方法主要在做什么最重要的直觉常见限制
Harris / Shi–Tomasi寻找稳定局部角点两个方向的灰度变化都明显本身不解决尺度、描述与匹配
FAST快速检测候选关键点圆环上出现连续明显亮/暗像素需要配合筛选、尺度和描述子
SIFT尺度/方向选择与浮点描述DoG 选尺度，梯度方向构造指纹计算代价较高，弱纹理仍困难
ORB高效关键点与二进制描述金字塔 + FAST + 方向化 BRIEF大视角变化、模糊、重复纹理仍困难
Ratio / Cross-check筛掉部分歧义匹配不能只看“谁最像”不能证明对应点的空间一致性
RANSAC + H验证平面参考的共同几何变化一组正确对应应由同一模型解释平面假设、重复图案和点分布退化

对于带独特文字或纹理的平面目标，局部特征匹配是一条可考虑的路线；如果目标几乎无纹理、重复图案严重、发生强烈非刚性形变，或者你要找的是一个尚无参考的“任意瓶子”，这条路线就未必合适。

这一页最值得记住的关系：角点检测解决“在哪里”，描述子解决“长什么样”，最近邻匹配解决“像不像”，几何验证解决“一组对应是否说得通”。这些环节能组合，但不能互相替代。
