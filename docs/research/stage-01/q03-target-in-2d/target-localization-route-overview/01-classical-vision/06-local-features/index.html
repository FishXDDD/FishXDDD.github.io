局部特征

Local Features — Find It Again by Its Details

不用先把整个物体分出来，只凭几个局部细节，能不能在另一张图里重新找到它？

前面讨论过像素、区域、轮廓、几何与拓扑。还有一种很有意思的路线：一张物体的参考照片已经给了我们，能不能只记住它上面那些容易再次找到的小地方，再去场景图里寻找对应关系？本页研究的不是“这是什么类别”，而是“这是不是我之前见过的同一处局部结构”。

Harris / Shi–Tomasi / FASTSIFT / SURF / ORBBRIEF / 描述子特征匹配RANSAC 几何验证

机制示意：不是要求找到完整 Mask，而是寻找跨图像可重复的局部细节。连线只是候选对应，只有通过匹配筛选和几何验证，才能作为可信的定位证据。

00PROBLEM & SCOPE

从“找出整个物体”，换成“重新找到它的局部细节”

比如我手里有一张印着文字、图标和纹理的包装盒照片。下一帧里盒子可能平移、旋转、变小，甚至被遮住一部分。能不能不依赖颜色阈值与完整轮廓，而是从参考照片里挑一些容易辨认的局部，拿到新图像中重新寻找？

DETECT

检测关键点

从图像里挑出位置相对稳定、容易再次检测的局部，例如角点、纹理细节。

DESCRIBE

描述关键点

关键点位置不够，需要把邻域编码成可以比较的数值向量或二进制串。

MATCH & VERIFY

匹配与验证

从两张图像中建立候选对应，并判断它们是否符合一个合理的二维几何变换。

Iref, Iscene → {(x, y, σ, θ, d)} → {(pi, qi)} → 2D alignment关键点可以具有位置 (x,y)、尺度 σ、方向 θ、描述子 d；并非所有检测器都提供全部属性。输出主要是二维对应关系，而非物体三维位姿。

这条路线有明确前提：参考物体或图像中存在足够可辨识的局部结构。它适合参考图匹配、平面目标重定位、图像对齐等场景；对于纯色物体、重复纹理、严重遮挡或大视角变化则可能失败。

研究边界：只研究传统二维关键点、局部描述、跨图像匹配与二维几何验证。不进入学习式目标识别、视觉语言 Grounding、深度与三维重建，也不将单应矩阵误当成六自由度物体 Pose。
01FIRST IDEA

能不能直接记住一小块像素，下次拿它去找？

最直接的想法是截取一个小窗口，再到另一张图里逐处比较。我们不需要马上学习 SIFT，先看看这个朴素方法能做到什么。

SSD(u,v) = Σ(i,j)∈W [T(i,j) − I(u+i,v+j)]²用平方误差比较模板 T 与待测图像 I 的局部窗口。小则相似，但相似不一定表示同一个物理位置。

在大小、角度、曝光都相近时，SSD 或 NCC 这类局部窗口比较确实可以工作。但稍微换个条件，像素就不再一一对齐：目标旋转使窗口内容改变；距离变化让局部缩放；光照与模糊也会改变数值。

位置变化

若只发生平移，遍历窗口通常可以找到相似位置，但运算可能昂贵。

角度变化

同一块图案旋转后，原窗口内的像素相对位置改变。

尺度变化

同一局部变大或变小，固定尺寸窗口不再是同一个内容。

还有一个比旋转更基础的困难：不是每块像素都值得记住。一片纯色区域到处相似；一条长直线即使移动窗口，也可能沿线找到大量相似结果。看来需要先研究：哪些局部在二维空间里具有可区分的位置？

这一节得到
直接比较局部像素是可行的基线，但对几何与光照变化敏感。下一步不是立刻换一个“更高级算法”，而是明确稳定局部位置的判断依据。
02WHAT IS A GOOD KEYPOINT?

什么样的局部，移动一点就能被认出来？

将一个小窗口在图像里做微小平移。如果窗口内部几乎没有变化，就很难定位；如果只有一个方向变化，它只能约束一个方向；如果两个方向都会明显变化，才有希望稳定确定二维位置。

2.1 · Harris：把“朝哪个方向移动都会变化”写成数学

考察窗口 W 在一个微小位移 (u,v) 下的灰度变化：

E(u,v) = Σ(x,y)∈W w(x,y)[I(x+u,y+v) − I(x,y)]²

对图像做一阶近似，便得到由梯度构成的结构张量 M：

E(u,v) ≈ [u,v] M [u,v]TM = Σw · [[Ix², IxIy],[IxIy, Iy²]]；Ix、Iy 为局部图像梯度。

两个特征值 λ₁、λ₂ 决定了局部窗口在两个主方向上的变化程度：都小是平坦区域；一个大一个小更像边缘；两个都大则更像角点。

Harris: R = det(M) − k · trace(M)²常用 k 在约 0.04–0.06 量级；R 大且为正是候选角点，仍需阈值与非极大值抑制。评分不是概率。

Shi–Tomasi 做了一个更直接的判断：取两个特征值里较小的那个，只有最弱方向也足够明显才保留。

Shi–Tomasi: score = min(λ₁, λ₂)与 Harris 是相关但不同的角点评分准则，不需要编造成前者必然淘汰后者。

2.2 · FAST：如果只想快速找候选角点，能更简单吗？

Harris 需要计算梯度和结构张量。FAST 走了另一条路：观察候选像素周围半径为 3 的 16 个圆周像素，检查是否有连续的一段相对中心显著更亮或更暗。它可以快速剔除大量非角点。

这里开始能看到技术的分工：Harris / Shi–Tomasi 说明角点为什么可定位；FAST 解决如何更快速地产生角点候选。检测到角点之后，仍没有解决“另一张图里如何辨认它”这个问题。

这一节得到
选择关键点需要考虑重复检测与二维定位能力。角点检测器输出的是位置与响应，不等于已经生成了跨图像可比较的描述子。
03SCALE & ORIENTATION

同一处角点变大、旋转了，还能重新检测吗？

即使一个角点在当前图像里很稳定，换个观察距离或视角，它所占的像素范围也会改变。固定窗口的角点检测器并不能保证跨尺度重复出现。

3.1 · 如果把图像放到不同尺度下观察呢？

Gaussian Pyramid 用逐级平滑、降采样构造不同分辨率；尺度空间则在不同 σ 下观察图像结构。一个特征如果在适合它的尺度上被检测到，就不必强行使用同一个像素窗口。

3.2 · SIFT：尺度极值与方向归一化为什么放在一起？

SIFT 先使用不同模糊尺度的 Gaussian 差分（Difference of Gaussians, DoG）寻找空间与尺度上的候选极值，剔除低对比度和不稳定的边缘响应，再为关键点分配主方向。

D(x,y,σ) = L(x,y,kσ) − L(x,y,σ)L = G(σ) * I；DoG 近似尺度归一化的 LoG 响应。极值比较包含同层邻域以及上下相邻尺度层。

这里的两个机制各自解决不同问题：尺度定位帮助在不同大小的成像中找到类似结构；方向分配让之后的描述子可以围绕局部主方向进行归一化，减小图像整体旋转影响。不能把“关键点被检测到”和“描述子能匹配”混为一谈。

3.3 · 另一种工程路线：金字塔 + FAST + 方向估计

ORB 并没有照搬 SIFT 的尺度空间极值检测，而是使用图像金字塔和 FAST 产生候选，再筛选角点，并用局部灰度质心方向让描述子尽量随旋转调整。

mpq = Σ xpyqI(x,y),   θ = atan2(m01, m10)方向由相对关键点中心的灰度一阶矩估计；当局部纹理对称或不稳定时，方向本身也可能不可靠。

SIFT 与 ORB 不是同一算法的“升级前后版”，而是两套设计权衡：前者倾向于较丰富的尺度、梯度描述，后者强调检测与二进制描述的计算效率。

这一节得到
关键点需要在尺度、方向发生变化时尽可能重复出现；但“尺度不变”“旋转不变”都是有条件的鲁棒性，不代表任意透视变形、遮挡或模糊下都能检测成功。
04LOCAL DESCRIPTION

两个角点都是角点，凭什么知道它们是不是同一个？

Harris 只能告诉我们某个位置“像角点”。想在另一幅图里识别它，还需要描述周围的局部图案。关键问题是：既要区分不同地方，又要容忍一定的成像变化。

4.1 · SIFT：统计梯度方向，而不是记住每个像素

把主方向对齐后的邻域划成 4×4 个区域，每个区域统计 8 个方向的梯度直方图，得到常见的 128 维浮点描述子，再做归一化与截断等处理。

4.2 · BRIEF：既然只要比较，能否只用 0 和 1？

在局部窗口里取若干对像素位置，比较亮度大小：小于就记 1，否则记 0。连续比较得到二进制串，匹配时计算 Hamming 距离。

BRIEF biti = [I(pi) < I(qi)]   ·   dH(a,b)=popcount(a XOR b)二进制比较对光照的某些单调变化比较稳健，但对局部旋转、采样误差和噪声仍敏感。

4.3 · ORB 怎么补上 BRIEF 的旋转问题？

纯 BRIEF 在固定坐标上比较像素对；局部旋转之后，比较到的就可能是其他位置。ORB 估计关键点方向，并旋转比较点对的采样模式，使用经过选择的二进制测试形成 rBRIEF。检测、方向估计、描述子生成是不同环节，只是 ORB 把它们集成了。

4.4 · SURF 放在哪里？

SURF 与 SIFT 都属于较成熟的浮点特征路线，但思路不同：它使用基于 Hessian 行列式的兴趣点响应，并借助积分图和盒式滤波实现近似计算，描述阶段使用局部 Haar 小波响应等信息。它适合放在方法比较中，不必因为名字熟悉就把每个细节扩展成另一套完整教程。

方法承担的环节核心机制典型度量 / 局限

这一节得到
“找到一个点”和“认出这是哪个点”是两个独立任务。浮点梯度描述与二进制像素比较是不同计算取舍，描述子越长、距离越小都不自动保证跨图像身份正确。
05MATCH & GEOMETRY

描述子看起来相似，怎么证明它们真的是同一处？

只比较描述子，最容易得到的并不是“目标位置”，而是一批候选匹配。有些局部图案很像，尤其是栅格、文字重复、螺丝孔、规则纹理。我们需要把外观相似和空间一致分开判断。

5.1 · 最近邻匹配：先找最像的候选

SIFT 等浮点描述子常用 L2 距离；ORB / BRIEF 一类二进制描述子常用 Hamming 距离。对参考描述子找到场景中的最近邻、次近邻后，可以做 Lowe Ratio Test：

d1 / d2 < τ若最好候选与第二好候选分数很接近，匹配具有歧义。τ 不是通用的正确率概率，也没有一个适合所有数据的固定最优值。

另外可以使用双向最近邻的一致性检查（Mutual Nearest Neighbor / Cross-check）。它与 Ratio Test 的判断依据不同；二者都主要处理描述子匹配歧义，不能替代后面的几何验证。

匹配示意：外观接近，不代表几何正确
几何一致候选外观相似但可能错误的候选

5.2 · 加上一个共同的二维变换约束

如果参考目标近似平面，而且两次观察满足单应性模型，可以寻找一个 H，把参考图上的点映射到场景图。它至少需要四对非退化的对应点；实际为了对抗错误对应，需要比四对更多、且空间分布合理的候选。

s [x′, y′, 1]T = H [x, y, 1]TH 为 3×3 单应矩阵，整体尺度不唯一。非平面目标在一般视角变化下，不存在适用于所有点的单一 H。

RANSAC 的关键不是“自动知道哪个点正确”，而是反复从候选中采样、估计模型，再统计满足重投影误差阈值的对应。与模型不一致的匹配被视为离群点。

ei = ‖ qi − π(H pi) ‖₂π 表示把齐次坐标除以第三维。误差阈值通常以像素计，需要结合图像分辨率、定位精度和任务容差设置。

5.3 · 交互观察：为什么光凭“匹配数”不够？

二维对应中的离群点与内点

固定一组真实仿射对应与错误匹配，拖动容差观察内点数量变化。这里只展示已知模型下的残差筛选，不是完整 RANSAC 或 SIFT 实现。
INTERACTIVE · GEOMETRIC RESIDUAL

阈值过大也会接纳错误对应，数量上升不等于定位更可靠。

演示里几何变换已知，真实任务需要从含有离群点的候选对应中用 RANSAC 等方式估计模型。内点统计也无法自行证明物体身份。

5.4 · 什么时候不能直接用 Homography？

平面包装盒正面、书封面等适合使用单应性作二维对齐；但如果目标存在明显三维起伏、弯曲或大幅非刚性形变，单一 H 会留下系统残差。若仅需要局部平移、旋转、缩放，可以先考虑自由度更少的相似或仿射模型，不必无条件使用最复杂的变换。

即使拟合到了 H，也应检查匹配点是否集中在一个很小区域、是否位于重复花纹上、估计四角是否畸形。几何自洽不自动等于目标确认。

这一节得到
距离匹配负责“外观候选”，Ratio / Cross-check 负责减少歧义，几何模型与 RANSAC 负责“空间一致性”。它们不应互相替代，也不能保证在纯色、重复纹理或非平面场景下可靠定位。
06VERIFICATION & TAKEAWAYS

这一条路线究竟解决了什么，又该如何验证？

回看整条路线：我们没有先找完整区域，而是挑出可重复局部；为了再次认出它，加入描述子；为了排除错认，再加入几何一致性。每一步扩展的是不同能力，而不是“新算法把旧算法淘汰了”。

遇到的问题实际使用的证据代表技术不能保证什么
局部是否容易精确定位？二维方向上的灰度变化Harris、Shi–Tomasi、FAST关键点跨尺度/旋转都稳定
成像大小或角度改变了？尺度空间响应、主方向SIFT、ORB 金字塔/方向机制大透视或模糊下仍能重复检测
两个局部是否相似？梯度统计或像素对关系SIFT、SURF、BRIEF、ORB描述子相似就是同一物理位置
候选对应是否歧义？最近邻和次近邻距离Ratio Test、Cross-check重复花纹能被完全排除
匹配是否空间一致？二维变换和重投影残差Homography、RANSAC物体身份、三维位姿都正确

三组最小验证实验

EXPERIMENT 01
关键点是否真的能够重新检测？

同一张参考图经过平移、旋转、缩放、模糊与亮度变化，统计在已知二维变换下的可重复检测比例，并显示丢失点的位置。对比 Harris / FAST / SIFT / ORB，明确检测阶段与描述阶段的区别。

EXPERIMENT 02
描述子相似，为什么还有很多错误对应？

使用有独特纹理和重复纹理的两组图，记录匹配候选、Ratio 筛选、双向一致性和错误对应分布。匹配数只做辅助，不单独用它判断结果好坏。

EXPERIMENT 03
几何验证后，目标真的定位准确了吗？

使用具有已知平面变换的图像对，统计内点比例、重投影误差中位数、空间覆盖范围以及参考图四角的映射误差；再人为加入遮挡、离群点与非平面变化，观察 Homography 的失效边界。

最小 OpenCV 工程验证

只保留一条简单可复现的路线：ORB 检测/描述 → KNN + Ratio → RANSAC 单应性 → 输出场景中的参考图四角。这不是推荐所有项目都使用 ORB，而是让每个中间结果都可以检查。

展开 · 完整 Python 示例（OpenCV / NumPy）

准备 reference.png 和 scene.png；仅对近似平面目标的二维对齐有解释力。阈值是实验起点，不是通用参数。

import cv2
import numpy as np

# 把下方路径替换为自己的参考图与场景图
ref = cv2.imread("reference.png", cv2.IMREAD_GRAYSCALE)
scene = cv2.imread("scene.png", cv2.IMREAD_GRAYSCALE)
if ref is None or scene is None:
    raise FileNotFoundError("请准备 reference.png 和 scene.png")

# 1. 检测 + 描述：ORB 内部组合了金字塔、FAST 和方向化 BRIEF
orb = cv2.ORB_create(nfeatures=1500, scaleFactor=1.2, nlevels=8)
kp1, des1 = orb.detectAndCompute(ref, None)
kp2, des2 = orb.detectAndCompute(scene, None)
if des1 is None or des2 is None or len(des2) < 2:
    raise RuntimeError("可用描述子不足：先检查纹理、对焦和图像质量")

# 2. 描述子匹配：ORB 默认 WTA_K=2 对应 Hamming
matcher = cv2.BFMatcher(cv2.NORM_HAMMING)
knn = matcher.knnMatch(des1, des2, k=2)
good = [m for pair in knn if len(pair) == 2
        for m, n in [pair] if m.distance < 0.75 * n.distance]
print(f"keypoints={len(kp1)}/{len(kp2)}, candidates={len(good)}")

# 3. 平面目标的几何一致性验证；4对只够理论上求解，不保证可靠
if len(good) < 8:
    raise RuntimeError("候选对应太少，不足以做稳健验证")
src = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
dst = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
H, mask = cv2.findHomography(src, dst, cv2.RANSAC, 3.0)
if H is None or mask is None:
    raise RuntimeError("单应性估计失败，检查分布和退化情况")

inliers = mask.ravel().astype(bool)
pts_pred = cv2.perspectiveTransform(src, H).reshape(-1, 2)
err = np.linalg.norm(pts_pred - dst.reshape(-1, 2), axis=1)
print(f"inliers={inliers.sum()}/{len(good)}; "
      f"inlier median error={np.median(err[inliers]):.2f}px")

# 4. 把参考图四角投影到场景图，仅对近似平面目标适用
h, w = ref.shape
corners = np.float32([[0, 0], [w-1, 0], [w-1, h-1], [0, h-1]]).reshape(-1,1,2)
projected = cv2.perspectiveTransform(corners, H).reshape(-1, 2)
result = cv2.cvtColor(scene, cv2.COLOR_GRAY2BGR)
cv2.polylines(result, [np.int32(np.round(projected))], True, (0, 200, 90), 2)
cv2.imwrite("local_features_result.png", result)

面对具体问题，应该优先判断什么？

纹理丰富
有已知参考图、局部结构独特时，先试 SIFT / ORB；不要在原始像素匹配上过度调阈值。
纯色弱纹理
难以产生有区分度的关键点，转向前面研究的颜色区域、轮廓或几何结构证据。
重复花纹
描述子匹配容易一对多，必须检查空间分布、几何模型与对应歧义。
遮挡变化
局部特征不要求完整轮廓，但需要剩余的足够多且分布合理的可靠对应。
大视角变化
SIFT / ORB 的旋转、尺度鲁棒性并不等于任意透视鲁棒性；确认是否仍有可重复的局部结构。
本章结论：局部特征路线利用局部结构的可重复性，在两张图像间建立对应关系。角点检测解释“哪里容易稳定定位”，描述子解决“怎样比较局部”，匹配与几何验证解决“哪些对应值得相信”。它可以定位参考图中的平面目标，但不能凭空解决目标语义、三维深度和任意形变。
