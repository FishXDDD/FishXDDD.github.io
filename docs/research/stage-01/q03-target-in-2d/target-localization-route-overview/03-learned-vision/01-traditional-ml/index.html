01 · HANDCRAFTED FEATURES + MACHINE LEARNING

传统机器学习定位

Handcrafted Features · From Features to Learned Decisions

前面已经研究了怎样从图像里提取颜色、纹理、梯度和形状。如果目标的外观变化很多，每种情况都靠手写判断规则，似乎越来越难维护。

换个思路：特征依然由人来设计，但「什么样的特征意味着目标」交给训练样本来决定。 接下来还得解决一个问题——分类器只认识一个图块，怎样让它在整张图像中找到位置？

HOG + SVMHaar + AdaBoostDPMSliding Window
00 DEFINE THE PROBLEM

先分清：哪些东西是人设计的，哪些是学出来的？

我们讨论的是监督式、基于人工特征的二维目标检测。输入若干正负样本，用它们训练出一个分类器，然后将分类器应用于图像中的候选位置。

FEATURE
人工特征

先设计图像怎样表示，例如 HOG、Haar 特征。特征的计算规则通常不随分类器训练而改变。

MODEL
学习判别

用正负样本学习特征到分类分数的映射，例如 SVM、AdaBoost。

POSITION
搜索位置

在不同候选窗口计算得分，再按阈值及重叠关系输出目标框。

研究边界：这里的「学习」主要指判别器参数来自训练数据；不重新讲 HOG、梯度和纹理如何计算，也不进入 CNN 的端到端特征学习。不同传统检测器的搜索过程可能有差异，滑窗只是最典型的组织方式。
01 LEARN A DECISION RULE

特征有了，模型怎样知道这是目标？

考虑一个行人检测器：对每个行人图块和背景图块，都计算同样的 HOG 特征。现在每个图块变成一个向量 x，问题就从「理解图片」变成了「区分两类向量」。

1.1 · SVM：从训练样本中学习分类边界

一个线性 SVM 为每个特征维度学习权重，再将它们加总。分数的正负可以表示候选更偏向目标还是背景，分数离边界多远则反映判别器的间隔信息。

LINEAR DECISION FUNCTION
f(x) = wTx + b
x：人工特征向量；w：由训练学到的各维特征权重；b：偏置；f(x)：原始判别分数（不是概率）。标准线性分类器按 f(x) 的符号决策。

这里不需要完整推导 SVM 的二次规划。只要理解：特征的设计是固定的，判别边界的位置由训练样本决定。一个重要局限是：如果人工特征无法有效区分两类目标，分类器也无从凭空恢复丢失的信息。

1.2 · AdaBoost：能不能组合许多简单判断？

另一种思路是不直接学习一条大型规则，而是训练很多简单的弱分类器，再给它们不同的权重。前一轮分错的样本，在后续训练中会得到更多关注。

WEIGHTED WEAK CLASSIFIERS
F(x) = ∑t=1T αt ht(x)
ht：第 t 个简单分类器；αt：学习得到的组合权重；F：组合后的判别分数。这里是二分类 AdaBoost 的示意形式。
训练弱分类器→找出难分样本→调整样本权重→组合多个判断
可以把 SVM 与 AdaBoost 看作两种不同的判别学习策略。它们不是需要串行执行的算法步骤，也并不只能配合某一种图像特征。
02 FROM CLASSIFICATION TO LOCALIZATION

会判断一个图块，怎样找到整张图中的目标？

分类器得到一个图块后可以打分，但它本身并不知道图块在整张图像中的位置。经典做法是把同一个检测器应用于不同位置和尺度，获得一组候选目标框。

当前图像→候选窗口 / 多尺度→人工特征→学习得到的分类器→候选得分
SLIDING WINDOW
逐位置评分

窗口沿图像移动。每个窗口提取相同定义的特征，再交给同一个分类器判断。

IMAGE PYRAMID
逐尺度评分

在不同图像尺度上重复检测，或等价地在不同大小的候选区域上工作，以发现不同尺寸目标。

2.1 · 多个位置都被认为是目标，应该怎么办？

一个目标附近通常会有许多高度重叠的候选框。先根据分数过滤较弱候选，再利用 IoU 衡量候选框重叠程度，使用 NMS 抑制重复检测。

BOX OVERLAP
IoU(A, B) = |A ∩ B| / |A ∪ B|
两个框交集面积与并集面积的比值，范围是 0～1。越接近 1，重叠越明显。它用于比较框，不直接判断框里的物体是真是假。
交互示意｜分类得分怎样变成最终目标框？模拟检测分数 · 并非真实模型推理
正在计算候选...
调整阈值：低分候选会消失；勾选 NMS：同一目标附近的重叠框被抑制。演示使用预设候选分数和标准贪心 NMS，不涉及训练。
关键区别：上一篇「直接相似性比较」也可能滑窗搜索，但它比较的是目标参考与候选区域的相似程度；这里比较的是候选区域是否符合从一类训练样本中学到的目标规则。
03 THREE REPRESENTATIVE APPROACHES

不同设计，究竟在解决什么困难？

下面三种方案并列介绍。它们都以人工设计的视觉表征为基础，但解决的侧重点不同：怎样判别、怎样更快判别、怎样容纳目标的结构变化。

3.1 · HOG + SVM：利用梯度形状学会判断

以行人检测为例。同一个人的衣服颜色可能变化很大，但头部、肩膀、躯干和腿部产生的局部梯度结构具有一定规律。

HOG 将候选窗口表示为局部梯度方向的统计；SVM 从正负样本中学习哪些梯度组合更像目标。检测时在候选窗口上重复计算、评分。

3.2 · Haar + AdaBoost：先把大量背景快速排除

Viola–Jones 人脸检测的一项重要思路是：整张图像里绝大多数候选位置都是背景，因此不值得让它们全部经过完整检测过程。

HAAR + INTEGRAL IMAGE
特征计算足够快

用矩形区域之间的亮度差构成简单特征。积分图让指定矩形区域的像素和可由少数次查询得到。

ADABOOST + CASCADE
容易的负样本尽早退出

学习哪些简单特征具有区分能力，并把多个分类阶段串联；只有通过前一阶段的窗口才进入下一阶段。

SUMMED-AREA TABLE
S(x,y) = ∑i≤x, j≤y I(i,j)
S(x,y) 保存从左上角到 (x,y) 的像素累加和。一个矩形的区域和可用四个积分图值做加减得到，不必每次遍历矩形中的全部像素。

3.3 · DPM：整体相像还不够，部件能不能适当移动？

同一类目标可能有不同姿态，例如人在走路时手臂和腿的位置会发生变化。只使用固定整体外观的检测器，容易把这些变化都看作不匹配。

DPM（Deformable Part Model）将整体外观、局部部件证据与部件偏移代价结合。每个部件可以在一定范围内移动，但远离合理位置时会付出惩罚。

PART-BASED DETECTION SCORE · 概念化表达
S = Sroot + ∑k( Spart,k − Cdef,k )
Sroot：整体模板匹配分数；Spart,k：第 k 个部件的匹配分数；Cdef,k：该部件偏离预期位置的代价。实际模型还会优化部件的潜在位置，并可能采用不同姿态的混合模型。
三种方案的关系：HOG + SVM 强调人工形状特征与判别边界；Haar + AdaBoost + Cascade 强调可快速计算和早期排除背景；DPM 强调整体与部件的空间关系。不是“前者失败，所以后一种必然替代前者”的单线演进。
04 TRAINING & HARD EXAMPLES

为什么模型训练过了，仍然会把背景当目标？

正负样本决定了分类器看到怎样的目标和背景。如果训练数据过于简单，模型可能在训练集得分很好，但在现场遇到相似背景、遮挡或不同尺度时失败。

4.1 · Hard Negative Mining：让模型再看一遍容易误判的背景

用已有样本训练→在负样本图像上检测→收集高分误检→加入困难负样本重新训练

例如一个行人检测器把路灯柱或门框误判成行人，可以把这些容易混淆的背景裁成新的负样本，提高模型区分它们的能力。

数据层面
覆盖真实变化

目标不同姿态、尺度、背景和遮挡情况，都可能影响模型从样本中学到的边界。

判断层面
阈值有代价

降低阈值可能减少漏检但增加误检；提高阈值通常让检测更保守。

这种困难样本挖掘是一种训练策略，不等同于「把所有错误样本无限加入」：错误标注、重复数据和训练集偏置也可能带来新问题。

05 CHOOSING & LIMITATIONS

这几种方法各自解决了什么问题？

代表方法主要解决的问题代价与典型边界
HOG + SVM把梯度形状转为特征，用样本学习区分类别的边界。特征定义固定；对明显形变、姿态变化及复杂遮挡的适应能力有限。
Haar + AdaBoost + Cascade组合简单矩形特征，并快速排除大量背景窗口。对特征与训练分布有依赖；早期阶段的错误拒绝无法在后面恢复。
DPM让整体和局部部件共同打分，允许结构存在一定形变。训练与推理更复杂；部件设计和表示能力仍受模型假设限制。

它们共有的能力边界

这些方案的核心特点是：特征如何表示，由研究者预先决定；模型主要学习如何根据特征做判别。当新场景中的有效视觉线索不在人工表示中，增加分类器训练数据不一定能完全弥补这一缺口。

这并不意味着传统机器学习检测器在所有工程任务中都已经失效。对于条件稳定、资源有限、目标规律明确的场景，它们仍可能是合理候选；只是对需要处理大幅外观变化的广泛任务，表达能力往往会受到约束。

这一篇最重要的三件事：
① 人设计特征，模型从样本学习判别规则。
② 分类器只能给候选图块评分，定位还需要位置搜索与候选筛选。
③ HOG + SVM、Haar + AdaBoost、DPM 重点解决的困难不同。
