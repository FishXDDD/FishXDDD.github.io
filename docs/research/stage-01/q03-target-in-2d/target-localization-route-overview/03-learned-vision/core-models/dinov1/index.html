DINO 自蒸馏视觉表征学习

不预测类别，也不重建 RGB。同一张图片的不同视图，经过 Teacher 与 Student，应当形成一致的输出分布。利用这种无标签的训练任务学习 ViT 特征。

目标：同图像的不同视图，预测出相似的特征分布。

关键差异：DINO 不需要为每张图片指定类别，也没有 MAE 的像素重建 Decoder。

核心研究假设

如果一张图经过裁剪、颜色变化、模糊后，仍然表示相同的视觉内容，那么模型应学习对这些变化相对稳定的表示。Student 向 Teacher 的目标分布对齐，促使 Backbone 提取可迁移特征。

但直接让两路输出相同，会有什么问题？

它们完全可以对所有图片都输出同一常量！这种 Collapse（表示坍塌） 也能使两路一致。DINO 必须额外设计 Teacher 更新和输出分布约束。

论文定位： DINO = Self-Distillation with No Labels。它是训练方法，不是另一套替代 ViT 的 Backbone 结构；论文特别研究了自监督 ViT 特征出现的物体边界与 k-NN 分类等性质。

FULL NETWORK

完整前向传播：一张图像到底走了哪些分支？

从这里开始，用 ViT-S/16 为例。始终区分「Token 数量」「特征维度」「Head 输出维度」。

04
BACKBONE & HEAD

ViT 与 DINO Head 到底各自负责什么？

这里不重新解释 QKV，只看 DINO 新加的 Head 怎样把 CLS 特征变成训练目标。

图 04 · 单个视图的严格前向：Image → ViT-S/16 → CLS → DINO Head
Head 的三层 Linear 在官方实现中分别产生 2048、2048、256 维；随后经 L2 归一化和权重归一化的线性层映射到 K 维 logits。
ViT Encoder 的价值

从不同裁剪中提取视觉信息

Self-Attention 融合当前视图内部 Patch 的上下文。网络提取的 CLS 特征是该视图的全局表示；通过跨视图训练，它逐渐对部分外观变化保持稳定。

Head 的价值

把视觉表示转成可比较的目标分布

Head 的 K 个输出不是人工指定的 K 个类别；它们是无标签训练中学习到的输出坐标/原型方向。Loss 约束这些概率分布，而不是让两个 384 维 CLS 直接算 MSE。

CLS 为什么能用：ViT-S 的标准前向返回最后的 CLS 表示。Teacher 与 Student 各有自己的 Backbone 和 Head，但初始化参数相同；随后 Student 通过梯度更新，Teacher 通过 EMA 更新。
05
DINO LOSS

最关键：不重建 RGB，那 Loss 比较的是什么？

比较的是 Teacher 和 Student 对 K 个输出坐标给出的概率分布，而不是类别标签或 RGB。

图 05 · 由 logits 到分布：教师作为软目标，学生向教师对齐

⇔
Student Softmaxp=softmax(zₛ/τₛ)
→
Cross-Entropy−Σ q log p
qt(i) = softmax((zt(i) − c) / τt)
ps(j) = softmax(zs(j) / τs)
ℒ = (1/18) ∑i∈{G1,G2} ∑j≠i,j∈{G1,G2,L1…L8} [ − ∑k=1K qt,k(i) log ps,k(j) ]
严格写法省略了 Batch 均值。Student 用梯度优化；Teacher 输出 detach，不计算 Teacher 反传。注意 DINO 这里的 CE 是「软目标分布的交叉熵」，不是人工分类标签 CE。

—
Cross-Entropy：−Σ q log p
—

—
KL(q ‖ p) = CE − H(q)

为什么不是 MSE？

原始 DINO 选择概率分布 Cross-Entropy。Teacher 的输出充当 soft target；Student 通过梯度增加教师更偏好的坐标概率。

为什么不能把 K 当成类别标签？

K 是训练 Head 输出空间维度。它不代表 65,536 个具名类别，也不需要人工标注每个坐标的语义。

06
AVOID COLLAPSE

所有图片都输出相同分布，为什么不算学会了？

Centering、Sharpening 与 EMA Teacher 共同抑制训练中的平凡解。

图 06 · 两类坍塌与稳定机制
示意概率结构，不是训练日志。单张图预测尖锐并非坏事；问题是不同图像全部预测相同分布。
Centering

控制某些维度长期主导

c ← μc + (1−μ)·mean(zₜ)

用 Teacher 的 Batch logits 均值做 EMA，并从新的 Teacher logits 中减去。它有利于避免同一坐标一直占优势，但单独使用可能偏向均匀解。

Sharpening

低温让教师目标更有选择性

q = softmax((zₜ−c)/τₜ)

较小温度使分布更集中，避免所有坐标都几乎一样；但单独使用容易让输出被少数坐标占据。

Momentum Teacher

防止目标与学生一起剧烈晃动

θₜ ← mθₜ + (1−m)θₛ

Teacher 不参加梯度下降，而是 Student 参数的滑动平均，提供更缓慢变化的目标。

论文的结论不是「Center 一定防止所有坍塌」或「Sharpen 一定防坍塌」。二者有相反偏置，结合 EMA Teacher 才构成有效的稳定训练机制。Teacher 温度实际常非常低（官方初始默认 0.04），与上面的可视化教学温度不同。

TRAINING LOOP

Loss 到底更新谁？Teacher 又是怎样进步的？

这是与 MAE 最大的训练形式区别：Student 走梯度，Teacher 走 EMA，两者不是同一个优化过程。

02 · 双分支前向

Center、Temperature、18 组交叉熵

backward() → optimizer.step()

Center 由 Teacher 当前 Batch 的 logits 均值更新；这是第三个状态更新过程，不是可训练网络参数的梯度更新。

图 08 · 谁有梯度？谁只有滑动平均？

Student Backbone + Head

有梯度 Cross-Entropy 对 Student 的输出反传，更新 ViT 与 DINO Head 参数。

Teacher Backbone + Head

Center 向量

对照源码｜训练循环的核心伪代码（展开查看）
views = multi_crop(image)        # 2 global + 8 local
z_teacher = teacher(views[:2]) # [2B,K]；停止梯度
z_student = student(views)     # [10B,K]
q = softmax((z_teacher - center) / teacher_temp).detach()
p = log_softmax(z_student / student_temp)
loss = mean_cross_view_ce(q, p, skip_matching_global_index=True)

optimizer.zero_grad()
loss.backward()                 # 只更新 Student
optimizer.step()
with no_grad():
    teacher_params = m * teacher_params + (1-m) * student_params
    center = mu * center + (1-mu) * batch_mean(teacher_logits)

说明：这是教学伪代码，不是逐行复制官方源码；例如真实代码在 Loss 计算时更新中心统计量，梯度裁剪、最后层冻结与温度调度也被省略。

8.1｜学完 DINO，你必须能够区分的五件事

Teacher ≠ 事先训练好的教师它从 Student 初始化，靠 EMA 动态更新。
两个 ViT ≠ 两种不同架构相同结构，不同参数；输入的视图数量不同。
Head 输出 K ≠ 人工类别它是无标签蒸馏的分布空间。
没有显式负样本 ≠ 不会坍塌需要 Centering、Sharpening、EMA 等稳定机制。
Loss 不是 MSE 像素重建是跨视图 Softmax 分布之间的 Cross-Entropy。
DINO 是方法，不是新 Backbone原始论文也支持 ResNet 等架构进行 DINO 训练。

8.2｜MAE 与 DINO：真正有研究意义的比较

维度MAE（2021/2022）DINO（2021）
自监督信号原图被遮挡区域的真实 RGB 像素Teacher 对同一图像其他视图的软分布
训练输入仅可见 Patch 进入 Encoder两条分支读取增强后的多裁剪图像
新增网络重建 Decoder + Pixel HeadTeacher–Student + DINO Projection Head
LossMasked MSE跨视图 Cross-Entropy

最终理解：DINO 并不要求模型直接重建图像，而是设计一个会随训练改进的 Teacher，让同图像不同视图的高层输出分布逐渐一致；在避免表示坍塌的条件下，ViT 学到更加稳定、有结构的视觉表征。
