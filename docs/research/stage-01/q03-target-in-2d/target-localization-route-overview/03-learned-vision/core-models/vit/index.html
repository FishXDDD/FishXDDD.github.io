02

研究起点：为什么有人想直接用 Transformer 看图像？

不是因为 CNN 无法完成分类，而是为了检验一个不同的结构假设。

旧方法具有哪些结构先验？

CNN 把二维邻域和权重共享直接写进网络：一个位置先看到局部区域，跨较远位置的信息通常要通过更多层或下采样传播。这是一种有用的归纳偏置（inductive bias）：图像里相邻像素更可能相关，物体在不同位置出现也应采用类似局部检测器。

这不是 CNN 的缺陷清单。

局部性在有限数据、计算效率和图像结构上往往是优势。ViT 并不是证明“局部卷积没有价值”，而是在追问：如果数据足够多，是否可以减少人为写入的视觉规则，让网络自己学习空间关系？

当时的 Transformer 有什么机会？

标准 Transformer Encoder 已经能用大规模矩阵计算处理 Token 序列。但若直接把 224×224 图像的每个像素当 Token，就会产生 50,176 个位置：单头注意力分数矩阵达到 50,176²，不现实。

ViT 的关键选择：先降低序列长度，再尽量不改 Transformer。

把相邻 16×16 像素合为一个 Patch Token，224×224 的图像只剩 196 个 Patch。然后加入位置向量和分类 Token，交给标准 Encoder。

图 02 · 科学假设：局部归纳偏置 vs 可从数据中学习的空间结构
论文层面的核心贡献：2017 Transformer 的 Attention、残差、MLP 并非 ViT 新发明；图像切 Patch 也不是最早由 ViT 独占提出。ViT 关键在于展示：只需很少的视觉专门设计，标准 Transformer 在充分大规模预训练后就可以成为有竞争力的图像识别模型。这是一项结构与规模假设的实验验证。

04

图像怎么变成 Token：Patchify → Flatten → Linear

ViT 最关键的输入设计。不是“从图片提取了 196 个目标”，而是规则网格切块。

4.1 为什么不直接把像素当成 Token？

Transformer 的 Attention 是建立在 N 个位置上的，单头分数矩阵尺寸为 N×N。一张 224×224 图像有 50,176 个像素位置，若按像素直接建立全局 Attention，分数项就有约 25.18 亿个。ViT 的思路是把 16×16 个相邻像素合并成一个 Token，先压缩位置数，再让这些 Token 相互交互。

Patchify 本身只是重排像素并分组，不需要神经网络训练。接下来的投影矩阵 E 才是可学习参数：每个 Patch 用同一组权重将原始 RGB 数值投影成 768 维 Token 表示。若把 ViT-B/16 的 D=768 换成其他隐藏维度，线性投影就会从 768→D，并不要求输入和输出维度刚好相同。

Flatten + Linear
ei = flatten(patchi) WE + bE
每个 patch 的参数矩阵是共享的；在原论文公式中常将偏置省略。

所有 Patch 共同使用一个映射，它将局部像素内容编码到网络特征空间。

可以等价实现为 Conv2d
Conv2d(3, 768, kernel=16, stride=16)
此时卷积核覆盖每个完整 Patch，步长也等于 Patch 大小，没有相邻 Patch 的卷积窗口重叠。

在恰当的权重展平顺序和偏置对应下，两者实现相同的线性运算。这里使用 Conv 算子不意味着 ViT 使用了 ResNet 那样的多层局部特征提取 Backbone。

真正的 ViT-B/16 使用 16×16×3=768 个输入值、768 个输出维度；这个 4→3 的例子只用来展示同一种矩阵乘法。其他三块的输出分别是 e₂=[10,19,−1]、e₃=[22,37,5]、e₄=[26,43,7]，所以四块共同形成 4×3 的 Token 矩阵。
科学代价：Patch 尺寸越大，Token 越少，Attention 更便宜，但一个 Token 汇总的像素区域也越大，细粒度位置分辨率越低。小 Patch 有更精细的空间粒度，也带来更高计算和显存成本。这是重要的设计权衡，而不是单调“越小越好”。
05

[CLS] 和 Position：如何保留二维空间，并得到整张图像的特征？

两种不同的“额外向量”：一个负责分类汇聚，一个负责空间位置。

5.1 为什么 Patch Embedding 之后还不够？

现在有 196 个 Patch Token，每个 768 维。它们包含局部图像内容，但纯 Self-Attention 如果没有任何位置线索，对输入 Token 的重排具有相应的置换等变性；仅靠排列后的特征值，模型不会自动知道哪个 Patch 来自图像左上角、哪个在右下角。ViT 使用可学习的绝对位置向量将网格位置信息注入 Token。

ViT 原论文采用标准可学习的 1D 绝对位置 Embedding；它不同于 2017 Transformer 的固定正弦位置编码。Patch 的二维网格按固定扫描顺序展平为 1D 序列。

为什么引入 [CLS]？

这是借鉴 BERT 的做法。添加一个不对应任何像素的可训练 Token，让它与 Patch 一起参与 Self-Attention；经过 12 层更新后，取它的最终表示连接分类 Head。

重要：初始 [CLS] 不等于“整张图像语义”的预计算向量；它开始只是可学习参数，必须通过 Attention 读取 Patch 信息，并经训练才可能成为有用的图像级表征。

为什么用 Learned Position？

对于固定分辨率的 Patch 网格，可以为每个序列位置建立一行 768 维可训练参数。训练中，这些位置参数通过分类 Loss 的梯度更新。ViT 论文比较了 1D、2D 与相对位置等方案，没有观察到复杂 2D 编码带来显著收益。

重要：这不是“1D 天然懂得二维距离”，而是对应的二维邻接规律需要从视觉数据中学习。

5.3 为什么不是 GAP（Global Average Pooling）？

你在 CNN 分类模型里常见的做法是：将空间特征平均池化，得到全局向量，然后分类。ViT 选择 [CLS] 是为了延续 Transformer/BERT 的序列分类形式，而不是数学上证明 GAP 不合适。原论文附录发现：在恰当调节学习率后，[CLS] 与 GAP 可以取得接近的结果。这是研究时非常重要的边界。

CLS Pooling

h = LN(z12CLS)

额外的 Token 是可学习的汇聚入口，由注意力构造图像表示。

Global Average Pooling

h = mean(z12patch1..196)

先聚合所有 Patch 特征，不需要新增分类 Token；具体实现中的归一化与池化次序需明确。

分辨率变化问题：如果预训练时有 14×14 个 Patch，而微调时使用 384×384 输入，就会变成 24×24 个 Patch。原来学习的 14×14 Patch 位置表不能直接一一对应，因此论文对空间位置向量做二维插值；[CLS] 对应的向量单独保留。第 12 章将完整解释这个过程。
06

Encoder ×12：ViT 为什么只需要 Encoder？每层实际怎么计算？

对于图像分类，输入已经完整可见，不需要生成目标序列。

原始 Transformer 的 Encoder–Decoder 架构是为机器翻译这样的条件序列生成服务的；ViT 的基本任务是读取一张完整图像并预测一个类别。它只需要把 Patch 序列编码成可用于分类的特征，因而保留 Encoder 堆栈，没有原始 Decoder 的 Masked Self-Attention、Cross-Attention，也不需要 Teacher Forcing。

ViT-B/16 的 12 层并非层与层共享同一个 Block；每一层都重新计算 Q/K/V 与 MLP，逐层变换特征。

6.1 为什么过了 12 层，Token 数没有变？

与常见 ResNet 随 Stage 下采样、空间分辨率递减不同，原始 ViT 在 Encoder 各层保持同一长度 197 与维度 768。每一层调整的是表示内容，不是位置数；注意力聚合发生在所有可见 Token 之间，MLP 则对各 Token 的通道向量独立处理。

这是 ViT 分类中常见的无 Padding 情况：没有 Causal Mask，所有 197 个 Token 相互可见。代码实现里也可以一次 Linear 输出 3D，再切分成 Q/K/V，数学上等价于三组投影。
12 个头各自学习独立投影，Head 维度 768/12=64；这里将前面的 LN 输入简写为 X。Attention Head 与最后的 Classification Head 是两种完全不同的“Head”。

Q / Query

当前 Patch 或 [CLS] 想从其他位置读取什么信息。它不是固定的“物体查询标签”，只是从当前特征学习的查询向量。

K / Key

各 Patch 和 [CLS] 用来与 Query 计算匹配分数的线索。不同位置的 Key 由同一投影矩阵计算。

V / Value

真正被加权汇总到当前位置的特征内容。QKᵀ 只产生权重，不会把其他 Patch 的信息传回来；还必须乘 V。

7.1 直观的问题：每个 Patch 为什么要与其他 Patch 交互？

比如图像左上角的 Patch 可能只看到一块弧线，右下角可能看到另一块纹理。对整图分类而言，单块局部颜色或纹理可能不足以识别对象。Self-Attention 允许当前 Patch 的 Query 与其他 Patch 的 Key 计算相似性，再按权重汇集 Value，从而组合跨区域上下文。并不是每次都平均融合所有 Patch，而是注意力权重可随输入图像变化。

7.2 为什么 ViT 的分类不需要 Decoder Mask？

语言模型的因果 Mask

自回归生成第 t 个词时，必须保证预测只依赖前缀 y<t，因此将未来位置在 Attention Scores 中设为负无穷。

其目的是防止未来答案泄露，保证生成概率分解成立。

ViT 的全图分类

推理时整张图像一开始就已知，训练标签是一个图像类别，而不是按顺序逐位置预测下一个 Patch。

所以典型 ViT 不使用因果 Mask。**它也没有 Cross-Attention**，因为输入仅是一组 Patch + CLS Token。

一个重要的科研边界：注意力是“可学习的信息聚合关系”，但直接可视化某个头的 Attention Map 并不等于严格证明模型的决策因果。不能只凭某一层 CLS 注意力最高的 Patch 就断言“模型只看了这里”。
08

MLP、Residual、LayerNorm：为什么 Attention 还不是整个 ViT？

ViT 不是“Patch → 一个 Attention → 分类”，而是 12 次注意力与通道变换的交替。

图 09 · 单个位置的 MLP 计算：768 → 3072 → 768
Token 特征1 × 768
→
Linear W₁768 × 3072
→
GELU非线性激活
→
Linear W₂3072 × 768
→
更新特征1 × 768
MLP(x) = GELU(xW₁ + b₁)W₂ + b₂
W₁ ∈ ℝ768×3072 ,   W₂ ∈ ℝ3072×768
同一层 MLP 的参数跨 Token 共享，对全部 197 个 Token 分别执行相同映射。GELU 是 ViT 的激活选择；2017 原始 Transformer 的 FFN 用 ReLU。

Attention：不同位置交互

197 个 Token 产生 197×197 的关系矩阵，建立跨 Patch 的信息流。

MLP：每个位置变换通道

对于单个 Token，将 768 维特征升到 3072 做非线性映射，再投回 768 维；不在 MLP 内部直接混合其他 Token。

Residual + LN：深层学习

残差允许信息和梯度走较短的直接路径，LayerNorm 稳定特征尺度；Pre-LN 是 ViT 结构的实际配置。

8.1 12 层“重复”究竟在重复什么？

虽然每层的计算模板相同，但参数不共享。第 1 层的注意力关系与第 12 层不必相同，特征也会多次被重建。原论文进一步观察到，有些早期头就能关注较远区域，也有一些关注局部区域；这提示模型可以通过学习得到不同空间交互范围，而不代表所有头必然实现既定分工。

与 CNN 的 Stage 结构对照：标准 ViT-B/16 不经过四个分辨率递减的 Stage；“层数变深”不等于“Patch 越来越少”。这也解释了为什么把原始 ViT 当作检测 Backbone 时，多尺度特征往往需要额外处理。

Loss：为什么 ViT 只需要一份分类交叉熵？

和你已经学过的 CNN 分类 Loss 完全相通；不需要右移目标序列，也不需要每 Patch 单独计算 CE。

模型对单张图只输出一个向量 logits ∈ ℝ^K，而标签是一个类别索引。经过 Softmax，得到各类别预测概率；交叉熵只关心模型分给正确类别的概率有多大。

pk = exp(sk) / ∑j=1Kexp(sj)
L = −∑k=1Kyk log pk = −log pcorrect
∂L / ∂sk = pk − yk
这里 y 是 One-Hot 真实标签。交叉熵通常在数值实现上使用交叉熵接口直接接收 logits，无需显式先执行 Softmax，内部采用稳定的 log-softmax 计算。

交互实验 C｜改变分类 Logit，直接看 CE 与梯度 p − y

教学例子：三分类（猫 / 狗 / 鸟）。修改任意 Logit，模型输出概率、CE 以及每个 Logit 上的梯度会按真实公式重新计算。这里的 Logits 是可编辑的例子，不是图中示意场景的真实模型预测。

CE = −log(p_correct)
∂L/∂logits = p − y

不要混淆：ViT 的 Attention 内部也有一个 Softmax，它的行归一化对象是各 Key 的注意力权重；分类 Head 后的 Softmax 才将 K 个 Logits 转成类别概率。两者用的是同一种数学函数，但意义、维度、监督角色完全不同。

11.1 一次前向与反向具体发生什么？

1
取有标签的图像 Batch

预处理、Patchify，将每张图像变成 197×768 输入序列。

2
运行 12 层 Encoder

在每层进行 Self-Attention、MLP 与残差变换；获取最终 CLS 表示。

3
Head 得到类别 Logits

计算分类 CE，对 Batch 的有效样本求平均得到训练 Loss。

4
Backward

从分类错误反向计算对 Head、12 层 QKV/MLP、Patch 投影、CLS、位置表等参数的梯度。

5
Optimizer 更新

根据梯度、学习率和权重衰减等规则修改参数，然后进行下一 Batch。

Fine-tuning：为什么预训练 224×224，微调 384×384 会出问题？

固定 Patch 尺寸能保持网络宽度不变，但位置数量一定会变化。

12.1 先算 Token 数

224 / 16 = 14
Ntrain = 14² + 1 = 197
384 / 16 = 24
Nfinetune = 24² + 1 = 577

保持同一 Patch 尺寸 P=16，每块仍是 16×16×3=768，投影矩阵 WE 的输入维度没有变化。但 Patch 位置从 196 增为 576，连同 CLS 后序列长度从 197 变为 577。

对 Attention 而言，这主要意味着矩阵行列数变长；同一层 QKV 和 MLP 的参数仍可复用。

12.2 真正对不上的是什么？

Epos,pre : 197 × 768
Epos,new : 577 × 768

预训练的 196 个 Patch 位置向量与新的 576 个网格位置无法逐行对应，直接相加会形状不匹配。

原始 ViT 的解决方法是保留 CLS 对应的单独位置向量，将其余 14×14×768 的学习式位置网格按二维坐标插值为 24×24×768，再与 CLS 位置合并。

图 13 · Learned Position Embedding 的二维插值，不是对原始图像进行位置插值
原位置表：14×14196 Patch Position
新位置表：24×24576 Patch Position
网格的蓝色梯度是用来展示“二维表重新采样”的教学图，不是论文训练好的真实位置参数。真正的插值需要对 768 个通道各自进行空间插值，且 CLS 位置不按空间网格插值。
前后什么发生变化？视觉特征维度 D=768、12 层 Encoder 的参数形状、每头 d=64 仍保持；改变的是 Patch 数和注意力矩阵长度。微调还需要更换与目标任务类别数对应的 Head，并允许网络利用下游数据继续更新参数。

只需要一次前向计算，就能得到图像分类结果。

编码时每层的 197 个 Token 可以在同一批矩阵运算中处理；分类取最后 CLS 向量，输出 K 个 Logits。没有“先生成一个 Patch、再生成下一个 Patch”的逐步循环。

输出怎么用？

分类概率与标签

若希望获得类别概率，对 K 个 Logits 做 Softmax；若只选最高分的类别，直接对 Logits 取 argmax 与先做 Softmax 再取 argmax 等价。

13.1 一次推理完整执行过程

①
图像预处理

将 RGB 图像调整为模型要求的分辨率，并按预训练或微调的均值方差进行归一化。具体预处理取决于模型 Checkpoint。

②
Patch Embed

用规则网格切出 196 个 Patch，对每块执行线性投影，得到 196×768。

③
加 CLS 与位置

合并形成 197×768 的序列表示。

④
12 层编码与最后 LayerNorm

每层实现多头 Attention、MLP、残差与归一化，得到全部 Token 的最后特征。

⑤
取 CLS → 分类 Head

将第 0 行 768 维向量变成 K 个 Logits，按需要得到概率、Top-1 或 Top-k 类别。

不要误用语言模型术语：ViT-B/16 的图像分类没有 Teacher Forcing、逐位置文本 CE、EOS 停止条件，也不需要自回归推理时的 KV Cache。这些是另外一类任务或其他 Transformer 变体的机制。

14.2 尽管有全局注意力，ViT 也不是没有局部信息

每个 Patch 本身是一个 P×P×3 的局部像素区域，Patch 投影会学习如何组合这块内部像素；这一步保留了一个粗粒度的局部先验。真正和经典 CNN 不同的是：原始 ViT 的 Encoder 不再强制每层只与固定的局部卷积邻域交互，而是让 Token 之间直接进行内容相关的全局聚合。

工程结论：不要只看“Attention 可全局访问”，也要考虑输入分辨率、Patch 大小、训练数据、硬件和下游任务需要的空间精度。原始 ViT 在分类上结构简洁，但并不是无需改造就适合所有检测和分割任务。

数据规模实验

大规模 ViT 的表现与效率

在论文的预训练与迁移比较设置中，ViT 的精度/训练计算量表现有竞争力，支持继续扩大网络规模。

结构消融

简洁设计并非所有细节唯一正确

15.2 容易被过度解读的研究结论

不能得出：“CNN 已经没价值”

局部归纳偏置在低数据、高效率和某些工业密集视觉任务中仍可能有价值；ViT 不会在所有数据和硬件条件下自动优于卷积模型。

不能得出：“Self-Attention 是 ViT 发明的”

Self-Attention 早已存在；ViT 的标志性思想是把图像处理成 Patch Token 后，使用近乎标准的 Transformer Encoder，并用足够大规模实验验证其竞争力。

一句话概括论文思想：不必每一层都强制使用卷积的局部连接与平移先验；将图像变成 Patch 序列，标准 Transformer 在充分规模的数据驱动训练下，可以获得很强的视觉分类与迁移能力。这是一个关于视觉归纳偏置与规模化学习的研究结果。

16.1 后续发展，是在改变 ViT 的哪部分？

DeiT · 2021

重点修改训练方法

针对原始 ViT 对大规模数据的依赖，强调数据增强、正则化与蒸馏；引入 Distillation Token 的版本与教师模型交互。它不是简单把 ViT-B 的 Head 改名。

Swin · 2021

重点修改 Backbone 结构

引入 Window Attention、Shifted Window 与分层特征，更符合检测、分割等密集视觉任务需要；已不是原始 ViT 的单尺度全局注意力结构。

MAE / DINO 等

重点改变表征学习目标

利用掩码重建、自监督或教师学生等学习范式训练视觉表示。它们可以以 ViT 为骨干，但与原论文的监督分类预训练目标不同。

以后读新视觉模型的方法：先定位它修改了 输入表示、Backbone / Attention、特征组织、任务 Head、Loss、预训练策略、推理计算 的哪一项，再理解改动动机。这样就能和你已学过的 CNN 与目标检测架构统一起来。

检查点你应该能够解释的内容
输入224×224×3 如何通过 P=16 切成 196 个 Patch；为什么每块 768 个数；Linear 的参数是什么
Position 与 CLS为什么还需要位置表；CLS 是从哪里来的；为什么插入之后长度变 197
Encoder为什么是 12 层；Pre-LN 与 Post-LN 的区别；每层怎样保持 197×768
MHSA12 Head、每头 64 维；为什么 QKᵀ 是 197×197；为什么不用 Causal Mask
MLP768→3072→768 的作用；为什么不直接混合不同 Token
Head / LossCLS 如何变 K 类 Logits；为什么一个图像一个 CE；梯度如何回到 Patch Embedding
训练ViT 原论文用什么监督数据；为什么大规模预训练很重要；为何 CNN 的先验在小数据下有优势
推理与迁移为什么一次前向就够；384 输入带来的位置插值问题；什么会保持维度不变
研究贡献哪些设计来自 Transformer/BERT，哪些是图像输入适配，论文真正验证了什么假设

三个必须记住的公式

Npatch = HW/P²
z₀ = [xcls; XpatchE] + Epos
zl = ul + MLP(LN(ul))

三个必须记住的思想

一：Patch 是图像到 Token 序列的桥梁。

二：标准 Encoder 通过全局 Attention 更新 Patch 与 CLS 表示。

三：ViT 的里程碑在于简单架构 + 大规模数据所验证的视觉归纳偏置取舍。

论文依据与继续阅读

核心结构、参数、训练设置及消融结论均按原论文核对；后续模型单独标记。

原始 ViT 论文：Dosovitskiy et al. An Image Is Worth 16×16 Words: Transformers for Image Recognition at Scale. arXiv:2010.11929（初稿 2020；ICLR 2021）。阅读论文 HTML · arXiv · 原始代码

原始 Transformer：Vaswani et al. Attention Is All You Need (2017). 原论文。比较时需注意 2017 Base 的 Encoder 6 层、512 维、Post-LN 与 ViT 的差异。

DeiT：Touvron et al. Training data-efficient image transformers & distillation through attention. ICML 2021. 原论文。对应后续训练数据效率与蒸馏路线。

Swin Transformer：Liu et al. Swin Transformer: Hierarchical Vision Transformer using Shifted Windows. ICCV 2021. 原论文。对应窗口注意力与层次化视觉 Backbone 路线。

本 HTML 中的示意场景、手算 W 矩阵、Attention 小实验和 CE 调参实验是为了教学创建的确定性例子，不是原论文训练权重，也不是原文数据集的真实图像。近似参数量与结论限于论文对应设置；ViT 的后续版本可能使用不同 Head、Norm、位置表示和训练配方。
