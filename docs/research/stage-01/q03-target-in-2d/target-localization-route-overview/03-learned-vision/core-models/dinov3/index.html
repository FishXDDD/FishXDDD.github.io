02
RESEARCH MOTIVATION

为什么 DINOv2 的训练目标还不够？

先看实际失败现象，再理解 Gram 究竟要保持什么。

CLS ↑

全局表示持续改善

延长训练之后，图像级表示的评估通常继续上升。模型越来越擅长从整张图像提取整体信息。

Patch ↓

局部表示可能退化

相同物体的局部区域特征不再保持清晰、一致的空间关系；无关 Patch 可能出现异常高的相似度。

为什么原来的 iBOT 没能完全解决？

iBOT 让 Student 在被遮挡位置预测 Teacher 的局部输出分布，能帮助学习局部特征。但在超长训练中，局部特征本身的两两关系仍然可能逐渐变化；DINO 的全局训练目标也可能占据更强的优化影响。于是作者新增加一个约束：不直接冻结 Patch 特征数值，而是保留 Patch 与 Patch 之间的相似关系。

RoPE 在这里到底改变了什么？

DINOv2：可学习绝对位置编码

为每个空间位置提供一个可学习向量，遇到不同分辨率通常需要插值等处理。

DINOv3：二维 RoPE（含 box jitter）

利用 Patch 的二维坐标，在 Attention 内旋转 Q/K 的分量，体现位置关系。使用可缩放的坐标范围让模型适应不同分辨率和宽高比。

RoPE 本身不会“预测旋转角度”，也不是对图像做旋转增强；它改变的是 Attention 中的位置信息编码方式。CLS 和 Register 不按普通 Patch 的二维位置处理。

06
OBJECTIVES · LOSS

原来的 DINO、iBOT、KoLeo 在 v3 怎么工作？

这里不重新教学所有交叉熵知识，只保留各项输入、输出、对齐对象和必要公式。

DINO · CLS 对齐

Teacher 的 Global CLS → DINO Head → Sinkhorn 平衡得到 q。Student 的 Global/Local CLS → Head → Softmax 得到 p。同图不同 View 的分布进行 CE。

LD = CE(qCLS, pCLS)

iBOT · Mask Patch 预测

Teacher 看到未遮挡的 Global 图像，对每个 Patch 产生目标分布。Student 某些 Patch 输入 Mask Token，在相同位置预测 Teacher 分布。

LP = Avgi∈M CE(qi, pi)

KoLeo · 批次特征铺开

取 Student 首个 Global 的 CLS，对特征归一化后，惩罚与最近邻样本距离过小。它不需要类别或教师概率。

LK ≈ − Avg log dNN

为什么 Teacher 不再只做传统 Centering？

原始 DINOv1 的 Teacher 通过 Centering + Temperature 调节目标分布；DINOv3 的大模型方案沿用了 DINOv2 中的 Sinkhorn–Knopp（SK） 原型分配平衡。它会在批次尺度迭代调整原型分配，防止所有样本长期挤向少量输出坐标。对单张图片，最终仍可把 Teacher 的目标理解成一个 K 维概率分布 q，与 Student 的 p 做交叉熵。

不要混淆：输出维度 K_D=262144 与 K_P=98304 是两个 Head 的独立超参数；不是图像类别数，也不是 Patch 数量。SK 的输出平衡也不是 Gram 相似矩阵。

07
GRAM ANCHORING · 核心新机制

Gram Anchoring：真正新增的 Loss 究竟监督什么？

先用四个 Patch 的关系图建立直觉，再回到论文的 P×P 矩阵。

7.1 为什么不能直接让 Student 的 Patch 特征等于旧 Teacher？

如果强行逐向量固定到旧模型：feature_student ≈ feature_old，会限制 Student 继续学习新的视觉特征。Gram Anchoring 的想法不同：允许特征向量本身变化，但要求不同 Patch 之间的相似关系不要被破坏。 例如眼睛与另一只眼睛可以保持较高相似，眼睛与天空保持较低相似。

图 07 · “对齐特征值”与“对齐特征关系”的区别RESEARCH DIAGRAM

❌ 直接钉死特征向量

旧模型的 Patch AeA = [a,b,c]
≈
新模型 Patch Ae'A 必须相同

会约束每个特征坐标的数值，限制表示继续演化。

✓ 只锚定两两关系

旧 Gram 矩阵Patch A 与 B 的相似度
≈
新 Gram 矩阵保留关系结构

特征可以整体旋转、改变坐标系，只要归一化后两两内积保持相近。

7.2 把 Patch 特征构造成 Gram 矩阵

Patch 特征 XP×d
→

假设一张图只有 4 个 Patch，每个 Patch 提取一个 2D 特征，得到 X∈R^(4×2)；相似度矩阵就是 G∈R^(4×4)。矩阵对角线是特征与自身相似，一般为 1。

7.3 真实 Gram Loss，输入和输出维度是什么？

LGram = ‖ Xstudent XstudentT − Xgram XgramT ‖F2
①
Student 特征

取 Global 裁剪的 256 个 Patch 特征：X_S: [B,256,4096]；对每个 Patch 的向量做 L2 Normalize。

②
Gram Teacher 特征

另一条冻结的教师路径获得同一图的 Patch 特征；可在 512×512 输入下先取得 32×32=1024 个 Patch，再双三次插值下采样到 16×16=256 个空间位置，然后进行 L2 Normalize。

③
各自产生相似矩阵

每张图片各生成 G_S, G_T: [256,256]；格子 (i,j) 表示 Patch i 与 Patch j 的内积。

④
计算矩阵差异

对 G_S−G_T 每一个格子求平方并汇总，得到标量 Gram Loss；梯度只流向 Student。

训练结束后，实际保留什么特征？

在推理中不会再跑两套教师、Masking、DINO/iBOT Heads 或 Gram Loss。

512×512 输入：Patch16 → 32×32=1024 个 Patch；加 CLS 1 + Registers 4，Backbone 序列总长 1029。Patch Token 可重排为 [B,4096,32,32]，CLS 为 [B,4096]。这是 ViT-7B/16 的真实配置示例，不代表所有 DINOv3 小模型都具有 4096 维。

为什么 DINOv3 的 Patch 特征值得单独保留？

CLS 是聚合过整张图的全局表征；Patch Token 保留空间对应关系。DINOv3 的新增 Gram 约束是为了让 Patch 间关系更加稳定，从而让整张空间特征图在长训练和高分辨率输入下更有用。Gram Loss 用于训练；推理时不需要显式计算 Gram 矩阵。

EVIDENCE · SCIENTIFIC SCOPE

论文证明了什么？哪些内容不应过度推断？

用少量直接对应研究问题的证据收束，而不是模型排行榜。

证据 A · 为什么要 Gram

长训练后 CLS 对应的全局评估持续改善，但 Patch 局部一致性及稠密评估下降。论文展示相似度图出现无关位置的高亮。

证据 B · Gram 有效吗

将早期模型的 Patch 两两相似矩阵作为监督后，局部特征与稠密结果明显恢复；高分辨 Gram Teacher 还能进一步改善局部一致性。

证据 C · 不只靠 Gram

大规模的数据策展、更大的 ViT、RoPE、稳定的大 Batch 训练、分辨率适配及蒸馏都构成 DINOv3 的完整成果。

检验是否真正理解 DINOv3

1
DINOv3 与 DINOv2 共用哪些 Loss？

DINO（CLS）、iBOT（Mask Patch）、KoLeo（特征分散），它们本身不是 v3 全新发明。

2
为什么要另加 Gram Teacher？

不是为了提供新的类别监督，而是给 Student 提供一个相对稳定的 Patch 相似结构参照。

3
为什么比较 Gram 矩阵，不直接比较 Patch 特征？

减少对特征具体坐标数值的束缚，只约束 Patch 两两相似的空间关系。

4
为什么不能把三个阶段合并成一个？

基础预训练、Gram 修复和高分辨适配使用不同训练目标/数据尺度/教师快照。

5
推理时还需要几个 Teacher 或 Gram Loss？

都不需要；保留训练好的 Backbone，用 CLS 和 Patch Token 作为视觉表示。

研究边界：论文的主模型与 LVD 数据为特定规模的训练路线；不是所有 DINOv3 权重都经过完全相同的“1M + Gram + 高分辨”流程。尤其小模型蒸馏时使用的是固定 7B Teacher，不是“两个同规模模型互做 EMA”。
