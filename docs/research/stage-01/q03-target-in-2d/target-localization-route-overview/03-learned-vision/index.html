STAGE 01 · LEARNING-BASED 2D LOCALIZATION

学习式视觉定位

Learning-based Visual Localization · Study Map

一种常见的传统思路，是先设计颜色、轮廓、纹理等视觉特征，再通过规则或分类器判断目标。那么，能不能让模型连特征本身也从数据中学出来？

这一站先把路线摊开：哪些是共同基础，哪些是不同视觉任务，研究者提出的模型又分别该放到哪里。先知道自己在地图的什么位置，再进入具体算法。

00PROBLEM & BOUNDARY

这一次，先明确研究边界

研究问题：给定一张二维图像，如何通过数据训练，让模型自动学习视觉特征，并把这些特征转化成类别、位置、区域或结构点？

简单补充一点背景：传统机器学习常把人工设计的特征交给分类器学习；深度学习进一步让特征提取与预测一起通过数据训练。这里了解这个区别即可，不单独展开传统机器学习模型。

这里不追求完整算法百科。 总览负责分清研究问题与下一步索引；基础页解释共同机制；任务页才整理 R-CNN、YOLO、FCN、OpenPose 等路线。多模态与 LLM 放在后续专题。

03WHAT DOES THE MODEL OUTPUT?

学完基础，先分清四种输出

用同一张番茄图像来看：任务分类应该依据要得到的结果，而不是依据用了哪个 Backbone。

图像分类 认识起点

这张图主要是什么？不要求逐个定位物体。

输出：图像类别 / 类别概率

目标检测

有哪些目标？每个目标在什么位置？

输出：类别 + BBox（也可扩展旋转框）

图像分割

哪些像素属于对象？要不要区分不同实例？

输出：像素类别 / 实例 Mask

关键点定位

目标上哪些结构点重要？它们在哪里？

输出：关键点坐标 / Heatmap
图例使用同一张生成场景；框、Mask 和关键点为人工绘制的概念示意，不是模型推理结果。语义分割与实例分割的区别会在分割专题解释。
分类主要是理解网络预测的起点。本阶段的下游研究重点是目标检测、图像分割、关键点定位；三者是不同任务，不必按顺序完成。
04DEEP VISION · MODEL EVOLUTION

深度视觉模型的发展脉络

回看视觉模型的历史，关键不是按年份背名字，而是理解前一个方案遇到了什么问题，后来的结构怎样回应它。这里按通用表征与具体任务两种维度组织：Backbone 研究“怎样提取特征”，检测、分割、关键点研究“怎样得到不同的结果”。它们相互影响，但不是四条并列的任务路线。

05HOW FAR TO GO

这一站的终点，不是背完所有模型

基础阶段的完成标准

能够沿着输入图像 → 特征 → 预测 → Loss → 梯度更新，把一个视觉网络最重要的机制讲明白，并理解重要参数及其代价。

模型发展史的完成标准

能说清一个代表模型想解决什么旧问题、做了什么结构改动，以及它的输入输出、适用范围与代价；不需要逐一复现。
