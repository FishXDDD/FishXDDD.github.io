LEARNED VISION · 从样本中学习视觉规律

学习式视觉定位

Learned Vision · 让模型从样本中学会找目标

如果要识别不同颜色、材质和形状的瓶子，很难提前写完每一种外观规则，也不一定有每个款式的参考照片。

另一种办法是提供样本，让模型学习哪些视觉信息有助于识别和定位目标。

这一页先把学习方式、定位任务和共同的训练问题区分清楚，具体算法留给下层笔记。

00DEFINE THE PROBLEM

先明确这一条路线研究什么

学习式定位不要求为每个目标手写完整的外观规则，而是从带有监督信息的样本中学习预测关系，再尝试应用于新图像。

二维学习式定位：输入一张图像，通过训练得到的模型预测符合目标条件的物体，并给出类别及相应的二维位置或区域。
学习依据样本图像、标签与训练目标；可以使用人工特征，也可以由网络学习特征。
任务区别分类只回答“是什么”；定位还需要回答“在哪里”，以 BBox、Mask 或关键点表示。
能力边界模型能否处理新的物体外观和场景，取决于数据、训练与泛化能力。
本篇边界：覆盖基于人工特征的传统机器学习与常规深度视觉定位。开放词汇 Grounding、VLM、多模态推理、视频跟踪及三维位姿暂不在这里深入。
01HOW THE MODEL LEARNS

模型怎样从样本中学会判断？

这一组讨论的是学习与表示的方式，而不是最终输出 BBox、Mask 还是关键点。

01
Handcrafted Features + Machine Learning

传统机器学习定位

特征由人来设计，能不能让模型从样本中学会判断目标？

研究人工特征怎样进入分类器，以及分类得分怎样结合位置搜索完成目标定位。代表思路：HOG + SVM、Haar + AdaBoost、DPM。

03SHARED QUESTIONS

训练得出来，是否就能在现场可靠工作？

不论选择哪种模型或定位输出，都绕不开数据、目标函数、评价方式和场景变化。这些是共享的研究问题。

06
Training · Evaluation · Generalization

研究样本与标注、损失函数、Precision / Recall / mAP 等指标，以及过拟合、数据增强和分布变化。
