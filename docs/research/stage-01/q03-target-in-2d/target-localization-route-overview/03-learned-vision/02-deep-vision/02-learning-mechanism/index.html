损失函数与反向传播

Learning Mechanism · How Neural Networks Adjust Their Parameters

上一篇，我们已经能给定权重，把一个两层 MLP 从输入算到输出。可权重从哪里来？如果预测错了，网络又怎么知道该调整哪一个参数？

一个有用的思路是：先定义「错了多少」，再计算「每个参数对错误有什么影响」，最后让参数向减小错误的方向移动。

这一篇只研究这条最小学习链路，用一个可以手算的网络解释清楚。训练技巧与优化器留给下一站。

01 LOSS FUNCTIONS

模型预测错了，怎样把「错误」变成数字？

仅仅知道预测值和真实答案不同还不够。要训练模型，必须定义一个可计算的目标函数：损失函数（Loss）。它衡量当前预测与目标的差异，训练希望降低这个值。

机制图 · 回归与分类，错误的定义不完全相同
回归任务经常衡量预测数值与目标数值的距离；分类任务常衡量模型给真实类别分配的概率。图中数值只是解释机制。

1.1 · 预测一个连续数值：平方误差

一个样本的半平方误差（方便后面求导）
L = ½(ŷ − y*)²
ŷ 为模型预测，y* 为真实值。差值平方始终非负；这里的 ½ 只是让求导更简洁，是否除以样本数属于后面批量训练的约定。

例如目标是 1，预测是 2，那么 L = ½ × (2−1)² = 0.5。这里不是说「0.5 一定不合格」，而是为后续优化提供一个连续、可计算的目标。

1.2 · 预测类别：交叉熵

分类通常需要的是各类别的得分或概率，而非直接回归类别编号。对于二分类，常见的二元交叉熵为：

BCE · 对概率 p 的定义
L = −[y log(p) + (1−y) log(1−p)]
真实标签 y∈{0,1}，p 是预测为正类的概率。若真实标签为 1，p 越接近 0，损失就越大。实践中通常直接把 logits 交给数值稳定的 BCEWithLogitsLoss / CrossEntropyLoss，而不是手动计算 log。
不要把损失与准确率混为一谈。 准确率用于评价离散预测是否正确，而可微的损失函数提供对参数调整有用的连续信号。我们后面的手算统一使用半平方误差，避免一开始混入多种任务。
02 DERIVATIVE & CHAIN RULE

有了损失，还怎么知道该改哪个权重？

损失只是一个数。为了调整参数，必须知道：某个参数略微增加，损失会增加还是减少，变化有多敏感？ 这就是导数（多参数时是梯度）要回答的问题。

2.1 · 先看只有一个参数的情况

一个简单模型
ŷ = wx，　L = ½(wx − y*)²
∂L/∂w = (wx − y*) x
导数的正负表示增大 w 时损失的局部变化方向；绝对值反映局部敏感程度。对多个参数同时求偏导，就得到梯度向量。

2.2 · 为什么深层网络需要链式法则？

因为一层参数并不直接决定损失，它先影响本层输出，再影响下一层，最终才影响损失。

一条依赖路径：w → z → h → ŷ → L
∂L/∂w = (∂L/∂ŷ) · (∂ŷ/∂h) · (∂h/∂z) · (∂z/∂w)
链式法则将复杂函数的导数拆为相邻计算环节的局部导数。若某个参数同时影响多条路径，对应的梯度贡献需要相加。
容易混淆的地方：梯度是损失对参数的导数，不是「模型输出的误差」本身；反向传播负责高效计算梯度，真正修改参数的是后面的优化步骤。
03 BACKPROPAGATION · ONE COMPUTABLE EXAMPLE

用一个只有两层参数的网络，手算一次反向传播

沿用上一篇的形式：输入 x，经过一个隐藏神经元的 ReLU，再得到预测值 ŷ。为了让每一步都能核对，我们给出一组具体数值。

最小模型 · 前向定义
z = w₁x + b₁，　h = ReLU(z)
ŷ = w₂h + b₂，　L = ½(ŷ − y*)²
已知 x=2，真实值 y*=1；初始参数 w₁=w₂=1，b₁=b₂=0。这里只有一个隐藏神经元，但已经能展示多层网络的梯度如何回传。
输入与目标x=2, y*=1
隐藏层z=h=2
模型输出ŷ=2
当前损失L=0.5
机制图 · 正向计算取值，反向沿同一计算依赖求导
这里 z=2＞0，因此 ReLU′(z)=1。绿色虚线表达计算梯度的方向，不表示网络在物理意义上传送误差。

3.1 · 从损失开始，逐段回传

梯度位置怎么算结果
预测 ŷ∂L/∂ŷ = ŷ−y* = 2−11
输出权重 w₂∂L/∂w₂ = (∂L/∂ŷ)·h = 1×22
输出偏置 b₂∂L/∂b₂ = (∂L/∂ŷ)·11
隐藏输出 h∂L/∂h = (∂L/∂ŷ)·w₂ = 1×11
激活前 z∂L/∂z = (∂L/∂h)·ReLU′(2)1
第一层权重 w₁∂L/∂w₁ = (∂L/∂z)·x = 1×22
第一层偏置 b₁∂L/∂b₁ = (∂L/∂z)·11

四个参数的梯度分别是 (∂L/∂w₁, ∂L/∂b₁, ∂L/∂w₂, ∂L/∂b₂)=(2,1,2,1)。

本节真正需要掌握的是计算顺序：先用前向传播保存中间值；再从损失的导数开始，对每一条计算关系应用局部导数，逐层返回参数梯度。对于矩阵和更复杂的网络，原理没有变，计算规模与梯度的形状变得更复杂。
04 GRADIENT DESCENT

梯度已经算出来了，怎样让参数真正改变？

最简单的做法叫梯度下降（Gradient Descent）：沿当前梯度的反方向，更新每一个参数。

单步梯度下降
θnew = θ − η · ∂L/∂θ
θ 表示任意待学习参数，η 是学习率。反向传播只是算出 ∂L/∂θ，优化器使用梯度执行更新。

4.1 · 沿用刚才的梯度，更新一次

如果学习率取 η=0.1，则四个参数更新为：

这次更新的精确数值
w₁′=0.8， b₁′=−0.1， w₂′=0.8， b₂′=−0.1
z′=1.5， h′=1.5， ŷ′=1.1
L′=½(1.1−1)²=0.005
此例从损失 0.5 降到 0.005。注意：这不意味着任意学习率、任意网络、每次更新都保证损失下降。

05 COMPUTATION GRAPH & AUTODIFF

真实网络有几百万个参数，难道每个都要手算？

不需要。深度学习框架会记录运算之间的依赖关系，形成计算图（Computation Graph），再通过自动微分按链式法则计算梯度。

FORWARD
前向阶段

按计算关系生成中间结果；反向求导所需的值由自动微分机制管理。

BACKWARD
反向阶段

从损失出发，对计算图中的操作求局部导数；分支相遇时累加梯度。

例如 PyTorch 中，一个标量损失调用 loss.backward() 计算参数梯度；调用优化器的 step() 才更新参数。连续训练时，还需要按训练方式清理或管理已累积的梯度。

5.1 · 怎样证明手算梯度没错？

一个直接的检验方式是有限差分（Finite Difference）：只改变某个参数一点点，重新计算两次损失，用差商近似它的导数。

中心差分 · 检查 w₁ 的梯度
∂L/∂w₁ ≈ [L(w₁+ε) − L(w₁−ε)] / (2ε)
其余参数与输入保持不变，初始 w₁=1。因为当前 z=2，离 ReLU 不可导点较远，较小 ε 下近似结果应接近手算值 2。
交互实验 · 有限差分检查梯度只扰动 w₁：其余参数保持初始值
解析梯度（反向传播）2.000000
中心差分近似2.000000

这里 ε = 10 的整数负幂（1、0.1、0.01、0.001、0.0001）。有限差分适合验证，不适合替代大型网络的反向传播；在非光滑点附近和浮点精度极限处也要谨慎。

还应认识一个事实：自动微分（Autodiff）并不等于数值差分。它把每个运算的导数通过链式法则组合，通常在浮点误差之外得到解析导数对应的结果；有限差分只是独立的近似校验手段。
06 MINIMUM CHECK & NEXT

这篇学到什么程度，才算打好了基础？

① 能定义损失

给定预测和标注，能计算半平方误差；知道分类任务为什么通常使用交叉熵，而不是把类别编码当成连续数值回归。

② 能按链式法则手算梯度

给定两层网络的输入与参数，能沿着「前向值 → 局部导数 → 参数梯度」的顺序，算出每个权重和偏置的梯度。

③ 能解释参数更新和自动微分

知道 backward() 计算什么、优化器 step() 修改什么；能够用有限差分核对一个简单梯度。
