01

从 FPN 继续追问：信息为什么还会丢失？

FPN 解决了跨尺度语义传播，却没有保证每一层、每个 RoI 都能充分使用需要的信息。

问题 A / Feature path

低层细节上不去

FPN 强化“高层 → 低层”的语义传递。低层边缘、位置等线索要影响高层输出，仍可能沿较长的 Backbone 路径传播。

对应：增加一条短的 Bottom-up 路径。

问题 B / RoI selection

一个 RoI 被指定到单层

FPN 按 RoI 尺寸选择 P2/P3/P4/P5 中的一层，直接忽略其余层上的上下文与精细定位信息。

对应：每个 RoI 从全部层取特征并融合。

问题 C / Mask view

卷积只提供一种预测视角

FCN 擅长保留局部空间结构；全连接层可汇集整个 RoI 的全局信息，对不同输出位置使用不同权重。

对应：在 Mask Head 中加入小型 FC 辅助分支。

PANet 原论文针对的是 proposal-based 实例分割，也能改进目标检测。它不是一个独立的分类 Backbone，也不是首次提出多尺度预测或 RoIAlign。
02

完整网络：先理解“在哪里多了一条路”，再看三项创新

以 Mask R-CNN + ResNet-FPN 为基线，PANet 在特征金字塔、RoI 特征抽取和 Mask Head 上增加可学习结构。

图 01 · 原始 PANet 关键结构与完整数据流科研结构重绘 · P2–P5 → N2–N5 → 全层 RoI 特征 → 预测头
FPN 特征 P2–P5PAN 特征 N2–N5检测输出实例 Mask 输出
简化结构图重点显示三项技术关系：四级 FPN → Bottom-up path → Adaptive RoI feature aggregation → Box/Mask heads。原论文的 RPN 在实验中独立训练，详见训练章节。

输入和输出

输入：RGB 图像；来自 RPN 的候选框 Proposal。
输出：每个实例的类别、检测框、像素 Mask。
训练监督：GT Box、GT Class、GT Mask（独立训练 RPN 还需要 Anchor 前景/回归目标）。

不能把 PANet 简化成“FPN 多一条箭头”

路径增强是第一个组件；RoI 跨层聚合影响框分类与定位；FCN + FC Mask 融合进一步改善实例分割。后来的 YOLO 结构中通常借鉴的是金字塔路径连接，不必包含这三项全部机制。

03

Bottom-up Path Augmentation：为什么让低层信息再走一遍向上？

FPN 先从 C5 向 P2 传播语义，PANet 再从 P2 开始将精细的局部信息向 N5 传播。

下采样为什么不可少？ N2 的分辨率为 1/4，P3 为 1/8；不改变尺寸就无法逐元素相加。stride=2 卷积既做可学习的下采样，也让位置线索向下一个层级传播。

为什么不是上采样？ 这一条通路的任务不是再提高分辨率，而是缩短低层到高层的特征与梯度传输路径。

N2 = P2：最底层直接继承 FPN 特征；增强路径从这一层出发。

高层 N5 既包含当前 P5 的语义，也接收到由低层传递上来的局部定位线索；示意箭头表示信息连接，不代表特征值无损复制。

注意“Bottom-up”的两种含义：ResNet Backbone 本来就自底向上提取 C2–C5；PANet 新增的 Bottom-up 是在已经生成的 FPN P2–P5 之上，再构建一条短的 N2–N5 路径，不是重复运行 Backbone。
04

Adaptive Feature Pooling：为什么一个 RoI 不只看一层？

这不是“在特征图之间再做一次 FPN 融合”，而是每个 Proposal 各自从多层抽取 RoI 特征，再融合属于这个 RoI 的特征网格。

各层采样后的 RoI 特征具有相同空间尺寸与通道数，因此可以逐元素融合。论文在 Box Head 的第一层 FC 之后、Mask Head 的第一层 Conv 之后进行融合。

“Adaptive”在这里不是预测一组注意力权重：默认的 max 在每个位置与通道上，从四层中选取当前最大响应（sum 则直接相加）。

点击最后一列输出的任意格子，观察来自 N2、N3、N4、N5 的对应位置。数字表示已变换后的单通道 RoI 特征，并非原图像像素。

输出某个格子是四层对应位置的最大值；反向传播在该格的 max 分支只流向获胜层（并可通过该层前面的卷积继续传播）。

它怎样解决“不同尺度之间的取舍”？

大 RoI 也可能需要 N2 的边缘和位置；小 RoI 也可能需要 N5 的大感受野上下文。PANet 不预先决定哪层“独占”预测，而给 RoI Head 更自由的跨层信息入口。

它的代价

原来一个 RoI 通常只做一次分层 RoIAlign，PANet 需从多层提取并融合；多出若干 RoI 特征计算及内存访问。并不是所有硬件或模型大小下都可忽略。

05

Fully-connected Fusion：为什么 Mask Head 还需要 FC？

这是原始 PANet 经常被后续简化图省略的第三项创新：卷积保留局部空间结构，FC 对整个 RoI 建立全局依赖。

论文原始 Mask 分支有一条 4 层卷积 + 反卷积的主路径，并从 conv3 连接一个额外的短路径。FC 输出 784 个数重排成 28×28 的类别无关前景/背景 Logits，与每个类别的 FCN 输出相加。

MaskLogitc,i,j = FCNc,i,j + FCi,j;  pc,i,j = sigmoid(MaskLogitc,i,j) FC 的 28×28 输出作为同一张空间校正图，对 K 个类别通道广播相加；训练只监督当前 RoI 的 GT 类别通道。

准备候选框

原论文为了消融比较，使用独立训练的 RPN 产生 Proposal，RPN Backbone 不与后续目标检测/分割网络共享。

构造 RoI 训练批次

原论文实验采用 image-centric 训练，每张图像抽样 512 RoI，正负比例约 1:3。

联合优化三个任务

分类分支学习类别；前景 RoI 的 Box Head 回归 GT 边框；Mask Head 对匹配实例的 GT Mask 进行逐像素监督。

Lhead = Lcls + λbox Lbox + λmask Lmask 这里是三项多任务监督的机制表达，未声称论文给出独有的新损失权重；原 PANet 的主要创新在特征信息流与 Mask Head，而非重新发明分类或边框回归损失。

完整推理：输入一张图片，怎样得到每个实例的 Mask？

原 PANet 仍是基于 Proposal 的两阶段框架；真正变化发生在共享特征路径、每个 RoI 的取样和 Mask Head。

检测分支

对每个候选框的融合 RoI 特征预测目标类别与边界框偏移量；解码得到更准确的框，按照类别置信度与 NMS 保留检测实例。

这条分支决定每个实例是什么、在哪里、得分多少。

分割分支

对保留的目标生成 FCN 与 FC 融合的 Mask Logits，选择检测类别对应通道，经 Sigmoid、映射回最终框位置并阈值二值化，输出每实例像素掩码。

具体实现对 mask 的计算时机、RoI 取样框与后处理可有所不同；这里强调论文的方法机制，不把阈值或 NMS 次序当作 PANet 独有创新。

PANet 没有替代 Proposal，也不是 YOLO 式密集单阶段检测头。其核心是让 Proposal 下游看到更强的跨层特征和更丰富的 Mask 预测视角。

09

最终理解检查：用三个问题记住 PANet

如果只记结构名，很容易把这篇文章误学成“更复杂的 FPN”。

① 为什么 FPN 之后还要 Bottom-up？

高层语义已向低层流动，但低层空间线索到高层仍可能路径较长；N2–N5 提供短的可学习上行通路。

② 为什么一个 RoI 要看全部层？

尺度不唯一决定特征价值。小框需要上下文，大框需要边缘细节；多层 RoIAlign + max/sum 让 Head 从不同层取用信息。

③ 为什么还要加 FC Mask 分支？

卷积擅长局部空间模式，FC 可以看全局 RoI 并使用位置敏感的权重；相加融合两种视角改善 Mask 预测。
