01 / CHRONOLOGICAL STORY

一条历史，几条不断分叉的研究路线

相近年份不等于直接继承；图中专门标注了并行研究。

01
2013—2014起点 · 两条并行探索

从分类到检测：深度特征能否真正找到目标？

当时卡在哪里

CNN 已会识别“是什么”，但检测还必须回答“在哪里、多少个”。

研究改变了什么

将目标位置作为预测对象；R-CNN 用候选区域把检测分解为“先找可能位置，再识别”。

2014—2015效率与系统整合

从逐框卷积到共享计算：候选也能由网络学习吗？

先共享整图卷积特征，再让 RPN 学会产生候选。

03
2016范式分叉 · 单阶段

从“先找再认”到直接预测：Proposal 是必需的吗？

当时卡在哪里

YOLOv1 将检测变成整图预测；SSD 在多个尺度上直接密集预测。

04
2017—2019并行分支 · 特征与监督

直接预测之后，性能瓶颈分成了不同问题

当时卡在哪里

小目标的细节与语义难兼顾；密集训练时简单负样本又太多。

研究改变了什么

FPN 解决多尺度特征表达；Focal Loss 调整困难样本的学习权重。这是不同的研究方向。

代表工作FPN↗RetinaNet↗Mask R-CNN↗Cascade R-CNN↗PANet↗EfficientDet / BiFPN↗
05
2018—2020预测单元 · 样本分配

Anchor 真的是核心分歧吗？先弄清谁负责预测

当时卡在哪里

不同方法在“哪些位置预测框”和“哪些预测当正样本”上做了不同决定。

研究改变了什么

角点、中心点、特征点提供不同预测单元；ATSS 进一步揭示样本分配的重要性。

06
2020新表示 · 与 DETR 并行

边界与定位质量：检测结果是否只能是几个确定值？

当时卡在哪里

分类分数无法完整表达框的质量，单点回归也难表示边界位置的不确定性。

研究改变了什么

GFL 将质量信息融入分类预测，并用概率分布学习边界距离。

07
2020范式突破 · 集合预测

不再先生成大量重复预测：目标集合能否直接学出来？

当时卡在哪里

密集检测往往一个物体对应许多预测，推理阶段需要 NMS 去重。

研究改变了什么

DETR 使用 Object Queries 和一对一集合匹配，重新定义检测输出。

代表工作DETR↗
08
2020—2023沿 DETR 路线继续

集合预测如何从“能工作”变得高效且容易训练？

当时卡在哪里

原始 DETR 收敛慢，处理高分辨率与小目标时成本较高。

研究改变了什么

Deformable DETR 改变特征采样，DINO 改进训练，RT-DETR 追求实时部署。

代表工作Deformable DETR↗DINO↗RT-DETR↗
09
2020—2026并行路线 · 工程优化

另一条持续推进的主线：工程可用性也成为研究目标

当时卡在哪里

更高的 AP 不能自动保证训练稳定、实际时延和部署成本合理。

研究改变了什么

模型结构、训练配方、任务分配和后处理被协同设计；YOLO 家族在专章展开。

专页怎么写，才能真正理解一个检测器？

总览页面：研究思想

它为什么出现？哪种假设被改变？哪个问题得到解决？怎样推动后续研究？

模型专页：完整系统

输入与 GT → 样本/匹配规则 → 网络前向 → Loss / 更新参数 → 推理输出 → 框解码和后处理。

原则：图优先，完整但不重复

独有机制用示意图、交互实验或小例子讲清；共性的 CNN、反向传播、IoU、NMS 等只给必要链接。

YOLO 家族专题
