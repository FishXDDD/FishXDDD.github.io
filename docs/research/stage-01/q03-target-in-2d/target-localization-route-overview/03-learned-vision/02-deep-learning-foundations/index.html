02 · NEURAL NETWORKS TO DEEP VISION

从神经网络到深度视觉

Neural Networks to Deep Vision

图像里只有像素，但要找到目标，我们需要从像素中获得有意义的特征。一个自然的问题是：能不能让网络通过数据，自己学出这些特征？

先弄明白神经网络怎样表达、学习与训练，再看看它如何处理图像、组织空间特征，并产生预测结果。

这一页只整理学习顺序。具体机制、公式和例子，都在下面的六篇笔记里。

00WHAT WE WILL LEARN

把问题分成两部分

一部分研究网络为什么能学习，另一部分研究网络怎样利用图像的空间结构。六篇笔记围绕这两个问题展开。

第一部分 · 神经网络基础

表达能力 → 反向传播 → 训练优化。先理解参数怎样参与计算，又怎样从数据中被更新。

→
第二部分 · 深度视觉基础

空间特征 → 深层与多尺度 → 预测输出。再理解图像信息怎样被提取、组织和使用。

02DEEP VISION FOUNDATIONS

再理解：网络怎样处理图像？

普通向量没有天然的二维位置关系，但图像有。接下来研究网络怎样提取具有空间位置的特征，并将它们用于预测。

机制示意：表达从像素到特征，再到输出的关系，并非某个具体模型的固定架构。

04
