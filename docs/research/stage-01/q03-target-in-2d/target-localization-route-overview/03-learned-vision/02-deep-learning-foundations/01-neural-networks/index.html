神经网络与表达能力

Neural Networks · From Linear Layers to Nonlinear Representation

上一站，分类器可以学习如何区分特征。但一个简单的线性判别函数，遇到更复杂的数据关系时怎么办？

直觉上，把计算层堆得更高似乎就能解决问题。可真正关键的不是「多几层」，而是：为什么只有线性层还不够？非线性加入后，网络究竟多了什么能力？

这一篇先把最小神经网络算清楚。先不急着训练，也不碰复杂的视觉网络。

00 PROBLEM & SCOPE

神经网络究竟是什么？

先给出一个最小定义：神经网络是把带参数的计算层与非线性操作组合起来的函数。 输入一组数，根据当前参数逐层计算，就能得到输出。

01 LINEAR MODEL & NEURONS

一个神经元到底算了什么？

可以把最简单的神经元理解为：接收若干输入，对它们做加权求和，再加上一个偏置。

单个仿射单元 · AFFINE UNIT
z = w₁x₁ + w₂x₂ + b = wᵀx + b
x：输入特征；w：每个输入对应的权重；b：偏置；z：计算结果。严格说，带偏置的是仿射变换，而不只是数学定义中的线性变换。

1.1 · 多个神经元怎样构成一层？

如果有三个输入、四个输出神经元，每个输出都有自己的一组权重。把所有权重排成矩阵，就得到一层的计算：

从标量到矩阵
z = Wx + b
x ∈ ℝ³ W ∈ ℝ⁴ˣ³ b ∈ ℝ⁴ → z ∈ ℝ⁴。矩阵的每一行，决定一个输出神经元如何使用输入。

1.2 · 线性模型擅长什么？

用于二维二分类时，设 f(x) = w₁x₁ + w₂x₂ + b，把 f(x) = 0 作为判别边界，它是一条直线；更高维时对应一个超平面。

这类模型非常有用，但并不是所有类别关系都能用一条直线分开。

02 WHY LINEAR DEPTH IS NOT ENOUGH

多堆几层线性计算，为什么仍然不够？

假设先做一次仿射变换，再做第二次。把第一层的结果代入第二层，就会发现：

两层仿射变换的合并
h = W₁x + b₁
y = W₂h + b₂
= (W₂W₁)x + (W₂b₁ + b₂)
令 W′ = W₂W₁，b′ = W₂b₁ + b₂，则整个网络仍然是 y = W′x + b′。

2.1 · XOR：线性边界到底解决不了什么？

异或（XOR）只有四种二值输入：两个输入相同输出 0，不同则输出 1。把它们画在二维平面里，两类点交错分布，无法用一条直线正确分开。

到这里的结论：层数本身不能突破仿射模型的表达形式。想让网络表示更复杂的函数，需要在层之间加入非线性操作。
03 ACTIVATIONS & NONLINEARITY

加入激活函数，网络为什么就不一样了？

关键变化很简单：仿射计算之后，不直接把 z 传给下一层，而是先经过一个非线性函数 σ。

一层带激活的计算
h = σ(Wx + b)
先用权重和偏置产生 z，再逐元素应用激活函数得到 h。不同激活函数会改变映射形状及梯度行为。

3.1 · 最常见的三个代表

函数表达式需要理解的特点
ReLUmax(0, x)分段线性，但整体不是单个仿射函数；负半轴输出 0。
Sigmoid1 / (1 + e−x)输出 0～1；输入绝对值较大时趋于饱和。
Tanhtanh(x)输出 −1～1，关于原点对称；两端也会饱和。

3.2 · ReLU 明明是分段直线，为什么可以实现非线性？

因为 ReLU 在 x ≤ 0 和 x > 0 时遵循不同的规则。组合多个 ReLU 单元，就能够构造具有多个分段区域的函数，而不再局限于一个全局仿射映射。

3.3 · 用两个 ReLU 神经元精确实现 XOR

仅针对 x₁, x₂ ∈ {0,1} 的简洁构造
h₁ = ReLU(x₁ − x₂)
h₂ = ReLU(x₂ − x₁)
y = h₁ + h₂
这等于 |x₁−x₂|。对于二值输入，只有两者不同时结果才为 1。
最小实验 · 选择一组 XOR 输入观察隐藏神经元如何把原始关系转换为可加和的输出
h₁ = ReLU(x₁−x₂)0
h₂ = ReLU(x₂−x₁)0
y = h₁ + h₂0
两者相同，两个隐藏单元都输出 0，所以结果为 0。
04 MULTILAYER PERCEPTRON & FORWARD PASS

多个神经元怎样成为一个完整网络？

多层感知机（MLP）就是把若干层仿射计算与激活函数组合起来。输入逐层变换为隐藏表示，最后得到模型输出。

最小两层 MLP（单隐藏层）
z₁ = W₁x + b₁
h₁ = ReLU(z₁)
y = W₂h₁ + b₂
这里说的「两层」按有参数的仿射层计数。输入层不额外算一层；输出层也可以根据任务选择是否添加激活函数。

4.1 · 看懂每一层的尺寸

x: 2 维→W₁: 2 × 2→h₁: 2 维→W₂: 1 × 2→y: 1 维

如果输入有 2 个数、隐藏层有 2 个神经元、输出只有 1 个数，那么第一层权重是 2×2 矩阵，第二层权重是 1×2 矩阵。矩阵尺寸来自输入与输出的维度，而非随意指定。

4.2 · 亲手观察一次前向传播

使用一组固定参数，让你只调整输入。这样能清楚地区分：前向传播会改变计算结果，但不会自动学习或更新权重。

交互实验 · 一个两层 MLP 怎样计算固定权重，调整 x₁、x₂，对比有 / 无 ReLU 时的输出
固定参数 · W₁、b₁、W₂、b₂
z₁ = x₁ + x₂ − 1
z₂ = 2x₁ − x₂ − 1
y = 2h₁ − h₂ + 0.5
其中 h₁、h₂ 默认是 z₁、z₂ 经过 ReLU 的结果。关闭激活时 h₁=z₁、h₂=z₂。
第一层 z = [z₁, z₂][2, −1]
激活后 h = [h₁, h₂][2, 0]
最终预测 y4.5
将 x₁=1，x₂=2 代入：z=[2, −1] → ReLU 后 h=[2, 0] → y=4.5。

可以关闭 ReLU，观察输出变为 y=3x₂−0.5（与 x₁ 无关）：这正是上一节所说的多层仿射函数合并。当前只演示固定参数的计算，不涉及训练过程。

05 EXPRESSIVITY & LIMITATIONS

表达能力强，意味着网络一定能学好吗？

增加隐藏层宽度，可以组合更多中间特征；增加深度，可以让多个非线性变换分层组合。但网络更复杂，不代表它自然就拥有好的参数。

能表示吗？

模型结构是否存在一组参数，能够表达或近似目标关系？这属于表达能力。

能学到吗？

训练算法能否找到足够好的参数？还要考虑优化难度与数据条件。

能泛化吗？

新输入与训练样本不同，模型是否还能预测正确？依赖数据和任务分布。

5.1 · 宽度与深度分别带来什么？

宽度增加同一层的表示单元；深度允许把前一层学到的表示继续组合。某些函数可以由深层网络更紧凑地表达，但并不存在「越深就一定越好」的普遍结论。

5.2 · 通用近似定理应该怎样理解？

在满足特定条件的情况下，具有足够隐藏单元的前馈神经网络可以在限定区域内，以任意指定的精度逼近一大类连续函数。但这不保证给定的小网络能精确表示任意函数，更不保证训练一定找到相应参数。

关键区分：表达能力研究「有没有一组参数能做到」；下一篇研究「怎样通过损失和梯度去寻找参数」。
06 MINIMUM CHECK & NEXT

学到什么程度，可以进入下一篇？

不需要复现复杂网络。能完成下面三个最小验证，就已经建立了继续学习的必要基础。

① 合并两层仿射变换

把 W₂(W₁x+b₁)+b₂ 展开，解释为什么没有激活函数时，层数增加并不会改变最终的仿射形式。

② 算清 XOR 的四种输入

验证 h₁=ReLU(x₁−x₂)、h₂=ReLU(x₂−x₁)、y=h₁+h₂ 的结果为什么恰好是异或。

③ 手算一次完整的前向传播

给定输入和权重，依次计算 z、激活后的 h 和输出 y，并能说明每一步的张量尺寸。

这一篇只需真正带走三件事：
① 神经元通过权重、偏置计算仿射映射。
② 没有非线性的多层仿射网络仍是仿射函数。
③ 激活函数让网络能组合更丰富的关系，而前向传播只是使用当前参数算出结果。
