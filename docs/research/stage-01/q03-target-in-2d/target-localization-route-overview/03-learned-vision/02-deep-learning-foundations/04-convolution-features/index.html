04 · CONVOLUTION · SPATIAL FEATURES

卷积与空间特征

Convolution & Spatial Features · From Pixels to Feature Maps

前面已经知道，神经网络能够从数据学习参数。但一张图像不是普通的一维特征向量：邻近像素之间有空间关系，目标也有明确的位置和大小。

如果简单把整张图像展平成向量，再用全连接层处理，会丢失显式的二维邻接结构，也需要大量参数。我们可以从一个更自然的想法开始：让同一组可学习的局部计算，在图像不同位置重复使用。

这一篇研究卷积怎样产生特征图，以及图像尺寸变化后，网络为什么仍能保留可用于定位的空间信息。

00 PROBLEM & SCOPE

从普通向量走向图像，真正增加了什么问题？

MLP 接收向量、逐层映射。图像则提供一张有序的二维网格：相同的边缘可能出现在左上角，也可能出现在右下角；网络不仅要发现某种图案，还要知道它大概出现在哪里。

输入图像张量

通常按 [N, C, H, W] 存储：批次、通道、高、宽。例如 [1, 3, 640, 640]。

目标具有空间结构的特征图

通过局部计算提取响应，同时保留特征图的行列索引，为后续检测与分割提供空间依据。

研究边界：这里理解卷积与空间表示的机制，不重新推导反向传播，不讲完整的 ResNet/FPN，也不提前展开 YOLO 的 BBox 解码。实际视觉网络还会组合归一化、激活、注意力等模块。

01 LOCAL COMPUTATION

卷积核为什么能从局部像素中提取信息？

先从最小的单通道灰度图开始。拿一个 3×3 权重矩阵，覆盖图像的一块 3×3 区域：对应元素相乘，再把九个乘积相加，得到输出特征图的一个数值。将窗口移动到其他位置，重复同样的运算。

二维卷积层的局部计算（深度学习框架常用的互相关记法）
Y[i,j] = b + ∑u=0K−1 ∑v=0K−1 W[u,v] · X[iS+u−P, jS+v−P]
X 为输入图像，W 为 K×K 卷积核，b 为偏置，S 为步长，P 为每侧填充宽度；越界位置按零填充。本篇先不考虑 Dilation。严格数学意义上的卷积通常还会翻转核，PyTorch 等深度学习框架常称这里的互相关运算为“卷积”。

1.1 · 一次手算：为什么某个方向的边缘会有较大响应？

设卷积核每一行都是 [-1, 0, 1]，表示从左到右计算亮度差。若一个局部 3×3 区域左侧较暗、右侧较亮，三个行差异会累加，输出较大的正响应。反过来则得到负响应。

最小算例 · 右侧比左侧更亮
(8−2) + (8−2) + (8−2) = 18
这是演示原理的人为设置核，不代表训练后的卷积核一定会变成边缘检测器。网络实际学习到的权重由训练目标与数据决定。

1.2 · “局部连接”和“权重共享”有什么区别？

局部连接只看附近的像素

一个输出位置通常只依赖输入的一个局部邻域，而不是整张图像的所有像素。

权重共享不同位置使用同一套权重

同一组核参数在图像中重复使用，因此能以较少参数检测不同位置出现的相似局部模式。

需要区分：卷积通常具有对平移的等变性（输出响应随图案平移而平移），不是不论目标移到哪里都得到相同输出的“完全平移不变性”。边界、步长和下采样也会影响这种性质。

02 CHANNELS & TRAINABLE KERNELS

RGB 有三个通道，为什么卷积后会变成几十个通道？

单通道例子只解释了空间计算。真实图像往往有 RGB 三个输入通道；一个普通卷积的输出通道会同时读取所有输入通道：每个输入通道都有相应的卷积核切片，结果相加得到一张输出特征图。

机制图 · 输入通道 → 卷积核组 → 多张输出特征图
一个输出通道不是“从 RGB 中选一个颜色通道”，而是将所有输入通道的信息按可学习权重组合起来。每增加一个输出通道，就增加一组独立的卷积核参数。
通道维度上的计算
Y[o,i,j] = b[o] + ∑c=0Cin−1 ∑u,v W[o,c,u,v] · X[c,iS+u−P,jS+v−P]
o 为输出通道索引，c 为输入通道索引。普通卷积的权重形状是 [C_out, C_in, K, K]；这里省略 Batch 维度。

2.1 · 3 个输入通道、16 个输出通道，要多少参数？

标准卷积参数量（groups = 1，含偏置）
3 × 3 × 3 × 16 + 16 = 448
空间核 3×3，输入 Cin=3，输出 Cout=16。每个输出通道有一个偏置；与输入图像是 64×64 还是 640×640 无关。分组卷积、Depthwise 卷积的参数规则不同，留作按需研究。

2.2 · 这些卷积核为什么是“可学习的”？

边缘核或平滑核可以人工设置，但神经网络中的卷积权重通常从初始化参数开始，通过损失函数与反向传播更新。训练目标不同，模型可能学到不同的局部模式；不应把每个通道都简单解释为一个固定、可命名的人类视觉特征。

连接上一阶段：卷积不是一套脱离神经网络的独立规则。它是一种带局部连接与权重共享约束的可训练线性运算；卷积后常接激活函数，才构成更丰富的非线性表示。
03 SPATIAL SHAPE

卷积之后，特征图为什么会变大或变小？

卷积既涉及“算什么”，也涉及“在什么位置算”。步长 Stride 控制窗口移动间隔；Padding 控制边缘是否补上额外数值；Pooling 则采用不同于学习卷积核的汇聚方式做空间压缩。

单个空间方向的输出尺寸（对称填充、Dilation = 1）
Hout = ⌊(H + 2P − K) / S⌋ + 1
H 是输入高度，K 是核尺寸，P 是单侧填充量，S 是步长。宽度方向同理。若采用非对称填充或空洞卷积，公式需相应调整。
输入卷积设置输出为什么
5×5K=3, S=1, P=03×3只有完整的 3×3 窗口参与计算
5×5K=3, S=1, P=15×5四周补零后保留空间尺寸
5×5K=3, S=2, P=13×3窗口按两个像素的间隔移动
640×640K=3, S=2, P=1320×320常见的下采样卷积配置

3.1 · Stride、Padding 各解决什么问题？

STRIDE决定输出采样密度

S=2 通常让空间宽高大约减半，但会降低采样密度。不能把它理解成简单“丢掉一半像素”，因为每个输出仍是局部加权组合。

PADDING决定边缘如何参与

P=1 可以让 3×3、S=1 卷积在常见设置下保持宽高不变；边界响应会受到填充值影响，不等同于真实图像外部的内容。

3.2 · Pooling 与 Stride 卷积有什么不同？

Max Pooling 取局部最大值，Average Pooling 取局部平均值。常见池化窗口不具有卷积那样的一组可学习核权重；而 Stride 卷积同时完成可学习特征变换与空间下采样。两者都可能减少空间尺寸，但机制和表达能力不同。

2×2 池化窗口：四个输入 [1, 4; 2, 3]
MaxPool = 4   ·   AvgPool = (1+4+2+3)/4 = 2.5
机制图 · 多次下采样后，空间网格逐渐变稀
这里每一阶段假设总步长为 2。特征图的空间尺寸变小，不代表通道数也必须同步变小；深层网络常同时增加通道数。
04 RECEPTIVE FIELD & POSITION

特征图变小后，目标的位置到底去哪了？

这是视觉定位中最关键的空间问题。特征图中的一个网格位置，不是原图中孤立的一个像素；它通常汇聚输入图像中一片邻域的信息。需要同时认识两个量：

RECEPTIVE FIELD理论感受野 r

某个特征位置在理论上能够依赖原图的多大区域。层层卷积会扩大它。

EFFECTIVE STRIDE / JUMP相邻中心间距 j

特征图中相邻两个网格位置，对应到输入图像时，其感受野中心相隔多少像素。

逐层叠加的理论感受野（无空洞卷积）
rl = rl−1 + (kl−1)jl−1
jl = jl−1 · sl
初始 r₀ = 1、j₀ = 1；kₗ 是第 l 层核大小，sₗ 是该层步长。这里讨论顺序堆叠的普通卷积，残差、并行分支与注意力网络的具体关系要分别分析。

4.2 · 特征网格与原图坐标怎样联系？

在刚才这种 K=3, S=2, P=1、连续下采样的简化设置中，第 l 层输出网格索引 (i, j) 对应原图上的感受野中心约为 (i · 2^l, j · 2^l)（采用零起点像素中心坐标）。

这不是任意网络都适用的通用坐标换算公式。实际还取决于核大小、填充方式、输入缩放、裁剪、插值、对齐约定与后续预测头；定位模型必须结合整条预处理和预测链路恢复原图位置。

很重要的区分：理论感受野表示一个位置可能受到影响的输入范围，并不意味着该范围内所有像素对输出的影响都一样大。实际有效感受野通常更集中，且受权重与非线性运算影响。
05 TRADE-OFFS & LIMITATIONS

空间特征表示解决了什么，又付出了什么代价？

为什么卷积很适合图像？

局部连接利用相邻像素的空间结构，权重共享降低参数需求，并让相似局部图案在不同位置产生相应响应。

为什么不能无限降低分辨率？

下采样减少计算，但会使小目标、细线和精确边界更难表示。步长采样也可能发生混叠，信息丢失后不能单靠扩大感受野恢复。

感受野大就一定懂全局吗？

不一定。理论感受野只是潜在依赖范围；模型是否真的利用这些信息，还与训练、权重、网络结构有关。

所有视觉网络都必须用卷积吗？

不是。Transformer 等模型也能形成视觉表示。卷积仍是理解空间局部性与视觉特征图的重要基础。

下一步为什么研究多尺度？浅层通常保留更密集的空间信息；深层通常拥有更大的感受野与更抽象的表示。目标定位需要同时照顾两者，因此后面才引出 Backbone 的分层特征与 FPN 等融合机制。
06 MINIMUM CHECK

学到哪里，才算真正建立了卷积的空间模型？

这篇不要求复现一个完整 CNN。只要能独立解释并验证下面几件事，就足够进入下一站：

  • 给定 3×3 灰度输入和 3×3 卷积核，能手算一个输出位置的数值。
  • 给定 C_in=3, C_out=16, K=3，能解释 16 个输出通道从哪里来，并算出参数量。
  • 给定 H=640, K=3, S=2, P=1，能算出输出高度为 320。
  • 面对连续三个 Stride=2 的卷积，能算出输出步长 8、理论感受野 15×15，并说清特征图坐标与原图的关系。
卷积层不是“把图像变模糊的滤波器”。它在空间网格上共享可学习权重，形成多通道特征图；Stride、Padding 与层级组合决定了这些特征的空间密度和感受范围。
