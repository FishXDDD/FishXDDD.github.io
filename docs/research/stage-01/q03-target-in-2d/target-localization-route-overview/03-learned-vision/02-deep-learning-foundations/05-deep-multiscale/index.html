深层网络与多尺度

Deep Networks & Multi-scale Representation

上一篇研究了卷积如何从局部像素得到特征图。现在有两个新的问题：只靠几层局部计算，怎样理解更复杂的目标？而随着网络不断下采样，目标的位置和小细节又该怎么办？

这篇从深层特征开始，先理解 Backbone 怎样形成不同层级的表示，再看 ResNet 为什么引入残差连接，最后用 FPN 说明怎样兼顾多尺度信息。

00 PROBLEM & SCOPE

这篇究竟研究什么？

一层卷积能在局部提取响应；多层网络能逐渐组合这些局部信息。但定位需要的不止是“看懂物体”，还要保留物体在图像中的位置和尺度。

PROBLEM A为什么要加深？

让网络逐层组合表示，获得更大的上下文范围。

PROBLEM B加深为什么难？

网络更复杂，优化会出现新的困难；残差连接如何缓解？

PROBLEM C不同尺度如何兼顾？

较高分辨率与较丰富的上下文信息如何融合？

本篇边界：学习 Backbone、残差连接和多尺度融合的机制。卷积与感受野的计算不重复；分类/检测 Head、Anchor、NMS 等放到后续笔记。这里展示常见 CNN 结构，而不是规定所有深度视觉模型都必须使用 ResNet 或 FPN。
01 WHY DEPTH?

既然卷积能提取特征，为什么还要堆很多层？

一个 3×3 卷积主要汇总邻近信息。连续堆叠后，后层特征可以利用前层已经提取的局部模式，形成更大范围的组合表示。比如从局部边缘、纹理响应，逐渐组合成与部件或整体有关的模式。这是一种常见观察，而不是“第几层必然识别什么”的固定规则。

机制图 · 局部证据怎样被逐层组合
网络越深，可能融合的输入范围越大，但表征内容依赖训练任务、模型结构与数据，不能把这里画成严格固定的人工语义层级。

1.1 · 深层真的一定比浅层好吗？

不一定。加深网络提供了构建复杂函数的机会，也带来更多计算、内存开销以及优化困难。表达能力更强 ≠ 训练必然更好 ≠ 推理必然更准确。

这就引出两个独立问题：如何把许多层组织成可复用的特征提取器，以及深层网络该怎样更容易被优化。

02 BACKBONE & STAGES

Backbone 究竟输出什么？为什么不只取最后一层？

Backbone 是承担主要特征提取的网络主体。对于常见 CNN Backbone，它往往由几个 Stage（阶段） 组成：同一阶段内重复若干计算块，进入下一阶段时通常减小空间尺寸、调整通道数。后续任务可以使用最后一层，也可以使用多个阶段的输出。

机制图 · 分层特征 C2、C3、C4、C5（以常见 4 倍起始下采样配置为例）
示例输入 640×640：C2=160×160，C3=80×80，C4=40×40，C5=20×20。数字仅描述空间尺寸，完整特征还包括通道数。不同 Backbone 的阶段命名、尺度及输出可能不同。

2.1 · VGG 与 ResNet 在这里分别代表什么思想？

VGG · STACKED CONVOLUTIONS通过规则的卷积堆叠构建深层表示

理解重复卷积、非线性与分阶段下采样怎样形成分层特征。这里只学习结构思想，不背不同 VGG 配置的层数清单。

RESNET · RESIDUAL BLOCKS让更深的网络更容易被优化

在卷积块周围增加 Shortcut，将输入与残差分支相加，改善深层网络训练困难。它仍然可以产生多个尺度的 Backbone 特征。

2.2 · “通道多”与“分辨率高”是一回事吗？

不是。每个特征张量通常可写作 [N, C, H, W]：H、W 决定网格密度，C 决定特征通道数量。深层阶段可能具有更小的 H×W 和更多通道，但并不意味着它能够恢复降采样时失去的全部细节。

给定位置信息时常用的总下采样比例
strideeffective = Hinput / Hfeature
仅在输入与特征图尺寸为整倍数、裁剪填充等对齐条件明确时，可作为便捷的空间尺度描述。具体位置映射仍需使用上一章讨论的步长和像素中心约定。
03 RESIDUAL LEARNING

层数增加之后，为什么 ResNet 要让输入“绕过去”？

如果直接堆叠许多层，较深网络有时会出现训练误差反而增加的退化现象。这不只是“测试集过拟合”，而是深层网络可能更难优化。残差学习将某个块要学习的映射改写为“相对于输入的变化量”。

机制图 · 普通映射与残差块的核心差别
示意一个维度匹配的基本残差块。实际 ResNet 还可能包含卷积、归一化、激活、通道投影和下采样；Shortcut 不总是无需参数的恒等映射。
残差块的基本表达
y = F(x; W) + x
x 是输入，F 为带参数 W 的残差分支；若目标映射是 H(x)，残差分支学习 F(x)=H(x)−x。输入与 F 的形状必须可相加，尺寸或通道不同通常需投影 Shortcut 或其他对齐方式。

3.1 · 为什么这种形式有助于优化？

当理想映射接近恒等映射时，残差分支只需学会接近零的修正。反向传播时，直接加法也提供了一条梯度通路：

一维简化示意：从输出到输入的导数
dy/dx = 1 + dF(x)/dx
真实网络使用 Jacobian、矩阵乘法和非线性，且可能存在投影 Shortcut；这个公式是说明“恒等路径提供一项直接贡献”，不是保证任意深度都不会出现梯度爆炸或消失。
交互实验 · 有无 Shortcut，输出会怎样改变？F(x) = 0.2x + 0.6

这里用一个人为设置的一维残差分支作演示，不代表真实模型训练后的参数。调整输入 x，并切换 Shortcut，可直接看到残差映射 y=F(x)+x 与普通映射 y=F(x) 的差别。

F(1) = 0.8；开启 Shortcut 后 y = 0.8 + 1 = 1.8。

这里展示的是计算路径，不是性能对比。残差连接改善优化能力需要通过更完整的网络、训练目标和数据验证。

本节记住的不是“ResNet 越深越好”。 残差连接主要提供一种更容易优化深层网络的参数化与信息路径；是否值得增加深度仍取决于任务与代价。
04 SPATIAL RESOLUTION & SCALE

深层特征能看更大范围，为什么还需要浅层特征？

深层特征通常能够整合更广的上下文，但经过多次下采样后，空间网格变稀。一个小物体如果在 640×640 的图像里宽 12 像素，到总步长 32 的特征图上，宽度只有约 0.375 个网格间距。这并不等于“小目标一定不可检测”，而是说明依赖单一低分辨率特征会更困难。

C2160 × 160空间步长约 4
C380 × 80空间步长约 8
C440 × 40空间步长约 16
C520 × 20空间步长约 32
仅作网格尺度的粗略换算
wfeature ≈ winput / S
w 为物体宽度，S 为特征层相对输入的总步长。这个比例不表示实际特征包含多少“完整目标像素”，更不能单独预测检测成功率。

4.1 · 图像金字塔与特征金字塔，是同一件事吗？

IMAGE PYRAMID先把输入图像缩放多次

在不同尺寸的图像上提取或比较特征；直观，但重复计算可能比较昂贵。

FEATURE PYRAMID利用一个网络的多层特征

从不同 Stage 获取多种空间尺度的特征，再通过融合让它们更适合后续预测。

直接使用 C3 / C4 / C5 这些层，已经是多尺度特征；但它们的信息质量和语义抽象层次不一致。FPN 的关键就是在不同尺度之间传递和融合信息。

05 FEATURE PYRAMID NETWORK

FPN 怎么让不同尺度的特征彼此补充？

经典 FPN 利用 Backbone 自下而上的分层特征，在其上增加自顶向下路径（Top-down）与横向连接（Lateral Connection）。高层特征先上采样到较大的空间尺寸，再与对应阶段的特征融合，使多个输出层都能够利用高层信息。

机制图 · C3/C4/C5 经横向连接与自顶向下融合形成 P3/P4/P5
简化的三层 FPN。经典论文通常还包含 P2 及输出平滑卷积等操作。图中展示的融合为常见的逐元素相加；前提是空间尺寸与通道数对齐。

5.1 · 为什么要先使用 1×1 Conv？

不同 Backbone Stage 的通道数往往不同，而逐元素相加要求通道一致。横向 1×1 Conv 可以把不同层的通道投影到同一个宽度；上采样则对齐 H、W。两者解决的是不同维度的对齐，不能互相替代。

简化的 FPN 融合公式
P4 = Conv1×1(C4) + Up(P5)
P3 = Conv1×1(C3) + Up(P4)
Up 表示空间上采样到目标层尺寸；这里把融合后的中间特征统一记为 P。经典 FPN 还会对融合结果使用 3×3 平滑卷积，精确命名可区分中间特征和最终 P 输出。

5.2 · 直接把两张特征图相加，实际发生了什么？

只看最小数值例子。设横向投影后的 C3 是 4×4，较深层的 P4 是 2×2，使用最近邻上采样放大到 4×4，再逐位置相加。现实网络会有更多通道和可学习权重，但空间尺寸对齐 → 相加融合这一机制是清楚的。

交互实验 · 一次简化 FPN 的逐元素融合4×4 ← 2×2

数字是人为构造的单通道特征，用来理解上采样与相加，不是训练模型的真实特征响应。切换显示对象并点击方格，可查看每个位置的来源。

真实 FPN 的特征不保证相加后数值更大就代表目标更明显；这种数值演示只解释信息来源和张量操作。

5.3 · FPN 解决了什么，没有解决什么？

解决的问题让多个空间尺度都获得更丰富的上下文

在较高空间分辨率的层级上引入深层信息，便于后续模型利用不同尺度的特征。

仍然存在的问题融合并不能凭空恢复已经丢失的信息

小物体可能在早期下采样时已损失关键细节；融合策略、对齐方式、计算代价仍影响结果。

06 EXTENSIONS & LIMITATIONS

FPN 之后，还值得知道哪些结构？

这里不按论文发展史逐个研究网络，而是认识后续改动通常在解决哪类问题。

技术思路关注的问题当前需要学到哪里
ResNet / Bottleneck深层网络的残差学习、参数和计算效率理解 Shortcut、维度对齐；不需背全部层配置
FPN把深层信息传到多个不同分辨率的特征层能看懂横向投影、上采样和相加
PAN / PANet 类路径增强进一步加强较低层到较高层的信息传播理解它新增自下而上的融合路径即可
BiFPN 等融合结构跨尺度双向融合、权重与效率认识为不同特征分配可学习融合权重的思路
Transformer Backbone不只依赖卷积来组织视觉表示知道它是另一类表征架构，后续单独学习
网络越深就越好吗？

不一定。需要在能力、数据、优化、推理时延和显存之间权衡。

FPN 就能保证小目标识别好吗？

不能。输入分辨率、标注、训练策略、目标实际像素尺度同样重要。

每个模型都有独立 Neck 吗？

不是。Backbone、Neck、Head 是便于理解的模块分工，不是必须存在的统一接口。

为什么不在这篇详细研究 YOLO 的 Neck？

这篇学习共性机制；具体检测结构、预测头和输出解码放在目标检测章节。

最重要的边界：ResNet 处理的是深层网络的表示与优化；FPN 处理的是跨尺度特征融合。两者可以组合，但不是必须依次选用的固定算法步骤。
07 MINIMUM CHECK

学到什么程度，就可以进入预测头？

这篇不需要复现 ResNet-50 或完整 FPN。能够独立解释下面几个问题，就已经有足够基础：

  • 为什么卷积层级加深后，可以组合更大范围的信息？深度增加为什么不保证性能提升？
  • 给定 C3=80×80、C4=40×40、C5=20×20，知道它们通常来自哪里，空间步长分别是多少。
  • 能画出并解释 y = F(x) + x，知道 Shortcut 在何时需要投影对齐。
  • 能用两张小矩阵演示：1×1 通道投影的作用、上采样的空间对齐，以及 FPN 的逐元素加法。
  • 能说清 FPN 与图像金字塔的区别，并解释为什么多尺度融合不等于恢复全部细节。
深层 Backbone 让网络逐步形成不同尺度的视觉表示；ResNet 帮助深层网络优化，FPN 则把不同尺度的信息融合起来。它们准备好了可用于定位的特征，但特征怎样变成具体的坐标、目标框或区域，仍需下一篇回答。
