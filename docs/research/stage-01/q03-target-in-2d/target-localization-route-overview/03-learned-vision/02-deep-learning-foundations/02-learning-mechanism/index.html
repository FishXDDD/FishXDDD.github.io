02 · LOSS · GRADIENT · BACKPROPAGATION

损失函数与反向传播

Learning Mechanism · 从「错了多少」到「每个参数该如何改变」

上一篇我们已经会让 MLP 做前向传播：给定权重，算出预测。但预测错了，怎样知道是哪一个权重造成的？又应该怎么修改？

这次不急着背反向传播公式。先弄懂导数和梯度在问什么，再用同一个最小网络，把四个参数的梯度一步一步算出来。

00 LEARNING ROADMAP

先把学习顺序理顺

这次最重要的调整是：梯度不是反向传播之后才学的东西。 反向传播本身就是一种高效计算梯度的方法。所以我们应该先知道梯度是什么意思，再理解如何把它从输出层一路算到输入层。

① 损失→② 导数 / 梯度→③ 链式法则→④ 反向传播→⑤ 梯度下降

这一篇要学会

损失的定义、单变量导数、多参数梯度、链式求导、反向传播、一次更新与梯度校验。

这一篇不扩展

SGD、Momentum、Adam、Batch、初始化、归一化、正则化：统一放到下一篇《训练与优化》。

贯穿全文的模型：一个输入 x，一个 ReLU 隐藏神经元，一个线性输出。它虽然小，但足以完整展示「前向 → 求导 → 反向 → 更新」。
01 LOSS · MEASURE THE ERROR

第一步：预测错了多少？

我们把模型输出记为 ŷ，真实答案记为 y*。先只考虑预测一个数值的回归任务，定义平方误差损失。

最小损失函数 · 半平方误差
L = 12(ŷ − y*)²
二分之一只是方便求导时与平方产生的 2 抵消，不是开平方。预测越接近目标，损失越小。

为什么要有损失函数？ 因为只有把预测错误变成一个明确的数值，我们才能进一步计算「改变参数会让这个错误增大还是减小」。

最小网络 · 初始条件
输入x = 2
→
隐藏层z = w₁x+b₁ = 2
h = ReLU(z) = 2
→
输出ŷ = w₂h+b₂ = 2
→
损失L = 0.5

固定参数：w₁ = w₂ = 1，b₁ = b₂ = 0；真实目标 y* = 1。这些数值后续全部沿用，不会中途更换例子。

转折：我们已经知道损失是 0.5，但这还没有告诉我们：到底应该修改 w₁、b₁、w₂ 还是 b₂？接下来要理解「参数对损失有多大影响」。
02 DERIVATIVE · GRADIENT

第二步：梯度究竟在告诉我们什么？

先不看神经网络，只看一个参数 w。如果我们轻微改变 w，损失 L 会怎样变化？导数是损失在当前位置对这个参数的变化率。

求导示例 · 一条参数如何影响损失
∂L∂w = ∂L∂ŷ · ∂ŷ∂w = (wx − y*) x
例如 x=2、w=1、y*=1，预测 ŷ=2，此时导数是 (2−1)×2=2。把 w 增大一点，损失在局部会增大。
图解 · 导数的正负，决定局部上升还是下降
在 w=1 时，导数为正。朝减小 w 的方向移动，损失在局部下降。

2.1 · 导数和梯度有什么区别？

一个参数：导数

例如只有 w 一个参数，我们关心 ∂L/∂w，是一个数。

多个参数：梯度

网络有许多参数，分别求偏导，再按固定顺序排成一个向量，叫梯度 ∇L。

梯度方向是损失在局部增长最快的方向；负梯度方向是局部下降最快的方向（在通常的欧氏距离度量下）。这里说的是局部性质，不保证跨很大一步仍然下降。

转折：单个参数的导数不难算。但是第一层的 w₁ 不直接决定损失：它先改变 z，再改变 h，再改变 ŷ，最后才改变 L。怎样处理一串间接影响？这就需要链式法则。
03 CHAIN RULE

第三步：一层影响下一层，导数怎么连起来？

前向计算依次发生：w₁ 改变 z → z 改变 h → h 改变 ŷ → ŷ 改变损失 L。链式法则的思想很朴素：把每一段的局部变化率连乘起来。

链式法则 · 一条完整的因果依赖
∂L∂w₁ = ∂L∂ŷ · ∂ŷ∂h · ∂h∂z · ∂z∂w₁
每一项都只对相邻两步求导；从最右边的 w₁ 到最左边的 L，连接起来就是它对最终损失的影响。
局部关系这一小段的导数在本例的值
ŷ → L∂L / ∂ŷ = ŷ − y*2 − 1 = 1
h → ŷ∂ŷ / ∂h = w₂1
z → hReLU′(z) = 1（z > 0）1
w₁ → z∂z / ∂w₁ = x2
把四段局部导数代入：
∂L∂w₁ = 1 × 1 × 1 × 2 = 2

这说明：让 w₁ 在当前位置增加一点，损失的变化率是 2。不过如果每次求 w₁ 的导数都从头展开完整长式子，会做很多重复计算。

转折：链式法则告诉了我们怎么算。反向传播更进一步告诉我们怎么复用已经计算的导数，快速求出所有参数的梯度。
04 BACKPROPAGATION · STEP BY STEP

第四步：真正手算一次反向传播

我们继续用同一组数值。前向先算出 z=2、h=2、ŷ=2、L=0.5；反向从损失开始，把已经求到的梯度继续向前一层传递。每走过一层，都顺手计算这一层的参数梯度。

05 AFTER BACKPROP · WHAT IS STILL MISSING?

反向传播算完了，关于梯度还缺什么？

5.1 · 梯度向量：四个偏导数合在一起是什么？

网络的参数是一个整体：θ=(w₁,b₁,w₂,b₂)。我们把刚刚算出的四个偏导数排在一起，就得到梯度向量。

θ = (w₁, b₁, w₂, b₂)∇L = (2, 1, 2, 1)

它告诉我们在当前参数位置，分别调整四个参数对损失的局部影响。

5.2 · 如果一项结果通往两条路径，梯度要相加

刚才的最小网络主要是一条链。但真实网络中，一个中间变量可能被多个后续操作使用。链式法则在分支汇合时，需要把各条路径的梯度贡献相加。

在 a=2 时，上路贡献 2a=4，下路贡献 3，最终 ∂L/∂a = 4+3 = 7。

5.3 · ReLU 会挡住梯度吗？

当 z<0 时，ReLU′(z)=0，这条路径的梯度会被乘成 0。本例 z=2，所以没有被挡住。z=0 处不可导，框架会采用约定的次梯度。

5.4 · 梯度可能算错吗？

可以用有限差分独立核对。自动微分使用链式法则；有限差分只是根据相邻损失近似导数，两者不是同一算法。

转折：现在我们有了完整的梯度向量，也知道分支出现时如何求和。但模型参数仍然没有变化。要让下一次预测更接近目标，还缺最后一件事：优化器根据梯度更新权重。
06 UPDATE · CHECK

最后一步：梯度怎么算成新的参数？

梯度的正方向是损失的局部上升方向，所以最简单的做法是沿负梯度方向迈出一小步。

最基本的梯度下降
θ新 = θ旧 − η · ∂L∂θ
η 是学习率；梯度只告诉我们局部方向，是否真正降低损失还要更新后重新前向计算。

6.1 · 四个参数一起更新

取学习率 η=0.1，初始参数 θ=(1,0,1,0)，梯度 ∇L=(2,1,2,1)。

带入四个梯度，一次性更新：
θ新 = (1,0,1,0) − 0.1 × (2,1,2,1)= (0.8, −0.1, 0.8, −0.1)

使用更新后的参数重新执行前向传播：

用新参数重新算：
z新 = 0.8 × 2 − 0.1 = 1.5ŷ新 = 0.8 × 1.5 − 0.1 = 1.1L新 = 12(1.1−1)² = 0.005

本例损失从 0.5 降到 0.005，说明这一次更新有效；但学习率过大或网络非线性复杂时，一次更新也可能让损失变大。

交互实验 · 同一梯度，不同学习率只更新一次所有参数，再重新计算损失
更新前损失0.5000
更新后损失0.0050

6.2 · 怎么确认反向传播的梯度真的算对了？

可以暂时固定其他参数，只对一个参数做很小的扰动，再观察损失的变化。

中心差分：检验 w₁ 的梯度
∂L∂w₁ ≈ L(w₁+ε) − L(w₁−ε)2ε
固定其他参数，分别向两侧轻微扰动 w₁，比较前后损失。它用来核对梯度，而非替代大型网络的反向传播。

三个动作不能混淆：forward() 用当前参数计算预测和损失；backward() 沿计算图计算梯度；optimizer.step() 才会使用梯度修改参数。实际 PyTorch 训练还需要在适当时机清空上一轮累计梯度。
07 CHECKPOINT & NEXT

怎样确认这条学习链真的闭合了？

现在应该理解你可以尝试回答
损失为什么需要把预测误差变成一个可优化的标量？
导数 / 梯度∂L/∂w=2 意味着什么？为什么它不等于参数应该减少 2？
链式法则为什么第一层的 w₁ 需要经过 z、h、ŷ 才能影响损失？
反向传播为什么先计算 ∂L/∂ŷ，再逐层算出四个参数的梯度？
梯度汇合如果中间变量通向两条路径，为什么梯度要相加？
参数更新为什么反向传播结束不代表模型已经学会了？
完整理解：前向传播计算预测和损失；导数描述局部变化；反向传播利用链式法则高效计算所有参数梯度；优化器使用这些梯度修改参数。
