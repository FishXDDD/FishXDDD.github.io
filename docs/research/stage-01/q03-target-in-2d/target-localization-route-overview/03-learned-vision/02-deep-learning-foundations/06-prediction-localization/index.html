06 · PREDICTION HEAD · LOCALIZATION

预测头与位置输出

Prediction Heads · From Features to Locations

上一站研究了 Backbone 与 FPN：网络已经能输出不同尺度的特征图。但特征图不是目标框，更不是 Mask 或关键点。如果机器人需要一个二维位置，网络究竟怎样把抽象的特征变成可用的坐标？

这一篇沿着一条最小计算链研究：特征 → 预测值 → 图像坐标 → 最终结果。弄清共同机制，具体的 YOLO、Mask R-CNN 和关键点模型放到后面独立研究。

00 PROBLEM & SCOPE

网络已经提取特征，为什么还不能直接定位？

Backbone 或 FPN 输出的是一组特征张量 F，其中包含对目标有用的信息，但它本身还没有约定“第几个数表示类别”“哪几个数表示坐标”。Head 负责把特征转换成任务要求的预测。

01特征是什么？

每个位置有一串特征值，代表局部与上下文信息。

02预测什么？

类别得分、坐标、边界、像素或关键点。

03位置在哪里？

把特征图坐标映射到输入图像坐标。

04能直接使用吗？

需要筛选、去重、还原缩放和检查。

本篇边界：理解常见 CNN 定位模型中 Head 的共性。Anchor、DFL、RoI Align、各种 YOLO Head 的具体实现属于后面目标检测或实例分割章节；这里的简化公式只是教学示例，不代表所有模型的实现。
01 FEATURES TO PREDICTIONS

预测头究竟在特征图上做了什么？

设输入图像大小为 64×64，某层特征图为 8×8×C，总步长 s=8。每个网格位置都有一个 C 维特征向量。预测头可以使用卷积或其他映射，把这个向量转换成任务需要的数值。

每个位置的一次简化预测
qr,c = gθ(Fr,c)
Fr,c：第 r 行、第 c 列的特征向量；gθ：具有可学习参数的预测映射；qr,c：该位置的预测结果。实际模型可能综合邻近位置或全局特征。
机制图 · 同一个位置的 C 维特征，转换为不同含义的输出
分类头和回归头可以共享特征，也可能采用独立分支。图中只是常见的一种局部预测思路。
转折：Head 只是把特征映射为数字。但有些数字回答「它是什么」，有些回答「它在哪里」。因此下一步必须先区分分类与回归。
02 CLASSIFICATION & REGRESSION

预测一个类别，和预测一个位置，有什么本质区别？

CLASSIFICATION分类：离散选择

输出各类别的分数（logits），需要时转为概率或分类分数。例如：瓶子、杯子、背景。

REGRESSION回归：连续数值

输出坐标、距离、宽高、偏移或其他连续参数。例如：边界距离为 1.5 个网格单位。

2.1 · 为什么分类分数不直接等于概率？

网络通常先输出 logits。对于互斥的 K 类，一种常见方法是 Softmax：

Softmax · 同一组互斥类别
pk=ezk∑j=1Kezj
zk 为第 k 类的 logit，pk 是归一化后的值，所有类之和为 1。多标签或独立类别预测也常采用 Sigmoid，不一定使用 Softmax。

例如「瓶子」logit 为 2，「杯子」为 0，「背景」为 −1，经过 Softmax 得到的是相对竞争后的概率样分数。高分不自动等于真实世界中的可靠概率，它是否校准良好还需要另行验证。

2.2 · 回归为什么不需要选类别？

回归输出的是连续参数：可以直接预测中心坐标和宽高，也可以预测一个网格点到矩形四边的距离。它不负责表达“是哪个类别”，而负责描述“目标边界在哪里”。

特征 F→分类 Head：类别 / 分数+回归 Head：位置 / 形状→候选结果
不要混淆：分类头输出的是类别证据，回归头输出的是位置参数；是否存在目标、类别预测和定位框的具体组织方式因模型而异。
03 FEATURE GRID TO BOX

特征图上的一个格子，怎样变成原图中的 BBox？

先采用一种便于理解的 Anchor-free、按网格预测边界距离 的简化形式。假设输入图像为 64×64，特征图为 8×8，总步长为 8。

3.1 · 先找到网格中心在原图的哪里

规则对齐的教学示例 · 行 r、列 c 从 0 开始
xc = (c + 0.5) × s，　yc = (r + 0.5) × s
s = 8。网格位置 (r=3,c=4)，对应中心 (xc,yc) = (36,28) 像素。实际网络的坐标对齐定义可能不同，此处明确采用单元格中心。

3.2 · 再由四个距离还原目标框

距离在特征网格单位中给出；像素距离需乘以 s
x₁ = xc − s·l，　y₁ = yc − s·t
x₂ = xc + s·r，　y₂ = yc + s·b
l、t、r、b 分别为预测点到左、上、右、下边界的非负距离；(x₁,y₁,x₂,y₂) 为原图中的角点形式 BBox。这里将网格距离转换为像素距离。
交互实验 · 点一个特征网格，看看输出框怎样移动8 × 8 的特征图映射到 64 × 64 的输入图像 · 点击左图网格
(0,0)输入图像坐标：64 × 64(64,64)

绿色点＝网格对应的原图中心；橙色框＝根据 l、t、r、b 解码得到的目标框。边界超出图像时在画布上裁切显示，但报告原始坐标。

为什么要区分坐标空间？ Head 可能在特征图上预测偏移或距离，最终用于画框、抓取或测量时必须转换到输入图像的坐标系。

真实检测器可以采用不同参数化方式，例如中心点 + 宽高、Anchor 偏移、四边距离或离散分布回归。不要将这个演示误当成 YOLO 所有版本的统一实现。

转折：到这里，我们知道 Head 怎样把特征转成 BBox。但目标定位不总是需要一个矩形：有时需要实际像素区域，有时只关心几个特定点。
04 OUTPUT TYPES

BBox、Mask、关键点，究竟改变了什么？

它们主要改变的是预测目标与标注形式，不是三种互斥的“学习原理”。可以采用共享特征、不同的 Head；也可以设计各自独立的架构。

DETECTIONBBox

用矩形描述目标大致位置与范围。适合目标发现与粗定位。

INSTANCE SEGMENTATIONMask

给出属于某个实例的像素区域。需要知道像素属于哪个实例。

KEYPOINTS关键点

预测目标的指定结构点，例如角点、关节点或操作点。

交互示意 · 同一场景，希望网络输出什么？点击三种任务；下方展示输出表示及任务差异，不是实际推理结果
DETECTION

目标检测 · 输出一个框

从图像中找到一个实例，输出类别得分和四个框参数。BBox 能描述目标的整体范围，但不能精确表示瓶身边界。

输出：类别 + (x₁,y₁,x₂,y₂)
主要约束：框的位置要准确；需要考虑多个候选的筛选。

4.1 · Mask 需要怎样的表示？

一种常见方式是先输出像素级 logits，再对每个像素做 Sigmoid 得到前景分数。但实例分割还需要区分不同实例：同一类别的两只瓶子不能只得到一张混合的语义前景图。

4.2 · 关键点怎样得到精确坐标？

两种常见思路：直接回归 (x,y)，或输出每个关键点的 Heatmap（位置响应图），再选择峰值或使用连续坐标解码。两者各有分辨率、计算量与训练难度取舍。

留到后面：目标检测篇专门研究 Anchor、NMS、IoU 与检测框回归；实例分割篇研究 Mask R-CNN、Prototype Mask；关键点篇研究 Heatmap、直接回归及坐标精度。
05 HOW PREDICTIONS LEARN

Head 为什么能学会这些不同的输出？

因为训练时存在与输出对应的标注和损失。对一个检测模型，类别标注告诉分类分支“它是什么”，框标注告诉回归分支“边界在哪里”。反向传播会把这些监督信号共同传给共享特征与预测头。

多任务训练 · 只表达损失组合关系
Ltotal = λclsLcls + λboxLbox + λauxLaux
Lcls：分类损失；Lbox：位置回归损失；Laux：可选的额外任务损失；λ 是损失权重。并非每个模型都恰好使用这些项。
机制图 · 同一份视觉特征，怎样同时收到不同监督？
这里展示的是监督关系，实际反向传播沿前向依赖方向的反向进行。正负样本分配等属于具体检测器设计。

损失怎么求导、优化器怎么改参数，已经在前面的 02 和 03 学过，这里不重复。你需要理解的是：不同输出对应不同监督，因而会推动共享网络学习不同的信息。

06 DECODE & POSTPROCESS

为什么网络输出了坐标，还不能直接给机器人？

很多模型对输入图像做缩放、裁切或 Letterbox（等比例缩放 + 填充）。因此，Head 解码得到的坐标可能属于预处理后的模型输入图像，而不是相机原始图像。

等比例缩放 + 左上填充时，恢复到原图坐标的简化关系
xorig = xnet−pxα， yorig = ynet−pyα
α 是等比例缩放比例；px、py 是输入图像中的实际左、上填充。最后还应根据原图尺寸裁剪合法范围。若采用非等比例缩放、裁切或其他变换，需要对应的逆变换。
处理步骤为什么需要常见误区
坐标解码把网格参数或相对偏移还原为坐标把特征图坐标直接当像素坐标
筛选 / NMS 等过滤低分候选或重复预测以为所有检测器都必须用 NMS
逆预处理从模型输入坐标恢复原始图像坐标忘记 Letterbox 的填充
结果检查核对可见区域、边界与任务约束高分候选就一定是正确目标
对后续机器人几何的影响：深度对齐、相机内参、二维抓取点需要明确是基于哪张图像和哪个坐标系。一个 BBox 即使视觉上正确，使用错了坐标尺度，也会导致空间定位错误。
07 MINIMUM CHECK & NEXT

学到什么程度，就可以进入目标检测？

必须理解Head 的职责

能说明一份特征怎样被映射成分类分数和位置参数。

必须理解坐标从哪里来

给出特征图尺寸与 Stride，能计算网格中心并解码简化 BBox。

必须理解不同输出要求

知道 BBox、Mask、Keypoints 的信息范围和监督差异。

知道边界即可具体算法实现

Anchor、分布回归、RoI、特定 Head 的内部结构留给专题。

到这里，深度视觉的最小模型已经完整：
图像 → Backbone / 多尺度特征 → Head → 类别或位置预测 → 解码与后处理。
下一站研究的就不再是“Head 是什么”，而是“目标检测器怎样设计候选、训练并筛选目标”。
