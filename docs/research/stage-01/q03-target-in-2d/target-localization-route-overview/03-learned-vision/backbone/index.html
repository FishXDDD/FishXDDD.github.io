视觉网络结构演进史

Visual Representation & Backbone Evolution · 1998—2023+

今天再看 LeNet，会觉得它只是几层简单卷积；再看 VGG，会觉得它只是不断堆叠；再看 Inception，甚至会怀疑为什么要设计那么多分支。但如果回到模型提出的那个年代，许多设计才真正显出精妙。

这不是一张“谁比谁先进”的榜单，而是一份关于研究者为什么改网络、具体改了哪里、改变为什么有效的学习笔记。从 DenseNet 开始，逐个拆解整网层级、每个核心 Block 的真实计算顺序、张量尺寸、公式与历史突破；遇到陌生结构不再只看一张概念草图。

先学会怎样读一张网络结构图

Reading a Network · before the timeline

接下来我们不从今天的结论出发评判过去。每到一个年代，先暂时忘记后来出现的技术：当时能做到什么？为什么原有网络不够用？研究者具体修改了哪条计算路径？ 只有站在这个位置，才能理解设计的精妙。

看完整网络：Stage 与张量

把输入写成 H×W×C：H/W 是空间尺寸，C 是通道数。网络通常通过下采样减小 H/W，通过增加通道数扩展特征表达。Stage 是一组分辨率相近、反复堆叠相同模块的网络层。

看核心模块：改变了什么

一个模型的突破可能在于 算子（普通卷积→深度卷积）、连接（串行→残差或密集连接）、信息范围（局部→全局）或 规模组织（深度、宽度、分辨率如何配合）。

LeNet-5｜卷积网络为什么适合图像？

LeCun et al. · local receptive fields, weight sharing, subsampling
站在当年 · 当时已知

在早期文档识别中，人们已经知道可以训练分类器，但直接把整幅图像展平成全连接输入会丢掉局部结构，也需要大量参数。手工设计特征与识别模块之间仍有明显的工程边界。

当时真正的问题

能否利用图像“邻近像素相关、局部形状重复出现”的规律，把特征提取和识别一起训练？

LeNet-5 的价值不是第一次让网络“变深”，而是给出了一个针对图像几何结构的网络组织方式：局部连接、空间共享卷积核、逐层下采样，最后将局部特征组合为类别判断。这一框架在当时就已经可以端到端训练。

为什么这是“结构思想”，而不只是一个小网络？
局部连接

一条边缘或一个拐角只依赖附近像素；卷积核不用直接连接到整幅图像，先提取局部模式。

权重共享

同一卷积核在不同位置扫描：识别一种模式不必为每个位置学习不同参数。这既降低参数量，也带来平移等变性——输入平移时，特征响应会相应平移。

子采样

压缩空间分辨率，降低计算和对微小位移的敏感性，但也会损失精确位置信息；“不变性”不是卷积本身自动保证的。

Y(i,j,o)=Σu,v,c K(u,v,c,o)·X(i+u,j+v,c)
同一组 K 在每个位置复用；K 是可学习的局部滤波器，o 是输出通道。
站在 1998 年：这已是很完整的可训练视觉系统，而不是“还没出现现代 ResNet 所以很简单”。真正令人惊讶的是：图像的空间先验被写进了网络连接方式。

02

AlexNet｜为什么深度 CNN 突然可以大规模成功？

Krizhevsky · Sutskever · Hinton · ImageNet 2012
站在当年 · 当时已知

卷积、池化和反向传播已知多年，但大规模自然图像比手写字符复杂得多；传统视觉特征与浅层方法仍有强竞争力。训练更大的 CNN 还面临数据、算力和过拟合限制。

当时真正的问题

能否把卷积网络训练到足以处理 ImageNet 级别的真实世界图像？

AlexNet 并非发明了卷积层。它把更大的 CNN、ReLU、GPU、高容量数据集、数据增强与 Dropout组织成了一次可行的系统性突破。站在 2012 年，这证明了学出来的分层特征能够大幅改变大规模图像分类的竞争格局。

网络结构上，发生了什么？

前层使用较大卷积核与较大步幅快速压缩高分辨率输入，后层使用 3×3 卷积提取复杂组合；ReLU 减少饱和非线性带来的训练困难；部分层之间使用重叠 MaxPool。

哪些进步不属于新结构？

GPU 训练让大模型成为现实；数据增强、Dropout 抑制过拟合。模型性能来自结构、数据与训练条件的共同作用，不能归因于某个单独模块。

相比 LeNet，保留了什么？

卷积 → 非线性 → 下采样 → 多层特征组合的基本框架。

改变了什么？

特征规模、训练方式与硬件约束，证明 CNN 可以在大数据集上占据优势；但巨大的全连接部分和计算需求很昂贵。

历史意义：不是“现代网络比它好多少”，而是 2012 年之后，研究中心开始从手工视觉特征大规模转向可学习网络的结构设计。

VGG｜结构可以简单到只靠小卷积核堆叠吗？

Simonyan & Zisserman · depth as a design variable
站在当年 · 当时已知

AlexNet 已显示 CNN 很强，但它的卷积核尺寸与层级配置不够统一。研究者还不能明确回答：精度提升究竟来自复杂的特殊设计，还是来自网络深度本身？

当时真正的问题

能否采用极其规整的 3×3 模块，系统研究“增加深度”到底带来什么？

VGG 的高明处在于有意识地简化结构变量：把几乎所有空间卷积统一为 3×3、stride 1、合适的 padding，按阶段增加通道，并在阶段末下采样。如此才能清楚观察层数从浅到深带来的变化。

GoogLeNet / Inception｜只能沿一条路径越堆越深吗？

Szegedy et al. · multi-branch computation and 1×1 reduction
站在当年 · 当时已知

同一时期，VGG 展示了串行堆叠小卷积的价值，但深度和宽度增加都会消耗计算资源。目标中的局部图案还具有不同大小，固定一种卷积尺度未必理想。

当时真正的问题

能否在有限计算预算内，同时增加网络表达的多样性与深度？

Inception 不是简单地“用了好几种卷积核”。它把一个单链路模块改成多个并行分支，让网络在同一层得到不同的特征处理结果，再沿通道维度拼接。更微妙的是，通过先用 1×1 卷积压缩通道，控制更大卷积核的成本。

Inception v1 模块：四种并行计算路径（逻辑示意）
共同输入 X：H × W × C
↓ 分到四个并行分支 ↓
分支 A1×1 Conv通道投影
分支 B1×1 降维3×3 Conv
分支 C1×1 降维5×5 Conv
分支 D3×3 MaxPool1×1 投影
↓ concat(·, channel) ↓

不同分支必须对齐 H/W；拼接增加通道维，和 ResNet 的逐元素相加不是一回事。
1×1 卷积为什么不是“毫无空间感受野”？

它确实不跨邻近像素，但可以在每个位置混合不同通道的信息。如果把输入从 192 通道先压到 16 通道，再用 5×5 卷积生成 32 通道，空间卷积所处理的通道数就大幅减少。

直接 5×5：25×192×32 = 153,600
先降维再 5×5：192×16 + 25×16×32 = 15,872
以上是一个位置的权重数量示例，并非某个原始 Inception 模块的指定配置；本例降至约 1/9.7。

VGG 的回答

把基本算子统一，研究深度与层级表达：一条规整的主干路径。

Inception 的回答

把不同尺度的操作并联，并精细分配通道与算力：一层内部存在多条路径。

站在 2014 年：两条路线并不冲突。VGG 研究“简单深层结构能走多远”，Inception 研究“计算资源能不能用得更聪明”。GoogLeNet 还尝试用全局平均池化减小昂贵的 FC 部分，并设置辅助分类器帮助训练。

ResNet｜为什么再深一点反而更难训练？

He et al. · optimization, residual mapping and identity paths
站在当年 · 当时已知

VGG 的研究让“深度”成为重要变量，但研究者发现：把普通网络从 18 层加深到 34 层，训练误差反而可能升高。这不仅仅是测试集过拟合，而是训练优化本身出了困难。

当时真正的问题

更深的网络理论上至少可以学到与较浅网络相当的映射，为什么实际训练却不能轻松做到？

ResNet 不再只是调卷积核和层数，而是直接改写了层与层之间如何连接。研究者令一组卷积学习残差 F(x)，并让输入 x 通过另一条恒等路径直接参与输出。

DenseNet｜为什么每一层要看到此前所有特征？

Densely Connected Convolutional Networks · feature reuse · concatenation
回到当年 · 已知的能力与困难

ResNet 已经通过 Shortcut 缩短了信息和梯度传播路径，深层网络的优化条件明显改善。但相加操作将旧特征与新残差融合成一个张量；如果早期某个特征在后续仍然有用，后续网络能否更直接地访问它？

那个年代真正值得提出的问题

能不能让后面的每一层直接使用前面已经学到的特征，而不是不断重新生成相似特征？

DenseNet 的关键不是“再加更多 Skip Connection”，而是改变保存和传递特征的方式：每一层只产生少量新特征，然后与全部旧特征沿通道维拼接，供之后的层使用。

01 · 从一个数字例子开始：Add 和 Concat 完全不同

ResNet · 相加56×56×64 + 56×56×64
→ 56×56×64

64 个位置对应的通道逐元素相加。两路信息在结果中融合，并不自动保留为两组独立通道。

DenseNet · 拼接[56×56×64 , 56×56×32]
→ 56×56×96

空间位置对齐，在通道轴上接起来：原来 64 通道仍在，新增 32 通道排在后面。没有做加法。

xℓ = Hℓ([x0, x1, …, xℓ-1])
[·] 表示通道拼接；Hℓ 是第 ℓ 层的卷积变换。注意：等式右边的 Hℓ 只产生本层新的 k 个通道，下一层输入才把这些新特征和旧特征一起拼接。

02 · 展开真正的 Dense Layer：它不是“Concat 后随便卷一下”

DenseNet-BC 中的一个 Dense Layer · k=32
输入全部旧特征56×56×C
↓
BatchNorm → ReLU → 1×1 ConvC → 4k = 128 通道；Bottleneck
↓
BatchNorm → ReLU → 3×3 Conv128 → k = 32 通道；仅产生 32 个新特征
↓
在通道维 Concat旧 C + 新 32 → C+32；送给下一层
真正的数据流：前三层的每次输入
初始输入x₀ · 64
Layer 1 输入 64 → 输出 32x₀ · 64x₁ · 32
Layer 2 输入 96 → 输出 32x₀ · 64x₁ · 32x₂ · 32
Layer 3 输入 128 → 输出 32x₀ · 64x₁ · 32x₂ · 32x₃ · 32

色块表示通道段，不表示实际激活数值。每个新 Layer 都从全部既有段中提取新信息；这些段在同一 H×W 上拼接。

必须理解：第 3 层不是“只接收第 2 层输出的 32 通道”，它收到 x₀ 的 64 + x₁ 的 32 + x₂ 的 32 = 128 通道。但第 3 层自身仍然只新生成 k=32 通道。growth rate（增长率）说的是“每层新增多少”，不是“每层总宽度是多少”。

03 · 从 Dense Layer 到 Dense Block，再到整张 DenseNet-121

如果无限拼接，通道数会不断增长。因此 DenseNet 只在同一分辨率的 Dense Block 内部做密集连接；两个 Block 之间插入 Transition Layer，用 1×1 卷积压缩通道，再用 2×2 AvgPool 减半分辨率。以论文常见的 DenseNet-121 / DenseNet-BC 为例：k=32、瓶颈通道 4k=128、压缩率 θ=0.5。

05 · 当时它到底证明了什么，又付出什么代价？

01
信息复用

早期边缘、纹理等特征的张量能直接提供给后层，后层有机会选择是否使用，而不是只能从上一层混合后的表示中间接恢复。

02
梯度路径

04 · 为什么叫 Linear Bottleneck？

01
问题：窄层里的 ReLU 有破坏信息的风险

例如一个窄表示经过 ReLU，负值会被截断；当通道数本来就少，强非线性可能导致有用的维度信息不可恢复。这是 V2 论文的直觉与实验结论，不是说“所有 ReLU 都有害”。

02
改法：复杂变换放在扩维空间

先扩张到 6 倍通道，随后在更宽的表示中执行 ReLU6 和 Depthwise Conv，使网络仍有非线性表达能力。

03
输出：投影回窄空间时不接 ReLU

最后用线性 1×1 Conv 压回较少通道，尽量减少窄瓶颈上的非线性信息损失。

04
Shortcut：连接两个窄端

当 stride=1 且输入输出形状完全相同，直接加回输入；若 stride=2 或通道变化，就不能按这个方式直接残差相加。

MobileNet 展示了 DW + PW 能大幅减少计算，但当计算预算特别低，很多 1×1 Pointwise Conv 仍占据显著开销。已有 Group Conv 可以减少 1×1 计算，可是分组太彻底会切断跨组信息交流。

02 · “Shuffle” 到底有没有可计算的规则？

不是随机噪声，也不是将通道值平均。一个典型的实现：先把 C 个通道 reshape 为 [groups, 每组通道数]，再转置两个维度，然后 flatten 回 C 个通道。这样得到确定的置换，通道数和值都不改变，只改变排列顺序。

reshape(C) → (g, C/g) → transpose → flatten(C)
例如 g=2, C=4：[A,B,C,D] → [[A,B],[C,D]] → [[A,C],[B,D]] → [A,C,B,D]。

SENet｜卷积知道哪些通道值得强调吗？

回到当年 · 已知的能力与困难

深度卷积不断把局部特征组合成更抽象的通道，但通常每个样本都用同一组卷积核处理通道。在一张图中与纹理相关的通道很重要，另一张图中可能更依赖形状线索。

那个年代真正值得提出的问题

SENet 的创新是一个可插入现有 CNN Block 的通道重标定模块，不是重新设计一整个卷积主干。它研究的是怎样从当前样本的全局信息出发，给不同通道生成不同的权重。

02 · 为什么不能误以为它是“空间注意力”？

SE 为每个通道产生一个权重，一个通道内部所有空间位置乘同一个权重：它没有直接对某个像素坐标生成单独的注意力。它确实利用整个 H×W 的信息判断通道重要性，但输出的权重长度是 C，不是 H×W。

03 · SE 在一整张网络里放哪里？

普通 ResNet Bottleneck

1×1 Conv → 3×3 Conv → 1×1 Conv → Add；原残差分支没有显式的通道重标定。

SE-ResNet Bottleneck

同样先完成卷积分支，再在残差加法之前对分支输出进行 SE 通道缩放，之后与 Shortcut 相加。整网仍沿用 ResNet 的 Stage 结构。

01

03 · 复合缩放：同样增加资源，为什么要三个维度一起变？

depth = αφ；　width = βφ；　resolution = γφ
约束：α·β²·γ² ≈ 2，且 α,β,γ ≥ 1
φ 是整体模型预算/规模系数；α、β、γ 是通过小范围搜索确定的缩放比例。粗略地说卷积计算量对 width、resolution 多为二次关系，所以近似使用 β²、γ²。
只加深 depth

每个 Stage 多重复几次 Block；空间分辨率与通道不变。获得更深的组合，但高分辨率细节或宽度可能仍是瓶颈。

只加宽 width

提高每层通道数，让中间表示更宽；但卷积参数和 MAC 常对通道数增长很敏感。

只提高 resolution

输入保留更多空间细节；但特征图面积变大，层层计算成本随之增加。

Compound Scaling

协调三者的增长而非只押注其中一个，形成一整套不同预算下的网络家族。这是架构规模组织的突破。

03 · 一次具体计算：为什么注意力可以关联远处 Patch？

01
Query：比如图像左上角的一个 Patch

它的 Q 向量不直接等于像素，而是由当前 Token 经学习到的线性层得到，代表该 Token 这一次寻找的关联信息。

02
Key：对所有 Token 打分

Q 与其他 Token 的 K 做点积，形成与所有 Patch（以及 CLS）相关的分数；同一个 Head 中 197 个 Query 生成一张 197×197 的分数矩阵。

03
Value：按权重汇总特征

Softmax 后每一行成为权重分布，当前 Token 可以从右下角的 Patch 中汇集信息，不需要中间经过很多层局部卷积传递。

04
多个 Head 并行学习不同关系

12 个 Head 不代表 12 次完全相同的结果；它们有不同的投影参数，允许模型学习不同关系。最终拼接并映射回 D=768。

04 · 为什么 Window 不够，还要 Shift？

假设图像被固定划成互不重叠的窗口 A、B、C、D。在 W-MSA 中，A 内 Token 只和 A 内 Token 直接交互。如果每一层都保持同一窗口边界，窗口 A 与 B 的信息长期被隔开。下一层把划分边界移动几个 Token 后，原本分属 A、B 的 Token 就有机会处在同一个窗口，信息经过堆叠逐渐传播到其他区域。

05 · 把计算开销算清楚

全局 Attention 分数元素：N²
窗口 Attention 分数元素：约 N·M²
N=整幅特征图的 Token 总数，M=窗口边长（例如7），窗口里有 M²=49 个 Token。因此固定窗口时，分数计算随 N 近似线性增长，而不是全局的 N²。这里仅比较 Attention 的 N 相关部分，不是整个网络成本。

以 56×56=3136 个 Token，M=7 为例：全局单 Head 需要 3136²=9,834,496 个注意力分数；按 64 个窗口分别算，每个窗口 49² 个分数，共 153,664 个元素。它不是 64 倍的总模型加速：QKV、MLP、访存、Shift 和其他 Stage 还要计算。

04 · 7×7 很大，为什么计算反而能控制？

大卷积核是否昂贵，要先看普通卷积还是 Depthwise。在输入输出通道都为 C 的情况下，普通 7×7 参数量约是 49C²，而 Depthwise 7×7 只有 49C；但 ConvNeXt 还有 Pointwise 扩维和压缩，所以不能直接把 49C 当成整个 Block 的成本。

普通 7×7：49C²；　Depthwise 7×7：49C；　Pointwise 主要部分：约 8C²
在不计偏置和归一化、扩维倍率为4的简化 Block 中，两层 Pointwise 分别是 C→4C 与 4C→C，合起来约 8C² 个权重。说明 ConvNeXt 不只是把“大卷积核变便宜”，而是在空间/通道间重新分配计算。

05 · 最后：这为什么是历史中的一次重要反思？

如果把 ConvNeXt 简单理解成“CNN 又赢了”，仍然是站在未来结果对历史下判断。研究本身更有价值：研究者控制架构与训练变量，逐个现代化传统 CNN，发现很多改进不是 Attention 独有的。这推动了更细致地比较算子、连接方式、特征层级与训练范式。
