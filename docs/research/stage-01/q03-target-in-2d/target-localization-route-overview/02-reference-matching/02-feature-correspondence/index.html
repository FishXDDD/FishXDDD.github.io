DEEP DIVE · 02 / FEATURE CORRESPONDENCE

局部特征与视觉对应

Feature Correspondence · 从局部相似到目标位置

上篇尝试直接比较整块图像。但如果相机换了角度，盒子在画面里发生旋转、缩放甚至透视变化，整块图像逐像素比较往往就不合适了。

假设盒子表面有几个容易辨认的局部图案，我们能不能在参考照片和当前画面里分别找到它们，再根据这些局部位置的对应，确定整个盒子在哪里？

这一篇重点研究：怎样比较局部特征、怎样排除模糊匹配，以及怎样利用对应点估计目标的二维位置。

输入：两图关键点 + 描述子核心：L2 / Hamming · Ratio输出：匹配点对 + 目标投影区域
00 DEFINE THE TASK

先明确：这一篇研究的不是怎样提取特征

我们假定参考图像与当前图像都已经提取出关键点及其描述子。接下来的任务是寻找哪些关键点代表同一个局部位置，并利用这些对应关系确定目标所在的区域。

INPUT
两组关键点 + 描述子

参考图 A 的点与特征，当前图 B 的点与特征。

CORE
相似性 → 对应关系

比较描述子、筛选候选对应，再确定所需的二维变换。

OUTPUT
匹配点对 + 目标位置

对应关系，以及在模型适用时得到的目标投影区域。

研究边界：Harris、FAST、SIFT、ORB 的检测和描述原理，在前面的「图像特征与结构提取」中研究；这里不重复。几何离群点剔除、RANSAC 和重投影误差留给下一篇《几何验证与可靠性判断》。
已提取的特征→描述子匹配→筛选歧义→估计几何关系→定位目标

这是常见的基于局部特征的定位流程，不代表参考匹配只能采用这一种路线。

01 DESCRIPTOR MATCHING

两张图里，怎样判断两个局部特征是否相似？

关键点只有一个二维坐标，例如 (120, 80)。坐标不同并不能说明不是同一个局部，因为目标可能在图像中移动。真正用于比较的通常是关键点周围计算出的描述子（Descriptor）。

1.1 · 描述子距离：把“长得像”变成数值

描述子是局部图像信息的数值表达。匹配时，把参考关键点的描述子与当前图像中的描述子比较，距离越小，通常表示它们越相似。

L2 DISTANCE · 浮点描述子的欧氏距离
dL2(a,b) = √[ Σi (ai − bi)2 ]
HAMMING DISTANCE · 二进制描述子的汉明距离
dH(a,b) = popcount(a XOR b)
a、b 是两个描述子；L2 累计各维数值差，常用于 SIFT 等浮点描述子；Hamming 统计不同的比特数量，常用于 ORB 等二进制描述子。两种距离不能拿原始数值互相比大小。
机制图｜同一个“相似”，对不同描述子的计算方式不同
这里只演示距离怎样计算；真实描述子通常有更多维度。距离小仅表示局部描述相似，不自动证明来自同一物体。

1.2 · 怎样从大量描述子中找到最近的？

已知参考描述子 a，把它与当前图像中的描述子 b₁, b₂, … 比较，再选择最近的候选。这一任务叫最近邻搜索。

BFMatcher · 暴力匹配

逐个比较候选描述子，找距离最小的一项。概念直接，数据量大时比较次数也多。

FLANN · 近邻检索

利用索引结构加速搜索；索引方法需要与描述子类型匹配，例如浮点向量与二进制描述子的配置不同。

需要区分：BF / FLANN 负责怎么找最近邻；L2 / Hamming 负责怎么量距离。它们不是四种互斥的匹配技术。

02 AMBIGUOUS CORRESPONDENCE

找到了最近邻，为什么还不能直接相信它？

一张图像里可能有重复的标签、规则纹理，甚至两个几乎一样的零件。参考特征无论有没有真正对应，总能在候选里找到一个“最近的”。问题是：这个第一名是否明显优于其他候选？

2.1 · Lowe Ratio Test：检查第一名是否足够突出

NEAREST-NEIGHBOR DISTANCE RATIO
r = d1 / d2，若 r < τ 则通过比值筛选
d₁、d₂ 分别是最近和次近候选的描述子距离（d₁ ≤ d₂）。r 较小，说明第一名比第二名明显更近；r 接近 1，说明两者难分。τ 是人为选定的阈值，不是目标存在的概率。
交互理解 · 第一名相似，为什么有时仍要拒绝？用真实 L2 距离计算的简化例子
候选 1
0.20
场景使用三维玩具描述子，例如参考 a = [1,2,3]，距离由欧氏公式实时计算。真实特征维数更高，判断机制相同。

举个固定例子：如果第一名距离为 20、第二名为 80，比例为 0.25，通常比较明确；如果是 20 和 22，比例约 0.91，虽然第一名仍最接近，但对应关系很模糊。

2.2 · Cross-check：两边都认为对方是最近邻吗？

从参考图 A 找最近邻得到 B，还可以反向检查：从当前图 B 找最近邻，得到的是否仍然是 A？如果双向都成立，叫相互最近邻。它可以减少一部分单向错配，但仍不能保证几何正确。

机制图｜单向最近邻与互相最近邻的区别
很重要的区分：Ratio Test 衡量的是最近邻是否明显优于次近邻；Cross-check 检查的是对应是否互相一致。两者是不同的筛选思路，不是必须按顺序执行的两个阶段；通过之后仍可能是错误匹配。
03 FROM MATCHES TO LOCATION

匹配点只有几个，怎样知道整个目标在哪里？

现在我们得到若干对应点对：参考图中的 pᵢ 和当前图中的 pᵢ′。但它们只是零散位置，而我们希望得到整个盒子的中心、边界或四角。这里需要一个几何变换模型，把参考图中的位置映射到当前图。

3.1 · 先分清：不同变换能描述怎样的变化？

变换可以描述的变化不能随意描述的变化
Translation · 平移整体向左、右、上、下移动旋转、缩放、剪切
Similarity · 相似平移 + 旋转 + 统一缩放一般剪切、透视变化
Affine · 仿射平移、旋转、非均匀缩放、剪切一般透视收缩
Homography · 单应平面物体在透视成像下的二维投影关系任意非平面物体的统一投影变换

3.2 · Homography：为什么四个对应点能帮助定位平面目标？

对近似平面的目标，参考图与当前图上的平面点可以通过一个 3×3 的单应矩阵 H 联系：

HOMOGRAPHY · 参考平面到当前图像的点映射
λ [u′, v′, 1]T = H [u, v, 1]T
(u,v) 是参考图位置；(u′,v′) 是当前图对应位置；H 为 3×3 矩阵；λ 表示齐次坐标的尺度因子。H 做的是点坐标映射，不是目标分类。

单应矩阵在忽略整体尺度后有 8 个自由度。理想情况下需要至少 4 组位置合适、且不退化的点对应才能估计 H。若点几乎共线、匹配错误，或者目标并非平面，就可能估计错误或不适用。

机制图｜先由局部对应估计 H，再映射参考目标四角
示意图：为了突出机制只画出三条对应线；实际估计非退化的平面单应至少需要四组点对应。橙色四边形表示四角映射的结果。

因此，即使匹配点不在目标四角，我们也可以在估计出可靠 H 后，把参考图事先标好的四个角映射到当前图，得到目标的投影四边形，进一步计算 BBox 或中心。

这里的关键假设：参考与当前图中的匹配点，需要对应同一个近似平面（或满足其他单应适用的成像条件）。对立体盒子的多个不同表面，不能默认使用同一个平面 H 精确映射全部结构。
04 WHEN MATCHING FAILS

特征有很多，为什么仍可能定位错？

描述子相似只说明局部数值接近，不能保证这些点在整个目标上处于合理的位置。想象一个包装盒反复印着相同图案：每个图案都很像，但连线可能彼此冲突。

问题会发生什么需要进一步检查什么
重复纹理许多点具有相似描述子Ratio Test、互相最近邻、空间一致性
纹理太少找不到足够可区分的关键点是否需要换成模板、轮廓或其他信息
遮挡、模糊、极端视角可重复识别的点减少或描述子改变候选数量与匹配的可靠程度
错误对应混入拟合出的几何变换发生偏移几何内点、重投影误差、模型适用性
非平面物体单个 H 无法统一映射各个表面是否只定位某个平面区域

这就引出一个还没完全解决的问题：即使不少描述子彼此相似，这批匹配是否真的能被同一个几何模型解释？

下一篇《03 · 几何验证与可靠性判断》专门解决这个问题：用 RANSAC、内点比例与重投影误差检查对应点，判断是否应当接受定位结果。本篇只明确为什么需要它们，不重复推导。
05 QUICK REFERENCE

回头看看：这些方法各自负责哪一件事？

我遇到的问题优先想到的工具它真正负责什么
两个局部特征像不像？L2 / Hamming把描述子的差异变成距离
候选点太多，找最近邻很慢？BF / FLANN搜索最近邻
第一名与第二名都很像？Ratio Test排除缺乏区分度的对应
A 选 B，但 B 并不选 A？Cross-check检查双向对应是否一致
怎样从几个点找到整个平面目标？Affine / Homography估计并应用几何映射
大量匹配点里混有错配？RANSAC（下一篇）利用几何一致性筛除离群对应
这一篇最需要记住：描述子距离负责找外观上可能对应的点；Ratio / Cross-check 减少歧义；变换模型负责把这些点变成目标的位置。但要相信这个位置，还需要几何验证。
