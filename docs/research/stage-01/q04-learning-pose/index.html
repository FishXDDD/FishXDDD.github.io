00这次换一个想法

几何有了，参考也有了。
为什么还是会想让模型来学？

前面一路研究下来，似乎已经有了不少办法。

有目标点云，可以尝试从几何中构造抓取姿态；有已知参考，可以通过对应关系和匹配恢复 Object Pose；而相机观测，也终于知道该怎样获取和判断是否可靠。

但慢慢发现，这些方法都有一个共同的难处：很多关键关系，需要事先能够明确描述，或者在当前观测中可靠地找出来。

规则盒体还算友好，可以利用尺寸、表面和方向约束。可一旦物体形状变得复杂、局部被遮挡，或者原本依赖的几何特征不再明显，手工建立这些关系就可能越来越困难。

那有没有另一种思路？既然人很难为每种情况都写出可靠的规则，能不能让模型从数据中学习观测与姿态之间的关系？

最开始想到的是让模型寻找关键点、对应关系，再交给熟悉的几何方法求解。但继续往下想，模型能不能直接预测 Object Pose？如果最终需要的是事先约定的抓取姿态，是否又有机会直接得到 Grasp Pose？

这一篇想弄清楚
哪些关系值得交给网络学习，哪些约束仍然需要保留，以及我们究竟用什么代价换来了这种能力。
研究边界：抓法已约定，研究固定约束下的 Pose 求解；多抓法候选生成、评分、选择留在后续 Stage，不在这里展开。
01研究之后，回头整理的结论

模型究竟替我们学了哪一部分？

学习式 Pose 求解，并不意味着抛开几何、让网络凭空猜姿态。更值得区分的是：求解时依赖什么参考，网络学习什么，以及最终要输出什么。

泛化条件 ≠ 求解机制
Object Pose → 约定抓取关系 → Grasp Pose或在抓法已有明确约束时，直接学习约定的 Grasp Pose

一套系统可以同时使用学习式对应、几何求解、姿态评分和局部精化。直接回归、参考匹配与类别规范坐标也不是单线的新旧替代。

最后，代价并没有消失。规则与匹配可以少写一些，但模型依赖的训练数据、物体参考、坐标系定义、跨物体泛化，以及预测结果的验证，都必须重新交代清楚。

技术地图先摆在这里。接下来还是从最朴素的困难开始：只看见一份不完整的目标几何时，原来的手工规则究竟卡在哪里？
02第一性探索 · 问题从哪里长出来的

先看前面付出了什么代价，
再看学习到底减少了什么。

这四段是我理解问题的一条路径，不是算法发展的唯一时间线，更不是四个必须依次执行的模块。第一段重新审视 Q01，第二、三段重新审视 Q02，最后回到 Stage 01 真正需要的抓取姿态。

当前几何→已知参考→跨实例复用→约定抓取
01重新看待 Q01

只靠当前观测，能不能让模型学到更多几何规律？

前面研究点云几何时，我已经有了一些相当直接的办法。规则盒体可以估计表面、方向与尺寸；圆柱可以尝试估计轴线和半径。只要结构够明确，再加上事先规定好的抓法，就有机会构造 Grasp Pose。

这些方法的优点也很明确：依赖什么几何关系，最后怎样得到坐标变换，基本都是看得见的。

可当物体形状不规则、相机只看到局部，或者某个主轴根本不稳定时，原先依赖的结构约束就可能不成立。要继续求解，我得不断针对目标增加新的形状假设和例外规则。

于是才会想：如果我能收集大量同类物体的图像、点云及姿态数据，模型能不能学会一些无法简单写成“拟合圆柱”“计算主轴”的规律？

一种尝试是直接让网络预测姿态。但很快就遇到一个基础问题：要回归的是哪个坐标系的旋转和平移？ 如果物体没有明确定义的参考坐标系，数字上的 Pose 标签本身就可能没有一致含义。对称物体甚至可能存在多个同样合理的姿态标签。

再继续研究，会遇到 NOCS 这样的思路：为一个物体类别定义共享的规范坐标空间，让模型学习观测与这个规范表示之间的对应，再利用深度恢复姿态与尺寸。它没有要求新实例必须有完整 CAD，却也不是凭空推断任意物体。

原来，所谓“没有实例参考”，仍可能依赖类别层面的几何先验。之前需要人工明确规定的部分形状规律，现在转移进了训练样本和规范坐标定义里。

原来的代价针对不同形状手工写规则，观测缺失时难以构造稳定约束。
试图减少让模型学习类别结构、特征或姿态映射，减少逐类手工几何设计。
新的代价需要可靠标签与坐标定义；未知类别、形变或分布偏移下的泛化仍然有限。

这条路很有价值，但有个问题没有解决：如果物体本来就有 CAD，我真的还需要模型去学习它长什么样吗？

02重新看待 Q02

物体模型都已经知道了，为什么求 Pose 还是这么麻烦？

回到已知参考这条路，困难其实变了。

我可能早就知道物体尺寸，甚至有完整 CAD。只要知道模型上的点在图像中对应哪里，就可以通过 PnP 求解；如果已经有足够接近的初始变换，还能用 ICP 等方法调整。

但知道模型本身，并不等于知道当前观测对应模型的哪个位置。 纹理不足、遮挡、重复结构，都会让人工特征与对应点变得难找；几何匹配、模板搜索和姿态验证也需要付出计算与调参的代价。

那能不能保留清楚的三维参考，不再强求手工把每个对应关系都找出来，而是让网络学习“从图像哪里看出模型的某个位置”？

沿着这个问题，就能理解 PVNet 的代表性：它让可见像素预测指向预定义关键点的方向，经过投票恢复图像中的关键点位置，再借助 PnP 得到 Object Pose。部分关键点即使没有直接露出来，也可以由可见区域提供投票线索。

这并不是让神经网络取代 PnP。它减少的是寻找关键对应点的困难，而不是把几何求解这一环抹掉。

不过，关键点究竟设在哪里、网络训练的监督数据从哪里来，仍然需要解决。很多方法需要训练时就知道目标实例或其模型。它能帮助特定目标建立更稳健的对应，却未必能直接处理随手换上的新物体。

原来的代价人工特征与对应建立困难，复杂场景下匹配搜索不稳定。
试图减少通过网络预测关键点或对应关系，把已有的几何求解器用起来。
新的代价关键点与标签需要定义，训练目标和实例依赖可能较强。

于是新的问题出现了：如果每换一个 CAD，都要再准备标签、采集数据或重新训练，是否又把代价换了个地方？

03从单个目标走向新实例

能不能让模型学会一种可以反复使用的参考匹配能力？

假设换来一个以前没训练过的物体。我能拿到它的 CAD，也能在当前图像中确定目标区域，可没有机会为它重新标注几千张图像并训练专属网络。

这时候再回头看传统参考匹配，会发现它有一个不该轻易丢掉的优点：只要提供了目标参考，方法原则上就不一定要求训练时见过这个实例。

那学习式系统能否继承这个特点？不让网络记住某只瓶子的姿态，而是学习一个更通用的问题：给定物体参考和当前观测，哪个姿态更像？如果偏了一点，该往哪里修？

MegaPose 给了一个很直观的入口：用 CAD 渲染假设姿态下的物体，与现场图像进行比较；网络学习粗姿态判断与修正。这让 Q02 中的“渲染—比较—精化”仍然存在，只是部分比较标准变成了可学习的。

继续研究就会遇到 FoundationPose。它可以在测试时接收未见过物体的 CAD，或者利用少量带位姿的参考图像建立物体表示；随后使用学习式姿态评分与精化求解。它研究的是如何把求解能力复用到新实例，而不是为每个新目标都重新训练一套网络。

到这里才看清楚，FoundationPose 不是因为“纯几何完全没用”才出现。它反而继承了 Q02 的核心思想：已知参考仍然很有价值，值得减少的是逐实例构造匹配器、准备专属训练数据的成本。

当然，提供 CAD 或参考图像本身也是代价。还要考虑目标 Mask、尺度、姿态假设数量、渲染与推理开销，以及对称和遮挡所带来的不可观测性。这里的“model-free”也不等于毫无参考地从一张未知物体照片恢复任意 6D Pose。

原来的代价逐实例设计匹配规则，或每个新物体重新训练专属 Pose 模型。
试图减少用大量物体上的学习经验，复用参考比较、姿态评分与精化能力。
新的代价仍依赖 CAD 或参考图像、目标定位和训练分布，推理与搜索也有开销。
这里还要分清两种“没见过”：类别级方法利用同类物体共享的结构；新实例的参考条件求解则允许提供该实例自己的模型或参考图像。二者的先验并不相同。

04回到真正要输出的抓取位姿

我最终想要 Grasp Pose，为什么必须先恢复 Object Pose？

到这里，前面讨论的大部分方法都在恢复物体坐标系相对于相机的姿态。对已知实例和明确抓法来说，这条路很干净：只要事先定义好物体到抓取坐标系的关系，就能把 Object Pose 转换为 Grasp Pose。

CTG = CTO · OTG
示意记号：左侧表示相机下的抓取坐标系；实际部署还需要正确转换到机器人所需的工具 / 基座坐标系。

但有些情况下，我关心的可能只是一个已经约定的抓取关系。比如一类盒体，指定从某侧面接近、夹爪沿固定方向闭合。若这样的规则有一致的定义，能不能直接训练网络从观测预测目标 Grasp Pose？

这样就不必要求网络每次先给出所有 Object Pose 自由度。对于某些对称物体，完整 Object Pose 的多个等价解甚至未必影响那一次约定抓取。

不过，少了中间步骤，不等于少了约束。 训练标签里的夹爪坐标系、接近方向、抓取中心必须统一；预测结果还要检查几何接触、碰撞和执行条件。若任务原本允许大量不同抓法，而标签没有规定选择哪一种，模型反而可能无从学到稳定目标。

相反，如果 CAD 完整、Object Pose 可以稳定求出，而且对象与抓取关系定义得很好，保留 Object Pose 通常更容易解释、调整和验证。

原来的代价为了一个任务相关的抓取位姿，可能先恢复超出任务需要的完整物体坐标系。
试图减少让网络直接预测预先约定的抓取关系，省去不必要的中间表示。
新的代价必须保证抓法标签一致、任务边界明确，并验证接触与实际可执行性。
这里仍然是 Stage 01：抓法已经定好，我们只研究对应的 Grasp Pose 如何得到。 要让模型自行生成、比较、评分大量可能抓法，才是后面更一般的抓取研究。

03研究之后留下的判断

规则少写了，代价转移去了哪里？

如果只记住“网络能输出 Pose”，这篇其实和没研究过差不多。更有用的是清楚每条路线减少了哪部分负担，又把风险留在什么地方。

减少手工几何假设

需要类别先验、统一坐标系及足够覆盖变化的数据。跨类别与形变泛化仍要验证。

减少人工对应与匹配

参考与几何求解仍然有用；学到的关键点或匹配也有不确定性。

减少逐实例训练成本

使用新的 CAD 或参考图像复用求解器，但输入条件、推理计算与尺度一致性仍然重要。

研究路线依赖什么最该检查的代价
类别规律 / 直接回归统一 Pose 定义、类别样本或实例标签类别跨度、未知形状、标签歧义
学习对应 + 几何求解有身份的关键点、参考坐标与训练监督对应误差、遮挡、实例训练需求
参考条件下的泛化求解新物体 CAD 或参考图像、可定位的目标参考获取、搜索与精化成本、跨实例失效
直接预测约定 Grasp Pose确定的抓法、夹爪坐标系与一致标签标签多解、接触约束与可执行性验证

还有一种问题不随算法改变：实际观测不充分时，哪些姿态自由度根本不可观测？ 对称、遮挡、深度错误都可能影响传统方法和学习方法。网络给出一个数值，不代表它消除了这种不确定性。

BACK TO STAGE 01 · 回到这次抓取

不是要不要用神经网络，而是该让它负责哪一部分。

如果几何足够可靠，保持可解释的约束很有价值；如果匹配或类别规律难以手写，可以研究学习式表示；如果目标参考已知，又希望处理新实例，就考察通用参考匹配。最后，都要回到预先约定的 Grasp Pose 和能够验证的执行条件。
