Q02 · ROUTE 04 / LOCAL REGISTRATION

有了大致 Pose，怎样把它真正对准？

局部配准 · 对应关系 · 几何残差 · 鲁棒估计 · 可观测性

前面几条路线，已经能够从同名点、三维形状或二维投影中获得一个 Object Pose。但只要把模型投影回观测，就可能发现：方向似乎对了，边缘却仍有一点偏差。

如果初始位置已经足够接近，或许不必再次进行全局匹配。更直接的办法是：利用当前 Pose 建立局部对应，再根据这些对应修正 Pose。

不过，这看似简单的一步，藏着几个不同的问题：对应到底是不是正确的？误差应该怎样定义？优化收敛后，又凭什么相信六个自由度都已经对准？

这一次，不急着重新发现物体在哪里。先研究：已有的姿态，究竟怎样才能变得可信。
00 / 先划清边界

局部精化不是第四种“从零找 Pose”的方法

前面的 PnP 可以在已知 3D–2D 同名点时直接求解；三维特征匹配和视图模板可以提供粗初值；轮廓与渲染比较，有时也已经在内部进行了连续优化。因此，局部精化并不是所有方法后面必须执行的固定流程。

它更像一个新的研究问题：当姿态假设已经落在正确解附近，怎样利用观测残差继续减小误差？

观测证据常见局部精化方式
已知 3D–2D 对应最小化重投影误差，例如 LM
已知 3D–3D 对应Kabsch / Umeyama 一类刚体最小二乘（尺度已知时固定尺度）
两份点云，稠密对应未知ICP、Point-to-Plane、GICP
已知 CAD 与 RGB 图像轮廓、边缘、光度或特征残差优化

为了避免重复 Route 01 与 Route 03，这一节把深入探索放在三维点云局部配准上：源点云为已知参考模型，目标点云为当前观测。模型坐标系到相机坐标系的变换记作 T；我们的目标是进一步修正 camera_T_object。

01 / POINT-TO-POINT ICP

不知道点对应谁，那就先找最近的

Kabsch 已经告诉我们：如果两组三维点之间的对应关系明确，最佳刚体旋转和平移可以通过中心化、协方差和 SVD 直接求出。

但现在，模型和观测是两份独立采样的点云。我们并不知道模型上的第 23 个点对应观测中的哪一个点。

假如初始 Pose 已经让它们大致重合，最自然的猜想是：离得最近的点，或许就是当前最合理的对应。

FIG 01 · 待补插图
ICP 一次迭代：变换 → 最近邻 → 刚体拟合 → 更新
建议用同一组源点云与目标点云，画出初始偏差、最近邻连线、更新后的对齐；强调「对应关系会随着 Pose 改变」。

一次 ICP 迭代实际发生了什么？

  1. 用当前估计 Tk 把模型点变换到相机坐标系。
  2. 对每个变换后的模型点，在观测点云中寻找最近邻（常用 KD-tree）。
  3. 先把这些点对当作对应，使用刚体最小二乘计算使距离缩小的位姿更新。
  4. 得到新的 Tk+1，重新寻找对应，直到达到停止条件。
qi = NN(Tkpi),　　Tk+1 ≈ arg minT Σi ‖Tpi − qi‖²

pi 是模型点，qi 是当前迭代选出的观测对应点；在一次最小二乘求解期间，这些对应被暂时固定。下次迭代再更新。

这也解释了 ICP 为什么需要反复迭代：它不只是在求 R、t，还在反复修正“谁对应谁”这个假设。

它与 Kabsch 究竟是什么关系？

Point-to-Point ICP 的刚体变换更新，完全可以使用 Kabsch 那套中心化与 SVD。Kabsch 解决的是「对应已知，怎样最佳对齐」；ICP 用一个外层循环，把「对应未知」逐步变成可以反复求解的已知对应问题。

第一笔代价：最近邻不等于真实同名点。初值偏离太大、几何结构重复、可见区域不一致时，ICP 可能在错误对应上稳定收敛。经典点到点 ICP 的目标对当前对应关系可以下降，却不保证找到全局正确姿态。
02 / POINT-TO-PLANE ICP

两个表面已经贴合，为什么点还没有重合？

想象两个人分别在同一块桌面上撒了一把点。桌面完全一样，但每个人撒下的点的位置几乎不可能一一重合。

Point-to-Point ICP 仍试图缩短点与最近采样点之间的三维距离。可对一张平面而言，沿着桌面滑动一点点，并不代表模型离开了真实表面。

于是出现更贴近几何结构的约束：不要求模型点与某个观测采样点完全重合，只要求模型点落在观测点附近的切平面上。

FIG 02 · 待补插图
点到点距离 vs 沿法线方向的点到面距离
同一张倾斜平面，两套不同的离散采样。用斜线表示最近邻位移，用法线方向的短线表示 Point-to-Plane 残差。

对于观测点 qi 及其单位法线 ni，点到面的有符号残差是：

ri(T) = niT(Tpi − qi)

残差绝对值越小，意味着变换后的模型点越接近观测点所代表的局部切平面。把所有残差平方相加，就形成了新的优化目标。

Eplane(T) = Σi [niT(Tpi − qi)]²

工程上，先由观测点的局部邻域估计法线，再通过小角度旋转参数化及 Gauss–Newton / LM 一类方法更新刚体位姿。它往往比点到点残差更符合局部平滑表面的几何性质，局部收敛也经常更快。

但它也主动放弃了一些约束

对于理想无限平面，沿切平面的运动不会改变点到面距离；绕平面法线的旋转也缺乏约束。因此，Point-to-Plane 并不是「更高级所以一定更准」，而是选择了更适合表面贴合的残差，同时弱化了某些方向的信息。

法线本身也有代价：邻域太小容易受噪声影响，邻域太大可能抹平边缘、混合多个面。对于透明、破碎深度或过度稀疏的点云，法线可能完全不可靠。

03 / GENERALIZED ICP

同样一厘米的误差，在不同方向上真的一样吗？

Point-to-Point 把三维位移的每个方向都纳入距离；Point-to-Plane 主要关心法线方向。那么，能否不把误差固定理解为某一种形式，而是让每个局部表面告诉我们：它在哪些方向上更确定，在哪些方向上更不确定？

GICP（Generalized ICP）提供了一个代表性的答案：用局部点云的协方差描述表面结构，并依据源、目标两侧的局部几何共同定义配准误差。

从 PCA 看局部协方差

以某个点附近的邻域为例，求出邻域均值 μ 与协方差矩阵：

C = (1/N) Σj (xj − μ)(xj − μ)T

如果邻域近似一张平面，沿两个切向方向分布较宽，而法线方向的变化较小。协方差经特征分解后，就表现为两个较大的特征值和一个较小的特征值。

这里要特别小心：实际 GICP 并非直接把未经处理的样本协方差当作真实测量噪声。常见实现会对局部协方差进行规则化，例如限制法线方向特征值，使其能够稳定地反映表面几何。

FIG 03 · 待补插图
同一局部平面：两个较宽的切向方向 + 一个很窄的法向方向
建议标出局部点云、PCA 三轴、协方差椭球，并并列展示「切向错位」与「法向错位」的不同惩罚。

误差怎样利用这种方向差异？

令源点与目标对应点的残差为 ei = Tpi − qi。把两侧局部协方差变换到同一坐标系后，建立加权残差：

EGICP(T) = Σi eiT (Citarget + R Cisource RT)−1 ei

直觉上，若某个方向对应更小的允许变化，同样大小的偏差就会受到更大惩罚；若某方向具有较大的局部分布尺度，惩罚相对较弱。

这被称为 Mahalanobis 型距离。与只看欧氏距离不同，它把「偏离多远」变成了「沿什么方向偏离、多大偏离才值得在意」。

它能统一理解点到点与点到面的部分思想，但GICP 并不因此保证解决所有局部配准问题。局部协方差需要足够可靠的邻域，矩阵必须数值稳定，且当前对应依然可能错误。

到这里，三种 ICP 最本质的区别

方法残差在问什么？依赖什么？
Point-to-Point两个对应采样点有多远？最近邻对应、离散点位置
Point-to-Plane模型点偏离目标局部平面多远？局部法线与初值
GICP相对于双方局部几何分布，这个误差有多不合理？可靠邻域协方差与数值优化
04 / ROBUST REGISTRATION

如果对应关系是错的，优化得再认真也没有用

到目前为止，我们一直在改善「有了点对之后，怎样衡量残差」。可单视角 RGB-D 经常有个更根本的问题：模型包含不可见的背面，观测点云只覆盖正面；Mask 还可能夹带背景，深度边缘也可能出现无效点。

这时，对每个模型点都找最近邻，往往是在强迫本来不该对应的表面建立联系。

第一层：先拒绝明显不合理的对应

  • 距离阈值：对应点距离超过上限就舍弃；阈值要与初值精度、尺度和传感器误差匹配。
  • 法线一致性：两侧局部法线差异太大时，不轻易建立对应；需注意法线朝向约定。
  • 双向一致性：A 的最近邻是 B，且 B 的最近邻也回到 A，才认为关系更可信。
  • 可见性与边界筛选：避免让 CAD 背面被强行匹配到单视角正面；可利用渲染的可见面或深度门限。

第二层：不要求所有点都参与拟合

Trimmed ICP 的思路是：把对应残差排序，仅让较可信的一部分对应参与优化。对于部分重叠的点云，这比把每个大残差都纳入目标函数更自然。

但保留比例本身就是一个假设：太高会混入错误对应，太低则可能只拟合到一个局部小平面，产生看似漂亮却错误的 Pose。

第三层：让大误差的影响自然减弱

另一条路径是鲁棒损失函数，例如 Huber、Cauchy 或 Tukey。它们改变的不是对应搜索，而是「某个残差变大后，应当承担多大的代价」。

E(T) = Σi ρ(ri(T))

普通最小二乘的 ρ(r)=r²，会让特别大的残差影响迅速增加；鲁棒核通常抑制这类大残差的权重。

不能误会的一点：鲁棒核只能降低离群残差的影响，不能自动识别所有错误匹配。若错误对应恰好具有很小的残差，例如对称结构、重复纹理或相邻相似表面，鲁棒优化仍可能稳定收敛到错误解。
05 / OBSERVABILITY & VALIDATION

配准误差已经很小，Pose 就一定正确吗？

这可能是 Route 04 最重要的一笔认识。

假设把一个理想、没有边界特征的平面模型放在真实平面上。Point-to-Plane 的残差已经接近零，但沿平面移动模型，残差仍然可能是零；绕平面法线旋转也一样。

此时不是优化器没努力，而是当前观测无法区分这些不同 Pose。

FIG 04 · 待补插图
同样低残差，不同可观测性
并列画出平面、理想圆柱、具有不对称几何细节的物体，标注缺乏约束的运动方向，避免把“已收敛”和“六自由度已确定”画成同一件事。

哪些几何容易发生退化？

  • 无限平面 + 点到面残差：两个切向平移、一个绕法线旋转缺乏约束。
  • 理想无限圆柱侧面：绕轴旋转和沿轴平移可能难以由几何区分。
  • 规则对称物体：不同姿态可能形成相同形状，真实姿态不唯一。
  • 单视角局部可见面：即使完整 CAD 有丰富结构，当前视角看到的也可能只有一块近似平面。

有限物体的轮廓、边界、角点、纹理以及其他视角，可能恢复其中部分约束，因此不能不加条件地把无限平面的退化结论套到所有实际物体上。

除了最终 RMSE，还应该检查什么？

检查项目能说明什么不能保证什么
Inlier RMSE被接纳点对的平均几何贴合程度错误小残差对应也可能很好看
Fitness / 对应占比在给定阈值下有多少点参与匹配受点云密度、裁剪、阈值、重叠定义影响
Overlap / 可见面一致性当前模型可见部分是否与真实观测相容不能单独解除几何对称歧义
局部 Hessian / 信息矩阵谱哪些小幅位姿扰动得到强约束、哪些方向很弱局部强约束不等于全局唯一解
多初值或跨帧一致性结果是否对初始化与视角变化稳定同一种错误可能反复出现

一类实用的退化诊断是观察优化目标对六维小扰动的敏感度。把局部线性化后的雅可比记作 J，可以检查近似信息矩阵 Jᵀ W J 的特征值。若某个方向对应的特征值很小，意味着沿这个方向稍微移动，残差变化也很弱。

不过，特征值比较需要考虑平移与旋转单位、参数尺度以及权重的影响，不能把一个未经规范化的数值阈值当作万能的可信度标准。

优化已经停止，只能证明当前停止条件满足了。Pose 是否真正可信，还需要检查对应质量、可见几何、可观测自由度和任务要求。
06 / 回到工程

如果现在就要做一个可验证的基线

对于已知 CAD、单视角 RGB-D、已有相机系粗 Pose 的场景，我会先采取保守路线，而不是直接把所有 ICP 变体都接进去。

  1. 整理坐标：统一模型单位、坐标系和相机外参；明确最终输出为 camera_T_object。
  2. 确定有效观测：使用有效深度、目标 Mask 和必要的离群点过滤，尽量避免背景与深度边缘污染。
  3. 让参考符合当前可见性：优先比较 CAD 在当前视角的可见表面与观测，而不是把不可见背面全部强塞进最近邻搜索。
  4. 建立 Point-to-Point 基线：使用粗初值、合理距离阈值与迭代次数，记录更新前后残差及 Pose 变化。
  5. 比较 Point-to-Plane / GICP：前提是局部法线、点云邻域足够可靠；观察是否获得真实改善，而不是只看数字更小。
  6. 检查稳定性：轻微扰动初值，观察是否收敛到相同姿态；评估有效重叠、对称歧义与任务相关自由度。

一个最小的 Open3D Point-to-Plane 示例

import numpy as np
import open3d as o3d

# model_pcd: 已知参考点云（Object Frame）
# obs_pcd:   当前观测点云（Camera Frame）
# T_init:    已有的 camera_T_object，shape = (4, 4)
# 以下对象与 T_init 均由上游步骤提供

obs_pcd.estimate_normals(
    o3d.geometry.KDTreeSearchParamHybrid(radius=0.02, max_nn=30)
)

result = o3d.pipelines.registration.registration_icp(
    model_pcd,
    obs_pcd,
    max_correspondence_distance=0.015,  # 米：按场景尺度调整
    init=T_init,
    estimation_method=(
        o3d.pipelines.registration.TransformationEstimationPointToPlane()
    ),
    criteria=o3d.pipelines.registration.ICPConvergenceCriteria(
        max_iteration=50
    ),
)

T_camera_object = result.transformation
print('fitness:', result.fitness)
print('inlier_rmse:', result.inlier_rmse)
print(T_camera_object)

这是接口级示例，不是完整生产流水线。点云必须使用一致的长度单位；半径和距离阈值需要依据物体大小、点密度、深度误差与粗初值精度确定。若 CAD 有不可见面或目标深度残缺，应额外处理可见性与对应过滤。

不要在这一步悄悄引入 Stage 02 的「多个抓取候选排序」。Route 04 仍然围绕一个已约定的 Object Pose / Grasp Pose：它是否可被当前几何可靠地修正和验证？
07 / 回头看

这一圈之后，ICP 不再只是一个接口名

方法 / 思路换来的能力不可忽略的代价
Point-to-Point ICP对应未知时，从最近邻与刚体拟合反复逼近初值、错误最近邻、采样密度
Point-to-Plane围绕局部表面而非离散采样点对齐法线质量与局部退化
GICP利用局部几何方向性定义误差协方差估计、数值稳定与计算成本
Trimmed / Robust ICP降低部分重叠与大残差的影响阈值、保留比例、错误小残差对应
可观测性分析区分低残差与六自由度是否真正被约束依赖局部线性化、任务尺度与额外证据

回过头看，ICP 的价值并不在于神奇地找到某个唯一 Pose，而在于：从一个可用的初始假设出发，交替建立对应并更新变换，让观测与参考逐步一致。

Point-to-Plane 改变了「距离」的几何意义，GICP 进一步引入局部方向性，鲁棒估计尝试处理不可靠对应。但没有一种方法能凭空补出缺失的几何约束。

于是，真正该问的不是「ICP 有没有收敛」，而是：我用哪些证据确认它对准了？哪些自由度仍然没有被观测确定？

对于 Stage 01，答案也不必永远是完整、唯一的 Object Pose。如果物体某个对称自由度并不影响预先约定的抓取关系，那么工程上可以接受这个等价性；但如果它会改变夹爪姿态、碰撞或 TCP 目标，就不能用低残差掩盖尚未解决的歧义。
