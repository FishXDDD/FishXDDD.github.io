00
研究边界 / 先让问题成立

已知参考，并不等于已知 Pose

Q01 的起点是“手里只有现场点云，能量出哪些空间约束”。Q02 换了一个前提：物体的某些参考信息事先已知。已知的是一组尺寸、一张标定过的平面、几处三维关键点，还是完整 CAD？它们能够提供的约束并不相同。

因此，这里先不按 ICP、PPF、PnP 这样的算法名称分类。先问清楚参考从哪里来、现场能观测到什么、两者如何建立对应，再选求解器。没有这些约束，算法清单再长，也无法形成可靠的技术路线。

任务约定单次抓取 · 固定两指夹爪抓法已提前决定，求空间 Pose，不自主生成新抓法
观测边界单视角 RGB-D相机标定已知；具体方法可只用 RGB 或三维点
对象边界已知参考的刚体主要研究实例级参考，变形与类别泛化另论
模型边界不额外做重建CAD、模板、参考点可事先存在；不为当次求解临时重建

需要的输出究竟是什么？

先约定模型坐标系 O 和相机坐标系 C。Q02 的主要结果是 ᶜTₒ，即把物体参考坐标系里的点变换到相机坐标系的刚体变换。若抓取方式已表示为 ᵒT𝗴，则有：

ᶜT𝗴 = ᶜTₒ · ᵒT𝗴

这里不需要算法直接理解夹爪。它只需要正确求出参考模型与现场观测之间的空间关系。对于对称物体，可能只得到任务等价的若干姿态，而不一定是唯一姿态。

01
约束矩阵 / 最重要的一页

先列条件，再谈算法

“已知物体”容易被说成一个条件，但它实际上包含许多独立维度。以下几项必须同时检查，不能只根据是否有 CAD 选择算法。

约束必须问清楚它决定什么
C1 · 参考信息只有长宽高、若干 3D 点、参考表面、CAD 网格，还是带位姿的参考视图？几何模型及其坐标系是否可用
C2 · 现场观测RGB、深度、目标点云、Mask、边缘或已提取特征，具体有什么？可以观测的量与匹配空间
C3 · 对应关系对应点已确认、只有候选，还是根本没有？能否直接求变换，或必须先找匹配
C4 · 位姿先验已粗对齐、已知搜索区域，还是位置姿态完全未知？局部优化还是全局搜索
C5 · 可观测性遮挡、共面、对称与重复结构是否使某些自由度不可区分？解能否唯一、是否稳定
C6 · 标定与尺度K/D、深度 scale、参考模型单位、相机与模型坐标定义是否可靠？结果是否为正确的度量位姿
C7 · 实例范围目标已经定位、同类对象很多，还是要从混杂场景搜索？是否需要实例检测与候选验证
先分清缺的是信息还是算法。如果已知模型点和观测像素的对应关系，问题可能已经是 PnP；若没有对应、没有可辨识纹理或轮廓，单独调用 PnP 并不会解决“点从哪里来”。

参考信息至少有四种层次

R1参数化形状盒体长宽高、圆柱半径等可建立形状约束，不等于拥有完整可配准模型
R2度量关键点角点、孔心、特征点 3D 坐标可供 PnP 或已知 3D 对应求解
R3三维表面 / CADMesh、点云、法线或可渲染几何可做表面配准与模型投影匹配
R4参考图像 / 视图带标定、尺度或空间关系的模板要确认是否真正拥有度量三维参考

R1～R4 表示参考类型而不是技术等级。模型信息越多，并不保证观测就越容易配准；例如无纹理且高度对称的 CAD，仍可能存在姿态歧义。

02
分类方法 / 把不同层级分开

五条几何主线，一组横向求解工具

如果直接把 ICP、PnP、PPF、LINEMOD 放在同一排，会混淆三个问题：用了什么参考、怎么建立几何约束、如何优化或搜索。

A · 参数形状

尺寸或形状参数 + 三维观测 → 通过几何约束拟合位置、方向与尺度。

盒体、圆柱等
B · 3D–3D 对应

已知空间点对应 → 直接估计 R、t；如果对应有误，再引入鲁棒估计。

Kabsch / Horn
C · 3D–2D 对应

模型点及其图像像素 + K/D → 按投影几何恢复 R、t。

PnP / IPPE
D · 3D 表面匹配

参考表面 + 现场表面 → 全局找候选或在已知初值附近精化。

PPF / ICP 等
E · 投影/轮廓匹配

可投影的度量模型 + 标定图像 → 对齐轮廓、梯度、渲染证据。

LINEMOD / 渲染
横向能力 · 学习式估计　学习式关键点、对应匹配、候选排序和姿态精化可插入 B～E；是否端到端预测并不改变参考和现场必须提供足够约束的事实。
03
路线 A / 形状参数已经明确

只有尺寸，也可能足够求位姿

如果只知道一个盒子的长、宽、高，而现场有深度点云，可以利用正交面、尺寸和可见范围约束估计盒体位置。这与“已经拥有一份可做 ICP 的参考点云”不是同一前提。

A1
盒体尺寸 + 平面约束

从现场寻找平面与边界，并把已知长宽高、正交性和可见面关系共同放进位姿求解。

成立条件：尺寸具有物理尺度；物体近似刚性盒体；至少有足以约束所需自由度的可见几何或摆放先验。

代价与检查：对只见一个无纹理平面的情形，不可自动区分所有旋转与隐藏面；可能存在镜像/对称候选。

A2
圆柱 / 球 / 规则基元

使用已知半径、长度或结构参数，从部分表面拟合几何参数与对象参考系。

成立条件：对象符合相应参数化模型，部分可见表面足以支持估计。

代价与检查：拟合残差小不等于每个旋转可观测；理想圆柱绕轴转角、球体全部朝向具有对称歧义。

工业实现可参考 HALCON 的 3D Box Finder：已知盒体尺寸，现场提供三维数据，就可以进行盒体定位，而不要求先给出完整 CAD。它证明“已知参数”本身就能构成独立的求解路线。

与 Q01 的边界：Q01 是从现场点云本身量几何；Q02 的 A 类额外允许使用事先确定的尺寸、正交性或基元参数来补足约束。
04
路线 B / 三维对应已明确

对应点已知，直接求 R 与 t

当模型中的点 pᵢ 与相机观测到的三维点 qᵢ 已经一一对应时，问题就不再是“怎么找对象”，而是求一组满足 qᵢ ≈ R pᵢ + t 的刚体变换。

min Σ ‖R pᵢ + t − qᵢ‖²，且 RᵀR = I，det(R)=1
B1
Kabsch / Arun（SVD）

去中心化两组对应点，用协方差的奇异值分解求旋转，再由两组中心得到平移。

成立条件：已知足够数量、几何配置非退化的真实 3D–3D 对应；刚体且两组尺度一致。

代价与检查：匹配不可信时不应直接把所有对应等权纳入求解；退化几何和测量噪声影响结果。

B2
Horn（Quaternion）

用四元数参数化旋转求刚体对齐，与 SVD 类方法面向同一类已知三维对应问题。

成立条件：对应已知；尺度与坐标含义统一。

代价与检查：需辨别刚体、相似变换等具体问题设置；不同数学表示不是新的输入路线。

B3
Umeyama（可选尺度）

通过统计形式估计旋转、平移，并可在相似变换设置中估计全局尺度。

成立条件：对应可靠；确认任务是 SE(3) 刚体还是 Sim(3) 相似变换。

代价与检查：对于已知真实尺度的抓取定位，不应无理由放开 scale，否则可能掩盖标定或数据单位错误。

如果“对应”只是候选，不能直接当真

这时可以用 RANSAC、鲁棒损失，或 TEASER++ 等方法在错误对应存在时估计变换。它们处理的是候选对应中的异常值，并不会自动告诉系统模型上的哪个点应该和现场哪个点对应。

必要区分：“已知 3D–3D 对应”与“有两份点云”不是同一个条件。前者可以直接求刚体变换；后者首先面临对应发现与匹配的问题。
05
路线 C / 已知点在图像中的位置

PnP 与平面参考：先有 3D–2D 对应

这一类不要求模型和现场都变成点云。只要已知物体坐标系下的度量 3D 点，并在当前图像找到了对应的像素点，加上正确的相机内参与畸变参数，就能够使用 PnP。

C1
PnP：P3P / AP3P / EPnP / SQPnP

通过透视投影关系，从 3D–2D 对应求物体到相机的旋转和平移。

成立条件：参考点 3D 坐标明确、K/D 正确、像素与 3D 身份匹配，点数和几何配置满足所选求解器要求。

代价与检查：少点法可能有多个解；误匹配需要 RANSAC；仅看重投影误差不等于姿态一定稳定。

C2
共面 PnP：IPPE / IPPE_SQUARE

专门处理所有参考点共面的情形，适合平面标记或已知平面角点。

成立条件：点在同一物体平面上，已知平面内的尺度、方向及图像对应；IPPE_SQUARE 要求特定正方形点顺序。

代价与检查：近正面、远距离等条件下可能出现相近重投影误差的姿态候选，应保留与验证。

C3
Homography 分解

由平面上 2D–2D 对应求单应矩阵；在已知平面度量坐标、K 和几何条件下恢复平面位姿候选。

成立条件：场景约束为同一平面，且参考平面坐标与尺度可确定。

代价与检查：纯图像间 Homography 不会自动给真实尺度的 6D Pose；平面法线歧义与几何退化须检查。

四个长方形角点的最小例子

已经知道

该面真实宽高 W,H，四点在物体坐标系为 (0,0,0)、(W,0,0)、(W,H,0)、(0,H,0)；图像中找到了对应的四个角点，且 K/D 已知。

可以做

按一致的点顺序构造 objectPoints 和 imagePoints，使用适用于共面的 PnP 或 Homography 分解，得到候选 ᶜTₒ。

需要验证

角点是否真是模型指定的那四个、实际尺寸是否正确、平面候选是否存在歧义、是否使用正确的图像 K 与畸变处理。

这里容易误解　“共面”不代表不能求 Pose；它意味着需要采用适合共面配置的求解器，并理解潜在的候选歧义。
06
路线 D / 有参考与现场表面

ICP、PPF、FGR 要按“已知什么”分层

有完整 CAD 或参考点云，现场也有目标点云，此时仍不能直接说“做 ICP”。要先看两份表面是否已有合理的初始对齐，以及候选对应从哪里来。

D1 · 已有位姿初值：局部精化

D1.1
Point-to-Point ICP

反复寻找最近邻对应，并最小化点到点距离更新刚体变换。

成立条件：初始位姿足够接近、参考与观测存在合理重叠、最近邻具有几何意义。

代价与检查：容易受错误初值、局部极小值、对称和离群点影响；不能保证全局找对实例。

D1.2
Point-to-Plane ICP

利用目标点的表面法线，最小化点到局部切平面的残差。

成立条件：局部法线可靠、初值合理、观测包含足够非退化表面。

代价与检查：法线误差与平坦/重复结构会影响求解；单一平面不能完整约束刚体 6DoF。

D1.3
GICP / Robust ICP

使用局部协方差或鲁棒权重描述观测几何与残差分布，提高某些场景下的局部对齐质量。

成立条件：仍需要重叠与可用初值；协方差和鲁棒损失参数应与传感器匹配。

代价与检查：计算与调参成本增加，并没有消除全局初始化需求。

D2 · 完全没有初值：先提出候选

D2.1
PPF（Point Pair Feature）

通过点对的距离与法线夹角构成几何描述，在参考模型和场景中搜索支持一致位姿的点对。

成立条件：参考模型/现场能估计表面点和法线；模型点对结构在可见区域有区分度。

代价与检查：点对采样、法线精度、量化/哈希、重复结构和对称性影响候选数量与成本。

D2.2
FPFH + 特征对应 + RANSAC

为模型与现场点计算局部几何描述子，在特征空间形成候选对应，再使用鲁棒求解产生全局位姿。

成立条件：场景具备足够稳定、可区分的局部几何；尺度/法线/邻域参数合理。

代价与检查：描述子相似不等于点对应正确；平整或重复结构中假匹配可能非常多。

D2.3
4PCS / Super4PCS

利用三维点集间的刚体不变量搜索相容的基元/点组，估计初始全局对齐。

成立条件：模型与现场有足够几何重叠，采样与距离阈值匹配尺度。

代价与检查：搜索成本、重叠率、重复结构与数据量直接影响工程表现。

D3 · 对应已经有了很多候选，但混有错误

D3.1
RANSAC / FGR / TEASER++

在候选对应集上鲁棒估计刚体变换；FGR 倾向快速鲁棒优化，TEASER++ 利用截断鲁棒估计等机制处理大量错配。

成立条件：输入是足以形成约束的候选点对应，或上游特征已提供候选匹配。

代价与检查：不等于目标检测器；缺乏对应时需要先补充候选生成流程。

实际管线往往可以组合：模型点云 → 法线与特征 → 候选对应 → 全局 R、t → ICP 精化 → 验证。如果已有可靠机器人先验或粗位姿，就可以跳过全局搜索。

07
路线 E / 参考模型可以投影到图像

没有稳定关键点，还能匹配轮廓和渲染

深度点云不是唯一能与 CAD 建立关系的观测。若模型可以从任意候选位姿投影到图像，就可以利用轮廓、梯度、纹理或渲染证据来评分和优化。这里的关键输入是已知尺度的三维模型 + 相机标定 + 可匹配图像结构。

E1
3D Shape-Based Matching / CAD 轮廓对齐

从 CAD 生成候选视角下的边缘或轮廓，与真实 RGB 图像中的结构做一致性匹配，输出候选 6D Pose。

成立条件：CAD 可投影、K/D 正确、可观测边缘具有区分度；需有足够的候选姿态搜索或初始化。

代价与检查：无纹理并不妨碍轮廓，但纯轮廓对称、遮挡和背景边缘可能造成多解；搜索视角有成本。

E2
LINEMOD 一类模板匹配

利用图像梯度、可选深度法线等信息，与预先离散的模板/视图进行匹配，再求或细化位姿。

成立条件：存在覆盖相关视角和尺度的模板库，模板与当前相机设置相容，目标可定位。

代价与检查：模板数量、视角量化误差、遮挡与背景混淆；模板匹配到 2D 位置不等于天然拥有度量 6D。

E3
Analysis-by-Synthesis / 渲染优化

把候选位姿下的模型渲染到图像，与现场轮廓、颜色、深度或特征比较，并优化 R、t。

成立条件：可渲染的度量模型、正确相机模型以及与损失函数相容的观测。

代价与检查：初始位姿与损失地形决定优化效果；可见性处理、GPU 算力和模型材质假设带来成本。

二维模板的界限：普通 2D Shape-Based Matching 得到位置、尺度和面内旋转，并不自动等价于物体在三维空间中的完整 Pose。必须明确模板是否包含可用的三维投影模型与度量约束。

这条路线与 PnP 的关系也值得区分：PnP 的关键是显式 3D–2D 点对应；轮廓和渲染路线可以不要求少数稳定关键点，而是利用整体图像匹配误差建立约束。

08
横向机制 / 数据驱动不改变几何前提

学习式方法放进哪一层，才比较清楚

学习式 Pose 估计应当作为一条横向能力来整理，而不是简单与“3D–2D”“3D–3D”并列。网络可以负责发现关键点、建立对应、预测初值、评价候选或在几何/渲染约束下精化位姿。

可学习的环节 ①关键点 / 对应特征匹配、2D–3D 或 3D–3D 对应候选
可学习的环节 ②初始位姿基于 RGB/RGB-D 与参考模型产生候选
可学习的环节 ③评分与精化渲染一致性、深度与特征约束下排序和细化

FoundationPose 放在哪里？

以其 CAD 模型模式为例，已知模型 + RGB-D + 目标 Mask + 相机内参构成实用前提。它利用候选位姿生成、评分和精化完成对象位姿估计。它不是“完全没有模型、给一张图就能随意求一个物体 Pose”的通用入口。

其少量参考图像模式引入神经隐式参考表示及额外预处理。这条分支值得了解，但在本页“不为当前任务额外重建”的边界下，应明确标注为带参考建模代价的扩展路线。

F1
学习式关键点 / 对应

利用神经网络在参考与现场提取稳定特征，然后通过 PnP 或 3D 刚体估计求 Pose。

成立条件：具有参考和现场间可迁移的可辨识特征，训练域与真实观测合理匹配。

代价与检查：训练分布、遮挡和重复外观影响匹配质量；几何验证仍然必要。

F2
已知模型的 RGB-D 姿态估计与精化

对 CAD 支持的已知刚体，从当前观测产生并优化 6D 位姿候选。

成立条件：参考模型与运行时数据接口满足具体模型要求，坐标系、单位与 Mask 正确。

代价与检查：权重、依赖、显存、候选评估和域差；对称形状仍需适合的评价口径。

不要按“传统 vs 学习”直接分上下级。如果网络预测了 2D 对应点，后续仍可能是 PnP；如果网络给出粗位姿，后续仍可以 ICP 或渲染精化。学习的是哪一环，才是可比较的技术差异。
09
求解验证 / 数据能否真正区分

能返回 Pose，不代表 Pose 已被唯一确定

即使已经得到一个数值形式的 R,t，也不能直接认为参考与现场已经建立了正确关系。很多时候，可观测性比求解器的收敛速度更值得先检查。

观测条件可能得到的结果需要承认的边界
仅可见一个无特征平面平面位置、法线与某些相对位置约束沿面平移及绕法线旋转可能无法由该信息唯一确定
共面 3D–2D 已知角点可计算候选平面 Pose近似退化视角可能出现多个合理候选；需要检验
理想圆柱侧面轴线、位置、半径等可估计绕圆柱自身轴线的绝对旋转不可辨
完全相同的重复结构可能找到多个高评分位姿须结合实例语义、场景约束或任务等价性
深度表面残缺、重叠很少有时仍可给出数值配准结果低重叠下单一配准残差不构成可靠验证
参考尺寸 / K / 深度单位错误求解器可能正常返回数值数值一致性不代表空间尺度正确

验证应当与求解目标相对应

3D–3D 点对应残差与几何一致性

对应残差、内点分布、点集空间跨度；是否落入退化或平面共线构型。

3D–2D / PnP重投影误差

误差分布、点位布局、正深度及多个候选；不能只看一个平均数。

ICP / 表面配准可见面的重叠与对齐

Fitness、RMSE、局部几何覆盖及遮挡；误差小可能来自错配的局部平面。

面向抓取的最终验证抓取 Pose 是否可用

基准点误差、任务等价旋转、夹爪姿态偏差与局部几何安全裕量。

对于物体对称，最好把 物体坐标系下的数学旋转误差 与 抓取任务所关心的实际差异 区分开。两个不同的 Object Pose 可能在几何或抓取上是等价的；也可能因为指定了特定侧面而完全不等价。

约束实例 / 用实际问题验证分类

同一个任务有哪些真正成立的路线？

下面使用几组明确条件检验分类是否真的能用。这里不预先指定“最佳算法”，而是列出哪些路线成立，以及条件少了什么时会发生变化。

输入场景成立的路线关键缺失与选择代价
一个盒面 4 角点
已知 W/H、K/D、像素四点对应		C · IPPE / 平面 PnP；可用 Homography 辅助理解检查角点顺序、平面候选和尺度；不需要先转成完整点云
一组已知三维点对应
模型点 ↔ 深度反投影点		B · Kabsch / Horn；错配时鲁棒估计确保对应、坐标单位与非退化配置
参考 CAD + 现场点云

参考 CAD + 现场点云

只有盒体长宽高

同一场景，多种路线可能都成立

例如“已知 CAD + 已知图像角点 + RGB-D”，既可以走 PnP，也可以利用深度进一步做 3D 对齐。选择不应该看哪个名字更新，而要比较：对应是否可信、观测是否足够、运行时预算、期望精度以及定位失败的代价。

Q02 与 Q01、Q03 的实际分工

Q01 不依赖已知实例模型，从现场几何提取可直接使用的抓取空间约束；Q02 允许借助事先已知的度量参考求 Object Pose，再完成固定抓法的空间变换；Q03/Q04 则研究当前画面如何提取目标、以及二维信息怎样落到三维。

最后留下一个判断：技术不是因为“有缺点”而不可用，而是某些必需条件并未满足。 先核对输入与可观测性，再比较工程成本，才有可能形成稳定的技术选型。
