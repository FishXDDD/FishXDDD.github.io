STAGE 01 / Q02 · KNOWN REFERENCE

已经知道物体的
一些信息，
怎样找回它的 Pose？

当尺寸、关键点、参考图像或三维模型已经掌握，问题就不再只是从观测里猜测几何，而是：怎样让参考与眼前的物体建立可以求解的关系？

单视角 · 已标定相机已定位目标已有物体参考抓取关系已约定目标：Object Pose → Grasp Pose
与 Q01 的边界：前面已经尝试只凭可见点云的统计分布和通用几何关系构造抓取约束。这一页不再重复中心、PCA 或几何模型拟合，而是研究怎样利用事先掌握的物体参考，恢复它在相机中的姿态。

00 / 先把目标说清楚

参考是已知的，
它现在的姿态仍然未知。

手里有物体的 CAD、关键点坐标，或带有姿态信息的参考图像；相机眼前也确实看见了它。但“认识这件物体”和“知道它现在相对于相机怎么放”是两回事。

这里假设已经定义了 Object Frame，以及夹爪相对于它的约定抓取关系。需要求解的是物体在相机坐标系中的变换，然后把既定的 Grasp Frame 带到相机坐标系下。

⁽ᶜ⁾TG = ⁽ᶜ⁾TO · ⁽ᴼ⁾TG  　｜　未知的是 ⁽ᶜ⁾TO

真正的难点不是“参考信息够不够多”，而是参考与当前观测之间，有没有足以约束位置和方向的证据。

01 / 探索之后才整理出来的地图

四个研究入口，
不是四级升级路线。

它们在研究分类上是平级的。前三条通常用来获取 Pose；第四条从“已经有可用初值”出发，研究怎样进一步对齐。分类不代表固定执行顺序；下面按照问题逐渐变化的顺序来讲述发现过程。

ROUTE 01 · CORRESPONDENCE KNOWN

明确对应 · 直接求解

已经知道参考中的哪个点，对应现场的哪个点。
PnP / IPPE · Kabsch / SVD
依据
参考 3D 点与图像 2D 点，或现场 3D 点的明确对应
能力
直接从投影或刚体关系求 R、t
代价
对应必须正确，数量与空间构型必须足够好
ROUTE 02 · GEOMETRY MATCHING

三维几何 · 寻找匹配

不知道点的身份，但参考和现场都有可靠的三维表面。
PPF · FPFH + RANSAC
依据
点对关系、法线、局部几何描述与全局一致性
能力
寻找潜在对应或直接搜索可能的 Pose
代价
辨识度、遮挡、噪声、搜索和误匹配
ROUTE 03 · IMAGE / PROJECTION

图像证据 · 投影匹配

三维测量不足，但轮廓、边缘或外观依然可用。
LINEMOD · Template · Render-and-Compare
依据
参考视图，或已知三维模型在候选姿态下的预测投影
能力
利用二维证据搜索、验证物体姿态
代价
参考覆盖、外观变化、投影歧义和尺度约束
ROUTE 04 · LOCAL REFINEMENT

已有初值 · 局部精化

已经大致知道物体在哪里，但还希望对得更准确。
ICP · Point-to-Plane · GICP
依据
已有姿态初值，以及初值附近的点、面或投影残差
能力
在局部范围内进一步调整 R、t
代价
初值、重叠区域、局部最优与错误收敛
别把“参考形式”当成“技术路线”。同一份 CAD 可以用于已知角点的 PnP，也可以用于 PPF 三维匹配，或者用于渲染投影；而 ICP 可以接在其中任意一条路线之后，也可以使用其他来源的初值。
02 / 顺着问题，一点点发现新的思路

从“我知道一些对应”，
到“参考究竟如何解释观测”。

这里记录的是发现不同解法的思考顺序，不是算法进化史。每一次转换，都来自上一个设想的前提在新场景中不再成立；新方法只是改换了证据，并不自动优于旧方法。

起点简记 · Q01 已经试过仅依据可见点云测量中心、主方向或通用形状。这次多了一份事先定义好的物体参考。与其从“知道长宽高为什么还不知道 Pose”重新铺垫，不如直接问：如果参考与观测能找到几个同名位置，会发生什么？
01 / 从确定的对应关系开始

如果已经认出了几个点，Pose 能不能直接算？

例如我有盒体参考中四个角点的三维坐标，也知道它们分别落在当前图像的哪四个像素上。此时不需要让整个模型和现场逐点重合，这四组对应本身就提供了可计算的几何约束。

沿着相机投影关系寻找旋转 R 与平移 t，使参考三维点变换到相机下再投影后，尽可能落在测得的像素上。这就是 PnP 最直接的思路。

3D–2D： ui ≈ π(K (R Pi + t))
minR,t Σ ‖ui − π(K (R Pi + t))‖²

如果这些像素还有可靠深度，可以恢复出现场的三维点 Qi。于是转为另一种更直接的刚体对应问题：寻找使两组三维点尽可能对齐的 R、t。Kabsch / SVD 刚体估计是这一思路的代表。

3D–3D： Qi ≈ R Pi + t
minR ∈ SO(3), t Σ ‖Qi − (R Pi + t)‖²
代表方法
PnP / IPPE：由 3D–2D 投影对应求位姿，平面参考可研究专门求解器与多解问题。
Kabsch：已知 3D–3D 对应时，通过去中心与 SVD 求最优刚体变换。
真正的收获：不一定需要恢复完整物体。对应点数量与空间构型合适时，少量明确关系就足以恢复位姿。
无法绕过的条件：角点必须认得对；平面、共线或视角退化的构型，需要特别检查稳定性和多解。

但“知道哪一个像素对应哪一个参考角点”，刚刚是被我直接假设为已知的。换成一件表面光滑、没有明显角点的零件，这个前提就不成立了。如果对应关系根本不知道，还能不能利用完整的参考几何？

02 / 不知道点的身份，改问形状关系

没有同名点，但模型和点云都有，能不能找到对齐关系？

现在已有 CAD 或参考点云，却认不出任何稳定角点。现场的单视角点云只覆盖物体部分表面。直接做已知对应求解不现实，因为对应关系本身还没建立。

不过，一个局部表面不一定需要“名字”才能被认出来。点与点的距离、法线间的夹角、邻域曲率变化，都可能作为几何线索。思路也就从利用现成对应求变换，转向利用几何关系寻找对应或候选姿态。

两种入口
PPF：利用有向点对的距离和法线夹角等相对几何关系进行匹配与姿态投票。
FPFH + RANSAC：先描述局部邻域法线结构，建立候选特征匹配，再通过几何一致性估计刚体变换。

这里也终于有必要区分“描述特征”和“求解 Pose”：FPFH 不是直接输出 6D 位姿的求解器；RANSAC 也不负责发明特征，它负责从含有错误匹配的证据中估计并验证模型。

收获：不需要人工为所有点指定身份，可以从模型几何中寻找定位线索。
代价：重复结构、对称性、法线噪声和严重遮挡，会同时削弱辨识度与匹配可靠性；全局搜索也有计算成本。

三维模型已经够完整了，但如果现场观测来自透明瓶子、镜面或者某些几乎没有有效深度的区域呢？模型几何有了，测量却不能支撑匹配。图像里的轮廓和外观，能不能成为另一种证据？

03 / 换掉不可靠的观测证据

深度不行，能不能让参考在图像里“对上”？

即使无法得到可靠的三维曲面，相机也可能清楚地看见物体的外轮廓、边缘、纹理或局部外观。如果我知道某个候选 Pose，就可以预测参考从这个角度看应该是什么样子，再与真实画面比较。

于是出现另一条入口：不是先把所有点提升到三维，而是让某个三维姿态假设在二维图像中接受检验。

代表方法
LINEMOD / 姿态模板：准备带已知姿态的参考模板，根据图像梯度和适用时的深度法线等特征寻找相符视图。
Render-and-Compare：利用已知几何及相机内参渲染候选姿态，比较轮廓、边缘或其他图像残差。
候选位姿 T → 预测观测 Î(T) → 与当前图像 I 比较
T* = argminT D(Î(T), I)　（D 依所选观测残差定义）

这种思路减少了对有效三维测量的依赖，但并不是说二维图像天然能确定完整 6D Pose。已知尺度、参考相机、模型几何、候选姿态覆盖或额外约束仍然可能是必要条件；不同姿态也可能产生相近投影。

收获：深度缺失时，还能使用外观与投影几何。
代价：视角覆盖、光照变化、遮挡、外观重复与姿态搜索成本，可能成为新的瓶颈。

到这里，已经找到三种并列的 Pose 获取思路。但无论哪一种，最终得到的初值都可能略微偏离真实观测。假如物体的大致位置已经知道，还有必要重新全局搜索吗？

04 / 已经知道大概在哪

有了合理初值，为什么不在附近直接调整？

有时初值来自前面的匹配；也可能来自固定工位、机械定位、上一轮估计或其他可靠参考。既然模型已经大体对齐，接下来希望解决的是局部误差，而不是从头寻找物体。

ICP 的思路可以理解为循环进行两件事：在当前位姿附近建立临时对应，再重新估计刚体变换；如果表面法线可靠，还可以将点到平面的残差作为优化目标。

Point-to-Plane： minR,t Σ [ niᵀ (R pi + t − qi) ]²
代表方法
Point-to-Point ICP：反复更新对应并最小化三维点距。
Point-to-Plane / GICP：进一步利用局部表面方向或协方差描述建立残差。
收获：初值合理时，把优化限制在局部可以高效改善几何一致性。
代价：它不会自动纠正错误的全局初值；局部重复结构、低重叠和遮挡可能造成错误收敛。

而且还不能只看最后的残差。一个错误的对齐也可能把局部可见表面对得非常好。更深一层的问题随之出现：如果不同姿态在观测里根本不可区分，所谓“唯一正确的 Pose”真的存在吗？

05 / 不是第五条算法路线，而是共同边界

匹配得很好，为什么 Pose 仍可能不唯一？

考虑一只完全无标记的理想圆柱。绕对称轴旋转以后，模型几何和可见表面可能没有任何可区分变化。即使有精确 CAD、高质量点云和完美求解器，单靠这些观测仍然分不出沿对称变换的不同 Object Pose。

这不是某一种算法的失误，而是参考与观测本身没有提供相应自由度的约束。已知尺寸、已知模型，都不意味着所有方向必然可观测。

若 S 是不改变可观测几何的对称变换：
Observation(T) ≈ Observation(T · S)

但当前研究的最终目标不是给所有物体强求一个唯一的数值姿态，而是恢复预先约定的抓取关系。如果尚未区分的物体姿态自由度，不影响所约定的夹持方式，这个歧义未必阻止抓取；反过来，如果必须对准特定结构，就需要额外参考才能消除它。

最终要问的不是“6D Pose 的六个数有没有全部算出来”，而是：当前证据是否足以确定与抓取任务相关的自由度？这仍然是在验证一个约定 Grasp Pose 是否成立，而不是进入 Stage 02 的抓取候选采样与评分。

03 / 走过这一圈，再收起算法名

不是哪条路线更先进，
而是哪一种约束真的成立。

前一条路线的前提不成立时，我才会尝试另一种证据。但一旦重新拥有可靠同名点，就没有理由为了“高级”而强行做全局模型匹配；如果初值已经可靠，也没必要每次都从零搜索。

技术路线换来的能力不可忽略的代价
明确对应求解
PnP / Kabsch		关系明确时，直接从几何约束恢复 R、t同名点的身份、精度、分布和退化问题
三维几何匹配
PPF / FPFH		在对应未知时，从三维形状发现姿态表面质量、几何辨识度、搜索及误匹配
图像与投影匹配
LINEMOD / Rendering		在深度不足时继续利用二维证据模型或参考覆盖、尺度、外观与投影歧义
局部姿态精化
ICP / GICP		给定可用初值后进一步减小局部误差收敛盆地、重叠、残差意义与错误初值

选方法之前，比算法名字更值得确认的是三件事：

01 · 手里到底有什么参考？

尺寸、同名关键点、CAD、参考点云、已知姿态的视图，还是可复现的相机 / 工位初值？

02 · 当前有哪些可靠的观测？

像素对应、轮廓、真实深度、法线、可见表面，哪些在现场真正成立？

03 · 哪些自由度必须确定？

是需要唯一 Object Pose，还是只要足以落实约定抓取关系的可观测部分？

参考不是把 Pose 直接交给我。它只是让我有机会把眼前有限的观测，变成可以检验的几何关系。技术没有错，只有条件与代价。

学习式方法放在哪里？它可以帮助提取关键点、建立匹配、生成候选初值、评价姿态或学习精化（例如完整的 CAD-based pose estimation 系统）。这属于跨环节的求解手段，不需要简单地在“3D–2D、三维几何、图像投影”旁边硬加一条以模型名称命名的路线。
