01
THE STORY

原来，我缺的是一份空间参照

这个故事只围绕一个问题展开。

想让机器人抓起东西，最终需要一个 Grasp Pose。这次先假设目标的几何信息已经准备好了，只研究怎样计算夹爪的位置与方向。

如果抓取方向固定，找到合适的位置，也许就够了。可物体一旋转、一倾斜，夹爪就不能总保持原来的朝向。回头想想，真正需要确定的是：人工规定的抓取关系，怎样跟随真实物体的位置与方向变化？

那么，能用来安放抓取姿态的「空间参考系」，究竟从哪里来？

顺着这个疑问调研，我发现两种思路：从现场几何中找，或者把已有的参考模型对到现场。前者从轴线、平面等结构构造参考；后者求出已知模型与当前观测的空间变换。

继续查才发现，“对齐”不等于只有 ICP。手头如果有 3D–2D 对应点，可以研究 PnP；有 3D–3D 对应点，可以研究刚体变换求解；如果是缺少显式对应的两份点云，才会进一步面对配准问题。

原来方法的分野，首先不在于新旧，而在于我们已经知道什么，又缺少哪一份空间关系。

一条必要的旁注 · PnP 使用图像中的 2D 观测，但它本身是几何求解器，并不等于使用视觉学习模型。视觉模型可以在 Route 1.2 中帮忙获得对应点。
02
THE MAP

两种思路，几类关键办法

这里负责说明“有什么、解决什么”；推导和论文留给附录。

这张图按空间参考关系的来源整理。它是个人调研索引，不是把位姿估计领域规定成仅有两大类别。

怎样把预定义抓取关系放到当前物体上？需要确定参考系，或估计已知参考系到现场的变换
PATH A · CONSTRUCT

现场构造参考系

物体没有可直接使用的完整模板，但它有位置、轴线、表面等可观察的结构。

中心 / 固定朝向抓取方向已约定，先确定夹爪放在哪里。
PCA / 3D OBB物体会旋转时，提取整体主方向与几何范围。
法线 / 平面 / 圆柱拟合需要侧向或倾斜接近时，寻找局部几何方向。
RANSAC / 稳健拟合有离群点时，提高几何模型估计的抗干扰能力。

注意：对称性可能使方向不唯一；一根轴或一个法线，也不足以单独确定完整的三维旋转。

PATH B · ALIGN

已有参考，对齐现场

已有物体模型、参考点或模板；关键是求出它与当前观测之间的变换。

3D–2D：PnP / IPPE已知模型点与图像点对应，用投影关系求物体位姿。
3D–3D：Kabsch / Horn两组三维点已对应，直接求刚体旋转和平移。
点云精配准：ICP / GICP对应尚不明确，但初始对齐较好时迭代优化。
粗配准与鲁棒匹配初值未知或误匹配多：FPFH + RANSAC、FGR、TEASER++ 等。

注意：PnP 需要可信的对应点和相机模型；点云配准还受初始化、重叠、对称性等条件影响。

不同方法，都服务于同一个任务
空间参考关系 + 人工抓取规则 → 实际 Grasp Pose同一场景也可以组合使用几何拟合、对应求解和精配准

必要补充：平面目标还有 Homography / 平面位姿估计的专门做法；学习型 6D Object Pose、相机定位与 SLAM 等也是位姿研究的重要分支，但不必挤进这篇抓取几何手记的正文。

顺路看见

观测维度 ≠ Pose 自由度。 2D、深度图（2.5D）、点云描述的是信息形式；固定方向、单轴旋转、完整 6DoF 描述的是求解要求。PnP 就说明：不输入完整点云，也可能估计出物体的 6D 位姿。

03
WHAT I KEEP

这次留下的三点认识

日后重读，比记住一长串算法名字更有用。

01

先看任务需要多少约束。 不是每次都要估计唯一、完整的物体 6DoF Pose；固定方向的抓取有时只需定位。

02

先看手里已经有什么信息。 可以现场构造参考，也可以依靠 3D–2D、3D–3D 对应或点云配准。它们不是简单的新旧替代关系。

03

估计出 Pose，不代表一定抓得住。 对称性、观测误差、夹爪干涉与执行条件仍需另外检验；抓取规则在此阶段仍由人定义。

附录 A｜方法走过的历史默认收起 · 代表方法如何回应不同的几何难题⌄

以下只保留具有代表性的方法；年份对应所列经典论文的发表年份。这里不是一条“前一个方法必然催生下一个方法”的直线，而是若干互相交叉的问题分支。

年份方法它试图解决什么？优势与留下的局限资料
1976Kabsch已知点对应，怎样求合适的刚体旋转？解析、快速；错误对应与退化点集仍然困难。论文 ↗
1981RANSAC大量观测里混入离群点，怎样稳健拟合？通用且易组合；依赖模型与阈值，低内点率代价高。论文 ↗
1987Horn已知 3D 对应点，怎样闭式求绝对定向？四元数形式清晰；依赖可靠对应。论文 ↗
1992ICP没有显式逐点对应，如何迭代对齐两份形状？局部精配准经典；初值不好易落入局部最优。论文 ↗
2009EPnP3D–2D 对应较多时，如何高效估计位姿？计算效率高；对应误差、退化情形需额外处理。论文 ↗
2009FPFH没有好初值时，怎样用局部几何寻找匹配？可用于粗配准；重复结构或低重叠时难区分。论文 ↗
2009GICP点到点距离没充分利用局部表面结构怎么办？改善局部几何误差建模；仍依赖初始对齐。论文 ↗
2016FGR已有粗对应，怎样更快地完成鲁棒全局配准？优化速度有优势；受候选匹配质量限制。论文 ↗
2020TEASER++大量对应关系错误时，能否稳健估计变换？高外点鲁棒性；本身不负责凭空产生正确对应。论文 ↗
2022GeoTransformer重叠少、局部几何难匹配时，怎样改善对应？建模几何关系；学习模型有数据和算力成本。论文 ↗

可继续参考：OpenCV · PnP 求解器文档 ↗，Open3D · 全局粗配准与 ICP 精配准 ↗。它们分别说明 3D–2D 求解与点云配准的工程使用条件。

附录 B｜位姿估计的其他风景默认收起 · 知道有哪些领域，不把它们全部挤进正文⌄
平面几何与 Homography平面图像的投影对应；结合已知尺寸和相机参数，也可进一步估计平面位姿。
学习型 6D Object Pose用学习方法获得对应、投票或直接预测位姿；需要明确已知模型、类别级或未见实例等任务设定。
Camera Pose / VO / SLAM估计相机运动和位置；与物体位姿不是同一个研究对象。
Tracking / 标定 / 多视角研究时序稳定、坐标系关系与多次观察；都是值得另外开篇的方向。
