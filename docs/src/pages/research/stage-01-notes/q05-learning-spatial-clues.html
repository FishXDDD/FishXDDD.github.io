有些特征不好手写，能不能让模型来学？

到了这里，我不是突然觉得几何过时了，而是在某些变形物体上，手写的空间参考不够稳定。那能不能把“找什么线索”交给数据学习，再按需要组合几何约束？

学习空间线索几何仍然有用

01 我想让模型学的，究竟是哪一种信息？

学习不是一条单独的 Pose 算法；先看输出的空间信息属于哪一类。下面几条常常能组合，不是先后淘汰。

① 学关键点和局部方向

网络从 RGB、Depth 或点云预测中心、轴线、2D/3D 关键点。它把原来人工定义或检测的局部参考交给数据学习；需要完整位姿时再配合 PnP 或几何约束。

留意：如果关键点没有稳定的物理意义、物体又高度对称，监督与 Pose 恢复都会有歧义。

② 学特征或对应关系，再用几何求解

网络找到图像与模型之间的像素对应、或两片点云之间的可靠对应，再利用 PnP、刚体配准、ICP / 优化求变换。

留意：仍然要问“对应到什么参考上”，以及局部遮挡、重复结构时的匹配可靠性。

③ 学同一类别共享的空间参考

不必为每一个瓶子准备精确 CAD。可学习类别关键点、类别轴线、规范坐标（如 NOCS）等，再利用深度与几何约束恢复实例姿态和尺度。

留意：同一类别也会发生不同程度的变形；类别先验≠对任意新形态都通用。

④ 学习式 Object Pose 或初值

模型直接输出 Object Pose、姿态分布或初始估计，再由观测几何与任务约束检查、细化。这条路既可能利用模型参考，也可能依赖类别定义。

留意：输出一个 6D Pose 不等于它唯一可观测；还要看类别坐标、对称性和训练数据。

02 从实例参考到类别参考，为什么要区分？

实例级参考知道这个具体物体

有 CAD、模板或已知参考，求某个实例相对相机的位姿。

类别级参考知道这一类大概的结构

只要求同类物体共享某种参考；不必逐个准备实例模型。

任务级局部参考不求全身，只求抓法用到的线索

例如侧夹只需位置、轴线、表面法线或局部接触区域。

三种参考各自解决不同问题。若想估计完整物体位姿，必须先定义物体坐标系；若只需夹爪姿态，不一定有这个必要。

我更愿意先问：这个模型到底需要什么参考、预测什么中间量？ 再讨论它是否“学习式”。

03 现在选技术时，我会先看哪些条件？

现场条件更值得考虑不能忽略
已知 CAD、几何稳定模板 / 配准，必要时加学习对应或初值对称、局部遮挡、模型误差
同类未知实例较多类别关键点、类别规范坐标或类别 Pose类别外形变异、尺度和训练分布
只要局部方向几何主轴 / 法线，或学习局部空间参考别无故恢复完整 Object Pose
形态差异大且训练数据不足先评估几何可观测线索；学习方案需验证学习本身也不会凭空泛化
