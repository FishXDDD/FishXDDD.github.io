STAGE 01 · Q02 / KNOWN REFERENCE

如果物体的形状，
本来就知道呢？

在 Q01 里，我试着从现场点云量出位置、方向和表面。后来想到：如果这只瓶子、这个工件的形状本来就已知，我是不是不用每次从眼前这一小片点云重新猜？

起点 / 一个自然的念头

既然形状早就知道，能不能直接在现场找到它？

Q01 的几何测量让我挺兴奋：原来不需要复杂的模型，只靠深度数据，也能量出很多有意思的东西。但反过来想，现场看见的物体往往只有一部分表面。如果我已经知道它的完整形状，何必把每一帧都当成一件从没见过的物体？

于是换了一种想法：先有一个参考物体，再去现场寻找与它相符的那一份观测。这听着似乎只是“比一比形状”，后来才发现，背后是一整套很成熟的位姿估计问题。

当时冒出来的念头

我不一定非要从零推测物体的轴线。如果能够知道“这个参考物体在相机下怎么摆着”，那么它的位置、朝向，以及参考模型上已知的几何关系，就一起有了空间依据。

发现 01 / 原来“对齐”有数学答案

两组对应的三维点，竟然可以直接求出变换。

顺着“把两个形状放到一起”的想法去看 Registration，第一件让我印象很深的事是：假如知道参考点和现场点谁对应谁，求旋转和平移竟然能化成一个很规整的数学问题。

像 Kabsch、Arun、Horn 这类经典方法，会从已知的 3D–3D 对应关系里求刚体变换。有些方法使用 SVD，有些使用四元数。最初看到时，我才真正意识到：我们不是“猜一个旋转角度再试试看”，而是直接利用空间点之间的几何一致性。

很重要的一次认知更新

原来“知道怎么配对”和“知道怎么对齐”是两件事。后者已经有很漂亮的解析或闭式求解；最麻烦的部分，往往是前者。

对应已知模型点 A ↔ 现场点 a
模型点 B ↔ 现场点 b
→
直接求 R、t让成对的点尽量重合
得到参考的空间姿态

但一个现实问题很快就显露出来：深度相机给我的是两片点云，不会自动告诉我哪个点应该配给哪个点。这不是数学求解失败，而是输入条件还没有满足。

发现 02 / 一种很巧妙的办法

原来 ICP 会一边找对应，一边慢慢把点云对齐。

接着认识 ICP（Iterative Closest Point），感觉很巧妙。它并不要求我提前手动把每个点配好：可以从当前姿态出发，先找附近的对应点，再估计一次变换，然后继续更新。

ICP 的直觉：找近邻 → 估计变换 → 再找近邻

原来点到点（Point-to-Point）之外，还能用点到平面（Point-to-Plane）的误差；后来 GICP 又把局部表面结构和噪声考虑得更多。这些方法是在配准准则与建模上分化，不是简单的“ICP 1、2、3 代”。

!

不过我也不该误解它的能力：ICP 很擅长把“已经比较接近的两份点云”对得更准，却不等于可以在任意大场景里凭空找出那个物体。这条边界要牢牢记住。

发现 03 / 原来还有另一套想法

要是完全不知道物体在哪，原来也有办法去找。

更有意思的发现，是 Global Registration 与 3D Object Recognition。我原本把配准想成“放在差不多的位置，再慢慢对齐”。但已有研究还在尝试另一件事：在初始姿态未知时，先找到可能的匹配位置。

PPF（Point Pair Feature）特别直观：利用参考物体和现场点云里两点之间的距离、法线夹角等几何关系，累积支持某个姿态的证据。原来不一定先知道单个点的精确对应，也可以通过局部几何之间的相对关系来投票寻找物体。

几何关系 / 投票PPF

把点对间不易受刚体摆放影响的几何关系，当成识别和粗定位的线索。适合已知模型、杂乱场景中的候选位姿搜索。

整体一致 / 粗对齐4PCS · FGR · Robust Registration

有的方法寻找几何一致的点集，有的方法利用候选对应做鲁棒优化。目标相近，依赖的输入和假设并不一样。

看到这里才发现，所谓“全局匹配”不是一种万能算法。PPF 偏重从场景中识别已知模型，4PCS 关注几何共形关系，FGR、TEASER++ 更重视已有候选对应中的一致性与鲁棒估计。它们是几条不同的思路，而不是同一个算法的下一版本。

发现 04 / 对应关系不一定都来自点云

如果我看到了模型上的特征点，原来还能直接从图像求 Pose。

了解参考模型后，我以前容易默认：既然是三维物体，那就一定要准备两份三维点云。接触 PnP（Perspective-n-Point）之后，才发现这个前提太窄了。

如果参考模型上某些三维点能和图像里的像素位置可靠对应，再结合相机内参，就能估计参考物体相对相机的姿态。EPnP 便是这类求解问题中的经典代表；当图像对应有错时，通常还要引入 RANSAC 这类鲁棒机制。

3D ↔ 3D点云 / 空间点对应

使用成对三维坐标求刚体变换；对应未知时，需要建立匹配或执行配准。

3D ↔ 2DPnP / 图像特征点对应

使用模型三维点与图像像素、相机内参求姿态；重点转向可辨识的 2D–3D 对应。

这不是“PnP 比点云配准更高级”，而是另一种观测条件下的求解方式。有没有深度、是否有纹理或明显特征、匹配是否可靠，都会改变选择。

回头看 / 一张知识地图

原来已知参考求 Pose，真正要先看的是手里有什么。

几种方法放在一起，最有收获的是终于弄清楚了“已知模型”下面，还藏着非常不同的输入条件。

已经知道 3D–3D 对应Kabsch / Arun / Horn：直接求刚体变换；匹配可靠程度决定解的可信度。
点云已大致对齐ICP / Point-to-Plane / GICP：沿局部几何误差继续精化；不替代全局定位。
初始姿态未知PPF / 4PCS / 特征匹配 + RANSAC / FGR：先寻找候选；不同方法有不同的对应与重叠前提。
可靠 3D–2D 对应PnP / EPnP：结合相机内参，直接从参考点与图像像素估计姿态。
已经知道形状 ≠ 已经有对应配准算法的输入假设必须仔细读。尤其要区分“候选对应已知”和“只知道有一份参考模型”。
算出姿态 ≠ 姿态一定唯一对称物体、遮挡、模型与实物不符都可能产生不止一个看起来合理的解。
这一站 / 写给之后的自己

我不再只盯着现场点云了。

最有意思的收获，是开始理解“已知参考”能把问题变成什么样子：它让物体位姿不必完全从当下的局部形状猜测出来；但也让我认识到，真正重要的是参考、观测、对应、初值能否衔接起来。

这次先把最核心的几种思想记下来就好。以后真要选型，再看点云质量、遮挡和对称性，远比背一长串算法名字更有意义。

原来“把一个已知物体找出来”，本身就是一门很有意思的学问。
