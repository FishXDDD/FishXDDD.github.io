研究中遇到的一个问题 · 不急着排名

如果已经知道物体长什么样呢？

对已知瓶子、盒体或固定工件，与其从局部几何猜位置，不如把现场观测和参考模型对齐。只要得到物体相对相机的变换，模板上预先规定的抓取位姿就能直接变到相机坐标系。可是：参考模型、对应关系和初始位姿，又不是自动存在的。 这页再往下拆技术方法，不评价谁更新。

有 CAD / 模板对应与配准PnP / ICP / 全局匹配

01 有了参考，问题从“猜形状”变成了“怎样对齐”

这里先讨论刚性、稳定的参考物体。对象可变形、已知 CAD 与真实物体差别大时，这一套前提本身就值得怀疑。

事先知道CAD / 模板 / 参考点云

以及定义在参考坐标系中的抓法

现场观测RGB / Depth / 点云

可能只有一部分可见，初始姿态未知

要得到参考 → 现场的变换

把预定抓取姿态带到实际位置

如果已得到物体坐标系到相机系的变换： T[C←G] = T[C←O] × T[O←G] 这里 T[O←G] 是离线定义的固定抓法；需要在线估计的是 T[C←O]。坐标系方向一定要在接口中写明白。

之前配准时值得记住：“模板不动”只描述了你选用哪个数据作为目标，不代表返回的矩阵方向必然是 Object → Camera。若把现场相机点云配到模板坐标系，得到 T[O←C]，后续要用 T[C←O] 就必须求逆。

02 先看手里到底是哪一种“对应”

目前有的资料真正要求解典型方法要注意
已知 3D ↔ 3D 对应点刚体变换 R,t（若尺度未知还要处理 s）Kabsch / Arun / Horn；Umeyama 可处理相似变换对应本身若错了，闭式解也会错；退化构型可能约束不全
已知 3D 模型点 ↔ 2D 像素物体到相机的外参PnP / RANSAC-PnP要有相机内参与可靠匹配，不是“只用一张图片就能随便算”
两份点云，但没有对应先建立关系，再求变换粗配准 → ICP / GICP / NDT 等起始姿态未知时，不能把普通 ICP 当全局搜索
场景混杂且不知道实例在哪目标发现 + 候选位姿 + 对齐PPF、形状匹配、全局配准或工业匹配工具模型质量、可见比例、对称性影响匹配可信度

换句话说，PnP、SVD 刚体对齐、ICP 并不是简单的“哪一个更高级”：它们解决的问题输入就不一样。

03 先找到大致位置，再把位置对准

① 对应已经知道闭式刚体求解

Kabsch / Arun / Horn 等，根据对应点求 R,t

② 起始位姿未知全局定位 / 粗配准

PPF、4PCS、特征匹配 + RANSAC、FGR 等得到候选

③ 已接近正确位姿局部精配准

Point-to-Point / Point-to-Plane ICP、GICP、NDT

这三个框不是所有算法都必须经过的流水线。如果点对应可靠，可以直接求变换；如果已有较好的初值，就可以直接做局部精化。只有在姿态未知且对应未知时，才需要先考虑全局寻找候选。

已知对应 → SVD 闭式解

求刚体变换不等于求对应。已知一组配对的三维点时，Kabsch / Arun / Horn 类方法非常合适；RANSAC 可以帮助抵抗错误对应。

没有好的初值 → 全局或较大范围粗搜

PPF、4PCS / Super4PCS、特征匹配 + RANSAC、FGR、TEASER++ 各有不同的前提。这里先知道分法，不急于把三维局部特征细节全部展开。

已经大致对齐 → ICP 等局部精化

Point-to-Point ICP、Point-to-Plane ICP、GICP、NDT 使用不同误差或概率建模；普通 ICP 不能保证从任意初值找回正确物体。

需要特别小心的误会

一次 ICP 的 fitness 很高，未必意味着姿态正确。重复结构、部分重叠、错误匹配或对称物体，都可能让“看似对齐”与“抓取位姿正确”不是一回事。

04 学术方法与工程工具，不需要分出胜负

这不是完整的年代史，只留下几组真正改变求解条件或使用方式的节点；同一年出现不代表存在直接继承。

时间 / 代表解决的关键问题今天怎样看它
经典几何Horn / Arun / Kabsch对应已知时，稳定求刚体变换仍是配准内部重要基础；它并不负责找到对应
1992ICP对应未知但已大致接近时，迭代细化工业与科研都常用；需注意初值与局部极值
2000sNDT / GICP通过分布或局部协方差改进配准表达根据噪声、密度、表面结构等条件选用
2010 前后PPF / 4PCS姿态未知或场景混杂时寻找粗对齐解决了不同于 ICP 的“从哪里开始”问题
2010s—2020sFGR / TEASER++提高含错误对应时的鲁棒性或全局求解效率不是默认替代所有匹配：仍依赖场景、对应和算力条件
工程工具PCL / Open3D / HALCON提供可复用的配准、表面匹配和调参流程先调用成熟接口再验证边界，不必重写整套工具

值得留下的区分：学术论文通常解释如何放宽假设、提升鲁棒性；工业工具更关注输入组织、可配置性、候选分数和持续运行。两者解决的是不同层级的问题。

05 放到真实物体里，哪些情况要换思路？

场景条件可能合适的做法重点风险
有可靠对应点直接 R,t 求解，再做几何验证错配、共线/共面退化、尺度和坐标约定
有 CAD，点云质量好，有近似位姿ICP / GICP / Point-to-plane 精配准局部极值、对称等价解
有 CAD，但在杂乱场景里找目标先全局表面匹配、PPF 或粗配准，再精化背景干扰和低重叠
只有 RGB + 可靠 2D–3D 对应PnP；不必强行先造一份深度点云内参、像素对应、几何退化
踩扁瓶、软包装、变形物体回到局部几何或后续学习抓取路线刚体参考模型本身不成立

这一页的认识：配准不是一个单独的“Pose 算法名字”，而是一组关于参考、对应关系、初值和几何残差的假设。方法是否值得用，取决于这些假设在当前场景是否成立。
