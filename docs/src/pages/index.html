一些越想越多的问题

研究笔记 · 01—05

一开始只想算出一个 Grasp Pose，后来又开始好奇：能不能自己找抓法、自己找目标，甚至把动作和整件事做完？先按这五个问题记着，哪天想法变了再改。🐟

01
STAGE 01 · 几何计算Geometry / Rule-based

先把 Pose 算出来

已经知道目标和抓取规则了，怎么根据物体的几何，把抓法落实成一个实际的 6DoF Pose？

这一站的变化 ·人规定抓法，算法负责求 Pose。

翻开这一站的笔记 ↗
02
STAGE 02 · 学习抓法Grasp Model / Grasp Synthesis

让模型自己找抓法

如果只告诉机器人要抓哪个物体，不再手写具体抓法，模型能不能自己生成靠谱的 Grasp Pose？

放开抓法 ·从人工规定，走向模型学习与生成。

03
STAGE 03 · 语义泛化VLM / Semantic Grounding

这次抓什么，也让它自己发现？

前面总是先告诉机器人目标是谁。如果只说“清理桌上的垃圾”，它能不能自己看懂场景、找到该处理的东西？

放开目标指定 ·从给定物体，走向根据任务发现目标。

04
STAGE 04 · 动作生成VLA / Action Policy

有了抓法，怎么抓得好？

知道抓什么，也有了抓取姿态。但真正伸手、靠近、抓住、提起，能不能根据观察生成一段合适的动作？

放开固定动作流程 ·从单个目标 Pose，走向动作轨迹与策略。

05
STAGE 05 · 自主任务Agent / Task Planning

试着把整件事情做完

如果要连续收拾好几个东西，或者中途没抓成功呢？想看看机器人能不能自己安排步骤、检查结果，再调整。

放开人工步骤安排 ·从一次操作，走向任务规划与失败重试。

只是我整理笔记的一种方式，不是什么行业标准，也不是必须一步步走完的路线。
