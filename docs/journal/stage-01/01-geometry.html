Q01 · 这次的研究问题

能不能直接从形状里量出 Pose？

从点云里找中心、主方向、平面或法线，看起来是一件挺顺手的事。PCA 可以帮助认识点云的统计主方向；形状拟合则尝试利用规则几何得到更明确的空间参考。

慢慢发现，这些结果都只是空间线索。一个瓶子的主轴，并不能自动给出完整的三维旋转；点云质心也未必等于理想的抓取中心。该求什么，要先看约定的抓法到底需要哪些约束。

目标点云→中心 / 轴线 / 表面→预定抓取约束→Grasp Pose
✎ 这次真正收获了什么

形状可以提供位置与方向的线索；不必每次都恢复完整 Object Pose，但必须确认这些约束是否足够。

Q02 · 这次的研究问题

如果物体本来就是已知的呢？

有参考信息之后，思路就不只是“从眼前的点云量出形状”了。可以把参考与现场观测联系起来：有的方法比较三维表面，有的方法通过局部几何匹配，有的方法依赖已知的三维点与图像中的二维对应。

这些思路的输入条件并不相同。ICP、PPF、PnP 不是一条连续升级链。已知参考的价值，是提供更明确的空间约束；它也会带来参考准备、匹配条件与遮挡等问题。

已知参考+现场对应→Object Pose→预定抓法变换→Grasp Pose
✎ 这次真正收获了什么

如果参考和观测之间有足够可靠的约束，可以先恢复 Object Pose，再转换到 Grasp Pose；但这不是唯一解法。

↗ 收获之后，自然又想到……

到这里 Pose 的求解似乎有方向了。不过，我拿来计算的“目标点云”和“对应点”，现实中的相机真的会直接给我吗？
